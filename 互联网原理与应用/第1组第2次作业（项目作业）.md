## socket介绍部分
#### TCP客户端与TCP服务器端

socket保证了不同计算机之间的通信，也就是网络通信。对于网站，通信模型是客户端服务器之间的通信。两个端都建立一个socket对象，然后通过socket对象对数据进行传输。通常服务器处于一个无线循环，等待客户端连接。
![[Pasted image 20221126224542.png]]
先从服务器端说起。服务器端先初始化Socket，然后与端口绑定(bind)，对端口进行监听(listen)，调用accept阻塞，等待客户端连接。在这时如果有个客户端初始化一个Socket，然后连接服务器(connect)，如果连接成功，这时客户端与服务器端的连接就建立了。客户端发送数据请求，服务器端接收请求并处理请求，然后把回应数据发送给客户端，客户端读取数据，最后关闭连接，一次交互结束。

#### socket原理：
##### server端
1.server端创建QTcpServer对象，绑定地址和端口

2.启动监听，接收客户连接请求

3.接收到客户端连接请求后，获得此次连接的新套接字，建立了连接

4.通过套接字进行相互通信

5.关闭套接字

##### client端

1.创建套接字

2.向服务器发送请求

3.和server进行通信

4.关闭套接字

#### 函数作用：
`nextPendingConnection()`:获取连接上的套接字对象，也叫客户端的套接号，也叫客户端在服务器链接时的端口号，用于和客户端联系用的。例如在接收信号的槽内，接收对象用它来找到发送对象的

`newConnection()`: newConnection()信号，该信号用于处理新接入的连接

`disconnected()`:断开连接后会触发该信号，一般在该信号的槽函数内处理内存清理释放等工作

`readyRead()`:数据到达信号，在该信号的槽函数内处理数据接收

## 关键源代码
#### 服务器端：
```cpp
//创建QTcpSocket套接字对象
    socket = new QTcpSocket(this);
        //设置ip地址和端口号
    ui->le_ip->setText("127.0.0.1");
    ui->le_port->setText("8080");
    //使用这个对象连接服务器
    connect(socket, &QTcpSocket::readyRead, this, &Widget::readMessage);
    //当断开连接时，执行
    //说明：当socket对象执行disconnected函数时，this对象执行里面的函数，下面以此类推
    connect(socket,&QTcpSocket::disconnected, this, [=](){
        ui->lb_conn->setText("断开连接");
    });
    //当连接时执行
    connect(socket, &QTcpSocket::connected, this,[=](){
        ui->lb_conn->setText("已连接");
    });
```

#### 客户端：
```cpp
//创建QTcpServer对象
    server = new QTcpServer(this);
    //监听端口
    server->listen(QHostAddress::Any, 8080);
    //当服务器被客户端访问时，会发出newConnection()信号，因此为该信号添加槽函数，并用一个QTcpSocket对象接受客户端访问
    connect(server, &QTcpServer::newConnection, this, &Widget::new_connect);
```

```cpp
void Widget::new_connect()
{
    // 获取已经建立的连接的套接字
    socket = server->nextPendingConnection();
    ui->lb_conn->setText("连接成功");
    //当对方进行write的时候socket发送readyRead信号随后执行
    connect(socket, &QTcpSocket::readyRead, this ,[=](){
        QString data = socket->readAll();
        ui->receive_mess->setText(data);
    });
    //当对方进行断开连接时，socket发出disconned信号，随后执行
    connect(socket, &QTcpSocket::disconnected, this, [=](){
        ui->lb_conn->setText("无连接");
        socket->close();
        socket->deleteLater();
    });
}
```

#include "widget.h"
#include "ui_widget.h"
#include <QDebug>
#include <QMessageBox>
Widget::Widget(QWidget *parent)
    : QMainWindow(parent)
    , ui(new Ui::Widget)
{
    ui->setupUi(this);
    setWindowTitle("Client");
    //创建QTcpSocket套接字对象
    socket = new QTcpSocket(this);
    //设置ip地址和端口号
    ui->le_ip->setText("127.0.0.1");
    ui->le_port->setText("8080");
    //使用这个对象连接服务器
    connect(socket, &QTcpSocket::readyRead, this, &Widget::readMessage);
    //当断开连接时，执行
    //说明：当socket对象执行disconnected函数时，this对象执行里面的函数，下面以此类推
    connect(socket,&QTcpSocket::disconnected, this, [=](){
        ui->lb_conn->setText("断开连接");
    });
    //当连接时执行
    connect(socket, &QTcpSocket::connected, this,[=](){
        ui->lb_conn->setText("已连接");
    });
}
Widget::~Widget()
{
    delete ui;
}
void Widget::readMessage()
{
	//从socket的readAll函数中获取数据
    QString message=socket->readAll();
    //将输入放入数组以便数据展示
    DataList.push_back(message);
    //将数据展示在展示栏
    ui->le_receive->setText(message);
}
void Widget::on_pushButton_clicked()
{
    //连接服务器
    socket->connectToHost(ui->le_ip->text(),
                          ui->le_port->text().toInt());
}
void Widget::on_pushButton_2_clicked()
{
    //与服务器断开连接
    socket->disconnectFromHost();
}
void Widget::on_pushButton_3_clicked()
{
    //从发送栏中获取数据
    QString str = ui->le_send->text();
    //执行socket的write函数从而进行数据发送
    socket->write(str.toUtf8());
}
void Widget::on_pushButton_4_clicked()
{
    QString str;
    //将数组里存储的数据展示在MessageBox中
    for (auto mess:DataList){
        str += mess + '\n';
    }
    QMessageBox::information(nullptr, "信息", str);
}
void Widget::on_pushButton_5_clicked()
{
	//将数组里的数据清除并通过Message告知用户
    DataList.clear();
    QMessageBox::information(nullptr, "信息", "已清空");
}
