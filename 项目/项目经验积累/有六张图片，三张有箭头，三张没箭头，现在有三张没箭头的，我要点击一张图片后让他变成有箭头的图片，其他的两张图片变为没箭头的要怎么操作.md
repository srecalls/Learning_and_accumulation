您可以在 Vue 组件中使用一个数组来保存图片的状态，其中每个元素表示一个图片是否显示箭头。例如，数组的第一个元素表示第一张图片是否显示箭头，第二个元素表示第二张图片是否显示箭头，以此类推。

当点击一个图片时，您可以更新对应元素的值，然后重新计算其他两张图片的状态，根据新的状态更新它们的显示。

以下是一个示例代码，可以实现您的需求：
```html
<template>
  <div>
    <img v-for="(showArrow, index) in imageStatus" :key="index" :src="getImageSrc(index)" :style="{ width: '200px', height: '200px', cursor: 'pointer' }" @click="toggleArrow(index)">
  </div>
</template>

<script>
export default {
  data() {
    return {
      images: [
        'https://example.com/image1.jpg',
        'https://example.com/image2.jpg',
        'https://example.com/image3.jpg',
        'https://example.com/image4.jpg',
        'https://example.com/image5.jpg',
        'https://example.com/image6.jpg',
      ],
      imageStatus: [
        false, // 第一张图片
        false, // 第二张图片
        false, // 第三张图片
      ],
    }
  },
  methods: {
    toggleArrow(index) {
      this.imageStatus[index] = !this.imageStatus[index];
      this.updateOtherImages(index);
    },
    updateOtherImages(index) {
      const shownArrowCount = this.imageStatus.filter((showArrow) => showArrow).length;
      if (shownArrowCount > 3) {
        // 如果已经有 3 张图片显示箭头了，需要找到最早的一个显示箭头的图片，并将其变为不显示箭头
        for (let i = 0; i < this.imageStatus.length; i++) {
          if (this.imageStatus[i]) {
            this.imageStatus[i] = false;
            break;
          }
        }
      } else if (shownArrowCount < 3) {
        // 如果当前只有不到 3 张图片显示箭头，需要找到最早的一个不显示箭头的图片，并将其变为显示箭头
        for (let i = 0; i < this.imageStatus.length; i++) {
          if (!this.imageStatus[i]) {
            this.imageStatus[i] = true;
            break;
          }
        }
      }
    },
    getImageSrc(index) {
      const arrowSuffix = this.imageStatus[index] ? '-with-arrow' : '-without-arrow';
      return `${this.images[index]}${arrowSuffix}.jpg`;
    },
  },
}
</script>

```

在上面的代码中，我们使用一个 `imageStatus` 数组来保存每个图片是否显示箭头。在 `toggleArrow` 方法中，我们会将点击的图片的状态取反，并调用 `updateOtherImages` 方法来更新其他图片的状态。在 `updateOtherImages` 方法中，我们会根据当前显示箭头的图片数量来决定需要如何更新其他图片的状态。


# 继续下去
可以考虑使用 `v-for` 循环遍历图片数组，并根据不同的状态显示不同的图片。下面是一个简单的示例代码：
```html
<template>
  <div>
    <div v-for="(item, index) in images" :key="index">
      <img
        :src="item.src"
        :class="{ active: item.active }"
        @click="toggleActive(index)"
      />
    </div>
  </div>
</template>

<script>
export default {
  data() {
    return {
      images: [
        { src: 'image1.png', active: false },
        { src: 'image2.png', active: true },
        { src: 'image3.png', active: false },
        { src: 'image4.png', active: true },
        { src: 'image5.png', active: false },
        { src: 'image6.png', active: true },
      ],
    };
  },
  methods: {
    toggleActive(index) {
      // 取反当前点击的图片的 active 属性
      this.images[index].active = !this.images[index].active;
      // 将其他图片的 active 属性设置为 false
      this.images.forEach((item, i) => {
        if (i !== index) {
          item.active = false;
        }
      });
    },
  },
};
</script>

<style scoped>
.active {
  /* 样式 */
}
</style>
```
其中，`images` 数组存储所有的图片信息，包括 `src` 和 `active` 两个属性。`active` 属性用于标记图片是否应该显示箭头。通过点击图片触发 `toggleActive` 方法，将当前点击的图片的 `active` 属性取反，同时将其他图片的 `active` 属性设置为 `false`。这样就可以实现点击一张图片后让它变成有箭头的图片，其他两张图片变为没箭头的效果
