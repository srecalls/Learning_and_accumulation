# 网站图标一般怎么命名
网站图标通常命名为“favicon.ico”。

“favicon”是“favorite icon”的缩写，是网站的标志性图标，通常显示在浏览器标签页、地址栏、书签栏等位置。这个图标的文件名为“favicon.ico”，其中“.ico”表示Windows系统中常用的图标文件格式。在大多数情况下，浏览器会自动查找网站根目录下名为“favicon.ico”的文件，并将其用作网站的图标。因此，将图标命名为“favicon.ico”可以确保浏览器能够正确地找到它。

如果您不想使用ICO格式的图标，也可以将图标命名为其他名称，并在HTML文档中使用<link>元素来指定它。例如，您可以将图标命名为“myicon.png”，然后在HTML文档中使用以下代码来指定它：

```html
<link rel="icon" type="image/png" href="myicon.png">
```
无论使用哪种方式，都应该将图标文件放置在网站的根目录下，以便浏览器能够轻松找到它。
