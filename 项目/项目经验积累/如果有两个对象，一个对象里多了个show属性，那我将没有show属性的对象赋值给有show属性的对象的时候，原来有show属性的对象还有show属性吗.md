如果一个对象拥有一个名为 `show` 的属性，而另一个对象没有，则在将没有 `show` 属性的对象赋值给具有 `show` 属性的对象时，原来的 `show` 属性将会被覆盖，也就是说，目标对象将不再具有 `show` 属性。

例如，假设有以下两个对象：
``` js
const obj1 = {
  name: "Object 1",
  show: true
};

const obj2 = {
  name: "Object 2"
};

```

现在，如果您执行以下操作：
`obj1 = obj2;
`
那么 `obj1` 对象的内容将被覆盖，变成：
`{ name: "Object 2" }`
也就是说，`show` 属性将会被删除，因为 `obj2` 中没有 `show` 属性。

# 怎么才能保留show属性呢

如果您希望在将一个对象赋值给另一个对象时保留目标对象原有的 `show` 属性，可以使用对象展开运算符（Spread Operator）来实现。例如，您可以使用以下代码将 `obj2` 对象的属性合并到 `obj1` 对象中，并保留 `obj1` 原有的 `show` 属性：

```js
obj1 = {
  ...obj1,
  ...obj2
};
```
在这个例子中，`...obj1` 和 `...obj2` 表示将 `obj1` 和 `obj2` 对象的所有属性展开为单独的属性。由于这两个对象都没有重复的属性，所以它们的属性会被成功合并到一个新的对象中。这个新对象中将包含 `obj1` 的 `show` 属性和 `obj2` 的其他属性。因此，如果您将 `obj2` 赋值给 `obj1` 后再次访问 `obj1.show`，它将保留原有的值。

```js
obj1 = {
  name: "Object 2",
  show: true
};
```
