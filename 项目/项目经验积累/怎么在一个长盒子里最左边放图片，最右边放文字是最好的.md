您可以使用CSS中的Flexbox布局来实现在一个长盒子中最左边放置图片，最右边放置文字的效果。

首先，将包含图片和文本的HTML元素放置在一个父容器中。然后，将该父容器的display属性设置为flex，以启用Flexbox布局。接下来，使用Flexbox的justify-content属性来控制内容在主轴上的对齐方式。

以下是一个基本的示例代码，其中假设图片和文本都是直接包含在一个div元素中：
HTML代码：
```html
<div class="container">
  <img src="your-image.jpg" alt="your image">
  <p>Your text goes here</p>
</div>

```

CSS代码：
```css
.container {
  display: flex;
  justify-content: space-between;
}
```

在这个示例中，`justify-content: space-between`将会把图片放在左边，文本放在右边，并且它们之间会有一些空间。如果您想让它们更靠近中间，可以尝试使用`justify-content: center`，或者使用其他Flexbox属性来微调它们的位置和间距。

# 如果想让文字稍微往左点怎么办
如果您想让文字稍微往左移一点，可以使用CSS中的`align-items`属性，它控制Flexbox容器内项目在交叉轴方向上的对齐方式。通过将其设置为`center`，可以将文本在交叉轴上居中对齐，同时将它们在主轴上向左移动。

以下是示例代码：

HTML代码：

```html
<div class="container">
  <img src="your-image.jpg" alt="your image">
  <p>Your text goes here</p>
</div>

```

css代码
```css
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

p {
  margin-left: 10px; /*调整文本与图片之间的距离*/
}

```
在这个示例中，我们将`.container`的`align-items`属性设置为`center`，将文本在交叉轴上居中对齐。然后，通过为`p`元素添加一个左边距（在这里是10像素），将其与图像之间的间距增加到所需的距离。

您可以根据需要微调这些值以获得所需的效果。
