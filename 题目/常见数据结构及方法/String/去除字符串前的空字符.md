在 JavaScript 中，没有内置的 `strip()` 方法。但是，你可以使用 `trim()` 方法来去除字符串开头和结尾的空白字符。

下面是一个例子，演示如何使用 `trim()` 方法去除字符串开头和结尾的空白字符：

```javascript
let myString = "   Hello, World!   ";
myString = myString.trim();
console.log(myString);
```

输出结果为：

```
"Hello, World!"
```

在这个例子中， `trim()` 方法被用来去除 `myString` 变量开头和结尾的空格字符，使得最终输出结果只包含 "Hello, World!" 字符串。

需要注意的是，`trim()` 方法只能去除字符串开头和结尾的空格字符，它并不能去除字符串中间的空格字符。如果你需要去除字符串中间的空格字符，你可以使用 `replace()` 方法来替换空格字符为空字符串，例如：

```javascript
let myString = "   Hello, World!   ";
myString = myString.replace(/\s+/g, '');
console.log(myString);
```

在这个例子中，`replace()` 方法使用一个正则表达式 `/\\s+/g` 匹配字符串中的所有空格字符，并将其替换为空字符串。
