## 什么是回溯算法
回溯和递归相辅相成

只要有递归，就会有回溯

回溯隐藏在哪？
通常都是递归函数的下方，递归函数的下面的部分就是回溯的逻辑

回溯函数其实也就是指递归函数
因为没有完全的是一个回溯。用来回溯的函数

回溯法效率：回溯其实是一个纯暴力的搜索，他并不是一个高效的算法

## 使用的原因以及解决的问题
效率这么低为什么还要用回溯法，因为有些问题能暴力搜出来就不错了，用for循环一层层嵌套的话根本搜不出来，所以说要依靠回溯法才能把所有的结果都搜索出来

1. 组合问题
	一般就是给你个集合（1，3，2，4），然后在这个集合里找出大小为2的组合
```js
(1, 2) 
(1, 3)
(1, 4)
(2, 3)
(2, 4)
(3, 4)
```

2. 切割问题
	给一个字符串，问他有几个切割方法，或者说再加一定特定的条件（给你一个字符串，如何切割才能保证他的子串都是回文字串，问有几种切割方式

3. 子集问题
```js
(1, 2, 3, 4)
(1, 2, 3) (1, 2, 4)
(2, 3, 4)
(1, 2) (1, 3) (1, 4)
(2, 3) (2, 4) 
(3, 4)
(1)
(2)
(3)
(4)
```
4.  排列问题
	   组合是强调没有顺序，也就是说，如果整个集合就是 （1 2）,
	   问他有几种组合，那么就只有(1 2)
	   如果求他的排列，那他有两种排列（1 2) (2 1)
	   排列是强调元素的顺序

5. 棋盘问题
	n皇后，解数独这些都是棋盘问题

这些问题用暴力for循环一层一层嵌套其实是不好解决的，必须要用回溯搜索法

- 组合问题：N个数里面按一定规则找出k个数的集合
- 切割问题：一个字符串按一定规则有几种切割方式
- 子集问题：一个N个数的集合里有多少符合条件的子集
- 排列问题：N个数按一定规则全排列，有几种排列方式
- 棋盘问题：N皇后，解数独等等
## 如何理解回溯法
所有的回溯法都可以抽象为一个树状结构，**所有的回溯法**
为什么呢？
因为回溯就是一个递归的过程，递归他就一定会有终止，
回溯法通常都可以抽象为一个n叉树
这棵树的宽度就是我们在回溯法处理中的这个集合的大小，这里通常使用for循环来进行遍历的
这棵树的深度就是这个递归的深度，因为递归一定会有终止，终止都有一层一层的向上返回，纵方向就是递归来处理的


回溯法里递归函数都是没有返回值的就是一个void。这个递归函数一般起名叫back tracking，
然后就是他的参数，回溯法的参数一般情况下是比较多的，所以说不太容易在一开始的时候就把所有的参数就确定下来，在写逻辑的时候遇到了想用什么数据之后，再在里面添加参数就可以了，
接着就要进行一个终止条件，因为递归一定是需要终止的

在到终止条件的时候，一般情况下就到收集结果的时候了，在这个树形结构中，对于一般问题，例如组合切割，排列问题，部分棋盘问题，都是在叶子结点

只有子集问题是在每一个节点都要去收集结果


在处理完终止条件之后，就进入到了一个单层搜索逻辑

单层搜索的逻辑，一般情况下是一个for循环
for循环的参数是用来处理这个集合里的每一个元素，通常放的是集合的元素集，也就是遍历集合里的每一个元素，对应的就是树里每一个字节点的个数

```js
处理怎么处理
比如 1 2 3 4
处理子集 1 2的时候， 1 2怎么来，
在处理节点的时候，把 1 2放到一个数组里以至于在终止条件里面，收集结果的时候，才会把 1 2放进我们的结果集里
```
那处理节点下面就是 递归函数
这里就开始我们递归的过程，也就是在树形图里一层一层往下走，递归下面就是我们的回溯操作
回溯操作就是 撤销处理节点 的情况
为什么处理了节点还要撤销呢？
```js
比如 1 2 3里求组合
一开始放进了 1 后来放进了 2 （ 1 2
这里需要把 2 弹出去，进来 3 才能实现 （ 1  3
如果没有撤销回溯的操作，就会 1 2 3一直加
```
最后就是一个正常的return操作


```js
function backTracking(arg) {
	if (终止条件) {
		收集结果
		return
	}
	for(集合元素集) {
		处理节点
		递归函数
		回溯操作
	}
	return
}


```
