难度：<font color ="lightgreen">简单</font>
给定两个字符串 `s `和 `t `，编写一个函数来判断 `t `是否是 `s `的字母异位词。

注意：若 `s `和 `t `中每个字符出现的次数都相同，则称 `s `和` t `互为字母异位词。

示例 1:

	输入: s = "anagram", t = "nagaram"
	输出: true

示例 2:

	输入: s = "rat", t = "car"
	输出: false

**提示:**

-   1 <= s.length, t.length <= $5 * 10^4$
-   `s` 和 `t` 仅包含小写字母

```js
/**
 * @param {string} s
 * @param {string} t
 * @return {boolean}
 */

 var isAnagram = function (s, t) {

     //在这理解 let in 和let of
        let map1 = {};
        let map2 = {};
        if (s.length != t.length) {
          return false;
        }
        //循环字符串s
        for (let v of s) {
          map1[v] = (map1[v] || 0) + 1;
        }
        //循环字符串t
        for (let v of t) {
          map2[v] = (map2[v] || 0) + 1;
        }
        
        for (let i in map1) {
          let judge = 0;
          for (let j in map2) {
            if (i == j && map1[i] == map2[j]) {
              judge = 1;
            }
          }
          if (judge == 0) {
            return false;
          }
        }
        return true;
      };
```

# 我的题解
## version 1
创建两个map用于记录两个字符串的状态。
对两个map进行循环并将遍历到的字符串与遍历到的相应字符串的个数。

	s=“car" 
	t="rat"
在这里 map1就会记录

	 a: 1
	 c: 1
	 r: 1

map2就会记录

	r: 1
	a: 1
	t 1

然后用内外循环对 `map1`和 `map2`的内容记录不重复的内容。比如map1里的 `a` 扫描map2的所有项，如果有对应的则继续扫描，如果遇到没有对应的则返回`false`,如果全部对应则返回 `true`。这里用到了judge来判断是否有遇到对应的来进入下一个循环。
