给你一个二维整数数组 `matrix`， 返回 `matrix `的 转置矩阵 。

矩阵的 转置 是指将矩阵的主对角线翻转，交换矩阵的行索引与列索引。
![[Pasted image 20230607002830.png]]


示例 1：

	输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
	输出：[[1,4,7],[2,5,8],[3,6,9]]
示例 2：

	输入：matrix = [[1,2,3],[4,5,6]]
	输出：[[1,4],[2,5],[3,6]]
 

提示：

	m == matrix.length
	n == matrix[i].length
	1 <= m, n <= 1000
	1 <= m * n <= 10^5
	-10^9 <= matrix[i][j] <= 10^9

来源：力扣（LeetCode）
链接：https://leetcode.cn/problems/transpose-matrix


## 我的提交
```js
/**
 * @param {number[][]} matrix
 * @return {number[][]}
 */

var transpose = function(matrix) {
    // 计算矩阵的行数
    let row = matrix.length
    // 计算矩阵的列数
    let col = matrix[0].length
    // 利用Array.from建立二位数组并将其置0
    let matrix_T = Array.from(Array(col), () => Array(row).fill(0))
    // 利用转置矩阵的概念 M(Ci,Rj) M_T(Cj,Ri) 
    for(let i = 0; i < row; i++) {
        for (let j = 0; j < col; j++) {
            matrix_T[j][i] = matrix[i][j]
        }
    }
    return matrix_T
};
```
