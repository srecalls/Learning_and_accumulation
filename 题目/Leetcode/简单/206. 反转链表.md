给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。
**示例 1：**
![[206. 反转链表.png]]
	
	输入：head = [1,2,3,4,5]
	输出：[5,4,3,2,1]


**示例 2：**
![[206. 反转链表-1.png]]
	
	输入：head = [1,2]
	输出：[2,1]


**示例 3：**

	输入：head = []
	输出：[]

**提示：**

- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

## 官方答案
### 迭代
![[206. 反转链表-2.png]]

```Js
var reverseList = function(head) {
    let prev = null;
    let curr = head;
    while (curr) {
        const next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
};
// null   1    2     3  null
// prev curr  next
//      prev  curr
//            prev  curr
```

### 递归
![[206. 反转链表-4.png]]


```js
var reverseList = function(head) {
    if (head == null || head.next == null) {
        return head;
    }
    const newHead = reverseList(head.next);
    head.next.next = head;
    head.next = null;
    return newHead;
};
// null 1 2 3
// 
```
