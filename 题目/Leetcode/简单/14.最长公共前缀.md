难度：<font color ="lightgreen">简单</font>

编写一个函数来查找字符串数组中的最长公共前缀。
如果不存在公共前缀，返回空字符串 ""。

示例 1：

	输入：strs = ["flower","flow","flight"]
	输出："fl"

示例 2：

	输入：strs = ["dog","racecar","car"]
	输出：""
	解释：输入不存在公共前缀。
	 

提示：

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` 仅由小写英文字母组成


# 我的提交
## version 1
```js
/**
 * @param {string[]} strs
 * @return {string}
 */

var longestCommonPrefix = function(strs) {
    if(strs.length==0){
        return "";
    }
    if(strs.length==1){
        return strs[0];
    }
    let res=strs[0];
    for(let i=0;i<strs.length;i++){
        let cut=0;
        for(let j=0;j<res.length&&j<strs[i].length;j++){
            if(res[j]==strs[i][j]){
                cut++;
            }
            else{
                break;
            }
        }
        res=res.substring(0,cut);
    }
    return res;
};
```
# 我的题解
## version 1
注意审题：这题要求的是最长”公共“前缀，所以数组中的每一个字符串都应该有这个前缀，而不是求数组中部分字符串的最长前缀。
这里用到的思想是让数组中的第一个字符串为标准，让后续数组中的每一个元素进行比较，求出这两个互相比较的字符串的最长前缀，然后后续两两不断的比较，直到最后从而求最长的前缀。
