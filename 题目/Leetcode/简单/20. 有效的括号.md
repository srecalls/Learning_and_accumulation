难度：<font color ="lightgreen">简单</font>
给定一个只包括` '('，')'，'{'，'}'，'['，']' `的字符串 s ，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。
 

示例 1：

	输入：s = "()"
	输出：true
示例 2：

	输入：s = "()[]{}"
	输出：true
示例 3：

	输入：s = "(]"
	输出：false


提示：

	1 <= s.length <= 10^4
	s 仅由括号 '()[]{}' 组成

### version 3
利用replace对字符串进行替换，如果全部替换则说明有效，如果不能全部替换，则说明无效
```js
/**
 * @param {string} s
 * @return {boolean}
 */

var isValid = function(s) {
    if (s.length % 2 == 1) {
        return false
    }

    while(true) {
        let len = s.length
        s = s.replace("()", "").replace("{}", "").replace("[]", "")
        if (len === s.length) {
            break
        }
    }
    return !s.length
}
```
