下面是 JavaScript 实现斐波那契数列的迭代和递归方法：

1. 迭代法实现斐波那契数列：

```javascript
function fibonacciIterative(n) {
  if (n === 0 || n === 1) {
    return n;
  }
  let prevPrev = 0;
  let prev = 1;
  let result = 0;
  for (let i = 2; i <= n; i++) {
    result = prevPrev + prev;
    prevPrev = prev;
    prev = result;
  }
  return result;
}
```

2. 递归法实现斐波那契数列：

```javascript
function fibonacciRecursive(n) {
  if (n === 0 || n === 1) {
    return n;
  }
  return fibonacciRecursive(n - 1) + fibonacciRecursive(n - 2);
}
```

需要注意的是，递归方法实现斐波那契数列在计算较大的数时会出现性能问题，因为它会重复计算已经计算过的子问题。而迭代方法则可以避免这个问题，因为它只需要计算一次每个子问题，然后从前往后依次计算，避免了重复计算的问题。

另外，斐波那契数列的实现方法还有很多，例如使用动态规划、矩阵快速幂等方法，不同的方法适用于不同的场景和问题。
