这道题是求解连续子数组的最大和，可以通过动态规划来解决。我们定义一个状态数组dp，其中`dp[i]`表示以第i个元素结尾的连续子数组的最大和。因此，状态转移方程为：

	dp[i] = max(nums[i], dp[i-1] + nums[i])

其中，`nums[i]`表示第i个元素的值，`dp[i-1]`表示以第i-1个元素结尾的连续子数组的最大和。我们需要不断更新dp数组中的最大值，最终得到的就是所有连续子数组的最大和。

在实现过程中，我们可以用一个变量maxSum来记录dp数组中的最大值，以便在更新dp数组时同时更新maxSum。最终返回的就是maxSum的值。时间复杂度为O(n)，空间复杂度为O(1)。

以下是JavaScript的代码实现：

```js
function maxSubArray(nums) {
  let dp = nums[0];
  let maxSum = nums[0];
  for (let i = 1; i < nums.length; i++) {
    dp = Math.max(nums[i], dp + nums[i]);
    maxSum = Math.max(maxSum, dp);
  }
  return maxSum;
}

var maxSubArray = function(nums) {
    let pre = 0, maxAns = nums[0];
    nums.forEach((x) => {
        pre = Math.max(pre + x, x);
        maxAns = Math.max(maxAns, pre);
    });
    return maxAns;
};

console.log(maxSubArray([-2,1,-3,4,-1,2,1,-5,4])); // 输出 6
```

对于第i个元素，它有两种选择：要么加入前面的连续子数组，要么自己单独成为一个新的连续子数组。我们需要在这两种选择中取最大值，作为以第i个元素结尾的连续子数组的最大和。因此，状态转移方程为：

`dp[i] = max(nums[i], dp[i-1] + nums[i])`

其中，`nums[i]`表示第i个元素的值，dp`[i-1]`表示以第i-1个元素结尾的连续子数组的最大和。如果`dp[i-1]`是负数，那么加上nums`[i]`反而会使得以第i个元素结尾的连续子数组的和更小，因此我们只需要选择`nums[i]`作为新的连续子数组的起点即可，即dp`[i]` = nums[i]。如果`dp[i-1]`是正数，那么我们可以将nums`[i]`加入到以第i-1个元素结尾的连续子数组中，得到一个更大的连续子数组，即`dp[i] = dp[i-1] + nums[i]。`

因此，状态转移方程的意义是，以第i个元素结尾的连续子数组的最大和，要么是它自己单独成为一个新的连续子数组，要么是它加入到以第i-1个元素结尾的连续子数组中得到的结果。最终，我们需要在dp数组中找到最大值，即为所有连续子数组的最大和。
