难度：<font color ="lightgreen">简单</font>
给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 ⌊ n/2 ⌋ 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

示例 1：

	输入：nums = [3,2,3]
	输出：3
	
示例 2：

	输入：nums = [2,2,1,1,1,2,2]
	输出：2
 

提示：
- n == nums.length
- 1 <= n <= $5 * 10^4$
- $-10^9$ <= nums[i] <= $10^9$ 

进阶：尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。

# 我的提交
## version 1
```js
/**
 * @param {number[]} nums
 * @return {number}
 */

var majorityElement = function(nums) {
    //创建一个map对象
    const map=new Map();
    // 找出每个数字的个数并将其放入map中
    const arr={};
    for(let v of nums){
          arr[v]=(arr[v]||0)+1;
          map.set(v,arr[v]);
    }
    // 对map中的值进行排序
    const sortMap = new Map([...map].sort((a, b) => b[1] - a[1]));
    //将其转换成数组找出第一个数组的键值
    const result = [...sortMap][0][0];
    return result;
};
```

# 我的题解：
## version 1
因为我们找到的是数组中出现最多次数的元素，那么最简单粗暴的方法，就是把所有数给遍历一遍然后找出谁是最多的。
这里用到了 一个map方法，用于存储数字与其个数的对应关系。
这里要注意的是如何对map中的值进行排序，因为我们要找到最多的那个数，所以就需要知道它对应的下标，这里利用了排序
```js
 const sortMap = new Map([...map].sort((a, b) => b[1] - a[1]));
```
从而将最多那个数字对应的数排序到map的第一个，然后通过扩展运算符转换成数组来获取对应的键，从而得出答案。
