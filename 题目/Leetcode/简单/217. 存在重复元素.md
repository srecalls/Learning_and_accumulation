难度：<font color ="lightgreen">简单</font>

给你一个整数数组 `nums` 。如果任一值在数组中出现 至少两次 ，返回 `true` ；如果数组中每个元素互不相同，返回` false` 。
 

示例 1：

	输入：nums = [1,2,3,1]
	输出：true
示例 2：

	输入：nums = [1,2,3,4]
	输出：false
示例 3：

	输入：nums = [1,1,1,3,3,4,3,2,4,2]
	输出：true
 

提示：

	1 <= nums.length <= 10^5
	-10^9 <= nums[i] <= 10^9

来源：力扣（LeetCode）
链接：https://leetcode.cn/problems/contains-duplicate


## 我的提交
### version 1
hash解决
```js
/**
 * @param {number[]} nums
 * @return {boolean}
 */

var containsDuplicate = function(nums) {
    let hash = []
    for (let item of nums) {
        hash[item] = (hash[item] || 0) + 1
    }

    for (let item in hash) {
        if (hash[item] > 1) {
            return true
        }
    }
    return false
};
```

### version 2
排序+遍历
```js
/**
 * @param {number[]} nums
 * @return {boolean}
 */

var containsDuplicate = function(nums) {
    nums.sort((a, b) => a - b)
    for (let i = 0 ;i < nums.length - 1; i++) {
        if (nums[i] == nums[i + 1]) {
            return true
        }
    }
    return false
};
```
