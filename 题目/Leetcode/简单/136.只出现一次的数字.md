难度：<font color ="lightgreen">简单</font>
给你一个 非空 整数数组 `nums` ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

示例 1 ：

	输入：nums = [2,2,1]
	输出：1
	
示例 2 ：

	输入：nums = [4,1,2,1,2]
	输出：4

示例 3 ：

	输入：nums = [1]
	输出：1

提示：

- 1 <= nums.length <= $3 * 10^4$
- $-3 * 10^4$<= nums[i] <= $3 * 10^4$
- 除了某个元素只出现一次以外，其余每个元素均出现两次。

# 我的提交
## version 1
```js
/**
 * @param {number[]} nums
 * @return {number}
 */

var singleNumber = function(nums) {
    const map = new Map();
    const arr={};
    //又是用map循环
    for(let v of nums){
       arr[v]=(arr[v]||0)+1;
       map.set(v,arr[v]);
    }
    let result=0;
     map.forEach(function(value,key){
        if(value==1){
            result = key;
        }
    })
    return result;
};
```


# 我的题解
## version 1
这里也再次用到了map，利用map存储数组中数字与出现次数的对应关系，然后通过foreach的遍历方法从而获取value为1的值，从而找出只出现了一次的数字。
但这里需要注意一点：
在JavaScript中，`forEach`方法是一个用于遍历数组的函数，它并不能返回一个值。它接受一个回调函数作为参数，该回调函数将在数组的每个元素上被调用。虽然在回调函数中可以使用`return`语句，但它只是用来终止当前的回调函数，而不是返回一个值给`forEach`方法。
因此不能在foreach方法中直接返回key值
即
```js
map.forEach(function(value,key){
	if(value==1){
		return key;
	}
})
```
这里无法进行返回
