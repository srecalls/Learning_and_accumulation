给你一个字符串 `s` ，请你去除字符串中重复的字母，使得每个字母只出现一次。需保证 **返回结果的字典序最小**（**要求不能打乱其他字符的相对位置**（难点））。

示例 1：

	输入：s = "bcabc"
	输出："abc"

示例 2：

	输入：s = "cbacdcbc"
	输出："acdb"
 
提示：

	1 <= s.length <= 104
	s 由小写英文字母组成


来源：力扣（LeetCode）
链接：https://leetcode.cn/problems/remove-duplicate-letters
注意：该题与 1081 https://leetcode-cn.com/problems/smallest-subsequence-of-distinct-characters 相同

## 官方答案
- 将res作为栈存放字符
- 如果字符已经存在则直接跳过循环
- 由于两个字符直接比较大小会根据字典序输出true/false
- 所以直接将循环字符和栈顶元素比较,如果栈顶元素大于当前字符且后续还有其他字符可以作为替代时,栈顶元素出栈
- 当前元素入栈

		输入：s = "cbacdcbc"
		输出："acdb"


`Array.prototype.indexOf()` 接受两个参数：**查找的值、查找起始位置**  
```js
var removeDuplicateLetters = function (s) {
    let res = []
    for (let i = 0; i < s.length; i++) {
        if (res.includes(s[i])) continue
        // 遍历，如果栈顶元素的 字典序 大于当前元素
        // 精髓：后续还有其他字符可以作为替代时,栈顶元素出栈
        while (res[res.length - 1] > s[i] && s.indexOf(res[res.length - 1], i) > i) {
            res.pop()
        }
        res.push(s[i])
    }
    return res.join('')
};
```
