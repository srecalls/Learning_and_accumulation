难度：<font color ="orange">中等</font>
给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。


**示例 1：**

![[19. 删除链表的倒数第 N 个结点.png]]

	输入：head = [1,2,3,4,5], n = 2
	输出：[1,2,3,5]

**示例 2：**

	输入：head = [1], n = 1
	输出：[]

**示例 3：**

	输入：head = [1,2], n = 1
	输出：[1]

**提示：**

- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

**进阶**：你能尝试使用一趟扫描实现吗？


## 官方答案
思路
本期B站视频讲解：[链表遍历学清楚！ | LeetCode：19.删除链表倒数第N个节点](https://leetcode.cn/link/?target=https%3A%2F%2Fwww.bilibili.com%2Fvideo%2FBV1vW4y1U7G)

双指针的经典应用，如果要删除倒数第n个节点，让fast移动n步，然后让fast和slow同时移动，直到fast指向链表末尾。删掉slow所指向的节点就可以了。

思路是这样的，但要注意一些细节。

分为如下几步：

首先这里我推荐大家使用虚拟头结点，这样方面处理删除实际头结点的逻辑，如果虚拟头结点不清楚，可以看这篇：  [链表：听说用虚拟头节点会方便很多？](https://leetcode.cn/link/?target=https%3A%2F%2Fmp.weixin.qq.com%2Fs%2FL5aanfALdLEwVWGvyXPDqA)

- 定义fast指针和slow指针，初始值为虚拟头结点，如图：

![[19. 删除链表的倒数第 N 个结点-1.png]]

- fast首先走n + 1步 ，为什么是n+1呢，因为只有这样同时移动的时候slow才能指向删除节点的上一个节点（方便做删除操作），如图：

![[19. 删除链表的倒数第 N 个结点-2.png]]

- fast和slow同时移动，之道fast指向末尾，如题：

![[19. 删除链表的倒数第 N 个结点-3.png]]
- 删除slow指向的下一个节点，如图：
![[19. 删除链表的倒数第 N 个结点-4.png]]

```js
/**
 * @param {ListNode} head
 * @param {number} n
 * @return {ListNode}
 */
var removeNthFromEnd = function(head, n) {
    let ret = new ListNode(0, head),
        slow = fast = ret;
    while(n--) fast = fast.next;
    if(!fast) return ret.next;
    while (fast.next) {
        fast = fast.next; 
        slow = slow.next
    };
    slow.next = slow.next.next;
    return ret.next;
};
```
