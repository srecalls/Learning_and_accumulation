	输入：preorder = [1,2,4,5,3,6,7], postorder = [4,5,2,6,7,3,1]
	输出：[1,2,3,4,5,6,7]

**示例 2:**

	输入: preorder = [1], postorder = [1]
	输出: [1]

**提示：**

- `1 <= preorder.length <= 30`
- `1 <= preorder[i] <= preorder.length`
- `preorder` 中所有值都 **不同**
- `postorder.length == preorder.length`
- `1 <= postorder[i] <= postorder.length`
- `postorder` 中所有值都 **不同**
- 保证 `preorder` 和 `postorder` 是同一棵二叉树的前序遍历和后序遍历

## 官方答案

1、先序遍历数组中的第一个数即为二叉树的根节点。
2、关键一步:找到根节点下左子树与右子树的分割点。方法如下: 先序遍历数组中，第一个数字为根节点，然后是左子树的先序遍历部分，然后是右子树的先序遍历部分。也就是说，先序遍历数组中第二个数为左子树的根节点; 然后观察后序遍历数组，由左子树的后续遍历部分、右子树的后续遍历部分和根节点组成，那么我们在后续遍历数组中找到左子树的根节点，则此位置之前则为左子树的节点值，此位置之后的，再去掉最后一个数 (根节点》即为右子树的节点值。图示如下，比较直观，参考
