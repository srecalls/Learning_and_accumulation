在 JavaScript 中，你可以使用一些方法来获取一个数字的第一位。以下是几种常见的方法：

1. 使用字符串转换：将数字转换为字符串，然后获取字符串的第一个字符。

```javascript
const number = 12345;
const firstDigit = String(number)[0]; // 转换为字符串后获取第一个字符
console.log(firstDigit); // 输出: "1"
```

2. 使用取整和求余运算符：将数字除以 10 的整数部分，即可获取第一位数字。

```javascript
const number = 12345;
const firstDigit = Math.floor(number / 10 ** (Math.floor(Math.log10(number)))) % 10;
console.log(firstDigit); // 输出: 1
```

3. 使用字符串方法 `charAt()`：将数字转换为字符串，然后使用 `charAt()` 方法获取第一个字符。

```javascript
const number = 12345;
const firstDigit = String(number).charAt(0);
console.log(firstDigit); // 输出: "1"
```

以上三种方法都可以用来获取一个数字的第一位。选择适合你需求的方法即可。

## 低复杂度
如果你希望通过数学运算获取一个数字的第一位，而不涉及字符串转换或迭代操作，可以使用以下方法：

1. 使用对数运算：通过对数运算可以确定数字的位数，进而提取第一位数字。

```javascript
const number = 12345;
const digits = Math.floor(Math.log10(number)); // 获取数字的位数
const firstDigit = Math.floor(number / 10 ** digits);
console.log(firstDigit); // 输出: 1
```

在这个方法中，我们首先使用对数运算 `Math.log10(number)` 来获取数字的位数（去除小数部分）。然后，我们使用除法和幂运算 `10 ** digits` 将数字缩小到只有第一位数字的范围，最后使用 `Math.floor()` 函数取整，得到第一位数字。

这种方法的时间复杂度为 O(1)，因为它只涉及一些基本的数学运算，不随数字的大小而改变。然而，它仅适用于正整数。
