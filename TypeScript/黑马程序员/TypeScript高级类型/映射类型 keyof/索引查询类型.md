# 索引查询类型 T\[P]
**作用： 用来查询属性的类型**
```ts
索引查询（访问）类型

type Props = { a: number; b: string; c: boolean }

type TypeA = Props['a'] // 相当于type TypeA = number

还可以同时查询多个索引的类型
type TypeB = Props['a' | 'b'] // 相当于type TypeA = number | string
type TypeC = Props[keyof Props]] // 相当于type TypeA = number | string | boolean

```
