# 函数之间的类型兼容性
*对象多赋值少（成员多赋值给成员少），函数少赋值多（参数少赋值给参数多）*

```ts
兼容条件：
1. 参数个数
2. 参数类型
3. 返回值类型

1. 参数个数
type F1 = (a: number) => void
type F2 = (a: number, b: number) => void
let f1: F1
let f2: F2 = f1
// 参数少的可以复制给参数多的（参数多的，兼容参数少的）

const arr = ['a','b','c']
arr.forEach(() => {})
arr.forEach((item) => {}) // 这个促成了兼容性

2. 参数类型
type F1 = (a: number) => void
type F2 = (a: number) => void
// 相同位置的参数类型要相同（原始类型）或兼容（对象类型）

3. 返回值类型
type F1 = (a: number) => void
type F2 = (a: number) => void
let f1: F1
let f2: F2 = f1
// 只关注返回值类型即可
```
