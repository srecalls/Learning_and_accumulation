**项目一：**基于TCP或UDP的大文件传输工具的实现

    在LAN上实现基于TCP或UDP的大文件传输工具，要求:

  （1）编写对等客户端程序，实现点到点的大文件传输客户（同时也作为服务器）程序；

  （2）采用Winsock API实现，选择其中一种Winsock I/O 模型来实现；

一、设计过程：

项目一实现了基于TCP协议的文件传输工具，包含了客户端和服务端两个部分。

首先，在实现网络编程之前，需要调用WSAStartup函数初始化Winsock。它的参数MAKEWORD(2,2)指示使用Winsock版本2.2。

接下来，在服务端部分，创建一个监听Socket，用于等待客户端连接。使用socket函数创建Socket，参数AF_INET指示使用IPv4地址族，SOCK_STREAM指示使用TCP协议，IPPROTO_TCP指示使用TCP协议。

然后，将Socket绑定到特定的端口上，以便客户端能够连接到该端口。使用sockaddr_in结构体指定要绑定的地址和端口号，并使用bind函数将Socket与该地址和端口号绑定。

接着，使用listen函数将Socket设置为监听状态，等待客户端连接请求。使用SOMAXCONN参数表示最大等待连接数为系统默认值。

当有客户端连接请求时，使用accept函数接受连接请求，并创建一个新的Socket来处理客户端请求。

在客户端部分，首先创建一个连接Socket，用于连接到服务端。与服务端一样，使用socket函数创建Socket，并使用connect函数连接到服务端指定的端口。

接下来，客户端需要将待传输的文件名和文件大小发送给服务端。使用send函数将文件名和文件大小分别发送给服务端。

在服务端部分，使用recv函数接收客户端发送的文件名和文件大小，并打开该文件，准备接收数据。

在客户端部分，使用recv函数接收服务端发送的数据，并保存到文件。

在服务端部分，使用send函数将文件数据发送给客户端。

最后，在服务端和客户端都完成文件传输后，需要关闭Socket并调用WSACleanup函数释放资源。

二、关键代码

1、创建Socket

SOCKET listenSocket = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);

这一段代码创建了一个Socket，用于在服务端等待客户端连接。AF_INET表示使用IPv4地址族，SOCK_STREAM表示使用TCP协议，IPPROTO_TCP表示使用TCP协议。

2、绑定Socket

iResult = bind(listenSocket, (SOCKADDR*)&serverAddr, sizeof(serverAddr));

这一段代码将Socket绑定到特定的地址和端口上，以便客户端能够连接到该端口。serverAddr是一个sockaddr_in结构体，包含了要绑定的地址和端口号。

3、监听Socket

iResult = listen(listenSocket, SOMAXCONN);

这一段代码将Socket设置为监听状态，等待客户端连接请求。SOMAXCONN参数表示最大等待连接数为系统默认值。

4、接受连接请求

SOCKET clientSocket = accept(listenSocket, NULL, NULL);

这一段代码使用accept函数接受客户端连接请求，并创建一个新的Socket来处理客户端请求。它返回一个新的Socket，用于与客户端通信。在代码中，我们将这个新的Socket称为clientSocket。

5、发送和接收数据

iResult = send(connectSocket, fileName, strlen(fileName) + 1, 0);

iResult = send(connectSocket, (char*)&fileSize, sizeof(fileSize), 0);

iResult = recv(clientSocket, fileName, MAX_PATH, 0);

iResult = recv(clientSocket, (char*)&fileSize, sizeof(fileSize), 0);

这些代码用于在客户端和服务端之间发送和接收文件数据。在客户端部分，使用send函数将文件名和文件大小分别发送给服务端。在服务端部分，使用recv函数接收客户端发送的文件名和文件大小。

6、关闭Socket和释放Winsock库资源

closesocket(listenSocket);

closesocket(clientSocket);

closesocket(connectSocket);

WSACleanup();

这些代码用于关闭Socket和释放Winsock库使用的资源。在程序结束时，需要显式地调用这些函数，以确保资源被正确释放。

**项目二：**基于C/S模型的聊天软件的实现

在LAN上实现基于C/S模型的聊天软件，要求：

（1）实现点对点的聊天程序，所有客户端先连接到服务器端，聊天时，聊天信息都经过服务器的转发。

   （2）基于TCP或UDP协议，采用Winsock API实现，选择其中一种Winsock I/O 模型来实现；

一、设计过程

项目二采用QT软件进行开发，提供可视化界面进行操作。

在实现客户端和服务器端的代码时，选择了TCP协议和Winsock API来实现。

客户端的代码主要分为三个部分：连接服务器、发送聊天信息和断开连接。在连接服务器时，客户端通过调用QTcpSocket的connectToHost()方法来连接指定的服务器。同时，客户端通过关联QTcpSocket的readyRead信号来接收服务器发送的聊天信息；在发送聊天信息时，客户端通过调用QTcpSocket的write()方法来向服务器发送聊天信息；在断开连接时，客户端通过调用QTcpSocket的disconnectFromHost()方法来断开与服务器的连接。

服务器端的代码主要分为四个部分：启动服务器、接收连接、接收聊天信息和断开连接。在启动服务器时，服务器通过调用QTcpServer的listen()方法来开始监听指定的端口。同时，服务器通过关联QTcpServer的newConnection信号来接收客户端的连接请求；在接收连接时，服务器通过调用QTcpServer的nextPendingConnection()方法来接收客户端的连接请求，并创建一个QTcpSocket对象来处理与客户端的通信。同时，服务器通过关联QTcpSocket的readyRead信号来接收客户端发送的聊天信息；在接收聊天信息时，服务器通过调用QTcpSocket的readAll()方法来读取客户端发送的聊天信息，并将其转发给所有连接到服务器的客户端；在断开连接时，服务器通过调用QTcpSocket的disconnectFromHost()方法来断开与客户端的连接。
