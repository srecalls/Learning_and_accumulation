transition-duration 属性用来设置过渡需要花费的时间（单位为秒或者毫秒），语法格式如下：
`transition-duration: time;`

其中，time 为完成过渡效果需要花费的时间（单位为秒或毫秒），默认值为 0，意味着不会有效果。

如果有多个参与过渡的属性，也可以依次为这些属性设置过渡需要的时间，多个属性之间使用逗号进行分隔，例如transition-duration: 1s, 2s, 3s;。除此之外，也可以使用一个时间来为所有参与过渡的属性设置过渡所需的时间。示例代码如下：

```html css
<!DOCTYPE html>
<html>
<head>
    <style>
        div {
            width: 100px;
            height: 100px;
            border: 3px solid black;
            margin: 10px 0px 0px 10px;
            transition-property: width, background;
            transition-duration: .25s, 1s;
        }
        div:hover {
            width: 200px;
            background-color: blue;
        }
    </style>
</head>
<body>
    <div></div>
</body>
</html>
```

`transition-duration` 是 CSS 中的一个属性，用于指定过渡效果的持续时间。

具体来说，`transition-duration` 用于定义一个过渡效果从开始到结束所花费的时间。这个属性控制着过渡的速度和持续时间，影响过渡效果的流畅度和时长。

以下是 `transition-duration` 属性的作用：

1. **指定过渡时间：** 使用 `transition-duration` 可以明确指定过渡效果的持续时间。可以使用秒（s）或毫秒（ms）作为单位来表示时间长度。较长的过渡时间会使过渡效果更为缓慢，而较短的过渡时间则会使过渡效果更为快速。

2. **控制过渡速度：** 通过调整 `transition-duration` 的值，可以控制过渡的速度。较长的过渡时间会使过渡效果变得更慢和平滑，而较短的过渡时间则会使过渡效果变得更快和突然。

下面是一个示例，展示了如何使用 `transition-duration` 来定义过渡效果的持续时间：

```css
.box {
  width: 100px;
  height: 100px;
  background-color: red;
  transition-property: width;
  transition-duration: 1s;
}

.box:hover {
  width: 200px;
}
```

在上述示例中，`.box` 类的元素在宽度发生变化时会有过渡效果。当鼠标悬停在 `.box` 元素上时，宽度会在 1 秒的时间内平滑地过渡到 200px。

通过使用 `transition-duration`，可以控制过渡的持续时间，从而调整过渡效果的速度和流畅度。这使得页面或元素的状态变化更加平滑，提供更好的用户体验。
