# 精灵图（sprites）的使用

#### 1.使用精灵图的核心
① 精灵技术主要针对于背景图片使用。就是把多个小背景图片整合到一张大图片中。
② 这个大图片也称为sprites精灵图或者雪碧图

③ 移动背景图片位置，此时可以使用**background-position**。

④ 移动的距离就是这个目标图片的×和y坐标。注意网页中的坐标有所不同
⑤ 因为一般情况下都是**往上往左**移动，所以**数值是负值**。
⑥ 使用精灵图的时候需要精确测量，每个小背景图片的大小和位置。

#### 使用精灵图核心总结
1.精灵图主要针对于小的背景图片使用。
2.主要借助于背景位置来实现---background-position 。
3.一般情况下精灵图都是负值。(千万注意网页中的坐标︰x轴右边走是正值，左边走是负值，y轴同理。)


精灵图（Sprites）是将多个小图标或小图片合并到一张大图中的技术。通过使用精灵图，可以减少浏览器请求的次数，提高网页的加载性能。在使用精灵图时，可以通过调整背景图的位置和大小来显示所需的图标或图片。

下面是使用精灵图的一般步骤：

1. 创建精灵图：将多个小图标或小图片合并到一张大图中。可以使用图像编辑软件（如 Photoshop）或在线精灵图生成工具来创建精灵图。确保各个小图标或小图片之间有足够的间距，以避免在调整背景图位置时出现重叠。

2. 导入精灵图：将精灵图导入到网页中。可以使用 `<img>` 标签将精灵图作为一张图片进行导入，或者使用 CSS 的 `background-image` 属性将精灵图作为背景图导入。

3. 设置图标或图片的样式：通过调整背景图的位置和大小来显示所需的图标或图片。可以使用 CSS 的 `background-position` 属性来指定背景图的位置，通过调整水平和垂直偏移量来选择要显示的具体图标或图片。可以使用 CSS 的 `width` 和 `height` 属性来调整背景图的大小，以适应所需的图标或图片尺寸。

以下是一个示例，展示如何使用精灵图显示一个图标：

1. 创建精灵图：将多个图标合并到一张大图中，确保每个图标之间有足够的间距。

2. 导入精灵图：将精灵图作为背景图导入到网页中的某个元素上，例如一个 `<div>` 元素。

```css
.icon-sprite {
  background-image: url('sprites.png');
  width: 24px;  /* 调整为需要的图标尺寸 */
  height: 24px;
}
```

3. 设置图标的样式：通过调整背景图的位置来显示所需的图标。

```css
.icon-sprite.icon-mail {
  background-position: 0 0;  /* 调整为需要的图标位置 */
}

.icon-sprite.icon-search {
  background-position: -24px 0;  /* 调整为需要的图标位置 */
}
```

在 HTML 中使用该图标：

```html
<div class="icon-sprite icon-mail"></div>
<div class="icon-sprite icon-search"></div>
```

通过以上步骤，可以使用精灵图的技术来显示所需的图标或图片，并减少浏览器的请求次数，提高网页的加载性能。
