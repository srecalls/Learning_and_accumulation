# 鼠标样式 cursor

#### 代码：
cursor : pointer;

**设置或检索在对象上移动的鼠标指针采用何种系统预定义的光标形状。**

![[Pasted image 20220916185708.png]]


在 CSS 中，`cursor` 属性用于指定鼠标光标在元素上的形态，即当鼠标悬停在元素上时，光标应该显示为何种形式。

`cursor` 属性可以接受多种值，每个值对应一个特定的光标样式。以下是一些常用的 `cursor` 属性值：

- `auto`：浏览器自动选择适当的光标样式。
- `default`：默认光标样式，通常是一个箭头。
- `pointer`：表示链接或可点击元素的光标样式，通常是一个手指形状。
- `text`：表示文本可编辑元素（如输入框或文本区域）的光标样式，通常是一个竖线或文本编辑符号。
- `move`：表示可拖动元素的光标样式，通常是一个带有四向箭头的手指形状。
- `crosshair`：十字线状光标，通常用于表示可进行选取或绘制的元素。
- `not-allowed`：表示禁止操作的光标样式，通常是一个圆圈加斜线。
- `help`：表示帮助信息的光标样式，通常是一个问号。

以下是一个示例，展示了 `cursor` 属性的使用：

```html
<style>
  .button {
    cursor: pointer;
  }
</style>

<button class="button">Click Me</button>
```

在上述示例中，`<button>` 元素应用了 `cursor: pointer;` 属性，使鼠标悬停在按钮上时，光标显示为一个手指形状，表示可点击。

通过使用 `cursor` 属性，您可以根据元素的交互性质和语义来设置适当的光标样式，提供用户与页面元素进行交互的视觉反馈。选择合适的光标样式可以改善用户体验，并增强页面的可用性。
