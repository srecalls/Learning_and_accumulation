关键帧（Keyframes）在 CSS 动画中用于定义动画效果的各个阶段或关键点。它允许您指定动画在不同时间点的样式和属性值。

关键帧通过 `@keyframes` 规则来定义，其语法如下：

```css
@keyframes animationName {
  /* 定义关键帧 */
}
```

其中 `animationName` 是您为动画效果指定的名称，可以自定义。

关键帧定义由多个百分比值（0% 到 100%）或关键字（`from` 和 `to`）组成。每个百分比值或关键字表示动画在特定时间点的样式状态。

以下是一个例子，展示了一个简单的动画效果，从透明度为 0 到透明度为 1 的淡入效果：

```css
@keyframes fadeIn {
  0% {
    opacity: 0;
  }
  100% {
    opacity: 1;
  }
}
```

在上述示例中，`fadeIn` 是动画的名称，关键帧定义了两个阶段：0% 和 100%。在 0% 的阶段，元素的透明度为 0；在 100% 的阶段，元素的透明度为 1。

您可以根据需要在关键帧中定义更多的阶段，以创建更复杂的动画效果。例如：

```css
@keyframes slideIn {
  0% {
    transform: translateX(-100%);
  }
  50% {
    transform: translateX(0);
    opacity: 1;
  }
  100% {
    transform: translateX(100%);
    opacity: 0;
  }
}
```

在上述示例中，`slideIn` 是动画的名称，关键帧定义了三个阶段：0%、50% 和 100%。在 0% 的阶段，元素从左侧滑入；在 50% 的阶段，元素位于原始位置且透明度为 1；在 100% 的阶段，元素向右侧滑出且透明度为 0。

定义好关键帧后，您可以将其应用于元素的动画效果，使用 `animation-name` 属性指定关键帧的名称，并设置其他动画属性（如持续时间、循环次数等）。

```css
.element {
  animation-name: fadeIn;
  animation-duration: 2s;
}
```

上述代码将应用名为 `fadeIn` 的关键帧动画效果到 `.element` 类的元素，并将动画的持续时间设置为 2 秒。

通过定义关键帧，您可以创建各种复杂的动画效果，通过在不同的时间点指定不同的样式状态，实现元素的平滑过渡和动态变化。
