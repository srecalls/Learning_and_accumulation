# 4、animation 简写
animation：动画名称 动画时长 动画运动速度 延迟时间 执行次数 往返动画

animation：动画名称 动画时长  （有这两个即可以完成动画，其它未设置，有默认值）

通过设置`animation`属性，可以定义元素的动画效果。下面是`animation`属性的语法：

```css
animation: [animation-name] [duration] [timing-function] [delay] [iteration-count] [direction] [fill-mode];
```

- `animation-name`：动画的名称，可以通过`@keyframes`规则定义。例如：`myAnimation`。
- `duration`：动画的持续时间，以秒或毫秒为单位。例如：`2s`、`2000ms`。
- `timing-function`：动画的时间函数，用于定义动画的速度变化。与过渡的时间函数相同。
- `delay`：动画开始之前的延迟时间，以秒或毫秒为单位。
- `iteration-count`：动画的重复次数。可以是具体次数（例如：`2`），也可以是`infinite`表示无限次循环。
- `direction`：动画的播放方向，可以是`normal`（默认值，正常播放）、`reverse`（反向播放）、`alternate`（交替正向和反向播放）等。
- `fill-mode`：动画结束后的样式状态，可以是`none`（默认值，回到初始状态）、`forwards`（保持动画结束时的状态）、`backwards`（使用动画的第一个关键帧的样式）等。

`animation` 是一个用于简化设置动画属性的 CSS 缩写属性。它可以一次性设置多个动画相关的属性，包括动画名称、持续时间、延迟、时间函数、播放次数和方向。

`animation` 属性的完整语法如下：

```css
animation: animation-name animation-duration animation-timing-function animation-delay animation-iteration-count animation-direction;
```

以下是各个属性的含义：

- `animation-name`：指定要应用的关键帧动画的名称。
- `animation-duration`：指定动画的持续时间。
- `animation-timing-function`：指定动画的时间函数（用于控制动画的加速和减速效果）。
- `animation-delay`：指定动画开始之前的延迟时间。
- `animation-iteration-count`：指定动画的播放次数。
- `animation-direction`：指定动画的播放方向。

您可以根据需要选择性地设置这些属性。例如，如果只想设置动画的名称和持续时间，可以这样使用 `animation` 简写属性：

```css
.element {
  animation: fadeIn 2s;
}
```

上述代码将应用名为 `fadeIn` 的动画效果到 `.element` 类的元素，并将动画的持续时间设置为 2 秒。

如果您想设置更多的动画属性，可以继续添加到 `animation` 简写属性中，以逗号分隔各个值。例如，如果要设置动画的播放次数为无限循环并且动画方向为交替播放，可以这样使用：

```css
.element {
  animation: fadeIn 2s linear 0s infinite alternate;
}
```

上述代码将应用名为 `fadeIn` 的动画效果到 `.element` 类的元素，并设置动画的持续时间为 2 秒，时间函数为线性，延迟为 0 秒，播放次数为无限循环，播放方向为交替播放。

通过使用 `animation` 简写属性，您可以更简洁地设置动画相关的多个属性，提高代码的可读性和维护性。请确保按照正确的顺序设置各个属性值，以避免出现意外的结果。
