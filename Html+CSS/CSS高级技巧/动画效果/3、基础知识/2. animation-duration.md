**animation-duration：5s  （动画持续时间为5s）**
`animation-duration` 是 CSS 中用于指定动画持续时间的属性。它定义了动画效果从开始到结束所需的时间长度。

该属性接受一个时间值作为参数，表示动画的持续时间。时间值可以使用秒（s）或毫秒（ms）表示。具体的语法如下：

```css
animation-duration: <time>;
```

例如，如果要将一个动画效果的持续时间设置为 2 秒，可以这样设置：

```css
.element {
  animation-name: myAnimation;
  animation-duration: 2s;
}
```

在上述示例中，`.element` 类的元素将应用名为 "myAnimation" 的动画效果，并将其持续时间设置为 2 秒。

通过调整 `animation-duration` 的值，您可以控制动画效果完成从开始到结束所需的时间。较长的持续时间将导致较慢的动画，而较短的持续时间将导致较快的动画。

此外，您还可以使用其他动画属性（如 `animation-delay`、`animation-iteration-count`、`animation-timing-function` 等）来进一步控制动画的延迟、重复次数和时间函数等。通过调整这些属性的值，您可以实现更精确的动画效果和过渡效果。
