**3、animation-timing-function： linear （动画时间曲线 也叫做运行速度为匀速）**

`animation-timing-function` 是 CSS 中用于指定动画过渡效果的时间函数的属性。它定义了动画在不同时间点上的变化速度。

**该属性接受一个时间函数值作为参数，表示动画过渡效果的时间函数。时间函数可以使用预定义的关键字（如 `linear`、`ease`、`ease-in`、`ease-out`、`ease-in-out` 等），也可以使用自定义的贝塞尔曲线函数（`cubic-bezier()`）来定义。**

具体的语法如下：

```css
animation-timing-function: <timing-function>;
```

例如，如果要将动画过渡效果设置为由慢到快的缓动效果，可以使用 `ease-in-out` 关键字：

```css
.element {
  animation-name: myAnimation;
  animation-duration: 2s;
  animation-timing-function: ease-in-out;
}
```

在上述示例中，`.element` 类的元素将应用名为 "myAnimation" 的动画效果，并使用持续时间为 2 秒的时间长度，以及 `ease-in-out` 时间函数来定义过渡效果。

您还可以使用自定义的贝塞尔曲线函数来定义更精确的时间函数。例如，使用 `cubic-bezier()` 函数可以提供更灵活的控制。以下是一个示例：

```css
.element {
  animation-name: myAnimation;
  animation-duration: 2s;
  animation-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1);
}
```

在上述示例中，使用自定义的贝塞尔曲线函数 `cubic-bezier(0.25, 0.1, 0.25, 1)` 来定义动画的过渡效果。通过调整贝塞尔曲线函数的参数，可以创建不同形状的时间函数，从而实现更具个性化的动画效果。

通过调整 `animation-timing-function` 的值，您可以控制动画在不同时间点上的变化速度，从而实现所需的动画效果和过渡效果。
