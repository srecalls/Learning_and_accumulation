1、**animation-name ：xx   （设置关键帧的名称为xx）**
`animation-name` 是 CSS 中用于指定动画效果名称的属性。它用于将一个或多个在 `@keyframes` 规则中定义的动画效果应用到元素上。

要使用 `animation-name`，您需要先定义一个或多个动画效果的 `@keyframes` 规则，然后将其名称指定给 `animation-name` 属性。具体的语法如下：

```css
animation-name: <animation-name>;
```

`<animation-name>` 是一个标识符，用于表示动画效果的名称。您可以为不同的动画效果定义不同的名称，并在需要应用动画的元素上使用相应的名称。

以下是一个示例，展示了如何定义并应用一个名为 "myAnimation" 的动画效果：

```css
@keyframes myAnimation {
  0% { opacity: 0; }
  100% { opacity: 1; }
}

.element {
  animation-name: myAnimation;
  animation-duration: 2s;
  animation-iteration-count: infinite;
}
```

在上述示例中，我们定义了一个名为 "myAnimation" 的动画效果，该效果在 0% 和 100% 关键帧之间改变元素的不透明度。然后，我们将 `animation-name` 属性设置为 "myAnimation"，并指定其他动画属性，如 `animation-duration` 和 `animation-iteration-count`。

通过指定不同的动画效果名称，您可以为元素定义多个动画，并根据需要应用它们。您还可以使用其他动画属性（如 `animation-duration`、`animation-delay`、`animation-iteration-count` 等）来控制动画的持续时间、延迟和重复次数等。
