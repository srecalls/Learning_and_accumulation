# 定位组成
#### 定位:
**将盒子定在某一个位置，所以定位也是在摆放盒子，按照定位的方式移动盒子。定位=定位模式＋边偏移。**
**定位模式用于指定一个元素在文档中的定位方式。边偏移则决定了该元素的最终位置。**
