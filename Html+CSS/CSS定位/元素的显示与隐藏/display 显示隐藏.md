## display 显示隐藏

#### display属性
**display属性用于设置一个元素应如何显示。
●display: none ;隐藏对象
●display : block ;除了转换为块级元素之外，同时还有显示元素的意思<font color=red>display隐藏元素后，不再占有原来的位置。</font>
后面应用及其广泛，搭配JS可以做很多的网页特效。**


`display` 是 CSS 属性，用于指定元素应该生成的框的类型。

`display` 属性可以接受多个值，常用的值包括：

- `block`：将元素显示为块级元素，生成一个独立的块框。
- `inline`：将元素显示为内联元素，元素在行内生成一个框，不会打断文本流。
- `inline-block`：将元素显示为内联块元素，元素在行内生成一个块框，可以设置宽度、高度和内外边距。
- `none`：不显示元素，元素在渲染时不占用空间，相当于隐藏元素。
- `flex`：将元素显示为弹性盒子，使其成为一个弹性容器，可以使用弹性布局来排列子元素。
- `grid`：将元素显示为网格容器，使其成为一个网格布局的容器，可以使用网格布局来排列子元素。
- `table`：将元素显示为表格，生成一个块级的表格框。
- `inline-table`：将元素显示为内联表格，生成一个内联的表格框。

示例：
```css
div {
  display: block;
}
```
上述示例将 `<div>` 元素显示为块级元素。

注意事项：
- `display` 属性可以影响元素的布局和行为。
- 不同的 `display` 值具有不同的特性和默认样式。
- `display` 属性可以与其他属性和值一起使用，以进一步控制元素的呈现方式，例如 `display: inline-block`。
- 通过修改 `display` 属性，你可以改变元素的默认显示方式，从而实现不同的布局效果。
