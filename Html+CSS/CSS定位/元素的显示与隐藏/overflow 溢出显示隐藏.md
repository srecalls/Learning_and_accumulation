# overflow 溢出显示隐藏

#### 1.介绍
**overflow 属性指定了如果内容溢出一个元素的框 （超出其指定高度及宽度）时，会发生什么。**

#### 2.属性值
属性值|描述
:-:|:-:
visible|不剪切内容也不增加滚动条
hidden|不显示超过对象尺寸的内容，超出的部分隐藏掉
scroll|不管超出内容否，总是显示滚动条
auto|超出自动显示滚动条，不超出不显示滚动条

#### 3.注意事项
**一般情况下，我们都不想让溢出的内容显示出来，因为溢出的部分会影响布局。但是如果有定位的盒子，请慎用overflow:hidden因为它会隐藏多余的部分。**

`overflow` 属性用于控制当元素的内容超出其指定尺寸时如何处理溢出部分。

`overflow` 属性接受以下值：

- `visible`：默认值。内容超出元素的尺寸时会显示在元素框之外。溢出的内容会覆盖其他元素并且不会被剪切。

- `hidden`：溢出的内容会被裁剪，不显示在元素框之外。

- `scroll`：溢出的内容会显示在元素框之外，并且会显示滚动条，以便用户可以滚动查看全部内容。

- `auto`：如果内容超出元素的尺寸，会显示滚动条以便用户滚动查看全部内容；否则，不显示滚动条。

以下是 `overflow` 属性的示例用法：

```css
div {
  overflow: visible;
}
```

在上述示例中，`div` 元素的溢出内容会显示在元素框之外，不会被剪切，并且可能会覆盖其他元素。

```css
div {
  overflow: hidden;
}
```

在上述示例中，`div` 元素的溢出内容会被裁剪，不会显示在元素框之外。

```css
div {
  overflow: scroll;
}
```

在上述示例中，`div` 元素的溢出内容会显示在元素框之外，并且会显示滚动条，以便用户可以滚动查看全部内容。

```css
div {
  overflow: auto;
}
```

在上述示例中，`div` 元素的溢出内容会根据需要显示滚动条。如果内容超出元素的尺寸，会显示滚动条以便用户滚动查看全部内容；否则，不显示滚动条。

通过使用 `overflow` 属性，您可以控制元素在内容溢出时的表现，以适应不同的布局和需求。
