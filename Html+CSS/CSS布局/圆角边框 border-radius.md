# 圆角边框 border-radius
**在CSS3中，新增了圆角边框样式，这样我们的盒子就可以变圆角了**。![[Pasted image 20220906225535.png]]
#### 语法：
**border-radius:length;**

**radius 半径(圆的半径)原理 （椭）圆与边框的交集形成圆角效果**

• **参数值可以为数值或百分比的形式**
**• 如果是正方形，想要设置为一个圆，把数值修改为高度或者宽度的一般即可，或者直接写50% 即 width的50%
• 如果是个矩形，设置为高度的一半就可以做
• 该属性是一个简写属性，可以跟四个值，分别代表左上角、右上角、右下角、左下角**

`border-radius` 属性用于创建元素的圆角边框效果。通过设置 `border-radius` 的值，可以使元素的边框具有圆角效果。以下是 `border-radius` 属性的详细说明和示例：

语法：
```css
border-radius: [top-left] [top-right] [bottom-right] [bottom-left] / [horizontal-radius] [vertical-radius];
```

- `[top-left]`：定义左上角的圆角半径值。
- `[top-right]`：定义右上角的圆角半径值。
- `[bottom-right]`：定义右下角的圆角半径值。
- `[bottom-left]`：定义左下角的圆角半径值。
- `[horizontal-radius]`：可选参数，用于指定水平方向的圆角半径。
- `[vertical-radius]`：可选参数，用于指定垂直方向的圆角半径。

示例：
```css
div {
  border: 1px solid #000;
  border-radius: 10px;
}
```
上述示例将 `div` 元素的边框设置为 1 像素的实线边框，并将边框的圆角半径设置为 10 像素，从而创建了具有圆角效果的边框。

可以将不同的值应用于每个角，以创建不同的圆角效果：
```css
div {
  border: 1px solid #000;
  border-radius: 10px 0 20px 5px / 15px 30px;
}
```
上述示例将 `div` 元素的左上角设置为 10 像素的圆角，右上角设置为 0，右下角设置为 20 像素，左下角设置为 5 像素。水平方向的圆角半径分别为 15 像素和 30 像素，垂直方向的圆角半径分别为 15 像素和 30 像素。

`border-radius` 属性还支持百分比值和具体的长度单位，可以根据需要调整圆角的大小和形状。使用 `border-radius` 属性，您可以创建各种不同形状的圆角边框，以增加元素的视觉吸引力。

当使用 `border-radius` 属性时，可以通过指定不同的值来创建不同的圆角效果。以下是更详细的说明和示例：

1. 相同圆角半径：
   ```css
   div {
     border: 1px solid #000;
     border-radius: 10px;
   }
   ```
   在上述示例中，`div` 元素的四个角都具有相同的 10 像素圆角半径，创建了一个相对较为均匀的圆角边框。

2. 不同圆角半径：
   ```css
   div {
     border: 1px solid #000;
     border-radius: 10px 0 20px 5px;
   }
   ```
   在这个示例中，`div` 元素的左上角设置为 10 像素的圆角半径，右上角设置为 0（没有圆角），右下角设置为 20 像素的圆角半径，左下角设置为 5 像素的圆角半径。这样可以创建非对称的圆角边框。

3. 水平和垂直方向分别不同的圆角半径：
   ```css
   div {
     border: 1px solid #000;
     border-radius: 15px 30px / 10px 20px;
   }
   ```
   在这个示例中，`div` 元素的水平方向圆角半径分别为 15 像素和 30 像素，垂直方向的圆角半径分别为 10 像素和 20 像素。这样可以创建椭圆形或椭圆角的边框。

4. 百分比值作为圆角半径：
   ```css
   div {
     border: 1px solid #000;
     border-radius: 50%;
   }
   ```
   在这个示例中，`div` 元素的圆角半径设置为 50%，这将使元素的四个角变为圆形。

5. 使用具体的长度单位：
   ```css
   div {
     border: 1px solid #000;
     border-radius: 20px 30px 40px 10px;
   }
   ```
   在这个示例中，`div` 元素的圆角半径使用具体的像素长度单位，分别为 20 像素、30 像素、40 像素和 10 像素。

通过调整 `border-radius` 属性中的值，您可以创建不同大小和形状的圆角边框，以实现各种视觉效果。请注意，`border-radius` 属性还可以与其他属性（如 `background`、`box-shadow` 等）一起使用，以进一步增强元素的外观。

`border-radius` 的计算方式取决于指定的值类型。下面是关于 `border-radius` 计算方式的具体说明：

1. 指定具体长度单位：
   当指定具体的长度单位（如像素(px)、英寸(in)、厘米(cm)等）作为 `border-radius` 的值时，这些值直接表示圆角的半径大小。

2. 指定百分比：
   当以百分比作为 `border-radius` 的值时，计算圆角的具体像素值是相对于元素的边框盒子尺寸来确定的。具体计算方式如下：
   - 对于**正方形盒子**（宽度和高度相等），圆角半径的计算是**以盒子的宽度或高度的一半作为基准**。例如，`border-radius: 50%` 将创建一个完全圆形的圆角，其半径等于盒子宽度或高度的一半。
   - 对于**非正方形盒子**，圆角半径的计算是**以较小的边（宽度或高度）的一半作为基准**。例如，对于一个宽度为 200px、高度为 100px 的盒子，`border-radius: 50%` 将创建一个半径为 50px 的圆角。

3. 多个值的情况：
   当指定多个值时，它们按顺序分别应用于左上、右上、右下和左下的角。如果**提供的值不足四个**，**则缺失的值将从相应的位置上复制已提供的值。**

4. 斜角情况：
   当**指定的圆角半径大于元素边框盒子的一半**时，圆角会被剪切为一个**椭圆形**。**椭圆的长轴和短轴**的长度将根据**圆角半径**和**元素边框盒子的尺寸**进行计算。

请注意，`border-radius` 的计算方式可能会受到浏览器的特定实现和渲染引擎的影响。因此，在使用 `border-radius` 时，最好通过实际测试来确认所需的效果是否符合预期。
