# 边框 border 

## 单个属性
#### ➢ 作用：
**给设置边框粗细、边框样式、边框颜色效果** 
#### ➢ 单个属性：
![[Pasted image 20220906142801.png]]


## 连写形式
#### ➢ 属性名：
**border** 
#### ➢ 属性值：
**单个取值的连写，取值之间以空格隔开** 
**• 如：border : 10px solid red;** 
#### ➢ 快捷键：bd + tab

## 单方向设置
#### ➢ 场景：
**只给盒子的某个方向单独设置边框** 
#### ➢ 属性名：
**border - 方位名词** 
#### ➢ 属性值：连写的取值
