# 盒子阴影 box-shadow
**CSS3中新增了盒子阴影，我们可以使用box-shadow属性为盒子添加阴影**


`box-shadow` 属性用于在元素周围创建一个或多个阴影效果。通过设置合适的值，可以为元素添加阴影，以增强其可读性或视觉效果。以下是 `box-shadow` 属性的详细说明和示例：

语法：
```css
box-shadow: [horizontal-offset] [vertical-offset] [blur-radius] [spread-radius] [color] [inset];
```

- `[horizontal-offset]`：表示阴影相对于元素的水平偏移量。正值向右偏移，负值向左偏移。
- `[vertical-offset]`：表示阴影相对于元素的垂直偏移量。正值向下偏移，负值向上偏移。
- `[blur-radius]`：表示阴影的模糊半径。值越大，阴影越模糊；值为 0 时，阴影没有模糊效果。
- `[spread-radius]`：表示阴影的扩展半径。正值会增加阴影的尺寸，负值会减小阴影的尺寸。默认值为 0，即阴影与元素具有相同的尺寸。
- `[color]`：表示阴影的颜色。可以使用颜色名称、十六进制值、RGB 值等来指定颜色。
- `[inset]`（可选）：指定阴影是否为内部阴影。如果指定了 `inset`，阴影将被绘制在元素内部而不是外部。

示例：
```css
div {
  box-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);
}
```
上述示例为 `<div>` 元素添加了一个向右下方偏移 2 像素、向下偏移 2 像素的阴影，模糊半径为 4 像素，并且阴影颜色为半透明的黑色（RGBA 值）。

可以使用多个 `box-shadow` 声明来为元素添加多个阴影层叠效果：
```css
div {
  box-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5),
              -2px -2px 4px rgba(255, 255, 255, 0.5);
}
```
在这个示例中，`<div>` 元素同时添加了一个黑色阴影和一个白色阴影，它们分别位于元素的右下方和左上方，模糊半径都为 4 像素。

通过调整 `box-shadow` 属性中的值，可以创建不同颜色、位置、模糊程度和尺寸的阴影效果，以实现所需的视觉效果。请注意，`box-shadow` 属性在某些旧版本的浏览器中可能不被支持，因此在使用时要考虑浏览器的兼容性。
