# 文字阴影 text-shadow

`text-shadow` 属性用于为文本添加阴影效果。通过设置适当的值，可以为文本创建阴影，从而增强其可读性或视觉效果。以下是 `text-shadow` 属性的详细说明和示例：

语法：
```css
text-shadow: [offset-x] [offset-y] [blur-radius] [color];
```

- `[offset-x]`：表示阴影相对于文本的水平偏移量。正值向右偏移，负值向左偏移。
- `[offset-y]`：表示阴影相对于文本的垂直偏移量。正值向下偏移，负值向上偏移。
- `[blur-radius]`：表示阴影的模糊半径。值越大，阴影越模糊；值为 0 时，阴影没有模糊效果。
- `[color]`：表示阴影的颜色。可以使用颜色名称、十六进制值、RGB 值等来指定颜色。

示例：
```css
h1 {
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);
}
```
上述示例为 `h1` 标签中的文本添加了一个向右下方偏移 2 像素、向下偏移 2 像素的阴影，模糊半径为 4 像素，并且阴影颜色为半透明的黑色（RGBA 值）。

可以使用多个 `text-shadow` 声明来为文本添加多个阴影层叠效果：
```css
h1 {
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5),
               -2px -2px 4px rgba(255, 255, 255, 0.5);
}
```
在这个示例中，`h1` 标签的文本同时添加了一个黑色阴影和一个白色阴影，它们分别位于文本的右下方和左上方，模糊半径都为 4 像素。


在 `text-shadow` 属性中，`blur-radius` 用于控制阴影的模糊程度。它表示阴影模糊的半径，可以使用以下值：

1. 长度单位：可以使用像素（px）、英寸（in）、厘米（cm）等具体长度单位来指定模糊半径的大小。例如，`text-shadow: 2px 2px 4px #000;` 中的 `4px` 表示模糊半径为 4 像素。

2. 数字：可以使用无单位的数字来指定模糊半径。此时，浏览器将默认将数字解释为像素值。例如，`text-shadow: 2px 2px 2 #000;` 中的 `2` 表示模糊半径为 2 像素。

3. `none`：表示没有模糊效果，阴影将是清晰的。例如，`text-shadow: 2px 2px none #000;` 中的 `none` 表示没有模糊效果。

需要注意的是，`blur-radius` 的值越大，阴影的模糊程度就越高。较小的值会产生较为清晰的阴影，而较大的值会产生更模糊的阴影效果。

此外，还可以通过使用 `rgba()` 函数来控制阴影的透明度。例如，`text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);` 中的 `0.5` 表示阴影的透明度为 50%。

通过调整 `blur-radius` 的值，您可以根据需要创建不同程度的阴影模糊效果，以实现所需的视觉效果。

通过调整 `text-shadow` 属性中的值，可以创建不同颜色、位置和模糊程度的阴影效果，以增强文本的视觉效果。请注意，`text-shadow` 属性在某些旧版本的浏览器中可能不被支持，因此在使用时要考虑浏览器的兼容性。
