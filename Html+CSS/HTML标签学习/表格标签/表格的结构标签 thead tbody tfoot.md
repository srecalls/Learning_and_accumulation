# 表格的结构标签 thead tbody tfoot
#### ➢ 场景：
**让表格的内容结构分组，突出表格的不同部分（头部、主体、底部），使语义更加清晰** 
#### ➢ 结构标签：

![[Pasted image 20220905193750.png]]
#### ➢ 注意点： 
**• 表格结构标签内部用于包裹tr标签 
• 表格的结构标签可以省略**

#### ➢ 表格的结构标签分别有哪些？表示什么含义？ 
**• thead：表格头部 
• tbody：表格主体 
• tfoot：表格底部** 
#### ➢ 表格结构标签书写在什么位置？ 
**• 表格结构标签写在table标签内部 
• 表格标签内部用于包裹tr标签**
