# 图片标签 Total

#### ➢ 在页面中展示一张图片，需要使用什么标签？ 
**• img标签** 
#### ➢ 图片的常见属性有哪些？
属性 | 说明 | 
 :-: | :-: | 
[[图片标签的src属性\|src]] | 指定需要展示图片的路径 |
[[图片标签的alt属性\|alt]] | 替换文本,当图片加载失败时,才显示的文字 | 
[[图片标签的title属性\|title]]|提升文本,当鼠标悬停时,才显示的文字 | 
[[图片标签的width和height属性\|width]] | 图片的宽度 | 
[[图片标签的width和height属性\|height]]| 图片的高度 |
