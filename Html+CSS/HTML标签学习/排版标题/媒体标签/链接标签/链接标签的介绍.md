# 链接标签的介绍

#### ➢ 场景：
**点击之后，从一个页面跳转到另一个页面** 
#### ➢ 称呼： 
**a标签、超链接、锚链接** 
#### ➢ 代码： 
![[Pasted image 20220906011133.png]]
![[Pasted image 20220906011140.png]]
#### ➢ 特点： 
**• 双标签，内部可以包裹内容 
• 如果需要a标签点击之后去指定页面，需要设置a标签的href属性**

#### ➢ 显示特点： 
**• a标签默认文字有下划线 
• a标签从未点击过，默认文字显示蓝色 
• a标签点击过之后，文字显示为紫色（清除浏览器历史记录可恢复蓝色**
