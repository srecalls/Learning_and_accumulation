# 内部样式表
#### 介绍
**内部样式表(内嵌样式表)是写到html页面内部.是将所有的CSS代码抽取出来,单独放到一个\<style>标签中。**


#### 注意点：
**●\<style> 标签理论上可以放在HTML文档的任何地方,但一般会放在文档的\<head>标签中
●通过此种方式，可以方便控制当前整个页面中的元素样式设置
●代码结构清晰,但是并没有实现结构与样式完全分离
●使用内部样式表设定CSS ,通常也被称为嵌入式引入,这种方式是我们练习时常用的方式**

能不能放到body里面
虽然将`<style>`标签放在`<body>`标签中是合法的HTML语法，但是根据HTML的语义，`<style>`标签应该放在`<head>`标签中。这是因为`<head>`标签是用来包含页面的元数据的，而CSS样式表是元数据的一部分。放在`<head>`标签中，可以让浏览器在渲染HTML之前就加载并解析CSS样式表，从而提高页面加载速度和性能。

将`<style>`标签放在`<body>`标签中还可能会导致一些样式问题。如果样式表中的某些样式与HTML标记的结构不匹配，可能会导致意外的样式效果。此外，将样式表放在`<body>`标签中可能会增加代码的复杂性和维护难度，特别是在需要应用到多个元素的情况下。

因此，虽然可以将`<style>`标签放在`<body>`标签中，但是推荐将样式表放在`<head>`标签中，以确保HTML的结构和语义得到保留，并且确保样式表在页面加载和渲染时能够正确地应用到HTML元素上。
