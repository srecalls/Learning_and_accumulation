#### HTML嵌套规范注意点
**1. 块级元素一般作为大容器，可以嵌套：文本、块级元素、行内元素、行内块元素等等…
但是：p标签中不要嵌套div、p、h等块级元素 
2. a标签内部可以嵌套任意元素 
但是：a标签不能嵌套a标签**
