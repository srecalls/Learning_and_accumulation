# 行高 line-height
#### ➢ 作用：
**控制一行的上下行间距** 
#### ➢ 属性名：
**line-height** 
#### ➢ 取值： 
**• 数字+px** 
**• 倍数（当前标签font-size的倍数）** 
#### ➢ 应用： 
**1. 让单行文本垂直居中可以设置 line-height : 文字父元素高度** 
**2. 网页精准布局时，会设置 line-height : 1 可以取消上下间距** 
#### ➢ 行高与font连写的注意点： 
**• 如果同时设置了行高和font连写，注意覆盖问题** 
**• [[字体font相关属性的连写|font]] :  style  weight  size/line-height  family ;**
