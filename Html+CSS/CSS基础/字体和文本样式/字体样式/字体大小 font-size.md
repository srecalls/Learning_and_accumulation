# 字体大小 font-size
#### ➢ 属性名：
**font-size** 
#### ➢ 取值：
**数字 + px** 
#### ➢ 注意点： 
**• 谷歌浏览器默认文字大小是16px** 
**• 单位需要设置，否则无效**

在 CSS 中，`font-size` 属性用于设置文本的字体大小。

`font-size` 属性可以接受以下类型的值：

- 绝对大小值：指定一个固定的字体大小，以像素（px）、点（pt）、英寸（in）、毫米（mm）等单位表示。例如，`12px` 表示字体大小为 12 像素。
- 相对大小值：相对于父元素字体大小的相对值。常用的相对大小值有 `em`、`rem` 和 `%`。例如，`1.5em` 表示字体大小为父元素字体大小的 1.5 倍。
- 关键字：常用的关键字包括 `small`、`medium`、`large`、`larger` 和 `smaller`。这些关键字表示相对的字体大小，具体大小取决于浏览器的默认设置。

以下是一个示例，展示了 `font-size` 属性的使用：

```html
<style>
  .container {
    font-size: 20px;
  }
</style>

<div class="container">
  <p>This is a paragraph with a font size of 20 pixels.</p>
</div>
```

在上述示例中，`.container` 类选择器的 `<div>` 元素应用了 `font-size: 20px;` 属性。这将使容器中的文本使用 20 像素大小的字体。

通过使用 `font-size` 属性，您可以控制文本的字体大小，以实现不同的视觉效果。较大的字体可以用于突出显示重要内容，而较小的字体可以用于辅助文本或提供更加紧凑的外观。选择合适的字体大小可以根据设计需求和排版风格来调整文本的外观。
