# 标准流（普通流 /文档流）
#### ➢ 标准流：又称文档流，是浏览器在渲染显示网页内容时默认采用的一套排版规则，规定了应该以何种方式排列元素 
#### ➢ 常见标准流排版规则： 
**1. 块级元素：从上往下，垂直布局，独占一行 
2. 行内元素 或 行内块元素：从左往右，水平布局，空间不够自动折行**
 
**所谓的标准流:就是标签按照规定好默认方式排列
1.块级元素会独占一-行,从上向下顺序排列。
●常用元素:div、hr、 p、h1~h6、 ul、 ol、 dI、 form、 table
2.行内元素会按照顺序,从左到右顺序排列,碰到父元素边缘则自动换行。
●常用元素: span、a、i、 em等
以上都是标准流布局,我们前面学习的就是标准流,标准流是最基本的布局方式。,标准流是最基本的布局方式。**

当元素脱离文档流后，它们有可能占据空间，也有可能不占据空间。以下是一些脱离文档流后不占据空间的元素：

1.  绝对定位元素（position: absolute）：绝对定位的元素不再占据空间，因为它们被移除了文档流，并且不再影响其他元素的位置和大小。
    
2.  固定定位元素（position: fixed）：与绝对定位元素类似，固定定位的元素也不再占据空间，因为它们被移除了文档流，并且不再影响其他元素的位置和大小。
    
3.  浮动元素（float）：浮动的元素不占据文档流中的空间，并且会环绕在其他元素周围。如果其他元素没有清除浮动，那么它们可能会发生重叠或布局问题。
    

需要注意的是，尽管这些元素不占据空间，但它们仍然会影响其他元素的位置和大小，可能导致布局问题。如果您需要使用这些元素，请确保您理解它们的行为，并使用它们来实现您的布局需求。

浮动元素虽然不再占据文档流中的空间，但它们仍然会影响其他元素的位置和大小，可能导致布局问题。具体来说，当一个元素浮动后，它会脱离文档流，但是仍然会占据空间，并且会影响其他元素的位置和大小。

当浮动元素占据了父元素的一整行时，它会导致父元素的高度塌陷（高度变为 0），从而使父元素无法正确包含后续的元素。这种现象被称为“父元素高度塌陷”或“父元素崩塌”。

为了避免这种问题，可以使用清除浮动（clear float）的方法来解决。清除浮动可以使后续元素不再受到浮动元素的影响，从而正确地排列在浮动元素下方。常用的清除浮动方法包括：

-   在浮动元素后面添加一个空的块级元素，并使用 `clear: both` 清除浮动。
-   在父元素的最后一个子元素后面添加一个空的块级元素，并使用 `clear: both` 清除浮动。
-   将父元素设置为浮动，并使用 `overflow: hidden` 或 `overflow: auto` 强制父元素包含浮动元素。

需要注意的是，清除浮动可能会对布局产生一定的影响，因此应该谨慎使用。在实际应用中，应该根据具体情况选择合适的清除浮动方法。
