## 1. 换行符是什么导致的？

在 HTML 源码中，为了代码的可读性，我们通常会这样写：

HTML

```
<div class="container">
    <div class="box">1</div>
    <div class="box">2</div>
</div>
```

**真相是：** 浏览器在解析这段代码时，标签之间的**换行符**（回车）和**缩进**（空格）会被视作一个普通的**空格字符**。

由于 `inline-block` 元素具有“行内（inline）”的特性，它就像单词一样。当你把两个 `div` 设置为 `inline-block` 时，它们之间如果有一个换行符，浏览器就会渲染出一个空格。

---

## 2. 为什么 `font-size: 0` 能解决？

空格本质上也是一个“字符”。

- **空格的宽度**是由父元素的 `font-size` 决定的。
    
- 当你设置父元素的 `font-size: 0;` 时，这个空格字符的宽度就变成了 **0 像素**。
    
- 空格虽然还在那里，但它不再占据任何物理空间，因此两个 `box` 就能紧紧贴在一起了。
    

> **注意**：必须在子元素里把 `font-size` 改回正常值（如 `16px`），否则子元素里的文字也会消失。

---

## 3. 除了 font-size: 0，如何避免这个空隙？

除了修改字体大小，还有几种常见的“避坑”方法：

### A. 物理消除法（最直接，但代码难看）

直接在 HTML 中删除换行和空格，让标签连在一起：

HTML

```
<div class="box">1</div><div class="box">2</div>
```

或者利用 HTML 注释连接：

HTML

```
<div class="box">1</div><div class="box">2</div>
```

### B. 负 Margin 法

给子元素设置一个负的左右外边距（通常是 `-4px` 或 `-5px`），但这取决于字体，不够精确。

CSS

```
.box {
    margin-right: -4px;
}
```

### C. 现代终极方案：Flexbox (推荐)

这是目前最标准的做法。当你给父元素设置 `display: flex;` 时，子元素之间的**所有空白符都会被自动忽略**，完全不需要考虑换行符的问题。

CSS

```
.container {
    display: flex; /* 开启 flex 布局后，换行符失效 */
}
```

---

### 总结

- **起因**：HTML 源码里的换行被浏览器解析成了**一个空格**。
    
- **原理**：`font-size: 0` 让这个空格的宽度归零。
    
- **现状**：在现代开发中，我们几乎不再使用 `inline-block` 来做整体布局，而是直接用 **Flexbox**，因为它从根源上无视了这些“烦人”的空白字符。
