![[Pasted image 20220907150016.png]]
![[Pasted image 20220907145956.png]]
#### 总结:
**有很多的布局效果,标准流没有办法完成,此时就可以利用浮动完成布局。因为浮动可以改变元素标签默认的排列方式.**
#### 浮动最典型的应用:
**可以让多个块级元素-行内排列显示。**
#### 网页布局第一准则:
**多个块级元素纵向排列找标准流,多个块级元素横向排列找浮动。**




在前端开发中，让原本独占一行的 `div`（块级元素）并排显示，本质上就是改变它们的**显示模式**或**脱离标准流**。

以下是两种实现方式的对比代码。

---

### 1. 使用行内块（inline-block）实现并排

通过修改 `display` 属性，让 `div` 具备行内元素的并排特性，同时保留块级元素的宽高属性。

HTML

```
<!DOCTYPE html>
<html>
<head>
    <style>
        .container {
            background-color: #eee;
            padding: 10px;
            /* 解决 inline-block 空隙的小技巧：父级字符大小设为 0 */
            font-size: 0; 
        }
        .box {
            display: inline-block; /* 核心：改为行内块 */
            width: 100px;
            height: 100px;
            margin: 10px;
            background-color: #4CAF50;
            color: white;
            font-size: 16px; /* 恢复子元素文字大小 */
            text-align: center;
            line-height: 100px;
        }
    </style>
</head>
<body>
    <h3>方法一：display: inline-block</h3>
    <div class="container">
        <div class="box">Box 1</div>
        <div class="box">Box 2</div>
        <div class="box">Box 3</div>
    </div>
</body>
</html>
```

---

### 2. 使用浮动（float）实现并排

浮动会让元素**脱离标准文档流**，向左或向右靠拢。这是早年网页布局的主流方法。

HTML

```
<!DOCTYPE html>
<html>
<head>
    <style>
        .container {
            background-color: #ddd;
            padding: 10px;
            /* 核心：清除浮动，否则父容器高度会塌陷 */
            overflow: hidden; 
        }
        .float-box {
            float: left; /* 核心：向左浮动 */
            width: 100px;
            height: 100px;
            margin: 10px;
            background-color: #2196F3;
            color: white;
            text-align: center;
            line-height: 100px;
        }
    </style>
</head>
<body>
    <h3>方法二：float: left</h3>
    <div class="container">
        <div class="float-box">Box A</div>
        <div class="float-box">Box B</div>
        <div class="float-box">Box C</div>
    </div>
    <p>注意：浮动元素下方的文字会环绕它，除非清除浮动。</p>
</body>
</html>
```

---

### 核心区别总结

|**特性**|**inline-block**|**float**|
|---|---|---|
|**文档流状态**|仍在标准流中|**脱离标准流**|
|**对齐方式**|可以轻松使用 `text-align: center` 居中|只能左右对齐，居中较麻烦|
|**空白间隙**|HTML 标签间的换行符会产生空隙|元素间紧密相连，无空隙|
|**父容器影响**|父容器会自动被撑开|若不“清除浮动”，父容器高度会塌陷为 0|

### 现代建议

虽然这两种方法很经典，但在现代开发中，**Flexbox (`display: flex`)** 是实现并排的最优解，因为它更强大且易于控制。
