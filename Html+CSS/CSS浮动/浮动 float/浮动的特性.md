# 浮动的特点

**1. 浮动元素会脱离[[标准流（普通流 、文档流）|标准流]]（简称：脱标），在标准流中不占位置
• 相当于从地面飘到了空中 

**2.如果多个盒子都设置了浮动,则它们会按照属性值一行内显示并且顶端对齐排列。**

**3.浮动元素会具有[[行内块元素]]特性。** inline-block
**任何元素都可以浮动。不管原先是什么模式的元素,添加浮动之后具有行内块元素相似的特性。**

●如果**块级盒子**没有设置**宽度** ,默认**宽度和父级一样宽**,但是**添加浮动后**,它的大小**根据内容来决定**

●**浮动的盒子**中间是**没有缝隙的** ,是紧挨着一起的

●**行内元素同理**

注意:浮动的元素是互相贴靠在一起的(不会有缝隙)，如果**父级宽度装不 下这些浮动的盒子**，多出的盒子**会另起一行对齐**。

4 浮动元素**比标准流高半个级别**，可以**覆盖标准流中的元素**

**5. 浮动找浮动，下一个浮动元素会在上一个浮动元素后面左右浮动** 

当多个元素都设置了浮动（`float`）属性时，它们会相对于其包含块（父元素）进行浮动定位。在布局中，如果一个浮动元素后面紧跟着另一个浮动元素，且**后一个浮动元素**设置了**左浮动或右浮**动，它会尝试在**上一个浮动元素的后面进行左右浮动**。

具体来说，**如果一个元素设置了左浮动（`float: left;`），那么下一个元素如果也设置了左浮动，它会尝试在上一个浮动元素的右侧进行浮动。同样地，如果一个元素设置了右浮动（`float: right;`），下一个元素如果也设置了右浮动，它会尝试在上一个浮动元素的左侧进行浮动。**

这种浮动行为可以用来实现多列布局或元素的流动效果。通过设置相邻元素的浮动方向，我们可以让它们在水平方向上相互靠拢并排列。

需要注意的是，浮动元素会脱离正常的文档流，并且浮动元素的浮动方向不会影响其后面的非浮动元素的布局。如果后续元素不希望受到浮动元素的影响，可以使用清除浮动（clear float）的技术，如**使用 `clear: both;` 或 `clear: left;`** 来清除浮动。


**6. 浮动元素有特殊的显示效果** 
• 一行可以显示多个  
• 可以设置宽高. inline-block



**7. 浮动元素会影响其后面的元素。**

当一个元素设置了浮动（`float`）属性后，它会尝试尽可能向左或向右浮动，导致其后面的元素会受到其影响。具体表现为，后面的元素会围绕浮动元素进行布局，以填充浮动元素所占据的空间。

这意味着在文档流中，浮动元素之后的元素会紧跟在浮动元素的后面，并且会在水平方向上靠近浮动元素。非浮动元素（即未设置浮动属性的元素）会尝试在浮动元素的旁边进行布局，而不会覆盖浮动元素。

需要注意的是，浮动元素不会影响其前面的元素，它们仍然按照文档流的顺序进行布局。

如果希望后面的元素不受浮动元素的影响，可以使用清除浮动（clear float）的技术，如在后面的元素上设置 `clear: left;`、`clear: right;` 或 `clear: both;`，以确保后续元素不浮动并且在浮动元素下方进行布局。

总结一下，浮动元素会影响其后面的元素，使得后续的元素围绕浮动元素进行布局。前面的元素不受浮动元素的影响，仍然按照文档流的顺序进行布局。
#### ➢ 注意点： 
**• 浮动的元素不能通过[[文本水平对齐方式 text-align|text-align]]:center或者[[外边框 margin|margin]]:0 auto**
你说得对，浮动元素无法通过设置 `text-align: center;` 或 `margin: 0 auto;` 来实现水平居中对齐。

浮动元素的布局特性会使它们**脱离正常的文档流**，并且浮动元素**会尽可能地靠近其包含块的左侧或右侧**。因此，`text-align: center;` 和 `margin: 0 auto;` 这些用于**居中对齐块级元素**的属性在浮动元素上不起作用。

如果你想要居中对齐浮动元素，可以考虑使用其他的布局方法，如使用相对定位（`position: relative;`）和负偏移（`left` 或 `right`）来实现水平居中。下面是一个示例：

```css
.container {
  position: relative;
}

.float-element {
  float: left;
  position: relative; /* 必须设置相对定位 */
  left: 50%;
  transform: translateX(-50%); /* 使用负偏移来实现水平居中 */
}
```

在上面的示例中，将包含浮动元素的容器设置为相对定位，并将浮动元素设置为相对定位。然后，使用 `left: 50%;` 将浮动元素的左边缘移动到容器的中心位置，最后使用 `transform: translateX(-50%);` 进行负偏移，将浮动元素的中心对齐到容器的中心位置，从而实现水平居中对齐。

这只是一种方法，具体的实现取决于你的布局需求和设计目标。根据具体情况，可能需要使用其他的布局技巧或组合多种方法来实现所需的居中效果。

当元素设置了浮动属性（如 `float: left` 或 `float: right`）时，它会从正常文档流中脱离出来，而且不再占据原来的位置。

这意味着，浮动元素**原来的位置会被周围的元素填补**，周围的元素会围绕浮动元素排列，**从而形成文本环绕效果**。具体来说，周围的块级元素会从上到下、从左到右依次排列，直到填满浮动元素离开的空间为止。

当浮动元素后面的元素也是浮动元素时，它们会按照浮动元素出现的顺序排列。如果两个浮动元素之间有空隙，那么后面的浮动元素会占据这个空隙。

同时，**浮动元素会影响父元素的高度**，如果**父元素没有设置高度**，则会自动适应浮动元素的高度。**如果父元素设置了高度，则可能会出现浮动元素溢出的情况，需要使用 `overflow` 属性来控制溢出的行为。**

需要注意的是，浮动元素的布局可能会受到其他因素的影响，如元素的位置、大小、背景等等。因此，在使用浮动布局时，需要仔细考虑这些因素，以确保布局的稳定性和可靠性。
