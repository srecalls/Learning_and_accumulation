# 双伪元素
#### 介绍
**同[[：after伪元素|:after伪元素]]类似，也是给父元素添加**

![[Pasted image 20220919215023.png]]
#### 代码：
```css
.clearfix::before, .clearfix::after {
			content: "";
			display: table;
		}
		
		.clearfix::after {
			clear: both;
		}
		
		.clearfix {
			*zoom: 1;
		}
```

#### 优缺点：
**●优点：代码更简洁
●缺点： 照顾低版本浏览器
●代表网站：小米、腾讯等**
