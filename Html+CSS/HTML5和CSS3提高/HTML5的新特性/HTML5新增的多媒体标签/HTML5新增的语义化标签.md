# HTML5新增的语义化标签

以前布局，我们基本用div来做。div对于搜索引擎来说，是没有语义的。
![[Pasted image 20220918133425.png]]

#### 介绍
\<header> :头部标签
\<nav>:导航标签
\<article>:内容标签
\<section>:定义文档某个区域
\<aside> :侧边栏标签
\<footer> :尾部标签


![[Pasted image 20220918134147.png]]

注意:
**●这种语义化标准主要是针对搜索引擎的
●这些新标签页面中可以使用多次
●在IE9中，需要把这些元素转换为块级元素
●其实，我们移动端更喜欢使用这些标签
●HTML5还增加了很多其他标签，我们后面再慢慢学**
