#### 广义的HTML5

1.广义的HTML5是**HTML5本身+ CSS3+ JavaScript**
2．这个集合有时称为HTML5和朋友，通常缩写为HTML5
3．虽然HTML5的一些特性仍然不被某些浏览器支持，但是它是一种发展趋势。
