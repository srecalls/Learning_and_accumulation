# 伪元素选择器

#### 1.介绍
伪元素选择器可以帮助我们利用**CSS创建新标签元素**，而不需要HTML标签，从而简化HTML结构。**伪元素是父元素的孩子**

伪元素默认是行内元素（`inline`）。

伪元素是在CSS中用来选择和样式化元素特定部分的虚拟元素。常见的伪元素包括 `::before` 和 `::after`，它们在选中元素的前面或后面创建一个虚拟的元素。

根据CSS规范，伪元素默认的 `display` 属性值是 `inline`，即行内元素。这意味着伪元素会按照行内元素的特性进行布局和显示，可以与其他行内元素放在同一行上。

然而，可以通过CSS样式来修改伪元素的 `display` 属性，以改变其布局行为。例如，将伪元素的 `display` 属性设置为 `block`，将其转换为块级元素，使其独占一行。

总结：伪元素默认是行内元素（`inline`），但可以通过CSS样式来改变其 `display` 属性，以改变其布局行为。

#### 注意∶
- before和after创建一个元素，但是属于行内元素
- 新创建的这个元素在文档树中是找不到的，所以我们称为伪元素
**- 语法: element::before** 
- before和after**必须有content属性**
- before在**父元素内容**的前面创建元素，after在父**元素内容**的后面插入元素
- 伪元素选择器和标签选择器一样，权重为**1**

伪元素选择器是 CSS 中用于选择元素的虚拟部分或状态的一种特殊选择器。它们允许您选择元素的某个特定部分或状态，并对其应用样式。

以下是常见的伪元素选择器及其用法：

1. `::before`：用于在选定元素的内容之前创建一个伪元素。
```css
.element::before {
  /* 样式规则 */
}
```

2. `::after`：用于在选定元素的内容之后创建一个伪元素。
```css
.element::after {
  /* 样式规则 */
}
```

3. `::first-line`：用于选择选定元素的第一行文本。
```css
.element::first-line {
  /* 样式规则 */
}
```

4. `::first-letter`：用于选择选定元素的第一个字母。
```css
.element::first-letter {
  /* 样式规则 */
}
```

这些伪元素选择器可以与其他选择器组合使用，以选择特定的元素，并对其进行样式化。例如，使用伪元素选择器来为段落的第一行设置特定样式：

```css
p::first-line {
  font-weight: bold;
  color: blue;
}
```

上述代码将选择所有 `<p>` 标签中的第一行文字，并将其设置为粗体并将颜色设置为蓝色。

请注意，伪元素选择器使用两个冒号 `::` 表示，以与伪类选择器（如 `:hover`、`:focus` 等）进行区分。然而，**为了向后兼容性，单个冒号 `:` 也仍然被支持，因此可以将 `::before` 和 `::after` 写为 `:before` 和 `:after`。**

使用伪元素选择器可以实现更精细的样式控制，以及创建一些特殊效果和装饰，如在元素前后插入内容、样式化首字母等。

`content` 属性可以接受多种不同类型的值，具体取决于您想要在伪元素中插入的内容的类型。以下是常见的 `content` 属性值的示例：

1. 文本内容: 插入文本内容时，可以直接将文本放在引号内。
```css
::before {
  content: "前缀文本";
}
```

2. HTML 实体: 您可以使用 HTML 实体来插入特殊字符或符号。
```css
::after {
  content: "\2022"; /* 使用实体编码插入圆点符号 */
}
```

3. 图片: 您可以使用 `url()` 函数来插入图像。
```css
::before {
  content: url(image.png);
}
```

4. 属性值: 您可以使用 `attr()` 函数来插入元素的属性值。
```css
::before {
  content: attr(data-text); /* 插入元素的 data-text 属性值 */
}
```
当使用 `attr()` 函数时，您可以插入元素的属性值作为伪元素的内容。这对于在伪元素中显示元素的文本内容或其他属性值非常有用。以下是一个示例，演示如何插入元素的 `data-text` 属性值：

HTML 代码：
```html
<div data-text="这是一个示例文本">内容</div>
```

CSS 代码：
```css
div::before {
  content: attr(data-text);
  font-weight: bold;
}
```

在上述示例中，我们有一个 `<div>` 元素，并设置了一个 `data-text` 属性，其值为 "这是一个示例文本"。然后，通过使用 `attr(data-text)` 将 `data-text` 属性的值插入到 `::before` 伪元素中，我们可以在伪元素的内容中显示该文本。

伪元素的 `content` 属性将使用 `attr(data-text)` 获取 `data-text` 的值，并将其作为伪元素的内容。此外，我们还为伪元素设置了 `font-weight: bold;`，以使其内容显示为粗体文本。

最终的效果是，在 `<div>` 元素之前插入了一个伪元素，内容为 "这是一个示例文本"，并且以粗体显示。

请注意，`attr()` 函数还可以用于插入其他属性值，如 `attr(src)`、`attr(href)` 等，以根据需要显示元素的不同属性。


5. 无内容: 如果您只想在伪元素中插入一个装饰性的元素，而不需要实际的内容，可以将 `content` 设置为空字符串或使用其他无意义的值。
```css
::after {
  content: ""; /* 插入空内容 */
}
```

这些只是 `content` 属性的一些示例值。您可以根据需要选择适当的值类型，并根据您的设计需求进行样式化和装饰。请注意，某些值可能需要使用引号或其他标记来正确解析。


对于 `div::after` 这个选择器，表示在 `div` 元素的内容之后插入一个伪元素。**这个伪元素与 `div` 元素是兄弟关系，而不是父子关系**。

例如，考虑以下 HTML 结构：

```html
<div class="parent">
  Content
</div>
```

使用 `div::after` 选择器并设置一些样式：

```css
div::after {
  content: "After";
  display: block;
  color: red;
}
```

在这种情况下，生成的效果将如下所示：

```html
<div class="parent">
  Content
</div>
After
```

可以看到，`::after` 生成的伪元素在 `div` 元素的内容之后，并且它们是兄弟元素的关系，而不是父子关系。
