结构伪类选择器用于选择符合特定结构或位置条件的元素。它们允许您根据元素在其父级或同级中的位置来选择元素。以下是一些常见的结构伪类选择器的示例：

1. `:first-child`：选择作为其父级的第一个子元素的元素。
```css
ul li:first-child {
  /* 样式规则 */
}
```

2. `:last-child`：选择作为其父级的最后一个子元素的元素。
```css
ul li:last-child {
  /* 样式规则 */
}
```

3. `:nth-child(n)`：选择作为其父级的第 n 个子元素的元素，其中 n 是一个整数或公式。
```css
ul li:nth-child(2) {
  /* 样式规则 */
}
```

4. `:nth-last-child(n)`：选择作为其父级的倒数第 n 个子元素的元素，其中 n 是一个整数或公式。
```css
ul li:nth-last-child(2) {
  /* 样式规则 */
}
```

5. `:nth-of-type(n)`：选择作为其父级中指定类型的第 n 个子元素的元素，其中 n 是一个整数或公式。
```css
p:nth-of-type(odd) {
  /* 样式规则 */
}
```

6. `:nth-last-of-type(n)`：选择作为其父级中指定类型的倒数第 n 个子元素的元素，其中 n 是一个整数或公式。
```css
p:nth-last-of-type(2) {
  /* 样式规则 */
}
```

7. `:only-child`：选择作为其父级的唯一子元素的元素。
```css
div:only-child {
  /* 样式规则 */
}
```

8. `:only-of-type`：选择作为其父级中指定类型的唯一子元素的元素。
```css
span:only-of-type {
  /* 样式规则 */
}
```

这些结构伪类选择器可以根据元素在其父级或同级中的位置选择特定的元素，并对其应用样式。这样，您可以根据需要对不同位置的元素进行样式化或调整布局。
