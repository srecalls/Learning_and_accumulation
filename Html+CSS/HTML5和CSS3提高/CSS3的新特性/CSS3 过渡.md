# CSS3 过渡
#### 介绍
**过渡(transition)**
是CSS3中具有颠覆性的特征之一，我们可以在不使用Flash 动画或JavaScript的情况下，当元素从一种样式变换为另一种样式时为元素添加效果。
**过渡动画:是从一个状态渐渐的过渡到另外一个状态**
可以让我们页面更好看，更动感十足，虽然低版本浏览器不支持( ie9以下版本)
但是不会影响
页面布局。
**我们现在经常和[[hover伪类选择器|:hover]]一起搭配使用。**
