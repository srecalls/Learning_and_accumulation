如果你想要避免写多个重复的函数，可以考虑将函数定义为可重用的函数，然后在多个组件中共享这个函数。

具体来说，你可以将年级和学院的选择器提取为一个组件，例如 `GradeCollegeSelect`，然后在这个组件中定义 `selection` 对象和 `handleGradeChange` 和 `handleCollegeChange` 事件处理函数。然后，你可以在需要使用这两个选择器的地方，使用 `GradeCollegeSelect` 组件，并将 `selection` 和事件处理函数作为 props 传递给这个组件。

下面是一个示例代码：

GradeCollegeSelect.vue：

```html
<template>
  <div>
    <a-select
      v-model="selection.gradeValue"
      show-search
      placeholder="请选择年级"
      style="width: 150px;margin-right:20px"
      :options="grade"
      :filter-option="filterOption"
      @change="handleGradeChange"
    >
    </a-select>
    <a-select
      show-search
      v-model="selection.collegeValue"
      placeholder="请选择学院"
      style="width: 150px"
      :options="college"
      :filter-option="filterOption"
      @change="handleCollegeChange"
    >
    </a-select>
  </div>
</template>

<script>
export default {
  name: 'GradeCollegeSelect',
  props: {
    selection: Object,
    grade: Array,
    college: Array,
    filterOption: Function,
    onGradeChange: Function,
    onCollegeChange: Function,
  },
  methods: {
    handleGradeChange (value) {
      this.selection.gradeValue = value
      this.selection.collegeValue = null
      this.onGradeChange && this.onGradeChange(value)
    },
    handleCollegeChange (value) {
      this.selection.collegeValue = value
      this.onCollegeChange && this.onCollegeChange(value)
    }
  }
}
</script>
```

然后，在你的主组件中，你可以这样使用 `GradeCollegeSelect` 组件：

```html
<a-card class="card table" title="延毕表">
  <div slot="extra" style="height: inherit;">
    <grade-college-select
      :selection="selection"
      :grade="grade"
      :college="college"
      :filter-option="filterOption"
      :on-grade-change="handleGradeChange"
      :on-college-change="handleCollegeChange"
    ></grade-college-select>
  </div>
  <div class="table-body">
    <!-- 省略部分代码 -->
  </div>
</a-card>

<a-card class="card line" title="班级热力图">
  <div slot="extra" style="height: inherit;">
    <grade-college-select
      :selection="selection2"
      :grade="grade"
      :college="college"
      :filter-option="filterOption"
      :on-grade-change="handleGradeChange2"
      :on-college-change="handleCollegeChange2"
    ></grade-college-select>
  </div>
  <!-- 省略部分代码 -->
</a-card>
```

这样，你就可以在多个组件中共享年级和学院的选择器，而不需要重复编写相同的代码。同时，因为 `GradeCollegeSelect` 组件是可重用的，你还可以在其他地方使用它。
