# 计算属性Computed
![[Pasted image 20230227201540.png]]

在 Vue 中，`computed` 属性可以用来定义一个计算属性。在 `computed` 中，你可以定义一个 `get` 函数，用于获取计算属性的值，也可以定义一个 `set` 函数，用于在计算属性被设置时执行一些操作。

下面是一个简单的示例，其中定义了一个名为 `fullName` 的计算属性，它由 `firstName` 和 `lastName` 两个属性组成：

javascript

Copy

```
var vm = new Vue({
  data: {
    firstName: 'John',
    lastName: 'Doe'
  },
  computed: {
    fullName: {
      // 定义计算属性的 get 函数
      get: function () {
        return this.firstName + ' ' + this.lastName
      },
      // 定义计算属性的 set 函数
      set: function (newFullName) {
        var names = newFullName.split(' ')
        this.firstName = names[0]
        this.lastName = names[names.length - 1]
      }
    }
  }
})
```

在上面的示例中，`fullName` 的 `get` 函数返回 `firstName` 和 `lastName` 的组合字符串，而 `set` 函数则将 `newFullName` 拆分为两个字符串，分别对 `firstName` 和 `lastName` 进行设置。

当你在模板中使用 `fullName` 属性时，Vue 会自动调用 `get` 函数来获取属性的值。而当你在代码中设置 `fullName` 属性时，Vue 会自动调用 `set` 函数来执行一些操作。这种方式使得我们可以通过一个属性来控制多个属性的值，从而简化模板和代码的编写。

需要注意的是，当你定义了一个带有 `set` 函数的计算属性时，你需要同时定义一个 `get` 函数，否则计算属性将无法正常工作。
