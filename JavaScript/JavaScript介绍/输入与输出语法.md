## 输出语法

### document.write()
![[Pasted image 20230308215948.png]]
![[Pasted image 20230308215920.png]]

document.write()是JavaScript中的一个方法，它的作用是向HTML文档写入内容。

当在HTML文档中使用JavaScript时，可以使用document.write()方法来动态地向文档中写入内容。使用这个方法，可以将HTML标记和文本插入到文档中，并可以在任何地方使用它，例如在页面加载时、在按钮点击时或在其他事件触发时。

例如，以下代码会将一个段落插入到文档中：

```js
document.write("<p>这是一个段落。</p>");
```

注意，使用document.write()方法会覆盖整个文档，因此必须小心使用。通常，更好的方法是使用DOM API来动态地创建、修改和删除文档元素。
