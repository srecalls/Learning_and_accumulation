## 事件委托
### 获取真正触发事件的元素 e.target.tagName
![[Pasted image 20230310124455.png]]
![[Pasted image 20230310124418.png]]



在事件委托中，`currentTarget` 和 `target` 是两个相关的属性，它们用于访问事件的目标元素和当前处理事件的元素。它们的区别如下：

1. `target` 属性：
   - 表示触发事件的目标元素，即事件最初发生的元素。它是事件流经过的当前元素，可以理解为事件的实际目标。
   - 在事件冒泡过程中，`target` 保持不变，始终表示最初触发事件的元素。
   - `target` 属性是只读的，无法被修改。

2. `currentTarget` 属性：
   - 表示当前正在处理事件的元素，即事件当前所绑定的元素。它是事件处理函数绑定的元素，也可以是该元素的父级或祖先元素。
   - 在事件冒泡过程中，`currentTarget` 的值会随着事件的传播而改变，始终表示当前处理事件的元素。
   - `currentTarget` 属性可以在事件处理函数中被修改，例如使用 `event.currentTarget = someElement` 来改变事件的当前处理元素。

下面以一个示例来说明这两个属性的区别：

```html
<div id="parent">
  <button id="child">Click me!</button>
</div>
```

```javascript
document.getElementById('parent').addEventListener('click', function(event) {
  console.log('currentTarget:', event.currentTarget.id);
  console.log('target:', event.target.id);
});
```

当点击按钮时，事件会冒泡从子元素传递到父元素。假设点击按钮，输出如下：

```
currentTarget: parent
target: child
```

可以看到，`currentTarget` 始终表示绑定事件处理函数的元素，即父元素，而 `target` 表示触发事件的目标元素，即子元素。

需要注意的是，事件委托是通过将事件处理函数绑定在父元素上，利用事件冒泡机制来处理子元素的事件。通过检查 `event.target` 来确定是哪个子元素触发了事件，从而执行相应的处理逻辑。这样可以避免为每个子元素都绑定事件处理函数，提高性能和代码的可维护性。
