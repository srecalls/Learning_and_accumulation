## 阻止默认行为 preventDefault
![[Pasted image 20230310125547.png]]
![[Pasted image 20230310125634.png]]

当你需要阻止事件冒泡时，可以使用以下方法：

```javascript
element.addEventListener('click', function (event) {
  event.stopPropagation();
});
```

在这个例子中，当元素被点击时，`event.stopPropagation()`将阻止事件冒泡，即阻止事件传播到父元素。

当你需要阻止元素的默认行为时，可以使用以下方法：

```javascript
element.addEventListener('click', function (event) {
  event.preventDefault();
});
```

在这个例子中，当元素被点击时，`event.preventDefault()`将阻止元素执行默认的行为，例如跳转到链接的URL或提交表单。

请注意，上述代码中的`element`是你想要绑定事件的HTML元素。你可以将其替换为具体的元素选择器或变量名，以适应你的代码。
