2. 数组求最大值的两种方法
```js
const arr = [3, 5, 2, 9]
// 原
console.log(Math.max(3, 5, 2, 9))
console.log(Math.max.apply(null, arr)) // Math.max这个函数名后面接apply改变指向
```

3. this指向
```js
1. 普通函数调用没有明确调用者时this值为window，严格模式下this值为undefined
2. this引用就是最近作用域中的this，向外层作用域中，一层一层查找this，直到有this的定义
```

### 深浅拷贝
1. 深浅拷贝
```js
浅拷贝
1. 拷贝的是地址
2. 如果是简单数据类型，就拷贝值。引用数据类型就拷贝地址。
3. 常用方法
对象：Object.assign() // {...obj}
数组：Array.prototype.concat() 或 [...arr]

深拷贝
1. 拷贝的是对象，不是地址
2. 常用方法
- JSON.stringify()
- lodash的cloneDeep
```

## 性能优化
1. 防抖和节流
```js
防抖(debounce)
1. 回城，打断就重新来过
2. 单位时间，频繁触发事件，只执行最后一次

节流(throttle)
1. 使用技能，n秒内只能执行一次
2. 单位时间，频繁触发事件，只执行一次
```

包装类型

引用类型

### 深入对象
1. 构造函数实例化
```js
1. 创建空对象
2. 构建函数this指向新对象
3. 执行构造函数代码，修改this，添加新的属性
4. 返回新对象

// 1. 创建构造函数
function Pig(name) {
	this.name = name
}

// 2. new 关键字调用函数
// new Pig("佩奇")
// 接受创建的对象
const peppa = new Pig("佩奇")
console.log(peppa) // { name: "佩奇"}
```
