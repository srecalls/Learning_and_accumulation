## 函数进阶
1. 动态参数（arguments）
```js
arguments是函数内部内置的"伪数组"变量, 它包含了调用"函数"时传入的所有实参
1. arguments时一个伪数组，"只存在于函数中"
2. 可以通过for循环来依次获得传递过来的实参

arguments不是函数参数，就是他不是函数的实参，他在函数里直接用
function test(arguments) {
	console.log(arguments) // 1
}
test(1,2,3)
function test() {
	console.log(arguments) // Arguments为数组
}

```
2. 剩余参数（...)
```ts
剩余参数
1. ...是语法符号，置于"最末函数形参"之前，用于获取"多余"的实参
2. 借助...获取的剩余实参, 是个"真数组"
function config(baseURL, ...other) {
	console.log(baseURL) // 'a'
	console.log(other)  // ['b', 'c']
}

function config(baseURL) {
	console.log(baseURL) // 'a'
}
function config(...baseURL) {
	console.log(baseURL) // ['a', 'b', 'c']
}
config('a', 'b', 'c')


动态参数是"伪数组"，
剩余参数是"真数组"
```

2. 对象解构
```js
1. 对象属性的值将赋值给与属性名"相同的"变量
2. 对象中找不到与变量名一致的属性时变量值为undefined

```

3. 数组赋值
```js
"变量的顺序"对应数组"单元值的顺序""依次"进行赋值操作
1. 情况1，变量多单元值少
const [a, b, c, d] = [1, 2, 3]
// 1, 2, 3, undefined

2. 情况2, 变量少单元值多
const [a, b, c] = [1, 2, 3, 4]
// 1, 2, 3
可以用"剩余参数"进行赋值
const [a, b, ...c] = [1, 2, 3, 4]
// 1, 2, [3, 4]

3. 默认值
const [a = '1', b = '2'] = [1]
// 1, '2'
只有在变量值为undefined时，默认值生效

4. 按需获取
const [a, , c, d] = [1, 2, 3, 4]
// 1, 3, 4

5. 多维数组也接受
const [a, b, [c, d]] = [1, 2, [3, 4]]
// 1, 2, 3, 4
```

### 原型
1. 原型
```js
1. 构造函数通过原型分配的函数是所有对象所"共享的"
2. 每一个"构造函数"都有一个"prototype属性",指向另一个对象,这个对象称为原型对象
3. 原型对象可以挂载函数，"对象实例化"不会多次创建原型上的函数
4. 不变的函数可以定义在"prototype"上，这样对象的实例就可以共享这些方法
5. "构造函数"和"原型对象"的"this"都指向实例化的对象
```

2. 对象原型
```js
实例对象可以访问到原型对象上方法的原因
1. 对象都有一个"属性""__proto__"，这个"__proto__"指向"构造函数的prototype原型对象"，之所以可以"使用"构造函数prototype"原型对象的属性和方法"，就是因为对象有"__proto__原型"的存在
2."__proto__"作用适用于表明当前的实例对象指向的是哪个原型对象的prototype的
3. "__proto__"对象原型里面也有一个constructor属性，"指向创建该对象的构造函数"
```
