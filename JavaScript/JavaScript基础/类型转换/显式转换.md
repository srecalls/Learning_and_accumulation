## 转为number数字型
![[Pasted image 20230309102634.png]]
直接将参数传递给函数并在函数内部将其转换为二进制数字符串。例如：
而且必须是字符串

```
var n = "0100";
hammingWeight(parseInt(n, 8).toString(2));
```
