## 使用for…in和for…of的区别
for…of遍历出的结果是value；for…in遍历出的结果是key
```js
        var numbers = ['一','二','三']

        for(let num of numbers){
            console.log(num);
        }

        for(let num in numbers){
            console.log(num);
        }
```
