一个嵌套对象，拍平对象，实现一个key对应一个简单类型的值  

要将嵌套对象拍平并实现每个键对应一个简单类型的值，你可以使用递归算法来处理嵌套对象的每个键值对。下面是一个示例的 JavaScript 代码，可以实现该功能：

```javascript
function flattenObject(obj, prefix = '') {
  let result = {};

  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      let propName = prefix ? `${prefix}.${key}` : key;
      if (typeof obj[key] === 'object' && !Array.isArray(obj[key])) {
        let nestedObj = flattenObject(obj[key], propName);
        result = { ...result, ...nestedObj };
      } else {
        result[propName] = obj[key];
      }
    }
  }

  return result;
}

// 示例对象
const nestedObject = {
  key1: 'value1',
  key2: {
    nestedKey1: 'nestedValue1',
    nestedKey2: {
      doubleNestedKey: 'doubleNestedValue'
    }
  },
  key3: 'value3'
};

// 拍平对象
const flattenedObject = flattenObject(nestedObject);
console.log(flattenedObject);
```

运行以上代码，你将得到如下拍平后的对象：

```javascript
{
  "key1": "value1",
  "key2.nestedKey1": "nestedValue1",
  "key2.nestedKey2.doubleNestedKey": "doubleNestedValue",
  "key3": "value3"
}
```

拍平后的对象中，每个键都对应一个简单类型的值。嵌套的键被连接成一个字符串，使用`.`作为分隔符。你可以根据需要对拍平后的对象进行进一步处理或使用。
