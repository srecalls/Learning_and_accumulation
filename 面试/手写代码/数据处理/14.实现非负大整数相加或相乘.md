JavaScript对数值有范围的限制，限制如下
```js

Number.MAX_VALUE //1.7976931348623157e+30823
Number.MAX SAFE INTEGER // 9007199254740991
Number.MIN_VALUE // 5e-324
Number.MIN SAFE INTEGER // -9007199254740991
```

(1)大数相加
如果想要对一个超大的整数(> `Number.MAX SAFE INTEGER` )进行加法运算，但是又想输出一般形式，那么使用 + 是无法达到的，一旦数字超过 `Number.MAX SAFEINTEGER` 数字会被立即转换为科学计数法，并且数字精度相比以前将会有误差。
实现一个算法进行大数的相加:
```js
function sumBigNumber(a, b) {
	let res = ''
	let temp = 0
	let numberA = a.split('')
	let numberB = a.split('')
	while(numberA || numberB || temp) {
		temp = temp + ~~numberA.pop() + ~~numberB.pop()
		res = res + temp % 10
		temp = temp > 9 ? 1 : 0	
	}
}
```
