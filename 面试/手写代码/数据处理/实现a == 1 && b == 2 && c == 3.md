在javascript中几乎所有的方法都有valueOf方法，这是一个内置方法，用于返回对象的原始值
[[JS 中 valueOf() 方法的详解]]

当需要将对象转换成原始值时，javascript引擎会自动调用对象里的valueOf方法，关键在于重写这个方法，实现这个需求，同时这里用到了 == 号，涉及到了隐式转换

## 解法
### 解法一
```js
let a = {
	value: 1,
	valueOf: function() {
		return this.value++
	}
}
```


### 解法二
```js
var i = 1
Number.prototype.valueOf = function() {
    return i++
}
var a = new Number(1)
if (a == 1 && a == 2 && a == 3) {
    console.log('here')
}
```

## 注意：
```Js
let a = {
	value: 1,
	valueOf: function() {
		return this.value++
	}
}
console.log(a == '1' && a == '2' && a=='3')
// 这里也为true
```

这是一个有趣的问题，涉及到 JavaScript 中的类型转换和比较运算符。

在 JavaScript 中，当使用相等运算符（\=\=）比较两个不同类型的值时，会进行类型转换。在这种情况下，比较运算符会调用对象的 `valueOf()` 方法，将对象转换为原始值，然后再进行比较。

在给定的代码中，对象 `a` 定义了一个 `valueOf()` 方法，它返回 `this.value++`。这意味着每次调用 `valueOf()` 方法时，都会返回 `this.value` 的当前值，并将其递增。

当执行 `a == '1'` 时，JavaScript 引擎会自动调用 `a` 对象的 `valueOf()` 方法，将其转换为原始值进行比较。由于 `this.value` 的初始值为 1，第一次比较时，`a` 被转换为数值类型的 1，然后与字符串 `'1'` 进行比较，因为类型不同，字符串 `'1'` 会被转换为数值类型的 1。由于它们相等，返回结果为 `true`。

接着执行 `a == '2'`，此时 `a` 的 `valueOf()` 方法再次被调用，返回当前的 `this.value`（已经是 2），然后将其与字符串 `'2'` 进行比较。同样，由于类型不同，字符串 `'2'` 被转换为数值类型的 2。由于它们相等，返回结果为 `true`。

最后执行 `a == '3'`，同样会调用 `valueOf()` 方法将 `a` 转换为数值类型的 3，然后与字符串 `'3'` 进行比较。由于它们相等，返回结果为 `true`。

因此，整个表达式 `a == '1' && a == '2' && a=='3'` 的结果为 `true`。

这种比较的结果可能会令人困惑，因为它依赖于对象的 `valueOf()` 方法和类型转换的行为。在实际开发中，为了避免这种混淆，通常建议使用严格相等运算符（===），它不会进行类型转换，只有在类型和值都相同的情况下才会返回 `true`。
