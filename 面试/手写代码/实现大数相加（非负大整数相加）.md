JavaScript对数值有范国的限制，限制如下：


```js
Number.MAX_VALUE // 1.7976931348623157e+308

Number.MAX_SAFE_INTEGER // 9007199254740991

Number. MIN_VALUE // 5e-324

Number.MIN_SAFE_INTEGER //-9007199254740991
```

(1)大数相加
如果想要对一个超大的整数`(>Number.MAX SAFE INTEGER )`进行加法运算，但是又想输出一般形式，那么使用 + 是无法达到的，一旦数字超过 `Number.MAX_SAFE_INTEGER`数字会被立即转换为科学计数法，并且数字精度相比以前将会有误差。
实现一个算法实现大数相加
```js
function sumBigNumber(a, b) {
	let res = ''
	let temp = 0
	a = a.split('')
	b = b.split('')
	while (a.length || b.length || temp) {
		temp += ~~a.pop() + ~~b.pop()
		res = (temp % 10) + res
		temp = temp > 9 : 1 ? 0
	}
	return res.replace(/^0+/, '')
}
```

其主要的思路如下:
- 首先用字符串的方式来保存大数，这样数字在数学表示上就不会发生变化
- 初始化res，temp来保存中间的计算结果，并将两个字符串转化为数组，以便进行每一位的加法运算
- 将两个数组的对应的位进行相加，两个数相加的结果可能大于10，所以可能要仅为对10进行取余操作，将结果保存在当前位
- 判断当前位是否大于9，也就是是否会进位，若是则将temp赋值为true，因为在加法运算中，true会自动隐式转化为1，以便于下一次相加
- 重复上述操作，直至计算结束

在这个函数中，`temp > 9` 是一个条件语句，它的含义是判断上一次计算是否产生了进位，如果产生了进位，那么将 `temp` 的值设为 `1`，否则 `temp` 的值仍然为 `0`。

具体地说，这个函数是用来计算两个大数相加的结果的。在每一次计算中，我们从两个数的个位开始，将它们相加并加上上一次计算的进位标志 `temp`，然后将计算结果的个位插入到结果字符串 `res` 的最前面。如果这次计算产生了进位，那么将 `temp` 的值设为 `1`，否则设为 `0`。然后我们继续处理两个数的十位、百位、千位等等，直到两个数的所有位都被处理完毕。

最后，我们需要将结果字符串 `res` 的前导零去掉，然后返回最终的结果。

因此，当 `temp > 9` 时，它表示上一次计算产生了进位，需要将 `temp` 的值设为 `1`，否则 `temp` 的值仍然为 `0`。


`~` 是 JavaScript 中的一种位运算符，叫做按位非运算符（Bitwise NOT operator）。它的作用是将一个数的二进制表示中的每一位取反，然后返回这个数的反码。

**在这个函数中，`~~` 的作用是将一个字符串转换为整数。具体地说，它将字符串转换为整数后进行取反运算，然后再次取反，相当于对这个整数进行了一次舍去小数部分的操作，得到了整数的值。**

这种方式将**字符串转换为整数**的方法是一种比较简单的方式，但是它只适用于非负整数。如果字符串中包含负号，那么这种方法将会得到错误的结果。在实际开发中，为了避免这种问题，我们通常会使用更加健壮的方法，比如使用 `parseInt()` 函数或者正则表达式来进行字符串转换。
