用一个滑动窗口装没有重复的字符，枚举字符记录最大值即可。用map维护字符的索引，遇到相同的字符，把左边界移动过去即可。挪动的过程中记录最大长度:

```js
// 计算给定字符串中最长的无重复字符的子串长度
var lengthOfLongestSubstring = function(s) {
    let map = new Map(); // 用 Map 存储字符和它们的索引
    let i = -1; // i 为滑动窗口的左边界
    let res = 0; // res 记录最长的无重复字符的子串长度
    let n = s.length; // 字符串的长度
    for (let j = 0; j < n; j++) { // j 为滑动窗口的右边界
        if (map.has(s[j])) { // 如果当前字符在 Map 中已经存在
            i = Math.max(i, map.get(s[j])); // 移动左边界，确保左边界不会向左移动
        }
        res = Math.max(res, j - i); // 更新最长的无重复字符的子串长度
        map.set(s[j], j); // 将字符和它的索引存入 Map 中
    }
    return res; // 返回最长的无重复字符的子串长度
};
// abcabcbb

```

这段代码使用了滑动窗口算法来解决最长无重复字符子串的问题。具体来说，它维护了一个滑动窗口，窗口的左边界为i，右边界为j。在遍历字符串时，如果当前字符在Map中已经存在，说明当前字符与前面的字符重复了，需要将左边界i向右移动，直到左边界i对应的字符在Map中只出现一次为止。在每次移动左边界i或右边界j时，都会更新最长的无重复字符的子串长度，最后返回该长度即可。由于使用了Map来存储字符和它们的索引，所以时间复杂度是O(n)，其中n是字符串的长度。
