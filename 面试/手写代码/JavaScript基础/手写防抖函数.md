	函数防抖是指在事件被触发 n 秒后再执行回调，如果在这 n 秒内事件又被触发，则重新计时。这可以使用在一些点击请求的事件上，避免因为用户的多次点击向后端发送多次请求。

```js
function debounce(fn, wait) {
	let timer = null
	return function() {
		let context = this
		let args = arguments
		// 如果此时存在定时器的话, 则取消之前的定时器重新计时
		if (timer) {
			clearTimeout(timer)
			timer = null
		}
		// 设置定时器, 使事件间隔指定事件后执行
		timer = setTimeout(() => {
			fn.apply(context, args)
		}, wait)
	}
}
```

## 例子
`debounce`函数是一种常用的函数节流方法，可以用于控制函数的执行频率，避免函数在短时间内被多次调用而导致性能问题。以下是一个使用`debounce`函数的例子：

```javascript
// 定义一个函数，用于在窗口滚动时输出当前滚动位置
function onWindowScroll() {
  console.log('Window scroll position:', window.scrollY)
}

// 使用debounce函数包装onWindowScroll函数，使其在滚动结束后才执行
const debounceOnWindowScroll = debounce(onWindowScroll, 1000)

// 给window对象绑定滚动事件
window.addEventListener('scroll', debounceOnWindowScroll)
```

在上述代码中，我们定义了一个`onWindowScroll`函数，用于在窗口滚动时输出当前滚动位置。然后，我们使用`debounce`函数包装`onWindowScroll`函数，将其转化为一个具有函数节流功能的新函数`debounceOnWindowScroll`。最后，我们将`debounceOnWindowScroll`函数绑定到window对象的滚动事件上，使其在滚动结束后才执行。

在这个例子中，`debounce`函数的第一个参数是要进行节流的函数（即`onWindowScroll`函数），第二个参数是时间间隔（即1000毫秒）。当`debounceOnWindowScroll`函数被执行时，会先检查是否存在之前设置的定时器，如果存在则先清除之前的定时器，再重新设置一个新的定时器，使得`fn`函数在`wait`毫秒之后执行。这样，即使在`wait`毫秒内多次触发了`debounceOnWindowScroll`函数，也只会执行一次`fn`函数，避免了函数频繁执行导致的性能问题。
