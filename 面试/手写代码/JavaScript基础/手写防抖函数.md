	函数防抖是指在事件被触发 n 秒后再执行回调，如果在这 n 秒内事件又被触发，则重新计时。这可以使用在一些点击请求的事件上，避免因为用户的多次点击向后端发送多次请求。

```js
function debounce(fn, wait) {
	let timer = null
	return function() {
		let context = this
		let args = arguments
		// 如果此时存在定时器的话, 则取消之前的定时器重新计时
		if (timer) {
			clearTimeout(timer)
			timer = null
		}
		// 设置定时器, 使事件间隔指定事件后执行
		timer = setTimeout(() => {
			fn.apply(context, args)
		}, wait)
	}
}
```

## vue实现

在 Vue 中实现防抖功能可以通过以下几种方式：

## 1. 使用 Lodash 库的防抖函数：
   - 首先，确保已经安装了 Lodash 库：`npm install lodash`
   - 在需要应用防抖的方法中，引入 lodash 的 `debounce` 函数，并在方法中使用它：
     ```javascript
     import { debounce } from 'lodash';
     
     export default {
       // ...
       methods: {
         // 需要应用防抖的方法
         debounceMethod: debounce(function() {
           // 在这里编写你的逻辑
         }, 500), // 设置防抖的延迟时间，单位为毫秒
       },
     };
     ```

## 2. 自定义防抖函数：
   - 在 Vue 的组件中，定义一个防抖函数，例如 `debounceFunc`。
   - 在需要应用防抖的方法中，调用 `debounceFunc` 函数。
   - 在组件的 `methods` 中添加以下代码：
     ```javascript
     export default {
       // ...
       data() {
         return {
           // ...
           timer: null,
         };
       },
       methods: {
         // 自定义防抖函数
         debounceFunc: function(func, delay) {
           // 清除定时器
           clearTimeout(this.timer);
           // 创建新的定时器
           this.timer = setTimeout(func, delay);
         },
         // 需要应用防抖的方法
         debounceMethod: function() {
           this.debounceFunc(function() {
             // 在这里编写你的逻辑
           }, 500); // 设置防抖的延迟时间，单位为毫秒
         },
       },
     };
     ```
     
```js
<template>
  <div>
    <input @change="debounceInput" :value="data"/>
  </div>
</template>

<script>
export default {
  name: 'my-component',
  data() {
    return {
      timer: null,
      placeholder: '',
      data: ''
    }
  },
  method: {
    debounce(func, delay) {
      clearTimeout(this.timer)
      this.timer = setTimeout(func, delay)
    },
    input() {
      this.data = "1111"
    },
    debounceInput() {
      this.debounce(input, 500)
    }
  }
}
</script>
```

以上两种方式都可以实现防抖功能，你可以根据项目需求选择其中一种方式来应用防抖。

## 例子
`debounce`函数是一种常用的函数节流方法，可以用于控制函数的执行频率，避免函数在短时间内被多次调用而导致性能问题。以下是一个使用`debounce`函数的例子：

```javascript
// 定义一个函数，用于在窗口滚动时输出当前滚动位置
function onWindowScroll() {
  console.log('Window scroll position:', window.scrollY)
}

// 使用debounce函数包装onWindowScroll函数，使其在滚动结束后才执行
const debounceOnWindowScroll = debounce(onWindowScroll, 1000)

// 给window对象绑定滚动事件
window.addEventListener('scroll', debounceOnWindowScroll)
```

在上述代码中，我们定义了一个`onWindowScroll`函数，用于在窗口滚动时输出当前滚动位置。然后，我们使用`debounce`函数包装`onWindowScroll`函数，将其转化为一个具有函数节流功能的新函数`debounceOnWindowScroll`。最后，我们将`debounceOnWindowScroll`函数绑定到window对象的滚动事件上，使其在滚动结束后才执行。

在这个例子中，`debounce`函数的第一个参数是要进行节流的函数（即`onWindowScroll`函数），第二个参数是时间间隔（即1000毫秒）。当`debounceOnWindowScroll`函数被执行时，会先检查是否存在之前设置的定时器，如果存在则先清除之前的定时器，再重新设置一个新的定时器，使得`fn`函数在`wait`毫秒之后执行。这样，即使在`wait`毫秒内多次触发了`debounceOnWindowScroll`函数，也只会执行一次`fn`函数，避免了函数频繁执行导致的性能问题。
