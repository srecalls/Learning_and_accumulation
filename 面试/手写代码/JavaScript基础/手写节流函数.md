	函数节流是指规定一个单位时间，在这个单位时间内，只能有一次触发事件的回调函数执行，如果在同一个单位时间内某事件被触发多次，只有一次能生效。节流可以使用在 scroIl 函数的事件监听上，通过事件节流来降低事件调用的频率。
```js
// 函数节流的实现
function throttle(fn, delay) {
	let curTime = Data.now()
	return function() {
		let context = this
		let args = arguments
		let nowTime = Data.now()
		// 如果两次事件间隔超过了指定事件,则执行函数
		if (nowTime - curTime >= delay) {
			curTime = Data.now()
			return fn.apply(context, delay)
		}
	}
}
```


## vue实现节流

在 Vue 中实现节流功能可以通过以下几种方式：

## 1. 使用 Lodash 库的节流函数：
   - 首先，确保已经安装了 Lodash 库：`npm install lodash`
   - 在需要应用节流的方法中，引入 lodash 的 `throttle` 函数，并在方法中使用它：
     ```javascript
     import { throttle } from 'lodash';
     
     export default {
       // ...
       methods: {
         // 需要应用节流的方法
         throttleMethod: throttle(function() {
           // 在这里编写你的逻辑
         }, 500), // 设置节流的间隔时间，单位为毫秒
       },
     };
     ```

## 2. 自定义节流函数：
   - 在 Vue 的组件中，定义一个节流函数，例如 `throttleFunc`。
   - 在需要应用节流的方法中，调用 `throttleFunc` 函数。
   - 在组件的 `methods` 中添加以下代码：
     ```javascript
     export default {
       // ...
       data() {
         return {
           // ...
           isThrottled: false,
         };
       },
       methods: {
         // 自定义节流函数
         throttleFunc: function(func, delay) {
           if (!this.isThrottled) {
             func();
             this.isThrottled = true;
             setTimeout(() => {
               this.isThrottled = false;
             }, delay);
           }
         },
         // 需要应用节流的方法
         throttleMethod: function() {
           this.throttleFunc(function() {
             // 在这里编写你的逻辑
           }, 500); // 设置节流的间隔时间，单位为毫秒
         },
       },
     };
     ```

以上两种方式都可以实现节流功能，你可以根据项目需求选择其中一种方式来应用节流。

## 例子
这个`throttle`函数实现了函数的节流，可以用来控制函数执行的频率，以避免函数在短时间内被多次调用而导致性能问题。以下是一个使用`throttle`函数的例子：

```javascript
// 定义一个函数，用于在窗口滚动时输出当前滚动位置
function onWindowScroll() {
  console.log('Window scroll position:', window.scrollY)
}

// 使用throttle函数包装onWindowScroll函数，使其在指定时间间隔内最多执行一次
const throttleOnWindowScroll = throttle(onWindowScroll, 1000)

// 给window对象绑定滚动事件
window.addEventListener('scroll', throttleOnWindowScroll)
```

在上述代码中，我们定义了一个`onWindowScroll`函数，用于在窗口滚动时输出当前滚动位置。然后，我们使用`throttle`函数包装`onWindowScroll`函数，将其转化为一个具有函数节流功能的新函数`throttleOnWindowScroll`。最后，我们将`throttleOnWindowScroll`函数绑定到window对象的滚动事件上，使其在指定时间间隔内最多执行一次。

在这个例子中，`throttle`函数的第一个参数是要进行节流的函数（即`onWindowScroll`函数），第二个参数是时间间隔（即1000毫秒）。当`throttleOnWindowScroll`函数被执行时，会先获取当前时间（即`nowTime`），然后与上一次执行时间（即`curTime`）进行比较，如果两次执行间隔超过了指定的时间间隔（即`delay`），则执行回调函数（即`fn.apply(context, args)`），并更新`curTime`变量的值，否则不执行回调函数。

这样，即使在短时间内多次触发`throttleOnWindowScroll`函数，也只会执行一次回调函数，避免了函数频繁执行导致的性能问题。

## 表单节流，倒计时60s

```jsx
import React, { useState, useEffect } from 'react';

const ThrottleWithCountdownExample = () => {
  const [countdown, setCountdown] = useState(60);
  const [isButtonDisabled, setIsButtonDisabled] = useState(false);

  useEffect(() => {
    let timerId;

    const handleCountdown = () => {
      setCountdown((prevCountdown) => prevCountdown - 1);
    };

    if (isButtonDisabled) {
      timerId = setInterval(handleCountdown, 1000);
    }

    return () => {
      clearInterval(timerId);
    };
  }, [isButtonDisabled]);

  const handleClick = () => {
    if (!isButtonDisabled) {
      setIsButtonDisabled(true);
      setCountdown(60);

      setTimeout(() => {
        setIsButtonDisabled(false);
      }, 60000);
    }
  };

  return (
    <div>
      <button onClick={handleClick} disabled={isButtonDisabled}>
        {isButtonDisabled ? `Countdown: ${countdown}s` : 'Start Countdown'}
      </button>
    </div>
  );
};

export default ThrottleWithCountdownExample;
```

在上述示例中，我们使用 `useState` 来存储倒计时的值 `countdown` 和按钮的禁用状态 `isButtonDisabled`。

在 `useEffect` 的回调函数中，我们创建一个 `timerId`，并定义一个 `handleCountdown` 函数来处理每秒减少倒计时的值。当按钮被禁用时（`isButtonDisabled` 为 `true`），我们使用 `setInterval` 来定时调用 `handleCountdown` 函数。

在组件的卸载或下一次 `useEffect` 回调执行之前，我们使用 `return` 语句清除计时器，以避免内存泄漏。

在按钮的点击事件处理函数中，我们首先检查按钮是否已禁用。如果按钮未禁用，则将按钮禁用，设置倒计时为60秒。然后，通过 `setTimeout` 在60秒后将按钮重新启用。

以上示例代码实现了点击后倒计时60秒的节流功能。在按钮被点击后的60秒内，按钮将被禁用，并显示当前的倒计时时间。一旦倒计时结束，按钮将重新启用。
