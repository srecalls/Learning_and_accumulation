您可以使用JavaScript编写一个函数来实现将输入框输入的数字转换为货币格式。以下是一个示例函数：

```javascript
function formatCurrency(input) {
  // 将输入转换为数字类型
  let num = parseFloat(input);

  // 判断输入是否为有效数字
  if (!isNaN(num)) {
    // 使用 toLocaleString() 方法将数字转换为货币格式
    return num.toLocaleString('en-US', {
      style: 'currency',
      currency: 'USD',
      minimumFractionDigits: 2
    });
  } else {
    // 如果输入无效，返回空字符串
    return '';
  }
}
```

该函数将输入作为参数，使用 `parseFloat()` 方法将其转换为数字类型，然后使用 `toLocaleString()` 方法将数字转换为货币格式。该方法的第一个参数指定语言环境（例如 `'en-US'` 表示美式英语），第二个参数是一个选项对象，其中 `style` 属性设置为 `'currency'`，`currency` 属性设置为 `'USD'`，表示使用美元货币符号，`minimumFractionDigits` 属性设置为 `2`，表示保留两位小数。如果输入无效，则返回空字符串。

在使用该函数时，您可以将其作为事件处理程序绑定到输入框的 `oninput` 事件上，以便在用户输入时自动格式化输入。例如：

```html
<input type="text" oninput="this.value = formatCurrency(this.value)">
```

在这个例子中，`formatCurrency()` 函数将输入框的值作为参数传递，并将格式化后的值赋值回输入框。这样，用户输入的数字就会自动转换为货币格式。

## 参数
### 第一个参数
`toLocaleString()` 方法的第一个参数是一个字符串，用于指定要使用的语言环境。该参数可以是 BCP 47 语言标记字符串，也可以是语言环境的子集，例如 `'en'`、`'en-US'` 等。

语言标记字符串由一系列用连字符分隔的字段组成，每个字段都代表不同的语言环境属性。例如，`'en-US'` 表示美国英语，其中 `'en'` 是语言代码，`'US'` 是国家/地区代码。您可以在 W3C 网站上找到有关语言标记的更多信息。

如果未提供第一个参数，则 `toLocaleString()` 方法将使用默认语言环境（通常是浏览器的默认语言环境）。如果提供了无法识别的语言环境，则方法将抛出 `RangeError` 异常。

### 第二个参数
`toLocaleString()` 方法的第二个参数是一个选项对象，用于指定各种格式化选项。以下是该对象的常用属性和可选值：

- `style`：指定要使用的格式化风格。可选值包括：
  - `'decimal'`：使用十进制数字格式（例如 `'1234567.89'`）。
  - `'currency'`：使用货币格式（例如 `'$1,234,567.89'`）。
  - `'percent'`：使用百分比格式（例如 `'123,456,789%'`）。
  - `'unit'`：使用计量单位格式（例如 `'1,234,568 meters'`）。
- `currency`：指定货币格式的货币代码。可选值包括 ISO 4217 货币代码，例如 `'USD'`、`'EUR'`、`'JPY'` 等。
- `minimumFractionDigits`：指定要显示的小数位数的最小值。默认值为 `0`。
- `maximumFractionDigits`：指定要显示的小数位数的最大值。默认值为 `3`，但是当 `style` 属性设置为 `'currency'` 时，默认值为货币的小数位数。
- `useGrouping`：指定是否使用分组分隔符。默认值为 `true`，表示使用分组分隔符（例如 `'1,234,567'`），如果设置为 `false`，则不使用分组分隔符（例如 `'1234567'`）。
- `localeMatcher`：指定在选择区域设置时使用的匹配算法。可选值包括 `'lookup'` 和 `'best fit'`。默认值为 `'best fit'`。
- `locale`：指定要使用的语言环境。可以是语言环境的字符串标识符（例如 `'en-US'`），或者是 `Intl.Locale` 对象。
- `numberingSystem`：指定要使用的数字系统。默认值为 `'latn'`，表示使用拉丁数字。其他可选值包括 `'arab'`（阿拉伯数字）、`'beng'`（孟加拉数字）、`'deva'`（天城体数字）等。
- `signDisplay`：指定如何显示正负号。可选值包括 `'auto'`、`'always'`、`'never'` 和 `'exceptZero'`。
- `notation`：指定数字表示法。可选值包括 `'standard'`、`'scientific'`、`'engineering'` 和 `'compact'`。
- `compactDisplay`：指定紧凑型表示法的显示方式。可选值包括 `'short'`、`'long'` 和 `'narrow'`。
- `unit`：指定计量单位格式的单位类型（例如 `'meter'`、`'second'` 等）。
- `unitDisplay`：指定计量单位格式的显示方式。可选值包括 `'short'`、`'long'` 和 `'narrow'`。

这些选项可以按需组合来生成所需的格式。例如，对于货币格式，您可以使用以下选项：

```javascript
{
  style: 'currency',
  currency: 'USD',
  minimumFractionDigits: 2,
  maximumFractionDigits: 2
}
```

这将生成一个美元货币格式，保留两位小数，并使用分组分隔符。如果您需要使用其他货币，请将 `currency` 属性设置为所需的 ISO 4217 货币代码。
