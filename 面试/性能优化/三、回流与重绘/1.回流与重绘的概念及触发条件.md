## (1) 回流
当渲染树中部分或者全部元素的尺寸、结构或者属性发生变化时，浏览器会重新渲染部分或者全部文档的过程就称为**回流**。
下面这些操作会导致回流
- 页面的首次渲染
- 浏览器的窗口大小发生变化
- 元素的内容发生变化
- 元素的尺寸或者位置发生变化
- 元素的字体大小发生变化
- 激活CSS伪类
- 查询某些属性或者调用某些方法
- 添加或者删除可见的DOM元素

在触发回流 (重排)的时候，由于**浏览器渲染页面**是基于流式布局的，所以当触发回流时，会导致周围的DOM元素重新排列，它的影响范围有两种:
- 全局范围:从根节点开始，对整个渲染树进行重新布局
- 局部范围:对渲染树的某部分或者一个渲染对象进行重新布局

## (2)重绘
当页面中某些元素的样式发生变化，但是不会影响其在文档流中的位置时，浏览器就会对元素进行重新绘制，这个过程就是**重绘**。
下面这些操作会导致重绘
- color、background 相关属性: background-color、background-image 等
- outline 相关属性: outline-color、outline-width 、text-decoration
- border-radius、visibility、box-shadow

注意: **当触发回流时，一定会触发重绘，但是重绘不一定会引发回流**


## 回流
以下是每个操作导致回流的例子：

1. 页面的首次渲染：
   当浏览器首次加载页面时，需要计算和渲染整个文档流，这会导致回流。例如，当页面包含大量复杂的DOM结构和样式时，浏览器需要耗费更多时间进行计算和渲染。

2. 浏览器的窗口大小发生变化：
   当用户调整浏览器窗口的大小时，页面中的元素需要根据新的窗口尺寸进行重新布局和渲染，这会导致回流。例如，当一个页面具有自适应布局并且元素的宽度是相对于窗口大小的百分比时，窗口大小变化会触发回流。

3. 元素的内容发生变化：
   当DOM元素的文本内容发生变化时，浏览器需要重新计算元素的大小和位置，这会导致回流。例如，通过JavaScript动态修改一个段落元素的文本内容，浏览器会重新计算段落元素的大小以适应新的文本内容。

4. 元素的尺寸或者位置发生变化：
   当改变元素的尺寸或者位置时，浏览器需要重新计算其他相关元素的布局，这会导致回流。例如，通过修改一个元素的宽度或者高度，浏览器会重新计算其他元素的位置以适应变化后的布局。

5. 元素的字体大小发生变化：
   当改变元素的字体大小时，浏览器需要重新计算元素及其子元素的布局，这会导致回流。例如，通过CSS样式或JavaScript动态修改元素的字体大小，浏览器会重新计算元素的尺寸和位置。

6. 激活CSS伪类：
   当激活某些CSS伪类时，浏览器需要重新计算元素的样式和布局，这可能导致回流。例如，当鼠标悬停在一个元素上，触发了`:hover`伪类，浏览器会重新计算元素的样式以反映悬停状态。

7. 查询某些属性或者调用某些方法：
   在JavaScript中查询某些属性或者调用某些方法可能会导致浏览器进行回流。例如，使用`offsetTop`、`offsetLeft`、`offsetWidth`、`offsetHeight`等属性获取元素的位置和尺寸信息，或者使用`getComputedStyle()`方法获取元素的计算样式。
   

8. 添加或者删除可见的DOM元素：
   当添加或删除可见的DOM元素时，浏览器需要重新计算整个文档流的布局和渲染，这会导致回流。例如，通过JavaScript动态地添加或删除一个元素，浏览器会重新计算其他元素的位置和尺寸以适应变化后的文档结构。

## 重绘
下面是一些常见属性的示例，它们可能会导致重绘（repaint）：

- `color`：修改文本颜色。

  ```css
  p {
    color: red;
  }
  ```

- `background-color`：修改元素的背景颜色。

  ```css
  div {
    background-color: yellow;
  }
  ```

- `background-image`：设置元素的背景图片。

  ```css
  div {
    background-image: url('image.jpg');
  }
  ```

- `outline-color`：更改元素的轮廓线颜色。

  ```css
  button {
    outline-color: blue;
  }
  ```

- `outline-width`：修改元素的轮廓线宽度。

  ```css
  input {
    outline-width: 2px;
  }
  ```

- `text-decoration`：改变文本的装饰效果，如下划线、删除线等。

  ```css
  a {
    text-decoration: underline;
  }
  ```

- `border-radius`：设置元素的边框圆角。

  ```css
  div {
    border-radius: 10px;
  }
  ```

- `visibility`：控制元素的可见性。

  ```css
  span {
    visibility: hidden;
  }
  ```

- `box-shadow`：添加元素的阴影效果。

  ```css
  div {
    box-shadow: 2px 2px 5px rgba(0, 0, 0, 0.3);
  }
  ```

当这些属性的值发生变化时，浏览器需要重新计算元素的样式并进行重绘，以反映新的样式效果。请注意，这些示例只涉及到了单个属性的变化，实际情况中可能会有多个属性同时变化，导致多次重绘。
