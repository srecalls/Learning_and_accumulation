	DocumentFragment，文档片段接口，一个没有父对象的最小文档对象。它被作为个轻量版的 Document使用，就像标准的document一样，存储由节点 (nodes)组成的文档结构。与document相比，最大的区别是DocumentFragment不是真实DOM 树的一部分，它的变化不会触发 DOM 树的重新渲染，且不会导致性能等问题。

当我们把一个 DocumentFragment 节点插入文档树时，插入的不是DocumentFragment 自身，而是它的所有子孙节点。在频繁的DOM操作时，我们就可以将DOM元素插入DocumentFragment，之后一次性的将所有的子孙节点插入文档中。和直接操作DOM相比，将DocumentFragment 节点插入DOM树时，不会触发页面的重绘，这样就大大提高了页面的性能。

## 例子

在早期的 Web 开发中，向文档中添加多个节点时通常使用以下方式：

```js
var list = document.getElementById('list');
for (var i = 0; i < 10; i++) {
  var li = document.createElement('li');
  li.textContent = 'Item ' + i;
  list.appendChild(li);
}
```

在这个例子中，我们首先获取了一个列表元素，并使用循环向其中添加多个 li 元素。由于每次添加一个元素都会导致 DOM 树的重新渲染，这样会影响性能。因此，为了提高性能，我们可以使用 DocumentFragment。

使用 DocumentFragment 的方式是，首先创建一个空的 DocumentFragment 对象，然后将多个节点添加到其中，最后将 DocumentFragment 添加到文档中。以下是使用 DocumentFragment 的方式：

```js
var list = document.getElementById('list');
var frag = document.createDocumentFragment();
for (var i = 0; i < 10; i++) {
  var li = document.createElement('li');
  li.textContent = 'Item ' + i;
  frag.appendChild(li);
}
list.appendChild(frag);
```

最后，我们可以将 DocumentFragment 中的所有元素一次性地添加到页面上的列表中：

```js
document.getElementById('list').appendChild(frag);
```

这样做的好处是，我们只需要一次性地将 DocumentFragment 中的所有元素添加到页面上，就可以避免多次触发 DOM 树的重新渲染，从而提高性能。

在这个例子中，我们首先创建了一个空的 DocumentFragment 对象，然后使用循环向其中添加多个 li 元素。由于 DocumentFragment 不是真实 DOM 树的一部分，它的变化不会触发 DOM 树的重新渲染，也不会导致性能等问题。最后，我们将 DocumentFragment 添加到文档中，这样就实现了向文档中添加多个节点的操作。

总的来说，使用 DocumentFragment 可以避免频繁地触发 DOM 树的重新渲染，从而提高性能。它是一个轻量版的 Document，用于存储由节点组成的文档结构，但不会影响实际的 DOM 树结构，因此可以避免性能等问题。
