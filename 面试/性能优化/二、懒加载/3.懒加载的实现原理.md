图片的加载是由 `src` 引起的，当对 `src` 赋值时，浏览器就会请求图片资源。根据这个原理，我们使用HTML5 的 data-xxx 属性来储存图片的路径，在需要加载图片的时候，将 `data-xxx` 中图片的路径赋值给 `src` ，这样就实现了图片的按需加载，即懒加载。
注意:` data-xxx `中的 `xxx` 可以自定义，这里我们使用` data-src` 来定义。
懒加载的实现重点在于确定用户需要加载哪张图片，在浏览器中，可视区域内的资源就获取图片的真实地址并赋值给图片是用户需要的资源。所以当图片出现在可视区域时，即可。

知识点:
(1) ` window.innerHeight `是浏览器可视区的高度
(2) `document.body.scrollTop || document.documentElement.scrollTop`是浏览器滚动的过的距离
(3) `imgs.offsetTop` 是元素顶部距离文档顶部的高度 (包括滚动条的距离)
(4) 图片加载条件: `img.offsetTop < window.innerHeight + document.body.scrollTop;`
17. `offsetTop`: 返回元素的上边界到 offsetParent 元素的上边界之间的像素距离。
24. `scrollTop`: 返回元素内容区域顶部隐藏的像素数。
25. `innerHeight` 是一个全局属性，它代表浏览器窗口的视口（viewport）高度，即浏览器窗口中可见部分的高度，不包括浏览器工具栏、地址栏等非页面区域的高度。

通常，可以使用 `window.innerHeight` 来获取浏览器窗口的视口高度。该属性返回一个表示视口高度的像素值。

```js
const windowHeight = window.innerHeight;
console.log(windowHeight);
```

`data-src` 是一个自定义属性，用于存储图片的真实路径。在一些使用懒加载技术的网站中，可以将图片的真实路径存储在 `data-src` 属性中，然后将 `src` 属性设置为占位图。当用户滚动页面时，通过 JavaScript 代码动态将 `data-src` 属性的值赋给 `src` 属性，从而实现图片的懒加载。

```html
<img src="placeholder.jpg" data-src="real-image.jpg" alt="Real Image">
```

在这个示例中，`img` 元素的 `src` 属性设置为占位图 `placeholder.jpg`，`data-src` 属性设置为真实图片的路径 `real-image.jpg`。当用户滚动页面，或者触发某些事件时，可以通过 JavaScript 代码将 `data-src` 属性的值赋给 `src` 属性，从而实现图片的懒加载。

## 优化（节流）
好的，以下是一个使用原生 JavaScript 实现节流的示例代码：

```html
<div class="container">
  <img src="loading.gif" data-src="pic.png">
  <img src="loading.gif" data-src="pic.png">
  <img src="loading.gif" data-src="pic.png">
  <img src="loading.gif" data-src="pic.png">
  <img src="loading.gif" data-src="pic.png">
  <img src="loading.gif" data-src="pic.png">
</div>

<script>
  var imgs = document.querySelectorAll('img');

  function lazyLoad() {
    var scrollTop = window.pageYOffset || document.documentElement.scrollTop;
    var winHeight = window.innerHeight;

    for (var i = 0; i < imgs.length; i++) {
      var rect = imgs[i].getBoundingClientRect();
      if (rect.top < winHeight && rect.bottom > 0) {
        imgs[i].src = imgs[i].getAttribute('data-src');
      }
    }
  }

  var timeoutId;

  function throttledLazyLoad() {
    if (timeoutId) return;

    timeoutId = setTimeout(function() {
      lazyLoad();
      timeoutId = null;
    }, 100);
  }

  window.addEventListener('scroll', throttledLazyLoad);
</script>
```

在这个示例中，使用一个名为 `throttledLazyLoad()` 的函数来实现节流。在函数的内部，使用一个变量 `timeoutId` 来记录定时器的 ID，如果定时器已经存在，则说明函数正在执行中，直接返回。否则，设置一个定时器，在 100ms 后调用 `lazyLoad()` 函数，并清空定时器 ID，以便下次调用。

在滚动事件处理函数中，将 `throttledLazyLoad()` 函数绑定到 `window` 对象的 `scroll` 事件上，这样就可以在滚动时触发节流函数了。
