```js
component: () => import(/* webpackChunkName: 'resource' */'@/views/resource/index')
// 为什么这种可以实现懒加载
```

这种方式可以实现懒加载，是因为它使用了 Webpack 的代码分割（code splitting）功能。

Webpack 是一个常用的 JavaScript 模块打包工具，它将应用程序打包成一些模块（modules），然后将这些模块打包成一个或多个 bundle 文件，以便在浏览器中加载和执行。

通过使用 `import()` 方法，可以将模块的加载推迟到代码运行时。当 Webpack 遇到这种动态导入（dynamic import）语法时，它会自动将相关的代码分割成一个独立的 chunk 文件，并在需要时动态加载。

在这个例子中，`component` 属性的值是一个函数，使用了动态导入语法来加载 `@/views/resource/index` 模块。由于使用了 Webpack 的代码分割功能，当应用程序需要显示 `resource` 页面时，才会请求加载对应的 chunk 文件，从而实现懒加载的效果。

需要注意的是，使用动态导入语法加载的模块会被打包成一个单独的 chunk 文件，并且该文件会有一个独立的 URL 地址。这意味着，在加载该模块时，会向服务器发送一个单独的 HTTP 请求，因此需要确保服务器能够正确地处理这些请求，并返回正确的响应。
