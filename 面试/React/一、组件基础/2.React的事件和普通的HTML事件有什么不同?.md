
## 区别:
- 对于事件名称命名方式，**原生事件为全小写**，react 事件采用**小驼峰**;
- 对于事件函数处理语法，原生事件为**字符串**，react 事件为**函数**;
- **react 事件不能采用 return false 的方式来阻止浏览器的默认行为**，而必须要地明确地**调用 preventDefault() 来阻止默认行为**。

合成事件是 react 模拟原生 DOM 事件所有能力的一个事件对象，其优点如下:
- 兼容所有浏览器，更好的跨平台;
- 将事件统一存放在一个数组，避免频繁的新增与删除 (垃圾回收)
- 方便 react 统一管理和事务机制。

事件的执行顺序为原生事件先执行，合成事件后执行，合成事件会冒泡绑定到 document 上，所以尽量避免原生事件与合成事件混用，如果原生事件阻止冒泡，可能会导致合成事件不执行，因为需要冒泡到document 上合成事件才会执行。

React事件和普通的HTML事件在几个方面有所不同：

## 1. 事件命名：
在原生HTML中，我们通常会使用全小写的方式来书写事件名称，如`onclick`，`onmouseover`等。而在React中，则是使用驼峰式命名法（camelCase），如`onClick`，`onMouseOver`等。

## 2.事件处理函数：
在原生HTML中，事件处理函数通常作为字符串传入，如`<button onclick="handleClick()">Click me</button>`。而在React中，事件处理函数是作为函数对象传入的，如`<button onClick={this.handleClick}>Click me</button>`。这意味着在React中，你可以直接在事件处理函数中使用JavaScript代码，而不需要像在HTML中那样通过字符串来调用函数。

## 3. `this`的指向：
在原生HTML事件中，事件处理函数中的`this`通常指向触发事件的元素。而在React中，类组件的事件处理函数中的`this`默认是`undefined`，因为JavaScript类的默认行为是不将方法绑定到实例上的。因此，如果你想在事件处理函数中使用`this`，你需要手动将函数绑定到实例上（通常在构造函数中完成这个操作）。

## 4.阻止默认行为：
在原生HTML中，我们可以通过在事件处理函数中返回`false`来阻止默认行为。而在React中，我们需要明确地调用`event.preventDefault()`来阻止默认行为。

当比较React事件和原生HTML事件时，以下是一个阻止默认行为的示例：

##### 原生HTML事件：

```html
<a href="#" onclick="return false;">Click me</a>
```

在上述示例中，通过在`onclick`事件处理函数中返回`false`，阻止了`<a>`标签的默认行为，即不会进行页面跳转。
##### React事件：

```jsx
import React from 'react';

class MyComponent extends React.Component {
  handleClick = (event) => {
    event.preventDefault();
    // 阻止默认行为的其他逻辑
  }

  render() {
    return (
      <a href="#" onClick={this.handleClick}>Click me</a>
    );
  }
}
```

在上述示例中，我们在React组件的`<a>`标签上使用了`onClick`属性来指定事件处理函数。在`handleClick`方法中，我们明确调用`event.preventDefault()`来阻止默认行为，例如阻止链接的默认跳转行为。然后可以在`handleClick`方法中添加其他逻辑来处理点击事件。

需要注意的是，即使在React中使用事件处理函数并调用了`event.preventDefault()`来阻止默认行为，仍然可以通过编程方式实现特定的行为，例如使用`history.push`进行页面跳转，而不是 `<a>` 标签的默认行为。阻止默认行为只是一种常见的用例，具体的处理逻辑取决于开发者的需求。

## 5. 事件冒泡和捕获：
在原生HTML中，我们可以通过`addEventListener`的第三个参数来指定监听函数是在**捕获阶段还是冒泡阶段触发**。而在React中，事件处理函数默认在冒泡阶段触发。

在原生HTML中，可以通过`addEventListener`的第三个参数来指定监听函数是在捕获阶段还是冒泡阶段触发。而在React中，默认情况下，事件处理函数是在冒泡阶段触发。以下是一个示例：

原生HTML事件：

```html
<div id="myDiv">
  <button id="myButton">Click me</button>
</div>
```

```javascript
const myButton = document.getElementById('myButton');
const myDiv = document.getElementById('myDiv');

myButton.addEventListener('click', () => {
  console.log('Button clicked');
}, false); // 在冒泡阶段触发

myDiv.addEventListener('click', () => {
  console.log('Div clicked');
}, true); // 在捕获阶段触发
```

在上述示例中，通过`addEventListener`的第三个参数来指定事件监听函数是在捕获阶段还是冒泡阶段触发。当点击按钮时，先触发捕获阶段的`Div clicked`，然后触发冒泡阶段的`Button clicked`。

React事件：

```jsx
import React from 'react';

class MyComponent extends React.Component {
  handleButtonClick = () => {
    console.log('Button clicked');
  }

  handleDivClick = () => {
    console.log('Div clicked');
  }

  render() {
    return (
      <div onClick={this.handleDivClick} >
        <button onClick={this.handleButtonClick}>Click me</button>
      </div>
    );
  }
}
```

在上述示例中，我们在React组件中使用了`onClick`属性来指定事件处理函数。由于React事件处理默认在冒泡阶段触发，所以当点击按钮时，会先触发`Button clicked`，然后触发`Div clicked`。

请注意，尽管React事件处理默认在冒泡阶段触发，但React并没有提供直接的方式来指定事件处理函数是在捕获阶段还是冒泡阶段触发。如果需要在React中使用事件捕获，可以将`useCapture`参数设置为`true`，并通过在事件处理函数中进行条件判断来模拟捕获阶段的行为。
## 6.事件系统：
React实际上实现了一个合成事件（Synthetic event）系统，**所有的事件处理函数**都被传入**一个合成事件实例**。这个合成事件实例的API与浏览器的原生事件API相同，但它们工作在一个更高级别的抽象之上。这样做的好处是，你的**事件处理代码能够在不同的浏览器中保持一致的行为**。

当使用React的合成事件系统时，所有的事件处理函数都会被传入一个合成事件实例，该**实例具有与浏览器原生事件API相似的属性和方法**，但它们工作在一个更高级别的抽象之上，以保持一致的行为在不同的浏览器中。以下是一个示例：

```jsx
import React from 'react';

class MyComponent extends React.Component {
  handleClick = (event) => {
    // 阻止默认行为
    event.preventDefault();

    // 获取鼠标位置
    const { clientX, clientY } = event;

    // 获取目标元素
    const target = event.target;

    // 获取键盘按键
    const { key } = event;

    // 其他事件处理逻辑
    // ...
  }

  render() {
    return (
      <button onClick={this.handleClick}>Click me</button>
    );
  }
}
```

在上述示例中，我们定义了一个`handleClick`方法作为按钮的点击事件处理函数。在该方法中，我们可以**通过合成事件参数`event`来访问一系列属性和方法**，以实现不同的功能：

- `event.preventDefault()`：阻止默认行为，例如阻止按钮点击后的表单提交或链接的跳转。
- `event.clientX`和`event.clientY`：获取鼠标点击位置的横坐标和纵坐标。
- `event.target`：获取触发事件的目标元素，即按钮本身。
- `event.key`：获取键盘按键的值。

通过合成事件系统，不同浏览器的差异被抽象化和处理，使得开发者能够在不同浏览器中保持一致的事件处理行为。这样，无论在哪种浏览器环境下运行，React的事件处理代码都能够按预期工作。
