	- Undefined 类型的值转换为 NaN。

	- Null 类型的值转换为 0。

	- Boolean 类型的值，true 转换为 1，false 转换为 0。

	- String 类型的值转换如同使用 Number() 函数进行转换，如果包含非数字值则转换为 NaN，空字符串为 0。

	- Symbol 类型的值不能转换为数字，会报错

	- 对象 (包括数组)会首先被转换为相应的基本类型值，如果返回的是非数字的基本类型值，则再遵循以上规则将其强制转换为数字。

	为了将值转换为相应的基本类型值，抽象操作 ToPrimitive 会首先 (通过内部操作DefaultValue) 检查该值是否有valueOf()方法。如果有并且返回基本类型值，就使用该值进行强制类型转换。如果没有就使用 toString()的返回值 (如果存在)来进行强制类型转换

	如果 valueOf()和 toString() 均不返回基本类型值，会产生 TypeError 错误。


对于上述类型转换规则，下面是一些例子：

```javascript
// Undefined 类型的值转换为 NaN
let a = Number(undefined);  // a 的值为 NaN

// Null 类型的值转换为 0
let b = Number(null);  // b 的值为 0

// Boolean 类型的值，true 转换为 1，false 转换为 0
let c = Number(true);   // c 的值为 1
let d = Number(false);  // d 的值为 0

// String 类型的值转换如同使用 Number() 函数进行转换
// 如果包含非数字值则转换为 NaN，空字符串为 0
let e = Number('123');    // e 的值为 123
let f = Number('abc');    // f 的值为 NaN
let g = Number('');       // g 的值为 0

// Symbol 类型的值不能转换为数字，会报错
let h = Number(Symbol());  // 抛出 TypeError 错误

// 对象 (包括数组)会首先被转换为相应的基本类型值
// 如果返回的是非数字的基本类型值，则再遵循以上规则将其强制转换为数字
let i = Number({});        // i 的值为 NaN
let j = Number([]);        // j 的值为 0
```

在这些例子中，我们可以看到基本类型值和对象在进行类型转换时的一些特点。需要注意的是，虽然大多数情况下 JavaScript 会自动进行类型转换，但在某些情况下，我们需要手动进行类型转换来确保代码的正确性。
