- 函数 isNaN 接收参数后，会尝**试将这个参数转换为数值**，**任何不能被转换为数值的的值都会返回 true**，因此**非数字值传入也会返回 true** ，会影响 NaN 的判断。

- 函数 Number.isNaN **会首先判断传入参数是否为数字**，如果**是数字再继续判断是否为 NaN** ，**不会进行数据类型的转换**，这种方法对于 NaN 的判断更为准确。


`isNaN()` 和 `Number.isNaN()` 都是 JavaScript 中用于检查一个值是否为 NaN（Not a Number）的函数，但它们之间有一些区别。

`isNaN()` 函数在检查一个值是否为 NaN 时，会首先尝试将这个值转换为数值，如果值不能转换为数值，则返回 `true`。这意味着，如果传入的参数不是数值类型，`isNaN()` 会将其转换为数值类型，而这种转换可能会导致意外的结果。例如：

```javascript
isNaN("hello world"); // true
isNaN(""); // false
```

上述代码中，`isNaN("hello world")` 返回 `true`，因为字符串不能转换为数值。但是，`isNaN("")` 返回 `false`，因为空字符串被转换为了数值 `0`。

相比之下，`Number.isNaN()` 函数不会将参数转换为数值，只有当参数是 NaN 时才返回 `true`，否则返回 `false`。例如：

```javascript
Number.isNaN("hello world"); // false
Number.isNaN(""); // false
```

上述代码中，`Number.isNaN("hello world")` 和 `Number.isNaN("")` 都返回 `false`，因为它们都不是 NaN。

因此，如果你只想检查一个值是否为 NaN，而不希望将其转换为数值类型，那么应该使用 `Number.isNaN()` 函数。如果你希望将参数转换为数值类型，并检查其是否为 NaN，那么可以使用 `isNaN()` 函数。
