|| 和 && 首先会对**第一个操作数**执行条件判断，如果其**不是布尔值**就**先强制转换为布尔类型**，然后再执行条件判断。

	- 对于||来说，如果条件判断结果为 true 就返回第一个操作数的值，如果为 false 就返回第二个操作数的值。
	- && 则相反,如果条件判断结果为 true 就返回第二个操作数的值，如果为 false 就返回第一个操作数的值。

	||和 && 返回它们其中一个操作数的值，而非条件判断的结果



确实，对于逻辑运算符 `||` 和 `&&`，它们返回的是其中一个操作数的值，而不是条件判断的结果。

```javascript
// 使用 || 运算符
// 如果第一个操作数为 true，则返回第一个操作数的值
// 如果第一个操作数为 false，则返回第二个操作数的值
let a = 'foo' || 'bar'; // a 的值为 'foo'
let b = undefined || 0;  // b 的值为 0

// 使用 && 运算符
// 如果第一个操作数为 true，则返回第二个操作数的值
// 如果第一个操作数为 false，则返回第一个操作数的值
let c = 'foo' && 'bar';        // c 的值为 'bar'
let d = undefined && 'hello';  // d 的值为 undefined
```

在第一个例子中，因为 `'foo'` 是一个 truthy 值，所以 `a` 的值为 `'foo'`，而不是 `'bar'`。在第二个例子中，因为 `undefined` 是一个 falsy 值，所以 `b` 的值为 `0`。

在第三个例子中，因为 `'foo'` 是一个 truthy 值，所以 `c` 的值为 `'bar'`，而不是 `'foo'`。在第四个例子中，因为 `undefined` 是一个 falsy 值，所以 `d` 的值为 `undefined`，而不是 `'hello'`。
