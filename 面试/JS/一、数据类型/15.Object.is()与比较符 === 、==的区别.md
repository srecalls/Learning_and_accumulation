1. 使用双等号 (`==`) 进行相等判断时，如果两边的类型不一致，则会进行强制类型转换后再进行比较。

2. 使用三等号 (`===`) 进行相等判断时，如果两边的类型不一致，则不会进行强制类型转换，直接返回 `false`。

3. 使用 `Object.is()` 来进行相等判断时，一般情况下和三等号的判断相同，但它处理了一些特殊的情况，比如 `-0` 和 `+0` 不再相等，两个 `NaN` 是相等的。

下面是一些例子：

```javascript
// 使用双等号进行相等判断时，会进行强制类型转换
console.log(1 == '1');      // true
console.log(true == 1);     // true
console.log(undefined == null);  // true

// 使用三等号进行相等判断时，不会进行强制类型转换
console.log(1 === '1');     // false
console.log(true === 1);    // false
console.log(undefined === null); // false

// 使用 Object.is() 进行相等判断时，处理了一些特殊的情况
console.log(Object.is(0, -0));    // false
console.log(Object.is(NaN, NaN)); // true
```
