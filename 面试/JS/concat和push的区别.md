## concat和push的区别

`concat()` 方法和 `push()` 方法都是 JavaScript 中用于操作数组的方法，它们的功能和使用方法有着一定的区别。

1. `concat()` 方法：
   - `concat()` 方法用于将多个数组拼接成一个新的数组，并返回这个新的数组。它不会修改原始数组，而是返回一个新的数组。
   - `concat()` 方法可以接受多个参数，每个参数可以是数组或者值，它会将这些参数按照顺序拼接成一个新的数组。示例代码如下：

  ```js
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];
const arr3 = [7, 8, 9];
const newArr = arr1.concat(arr2, arr3);
console.log(newArr);  // 输出 [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

2. `push()` 方法：
   - `push()` 方法用于向数组的末尾添加一个或多个元素，并返回修改后的数组的长度。它会修改原始数组，而且只能添加元素，不能添加数组。
   - 示例代码如下：

```js
const arr = [1, 2, 3];
const len = arr.push(4, 5, 6);
console.log(arr);  // 输出 [1, 2, 3, 4, 5, 6]
console.log(len);  // 输出 6
```
   
综上所述，`concat()` 方法用于将多个数组拼接成一个新的数组，不会修改原始数组；`push()` 方法用于向数组的末尾添加一个或多个元素，会修改原始数组，并返回修改后的数组的长度。
