箭头函数不同于传统JavaScript中的函数，箭头函数并没有属于自己的this，**它所谓的this是捕获其所在上下文的 this 值**，作为自己的 this 值，并且由于没有属于自己的this，所以是不会被new调用的，这个所谓的this也不会被改变

可以用Babel理解一下箭头函数
```js
// ES6
const obj = {
	getArrow() {
		return () => {
			console.log(this === obj)
		}
	}
}
```

转化后

```js
// ES5，由Babel转译
var obj = {
	getArrow: function getArrow() {
		var _this = this
		return function() {
			console.log(_this === obj)
		}
	}
}
```
