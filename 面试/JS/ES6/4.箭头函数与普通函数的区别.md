## (1) 箭头函数比普通函数更加简洁
- 如果没有参数，就直接写一个空括号即可
- 如果只有一个参数，可以省去参数的括号
- 如果有多个参数，用逗号分割
- 如果函数体的返回值只有一句，可以省略大括号
- 如果函数体不需要返回值，且只有一句话，可以给这个语句前面加一个void关键字。
- 最常见的就是调用一个函数
```js
let fn = () => void doesNotReturn()
```

## (2)箭头函数没有自己的this
箭头函数不会创建自己的this，所以它没有自己的this，它只会**在自己作用域的上一层继承this**。所以箭头函数中this的指向在它在定义时已经确定了，之后不会改变。

## (3)箭头函数继承来的this指向永远不会改变
```js
var id = 'GLOBAl'
var obj = {
	id: 'OBJ',
	a: function() {
		console.log(this.id)
	},
	b: () => {
		console.log(this.id)
	}
}
obj.a() // 'OBJ'
obj.b() // 'GLOBAL'
new obj.a() // undefined
new obj.b() // Uncaught TypeError: obj.b is not a constructor
```
[[手写new操作符]]
对象obj的方法b是使用箭头函数定义的，这个函数中的this就永远指向它定义时所处的全局执行环境中的this，即便这个函数是作为对象obj的方法调用，this依旧指向Window对象。需要注意，**定义对象的大括号{ } 是无法形成一个单独的执行环境的**，它依旧是处于全局执行环境中。

## (4) call()、apply()、bind()等方法不能修改箭头函数中this的指向
```js
var id = 'Global'
let fun1 = () => {
	console.log(this.id)
}
fun1()   // 'Global'
fun1().call({id: 'Obj'})   // 'Global'
fun1().apply({id: 'Obj'})   // 'Global'
fun1().bind({id: 'Obj'})   // 'Global'
```

## (5)箭头函数不能作为构造函数
使用构造函数在new的步骤在上面已经说过了，实际上第二步就是将函数中的this指向该对象。但是由于箭头函数时没有自己的this的，且this指向外层的执行环境，且
不能改变指向，所以不能当做构造函数使用。

## 6)箭头函数没有自己的arguments
箭头函数没有自己的arguments对象。**在箭头函数中访问arguments实际上获得的是它外层函数的arguments值.**

假设我们有一个包含箭头函数的函数 `outerFunction`，并且我们想在箭头函数中访问 `arguments` 对象。在这种情况下，访问的将是 `outerFunction` 的 `arguments` 对象。

```js
function outerFunction() {
  const arrowFunction = () => {
    console.log(arguments);
  };

  arrowFunction('apple', 'banana', 'orange');
}

outerFunction('dog', 'cat');
```

在这个例子中，`outerFunction` 被调用时传入了两个参数 `'dog'` 和 `'cat'`。`outerFunction` 中的箭头函数 `arrowFunction` 被调用时传入了三个参数 `'apple'`、`'banana'` 和 `'orange'`。

当在 `arrowFunction` 中访问 `arguments` 对象时，打印的结果将是 `outerFunction` 的 `arguments` 对象，即包含 `'dog'` 和 `'cat'` 这两个参数。

输出结果为：
```js
Arguments(2) ["dog", "cat", callee: ƒ, Symbol(Symbol.iterator): ƒ]
```
因此，箭头函数没有自己的 `arguments` 对象，它只能访问外层函数的 `arguments` 对象。

## (8) 箭头函数不能用作Generator函数，不能使用yeild关键字
是的，箭头函数不能用作生成器函数，因为它们不能使用 `yield` 关键字。以下是一个使用箭头函数定义的生成器函数示例，它会抛出语法错误：

```
const generatorFunction = function* () {
  yield 1;
  yield 2;
};

const arrowGeneratorFunction = () => {
  yield 1; // SyntaxError: Unexpected identifier
  yield 2;
};
```

在 `arrowGeneratorFunction` 中，当我们尝试使用 `yield` 关键字时，它会抛出语法错误，因为箭头函数不能使用 `yield` 关键字。

相反，我们应该使用普通函数来定义生成器函数，如上面的 `generatorFunction` 示例所示。

生成器函数是一种特殊类型的函数，它使用 `function*` 语法定义，可以通过 `yield` 关键字来暂停和恢复函数执行。当我们使用 `yield` 关键字时，它会将值传递回生成器函数的调用者，并暂停函数执行，直到再次调用生成器函数时恢复执行。

然而，箭头函数不能用作生成器函数，因为它们不能使用 `yield` 关键字。这是因为箭头函数没有自己的执行上下文，它们始终在其定义的上下文中运行。而生成器函数需要具有自己的执行上下文，以便可以使用 `yield` 关键字来暂停和恢复函数执行。因此，我们必须使用普通函数来定义生成器函数，以便可以使用 `yield` 关键字。
