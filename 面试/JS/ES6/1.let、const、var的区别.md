## 区别
### 1-7
	 (1)块级作用域: 块作用域由{}包括，let和const具有块级作用域，var不存在块级作用域。块级作用域解决了ES5中的两个问题:
		内层变量可能覆盖外层变量
		用来计数的循环变量泄露为全局变量

	(2) 变量提升: var存在变量提升，let和const不存在变量提升，即在变量只能在声明之后使用，否在会报错

	(3) 给全局添加属性: 浏览器的全局对象是window，Node的全局对象是global.
	var声明的变量为全局变量，并且会将该变量添加为全局对象的属性，但是let和const不会。

	(4)重复声明: var声明变量时，可以重复声明变量，后声明的同名变量会覆盖之前声明的遍历。const和let不允许重复声明变量

	(5)暂时性死区: 在使用let、const命令声明变量之前，该变量都是不可用的。这在语法上，称为暂时性死区。使用var声明的变量不存在暂时性死区。

	(6)初始值设置: 在变量声明时，var 和 let 可以不用设置初始值。而const声明变量必须设置初始值。

	(7) 指针指向: let和const都是ES6新增的用于创建变量的语法。 let创建的变量是可以更改指针指向 (可以重新赋值)。但const声明的变量是不允许改变指针的指向。




### 1. 块级作用域的例子：

```js
// ES6
{
  let x = 1;
  const y = 2;
  var z = 3;
}
console.log(z); // 输出3
console.log(x); // 报错：Uncaught ReferenceError: x is not defined
console.log(y); // 报错：Uncaught ReferenceError: y is not defined
```

在这个例子中，变量 `x` 和 `y` 被声明在一个块级作用域中，因此在块级作用域外部无法访问它们。而变量 `z` 被使用 `var` 声明，因此它是一个全局变量，可以在块级作用域外部访问。

### 2. 变量提升的例子：

```js
// ES5
console.log(a); // 输出undefined
var a = 1;

// ES6
console.log(b); // 报错：Uncaught ReferenceError: b is not defined
let b = 2;
```

在 ES5 中，变量 `a` 被使用 `var` 声明，因此它存在变量提升，可以在声明之前访问，但是其值为 `undefined`。而在 ES6 中，变量 `b` 被使用 `let` 声明，不存在变量提升，因此在声明之前访问会报错。

### 3. 给全局对象添加属性的例子：

```js
// ES5
var a = 1;
window.b = 2;

console.log(window.a); // 输出1
console.log(window.b); // 输出2

// ES6
let c = 3;
const d = 4;

console.log(window.c); // 输出undefined
console.log(window.d); // 输出undefined
```

在 ES5 中，使用 `var` 声明的变量会成为全局变量，并且会将该变量添加为全局对象的属性。因此，在上面的例子中，变量 `a` 和 `b` 都可以通过 `window` 对象访问。然而，在 ES6 中，使用 `let` 或 `const` 声明的变量不会添加为全局对象的属性，因此在上面的例子中，变量 `c` 和 `d` 无法通过 `window` 对象访问。

### 4. 重复声明的例子：

```js
// ES5
var a = 1;
var a = 2;
console.log(a); // 输出2

// ES6
let b = 1;
let b = 2; // 报错：Uncaught SyntaxError: Identifier 'b' has already been declared
```

在 ES5 中，使用 `var` 声明的变量可以重复声明，后声明的同名变量会覆盖之前声明的变量。而在 ES6 中，使用 `let` 或 `const` 声明的变量不允许重复声明，否则会报错。

### 5. 暂时性死区的例子：

```js
// ES6
if (true) {
  console.log(a); // 报错：Uncaught ReferenceError: a is not defined
  let a = 1;
}
```

在这个例子中，变量 `a` 被使用 `let` 声明，因此它存在暂时性死区，在声明之前访问会报错。

### 6. 初始值设置的例子：

```js
// ES5
var a;
var b = 1;

console.log(a); // 输出undefined
console.log(b); // 输出1

// ES6
let c;
const d = 2;

console.log(c); // 输出undefined
console.log(d); // 输出2
```

在 ES5 中，使用 `var` 声明变量可以不设置初始值。而在 ES6 中，使用 `const` 声明变量必须设置初始值，而使用 `let` 声明变量可以选择是否设置初始值。

### 7. 指针指向的例子：

```js
// ES6
let a = [1, 2, 3];
a = [4, 5, 6];
console.log(a); // 输出[4, 5, 6]

const b = [1, 2, 3];
b = [4, 5, 6]; // 报错：Uncaught TypeError: Assignment to constant variable.
```

在这个例子中，变量 `a` 被使用 `let` 声明，因此它可以更改指针指向，即可以重新赋值。而变量 `b` 被使用 `const` 声明，因此它不允许改变指针的指向，如果尝试重新赋值会导致类型错误。
