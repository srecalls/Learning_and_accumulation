**扩展运算符**被用在函数形参上时，它还可以把一个分离的参数序列整合成一个数组
```js
function mutiple(...args) {
	let result = 1
	for (var val of args) {
		result* = val
	}
	return result
}
mutiple(1, 2, 3, 4) // 24
```
这里，传入 mutiple 的是**四个分离的参数**，但是如果在 mutiple 函数里尝试输出args 的值，会发现它是一个数组:
```js
function multiple(...args) {
	console.log(args)
}
mutiple(1, 2, 3, 4) // [1, 2, 3, 4]
```
这就是...rest运算符的又一层威力了，它可以把函数的多个入 参收敛进一个数组里。这一点经常用于**获取函数的多余参数，或者像上面这样处理函数参数个数不确定的情况。**
