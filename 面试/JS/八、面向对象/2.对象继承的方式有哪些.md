## 1.原型链
(1) 第一种是以原型链的方式来实现继承，但是这种实现方式存在的缺点是，在包含有引用类型的数据时，会被所有的实例对象所共享，容易造成修改的混乱。还有就是在创建子类型的时候不能向超类型传递参数。
```js
function SuperType() {
  this.property = true;
}

SuperType.prototype.getSuperValue = function() {
  return this.property;
}

function SubType() {
  this.subproperty = false;
}

SubType.prototype = new SuperType();

SubType.prototype.getSubValue = function() {
  return this.subproperty;
}

var instance = new SubType();
console.log(instance.getSuperValue()); // true
console.log(instance.getSubValue()); // false
```
上面的代码演示了原型链继承的实现。在这个例子中，我们定义了 `SuperType` 和 `SubType` 两个构造函数，`SubType` 继承了 `SuperType`，通过 `SubType.prototype = new SuperType()` 这一句代码实现了原型链继承。这种继承方式的优点是简单易用，缺点是无法实现对超类型的传递参数，同时所有的实例对象都会共享同一个原型对象，容易造成修改的混乱。

## 2.构造函数
(2)第二种方式是使用借用构造函数的方式，这种方式是通过在子类型的函数中调用超类型的构造函数来实现的，这一种方法解决了不能向超类型传递参数的缺点，但是它存在的一个问题就是无法实现函数方法的复用，并且超类型原型定义的方法子类型也没有办法访问到。
```js
function SuperType(name) {
  this.colors = ['red', 'green', 'blue'];
  this.name = name;
}

function SubType(name) {
  SuperType.call(this, name);
}

var instance1 = new SubType('instance1');
instance1.colors.push('yellow');
console.log(instance1.colors); // ['red', 'green', 'blue', 'yellow']
console.log(instance1.name); // 'instance1'

var instance2 = new SubType('instance2');
console.log(instance2.colors); // ['red', 'green', 'blue']
console.log(instance2.name); // 'instance2'
```
上面的代码演示了借用构造函数继承的实现。在这个例子中，我们定义了 `SuperType` 和 `SubType` 两个构造函数，`SubType` 继承了 `SuperType`，通过 `SuperType.call(this, name)` 这一句代码实现了借用构造函数继承。这种继承方式的优点是可以实现对超类型的传递参数，缺点是无法实现方法的复用，并且超类型原型定义的方法子类型也没有办法访问到。

## 3.原型链和构造函数组合继承
(3)第三种方式是组合继承，组合继承是将原型链和借用构造函数组合起来使用的一种方式。通过借用构造函数的方式来实现类型的属性的继承，通过将子类型的原型设置为超类型的实例来实现方法的继承。这种方式解决了上面的两种模式单独使用时的问题，但是由于我们是以超类型的实例来作为子类型的原型，所以调用了两次超类的构造函数，造成了子类型的原型中多了很多不必要的属性
```js
function SuperType(name) {
  this.colors = ['red', 'green', 'blue'];
  this.name = name;
}

SuperType.prototype.sayName = function() {
  console.log(this.name);
}

function SubType(name, age) {
  SuperType.call(this, name);
  this.age = age;
}

SubType.prototype = new SuperType();
SubType.prototype.constructor = SubType;

SubType.prototype.sayAge = function() {
  console.log(this.age);
}

var instance1 = new SubType('instance1', 20);
instance1.colors.push('yellow');
console.log(instance1.colors); // ['red', 'green', 'blue', 'yellow']
instance1.sayName(); // 'instance1'
instance1.sayAge(); // 20

var instance2 = new SubType('instance2', 25);
console.log(instance2.colors); // ['red', 'green', 'blue']
instance2.sayName(); // 'instance2'
instance2.sayAge(); // 25
```
上面的代码演示了组合继承的实现。在这个例子中，我们定义了 `SuperType` 和 `SubType` 两个构造函数，`SubType` 继承了 `SuperType`，通过 `SuperType.call(this, name);` 实现了属性的继承，通过 `SubType.prototype = new SuperType();` 实现了方法的继承，并且通过 `SubType.prototype.constructor = SubType;` 来修正 `SubType` 的构造函数。这种继承方式的优点是可以实现属性和方法的继承，缺点是调用了两次超类的构造函数，造成了子类型的原型中多了很多不必要的属性。

## 4.原型式继承
(4) 第四种方式是原型式继承，原型式继承的主要思路就是基于已有的对象来创建新的对象，实现的原理是，向函数中传入一个对象，然后返回一个以这个对象为原型的对象。这种继承的思路主要不是为了实现创造一种新的类型，只是对某个对象实现一种简单继承，ES5 中定义的 Object.create() 方法就是原型式继承的实现。缺点与原型链方式相同。
```js
var person = {
  name: "Nicholas",
  friends: ["Shawn", "Van"]
};

var anotherPerson = Object.create(person);
anotherPerson.name = "Greg";
anotherPerson.friends.push("Rob");

var yetAnotherPerson = Object.create(person);
yetAnotherPerson.name = "Linda";
yetAnotherPerson.friends.push("Barbie");

console.log(person.friends); // ["Shawn", "Van", "Rob", "Barbie"]
console.log(anotherPerson.friends); // ["Shawn", "Van", "Rob", "Barbie"]
console.log(yetAnotherPerson.friends); // ["Shawn", "Van", "Rob", "Barbie"]
```
上面的代码演示了原型式继承的实现。在这个例子中，我们使用 `Object.create()` 方法以 `person` 对象为原型创建了两个新的对象 `anotherPerson` 和 `yetAnotherPerson`。这种继承方式的优点是简单易用，缺点与原型链方式相同，即包含有引用类型的数据时，会被所有的实例对象所共享，容易造成修改的混乱。

## 5.寄生式继承
第五种方式是寄生式继承，寄生式继承的思路是创建一个用于5)封装继承过程的函数，通过传入一个对象，然后复制一个对象的副本，然后对象进行扩展，最后返回这个对象。这个扩展的过程就可以理解是一种继承。这种继承的优点就是对一个简单对象实现继承，如果这个对象不是自定义类型时。缺点是没有办法实现函数的复用。
```js
function createAnother(original) {
  var clone = Object.create(original);
  clone.sayHi = function() {
    console.log("hi");
  };
  return clone;
}

var person = {
  name: "Nicholas",
  friends: ["Shawn", "Van"]
};

var anotherPerson = createAnother(person);
anotherPerson.name = "Greg";
anotherPerson.friends.push("Rob");

var yetAnotherPerson = createAnother(person);
yetAnotherPerson.name = "Linda";
yetAnotherPerson.friends.push("Barbie");

console.log(person.friends); // ["Shawn", "Van"]
console.log(anotherPerson.friends); // ["Shawn", "Van", "Rob"]
console.log(yetAnotherPerson.friends); // ["Shawn", "Van", "Barbie"]
```
上面的代码演示了寄生式继承的实现。在这个例子中，我们定义了一个 `createAnother` 函数，这个函数的作用是创建一个新对象的副本，并为这个新对象添加一个 `sayHi` 方法，然后返回这个新对象。这种继承方式的优点是对一个简单对象实现继承，如果这个对象不是自定义类型时。缺点是没有办法实现函数的复用。

## 6.寄生式组合继承
第六种方式是寄生式组合继承，组合继承的缺点就是使用超类型的实例做为子类型的原型，导致添加了不必要的原型属性。寄生式组合继承的方式是使用超类型的原型的副本来作为子类型的原型，这样就避免了创建不必要的属性,
```js
function inheritPrototype(subType, superType) {
  var prototype = Object.create(superType.prototype);
  prototype.constructor = subType;
  subType.prototype = prototype;
}

function SuperType(name) {
  this.colors = ['red', 'green', 'blue'];
  this.name = name;
}

SuperType.prototype.sayName = function() {
  console.log(this.name);
}

function SubType(name, age) {
  SuperType.call(this, name);
  this.age = age;
}

inheritPrototype(SubType, SuperType);

SubType.prototype.sayAge = function() {
  console.log(this.age);
}

var instance1 = new SubType('instance1', 20);
instance1.colors.push('yellow');
console.log(instance1.colors); // ['red', 'green', 'blue', 'yellow']
instance1.sayName(); // 'instance1'
instance1.sayAge(); // 20

var instance2 = new SubType('instance2', 25);
console.log(instance2.colors); // ['red', 'green', 'blue']
instance2.sayName(); // 'instance2'
instance2.sayAge(); // 25
```
上面的代码演示了寄生式组合继承的实现。在这个例子中，我们定义了一个 `inheritPrototype` 函数，这个函数的作用是创建一个新对象的副本，并将这个副本的构造函数设置为子类型，然后将这个副本作为子类型的原型。这种继承方式解决了组合继承的缺点，即使用超类型的实例做为子类型的原型，导致添加了不必要的原型属性。

## extends
`extends` 并不属于上面提到的六种继承方式之一，因为它是 ES6 引入的新语法，而这六种继承方式都是在 ES6 之前就已经存在的 JavaScript 继承实现方式。`extends` 关键字是一种语法糖，它的底层实现其实是基于原型链继承和构造函数继承的组合继承方式。当使用 `extends` 来继承一个父类时，子类的原型会被设置为父类的实例对象，同时子类的构造函数会被设置为子类本身。这种方式既继承了父类的属性和方法，又没有出现组合继承中的缺点，使代码更加简洁易读。

需要注意的是，`extends` 关键字只能用于类之间的继承，不能用于其他类型的继承，例如函数之间的继承。如果需要实现函数之间的继承，仍然需要使用原型链继承、构造函数继承或组合继承等方式。
