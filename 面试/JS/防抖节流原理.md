防抖和节流都是常用于优化前端性能的技术，它们的原理如下：

## 1. 防抖（Debounce）

防抖的原理是当事件被触发时，延迟一段时间后再执行回调函数。如果在延迟时间内再次触发事件，则重新开始计时。这样可以避免事件被频繁触发造成的性能问题。具体实现方式是使用定时器和闭包。

例如，我们可以通过实现一个 debounce 函数来实现防抖：

```javascript
function debounce(fn, delay) {
  let timer = null;
  return function() {
    const context = this;
    const args = arguments;
    clearTimeout(timer);
    timer = setTimeout(function() {
      fn.apply(context, args);
    }, delay);
  };
}
```

## 2. 节流（Throttle）

节流的原理是当事件被触发时，执行回调函数后，等待一段时间后再次触发才会执行回调函数。这样可以保证事件不会被短时间内频繁触发。具体实现方式是使用定时器和时间戳。

例如，我们可以通过实现一个 throttle 函数来实现节流：

```javascript
function throttle(fn, delay) {
  let timer = null;
  return function() {
    const context = this;
    const args = arguments;
    if (!timer) {
      timer = setTimeout(function() {
        fn.apply(context, args);
        timer = null;
      }, delay);
    }
  };
}
```


时间戳的节流函数实现方式是记录上一次执行的时间戳，每次触发事件时，判断当前时间戳距离上一次执行的时间戳是否超过规定的时间间隔，如果超过，则执行回调函数，否则不执行。以下是一个时间戳实现方式的节流函数例子：

```javascript
function throttle(fn, delay) {
  let lastTime = 0;
  return function() {
    const context = this;
    const args = arguments;
    const nowTime = +new Date();
    if (nowTime - lastTime > delay) {
      fn.apply(context, args);
      lastTime = nowTime;
    }
  };
}
```

这个函数的作用是：在规定时间内只执行一次函数，如果在规定时间内函数被多次触发，则只有第一次触发会执行函数，后面的触发会被忽略，直到规定时间过去后才会再次执行函数。

这个函数的实现方式是：记录上一次执行函数的时间戳 lastTime，每次触发事件时，获取当前时间戳 nowTime，判断当前时间戳与上一次执行函数的时间戳之差是否超过规定的时间间隔 delay，如果超过，则执行回调函数，并更新上一次执行函数的时间戳。这样可以保证在规定时间内只执行一次函数。

总之，防抖和节流都是通过延迟执行回调函数来避免事件被频繁触发造成的性能问题。防抖和节流的区别在于防抖是在事件触发后延迟一段时间执行回调函数，而节流是在一定时间内只执行一次回调函数。具体实现可以使用定时器和闭包或时间戳来实现。
