前端监控报错的方法有以下几种：

1. **全局错误事件监听 (`window.onerror`)：** 可以通过 `window.onerror` 事件来捕获全局的 JavaScript 错误。当 JavaScript 运行时发生未被捕获的错误时，该事件会被触发，可以在事件处理函数中对错误进行记录和处理。

   ```javascript
   window.onerror = function(message, source, lineno, colno, error) {
     // 处理错误的逻辑
   };
   ```

2. **静态资源错误监听 (`window.addEventListener('error')`)：** 可以通过监听 `error` 事件来捕获静态资源（如图片、脚本、样式表等）加载失败的错误。这样可以获取到加载失败的资源信息，方便进行监控和记录。

   ```javascript
   window.addEventListener('error', function(event) {
     // 处理静态资源加载错误的逻辑
   });
   ```

3. **Promise 错误捕获 (`promise.catch`)：** 当使用 Promise 进行异步操作时，可以使用 `catch` 方法来捕获 Promise 的拒绝状态（rejected），并处理相应的错误逻辑。

   ```javascript
   promise.catch(function(error) {
     // 处理 Promise 错误的逻辑
   });
   ```

4. **全局未捕获异常捕获 (`window.addEventListener('unhandledrejection')`)：** 当 Promise 被拒绝且没有被捕获时，`unhandledrejection` 事件会被触发。可以通过监听该事件来捕获全局的未捕获异常，并进行相应的处理。

   ```javascript
   window.addEventListener('unhandledrejection', function(event) {
     // 处理未捕获的异常
   });
   ```

5. **Vue 错误捕获 (`Vue.config.errorHandler`)：** 如果使用 Vue.js 开发前端应用，可以通过设置 `Vue.config.errorHandler` 来捕获 Vue 组件中发生的错误。

   ```javascript
   Vue.config.errorHandler = function(err, vm, info) {
     // 处理 Vue 组件错误的逻辑
   };
   ```

这些方法可以帮助你在前端监控中捕获和处理错误，以便及时发现和解决潜在的问题。根据具体的应用场景和需求，可以选择适合的监控方法或结合多种方法来实现全面的错误监控。
