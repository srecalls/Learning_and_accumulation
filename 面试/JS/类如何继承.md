## class
使用 `class` 关键字创建类并实现继承的方式：

```js
class Animal {
  constructor(name) {
    this.name = name;
  }

  sayName() {
    console.log(`My name is ${this.name}.`);
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);
    this.breed = breed;
  }

  sayBreed() {
    console.log(`I'm a ${this.breed} dog.`);
  }
}

let dog = new Dog('Buddy', 'Golden Retriever');
dog.sayName(); // 输出 "My name is Buddy."
dog.sayBreed(); // 输出 "I'm a Golden Retriever dog."
```

在上述示例中，使用 `class` 关键字创建了一个名为 `Animal` 的父类和一个名为 `Dog` 的子类。子类通过 `extends` 关键字继承了父类的属性和方法，并在子类的构造函数中使用 `super` 方法调用父类的构造函数。然后，可以在子类中添加自己的属性和方法。通过 `new` 关键字创建子类的实例，并调用实例的方法输出信息。
## function
使用函数创建类并实现继承的方式：

```js
function Animal(name) {
  this.name = name;
}

Animal.prototype.sayName = function() {
  console.log(`My name is ${this.name}.`);
};

function Dog(name, breed) {
  Animal.call(this, name);
  this.breed = breed;
}

Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

Dog.prototype.sayBreed = function() {
  console.log(`I'm a ${this.breed} dog.`);
};

let dog = new Dog('Buddy', 'Golden Retriever');
dog.sayName(); // 输出 "My name is Buddy."
dog.sayBreed(); // 输出 "I'm a Golden Retriever dog."
```

在上述示例中，使用函数的方式创建了一个名为 `Animal` 的父类和一个名为 `Dog` 的子类。子类通过 `Object.create` 方法继承了父类的原型对象，并在子类的构造函数中使用 `Animal.call(this, name)` 方法调用父类的构造函数。然后，可以在子类中添加自己的属性和方法。通过 `new` 关键字创建子类的实例，并调用实例的方法输出信息。

需要注意的是，使用 `class` 关键字和函数的方式都可以实现类的继承，但语法略有不同。使用 `class` 关键字创建类的方式语法更加简洁明了，易于理解和维护；而使用函数创建类的方式更加灵活，可以通过原型链实现更多高级功能。

## class
在 JavaScript 中，使用 `class` 关键字可以定义一个类，并使用 `extends` 关键字来实现类的继承。具体来说，继承的语法如下：

```js
class Child extends Parent {
  // 子类的构造函数
  constructor() {
    super(); // 调用父类的构造函数
    // 子类的其他初始化代码
  }

  // 子类的其他方法
  childMethod() {
    // ...
  }
}
```

在上述示例中，`Child` 类继承了 `Parent` 类，通过 `extends` 关键字将 `Child` 类声明为 `Parent` 类的子类。在子类的构造函数中，需要使用 `super()` 方法调用父类的构造函数，以初始化父类的属性和方法。然后，可以在子类中定义自己的属性和方法。

通过继承，子类可以继承父类的属性和方法，并且可以重写或扩展父类的方法。子类还可以添加自己的属性和方法，以实现更复杂的功能。

需要注意的是，子类继承父类后，可以访问父类的公共属性和方法，但不能访问父类的私有属性和方法。私有属性和方法只能在父类内部访问，子类无法直接访问。

## function
在 JavaScript 中，使用函数创建类的方式也可以实现继承。通常情况下，使用函数创建类时，可以使用原型链来实现继承。

具体来说，可以先定义一个父类函数，然后将父类的方法和属性添加到其原型对象中。接下来，定义子类函数，将子类函数的原型对象设置为父类函数的一个实例，从而实现继承。示例如下：

```
// 父类函数
function Parent() {
  this.name = 'Parent';
}

Parent.prototype.sayHello = function() {
  console.log('Hello from ' + this.name);
};

// 子类函数
function Child() {
  Parent.call(this);
  this.name = 'Child';
}

Child.prototype = Object.create(Parent.prototype);
Child.prototype.constructor = Child;

Child.prototype.sayHi = function() {
  console.log('Hi from ' + this.name);
};

// 创建子类的实例
var child = new Child();
child.sayHello(); // 输出 "Hello from Child"
child.sayHi(); // 输出 "Hi from Child"
```

在上述示例中，`Parent` 函数定义了一个名为 `name` 的属性和一个名为 `sayHello` 的方法，并将 `sayHello` 添加到其原型对象中。`Child` 函数继承了 `Parent` 函数，并重写了 `name` 属性。在子类函数的构造函数中，通过调用 `Parent.call(this)` 方法调用父类函数的构造函数，以初始化父类的属性。然后，将子类函数的原型对象设置为父类函数的一个实例，从而实现继承。最后，可以在子类中添加自己的方法。

需要注意的是，在使用函数创建类时，继承的实现方式与使用 `class` 关键字创建类时略有不同，但原理类似。
