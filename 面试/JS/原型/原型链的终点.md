在 JavaScript 中，原型链的终点是null。也就是说，如果一个对象的原型链上一个对象的原型为null，那么这个对象的原型链就到达了终点，不会再继续向上查找。

在 JavaScript 中，所有对象的原型链最终都会指向Object.prototype，而Object.prototype的原型为null。因此，如果一个对象的原型链上无法再找到其他原型，那么这个对象的原型链就到达了终点null。

例如，对于以下代码：

```javascript
var obj = {};
console.log(obj.toString());
```

在这个例子中，obj对象的原型链如下所示：

obj -> Object.prototype -> null

当访问obj对象的toString()方法时，由于obj对象本身没有这个方法，因此会沿着原型链向上查找，最终找到Object.prototype对象中的toString()方法，并返回其结果。

总之，JavaScript 中所有对象的原型链最终都会指向Object.prototype，而Object.prototype的原型为null，因此原型链的终点是null。
