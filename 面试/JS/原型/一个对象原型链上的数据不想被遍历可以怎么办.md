
当我们想在对象中定义一个不可枚举的属性时，可以使用 Object.defineProperty() 方法来实现。下面这个例子演示了如何将一个属性设置为不可枚举：

``` js
const obj = {
  name: "John",
  age: 28
};

Object.defineProperty(obj, "address", {
  value: "New York",
  enumerable: false // 设置为不可枚举
  configurable: true // configurable：该特性表示该属性是否可被删除或修改。如果属性被设置为可配置（configurable: true），则该属性可以使用delete运算符删除，并且可以使用Object.defineProperty()方法修改该属性的值、writable和enumerable特性。
});

for(let key in obj) {
  console.log(key); // 输出 name 和 age，不包含 address
}

console.log(Object.keys(obj)); // 输出 ['name', 'age']

console.log(obj.address); // 输出 "New York"
```

在上面的例子中，我们使用 Object.defineProperty() 方法将对象 obj 中的属性 address 设置为不可枚举的，这样该属性就不会被 for...in 循环遍历到了，也不会被 Object.keys() 方法返回。但是我们仍然可以通过 obj.address 来访问该属性，因为它仍然存在于对象中，只是不可枚举而已。
