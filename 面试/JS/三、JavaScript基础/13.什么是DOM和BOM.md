DOM 指的是**文档对象模型**，它指的是把**文档**当做**一个对象**，这个对象主要定义了**处理网页内容的方法和接口**

BOM 指的是**浏览器对象模型**，它指的是把**浏览器**当做**一个对象**来对待，这个对象主要定义了与浏览器进行交互的法和接口。BOM的核心是 window，而window 对象具有双重角色，它既是**通过 js 访问浏览器窗口的一个接口**，又是**一个 Global (全局)对象**。这意味着在网页中定义的任何对象，变量和函数都作为全局对象的一个属性或者方法存在。window 对象含有 location 对象navigator 对象、screen 对象等子对象，并且 **DOM 的最根本的对象document 对象也是 BOM 的 window 对象的子对象**。

[[Web API基本认知]]
下面是一些 DOM 和 BOM 的例子：

##### DOM 的例子

```html
<!DOCTYPE html>
<html>
<head>
  <title>DOM Example</title>
</head>
<body>
  <h1>Hello World!</h1>
  <p>This is an example of the Document Object Model (DOM).</p>
  <script>
    // 获取 h1 元素，并修改它的内容
    const h1 = document.querySelector('h1');
    h1.textContent = 'Hello DOM!';
    
    // 获取 p 元素，并添加一个新的子元素
    const p = document.querySelector('p');
    const span = document.createElement('span');
    span.textContent = 'DOM is awesome!';
    p.appendChild(span);
  </script>
</body>
</html>
```

在这个例子中，我们使用 DOM 操作来修改网页的内容。我们获取 h1 元素和 p 元素，并使用 textContent 属性来修改它们的文本内容。我们还创建了一个新的 span 元素，并将其添加为 p 元素的子元素，以展示 DOM 操作的一些基本用法。

##### BOM 的例子

```html
<!DOCTYPE html>
<html>
<head>
  <title>BOM Example</title>
</head>
<body>
  <h1>Hello World!</h1>
  <p>This is an example of the Browser Object Model (BOM).</p>
  <script>
    // 获取浏览器窗口的宽度和高度，并显示在网页上
    const width = window.innerWidth;
    const height = window.innerHeight;
    const p = document.querySelector('p');
    p.textContent = `Window size: ${width} x ${height}`;
    
    // 弹出对话框
    window.alert('Hello BOM!');
  </script>
</body>
</html>
```

在这个例子中，我们使用 BOM 操作来获取浏览器窗口的宽度和高度，并使用 DOM 操作将其显示在网页上。我们还使用 window.alert() 方法来弹出一个对话框，以展示 BOM 操作的一些基本用法。
