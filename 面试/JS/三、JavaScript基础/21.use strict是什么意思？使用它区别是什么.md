`use strict` 是一种 **ECMAscript5** 添加的 (严格模式)运行模式，这种模式使得

Javascript 在更严格的条件下运行。设立严格模式的目的如下

	- 消除 Javascript 语法的不合理、不严谨之处，减少怪异行为;
	- 消除代码运行的不安全之处，保证代码运行的安全;
	- 提高编译器效率，增加运行速度;
	- 为未来新版本的 Javascript 做好铺垫

区别：

	- 禁止使用 with 语句。
	- 禁止 this 关键字指向全局对象
	- 对象不能有重名的属性。

##### 例子
好的，让我来给你举几个例子来说明 `use strict` 的作用。

1. 禁止使用 with 语句

在严格模式下，使用 `with` 语句会抛出语法错误。例如：

```javascript
'use strict';
let obj = { x: 1 };
with (obj) {
  x = 2;
}
```

上面的代码在严格模式下会抛出语法错误，因为 `with` 语句被禁止使用。

2. 禁止 this 关键字指向全局对象

在严格模式下，当函数中的 `this` 指向全局对象时，它的值是 `undefined`，而不是全局对象。例如：

```javascript
'use strict';
function foo() {
  console.log(this);
}
foo(); // 输出 undefined
```

上面的代码在严格模式下运行，输出 `undefined`。

3. 对象不能有重名的属性

在严格模式下，对象不能拥有重名的属性。例如：

```javascript
'use strict';
let obj = { x: 1, x: 2 }; // 抛出语法错误
```

上面的代码在严格模式下会抛出语法错误，因为对象不能拥有重名的属性。

综上，`use strict` 可以帮助我们写出更加严谨、安全、高效的 JavaScript 代码，避免一些可能产生的错误和怪异行为，提高代码的质量和可读性。

## with语句
`with` 语句是 JavaScript 中的一个特殊语句，它的作用是**将一个对象添加到当前的作用域链的头部**，从而可以**直接访问**该**对象的属性和方法**，而不**需要**通过**对象的名称来访问**。`with` 语句的语法如下：

```
with (object) {
  // some code
}
```

其中 `object` 是一个对象，`some code` 是需要执行的代码。

例如，我们有一个对象 `person`，包含了姓名和年龄两个属性：

```javascript
let person = {
  name: 'Tom',
  age: 18
};
```

如果我们想要访问 `person` 对象的属性，通常的做法是通过对象的名称来访问，例如：

```javascript
let name = person.name;
let age = person.age;
```

但是，使用 `with` 语句可以简化这个过程，例如：

```javascript
with (person) {
  let name = name;
  let age = age;
}
```

在这个例子中，我们使用 **`with` 语句将 `person` 对象**添加到**当前的作用域链**中，从而可以**直接访问其属性**。需要注意的是，在 **`with` 语句中访问的变量**，如果当前作用域中**已经存在同名变量**，则会优先使用**当前作用域中的变量**，而**不是**访问**对象的属性。**

虽然 `with` 语句可以简化代码，但是它也有一些缺点和问题。首先，**`with` 语句会改变当前的作用域链**，从而增加了代码的复杂性和不确定性，容易引发一些意想不到的错误。其次，**由于 `with` 语句会将对象添加到作用域链的头部，从而导致属性的查找速度变慢，影响代码的性能。**


当我们使用 `with` 语句时，它会将指定的对象添加到当前作用域链的头部，从而修改了作用域链的结构。这意味着在 `with` 语句内部，可以直接访问该对象的属性和方法，而不需要通过对象的名称来访问。

然而，由于 `with` 语句改变了当前作用域链的结构，容易增加代码的复杂性和不确定性。虽然 `with` 语句可以简化代码，但是它也会引发一些意想不到的错误，例如：

```javascript
let x = 10;
let person = {
  x: 20,
  sayHello: function() {
    console.log(`Hello, my name is ${this.name}, and x is ${x}`);
  }
};

with (person) {
  let name = 'Tom';
  sayHello();
}
```

在这个例子中，我们使用 `with` 语句将 `person` 对象添加到当前作用域链的头部，然后在 `sayHello` 方法中访问了 `x` 变量。由于当前作用域链中已经存在 `x` 变量，因此在 `sayHello` 方法内部访问的 `x` 变量实际上是当前作用域中的 `x` 变量，而不是 `person` 对象中的 `x` 属性。这样就导致了输出结果出现了错误，因为 `x` 变量的值并不是 `person.x`，而是当前作用域中的 `x` 变量。

另外，由于 `with` 语句会将对象添加到作用域链的头部，从而导致属性的查找速度变慢，影响代码的性能。因此，一般情况下不建议使用 `with` 语句。在 ES5 中的严格模式下，`with` 语句是被禁止使用的。

因此，建议尽量避免使用 `with` 语句，而是使用常规的变量访问方式来访问对象的属性。并且值得注意的是，在严格模式下，`with` 语句是被禁止使用的。
