**for...of** 是**ES6新增**的**遍历方式**，允许遍历一个含有**iterator接口**的数据结构(数组、对象等)并且**返回各项的值**，和ES3中的for...in的区别如下

- **for...of** 遍历获取的是**对象的键值**，**for...in** 获取的是**对象的键名**;
- **for... in** 会遍历对象的**整个原型链**，性能非常差不推荐使用，而 **for ...of** 只遍历**当前对象**不会遍历原型链;
- 对于数组的遍历，**for...in** 会返回数组中**所有可枚举的属性(包括原型链上可枚举的属性**)，**for...of** 只返回**数组的下标对应的属性**值;

总结: **for...in** 循环主要是为了**遍历对象**而生，**不适用于遍历数组;**
**for...of** 循环可以用来**遍历数组**、类数组对象，字符串、Set、Map 以及 Generator 对象


好的，下面我来举几个例子来说明 for...in 和 for...of 的区别。

#### for...in 的例子

for...in 循环主要是为了遍历对象而生，可以遍历对象中的所有可枚举属性，包括原型链上的属性。下面的代码演示了 for...in 循环的使用方法。

```javascript
let obj = {a: 1, b: 2, c: 3};
for (let key in obj) {
  console.log(key); // 输出 a b c
  console.log(obj[key]); // 输出 1 2 3
}
```

在上面的代码中，我们定义了一个对象 `obj`，并使用 for...in 循环遍历对象中的所有属性。在每次循环中，变量 `key` 代表对象的属性名，`obj[key]` 代表属性的值。

#### for...of 的例子

for...of 循环可以用来遍历数组、类数组对象，字符串、Set、Map 以及 Generator 对象。下面的代码演示了 for...of 循环遍历数组的用法。

```javascript
let arr = [1, 2, 3];
for (let value of arr) {
  console.log(value); // 输出 1 2 3
}
```

在上面的代码中，我们定义了一个数组 `arr`，并使用 for...of 循环遍历数组中的所有元素。在每次循环中，变量 `value` 代表数组中的元素值。

总之，for...in 循环主要是为了遍历对象而生，不适用于遍历数组；for...of 循环可以用来遍历数组、类数组对象，字符串、Set、Map 以及 Generator 对象。


##### for...in遍历原型链的例子
当使用 `for...in` 循环遍历一个对象的属性时，循环将包括对象的原型链中可枚举的属性。下面是一个简单的例子：

```javascript
// 定义一个构造函数
function Person(name, age) {
  this.name = name;
  this.age = age;
}

// 给 Person 的原型对象添加一个方法
Person.prototype.sayHello = function() {
  console.log("Hello!");
};

// 创建一个 Person 实例
var person = new Person("Alice", 28);

// 使用 for...in 循环遍历 person 对象的属性
for (var prop in person) {
  console.log(prop + ": " + person[prop]);
}
```

在这个例子中，`person` 对象的原型是 `Person.prototype`，它有一个 `sayHello` 方法。当使用 `for...in` 循环遍历 `person` 对象的属性时，`sayHello` 方法也会被遍历到并输出。

输出结果如下：

```js
name: Alice
age: 28
sayHello: function() {
  console.log("Hello!");
}
```
