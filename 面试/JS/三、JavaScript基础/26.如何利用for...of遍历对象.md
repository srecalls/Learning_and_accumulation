`for...of`是作为ES6新增的遍历方式，允许遍历一个**含有iterator接口**的数据结构(**数组、对象等**)并且返回各项的值，**普通的对象用for...of遍历是会报错的**。


是的，`for...of` 循环是 ES6 新增的一种用于遍历可迭代对象的语法。**可迭代对象是指实现了 `Symbol.iterator` 方法的对象**，例如数组、Map、Set 等，而普通的对象并不是可迭代对象。

下面是一个示例，展示了如何使用 `for...of` 循环遍历一个数组和一个普通对象，并展示了普通对象会导致循环失败：

```javascript
// 定义一个数组
const arr = [1, 2, 3];

// 使用 for...of 循环遍历数组
for (const item of arr) {
  console.log(item);
}

// 定义一个普通对象
const obj = { a: 1, b: 2, c: 3 };

// 使用 for...of 循环遍历普通对象
try {
  for (const item of obj) {
    console.log(item);
  }
} catch (e) {
  console.log(e); // TypeError: obj is not iterable
}
```

因此，在使用 `for...of` 循环时，需要确保遍历的对象是一个可迭代对象，否则会导致类型错误。

如果需要遍历的对象是**类数组对象**，用**Array.from转成数组**即可
```js
var obj = {
	0: 'one',
	1: 'two',
	length: 2
}
obj = Array.from(obj)
for (let k of obj) {
	console.log(k) // one two
}
```

如果不是类数组对象，就给对象添加一个`[Symbol.iterator]`属性，并指向一个迭代器即可
```js
var obj = {
	a: 1,
	b: 2,
	c: 3
}
obj[Symbol.iterator] = function() {
	let keys = Object.keys(this)
	let count = 0
	return {
		next() {
			if (count < keys.length) {
				return {value: obj[keys[count++]], done: false}
			} else {
				return {value: undefined, done: true}
			}
		}
	}
}
for(let k of obj) {
	console.log(k)
}
```

方法2
```js
let obj = {
	a: 1,
	b: 2,
	c: 3
}
obj[Symbol.iterator] = function*() {
	let keys = Object.keys(obj)
	for (let k of keys) {
		yield [k, obj[k]]
	}
}
for (let [k, v] of obj) {
	console.log(k, v)
}
```
