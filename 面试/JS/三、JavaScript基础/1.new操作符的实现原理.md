[[手写Object.create]]
[[改变this(apply、call、bind)]]
	(1) 首先创建了一个新的空对象
	(2) 设置原型，将对象的原型设置为函数的 prototype 对象.
	(3)让函数的 this 指向这个对象，执行构造函数的代码 (为这个新对象添加属性)
	(4)判断函数的返回值类型，如果是值类型，返回创建的对象。如果是引用类型，就返回这个引用类型的对象。
```js
function objectFactory() {
	let newObject = null
	let constructor = Array.prototype.shift.call(arguments)
	// 取出传入给 `objectFactory` 函数的第一个参数，并将其作为构造函数 `constructor`。
	let result = null
	// 判断参数是否是一个函数åå
	if (typeof constructor !== "function") {
		console.error("type error")
		return 
	}
	// 新建一个空对象，对象的原型为构造函数的 prototype 对象
	newObject = Object.create(constructor.prototype)
	// 将 this 指向新建对象，并执行函数
	result = constructor.apply(newObject, arguments)
	// 判断返回对象
	let flag = result && (typeof result === 'object' || typeof result === 'function')
	return flag ? result : newObject
}
// 使用方法
objectFactory(构造函数, 初始化参数)
```

### `Array.prototype.shift.call(arguments)` 的作用

在您提供的 `objectFactory` 函数中，`Array.prototype.shift.call(arguments)` 的作用是：

**取出传入给 `objectFactory` 函数的第一个参数，并将其作为构造函数 `constructor`。**

#### 详细分解：

1. **`arguments`**：
    
    - 这是在函数内部可用的一个类数组对象（Array-like Object），它包含了所有传入 `objectFactory` 函数的参数。
        
    - 例如，如果您调用 `objectFactory(Person, 'Alice', 30)`，那么 `arguments` 类似于 `{ '0': Person, '1': 'Alice', '2': 30, length: 3 }`。
        
2. **`Array.prototype.shift`**：
    
    - 这是数组的原生 `shift()` 方法。该方法会**移除数组的第一个元素，并返回该元素**。同时，它会修改原数组（类数组对象）。
        
3. **`.call(arguments)`**：
    
    - 因为 `arguments` 是一个**类数组对象**而不是真正的数组，它没有 `shift` 方法。
        
    - 通过使用 `call` 方法，我们可以**借用**数组的 `shift` 方法，并将 `this` 显式地绑定到 `arguments` 这个类数组对象上。
        

#### 整个语句执行的结果：

- 它将 `arguments` 中的第一个元素（即我们希望作为构造函数的那个函数，例如 `Person`）移除并返回。
    
- 返回的值被赋给变量 `constructor`。
    
- `arguments` 中剩下的元素（即传递给构造函数的参数，例如 `'Alice', 30`）仍然保留在 `arguments` 中，以供后续的 `constructor.apply(newObject, arguments)` 使用。
    

### 对应 `new` 操作符的执行步骤：

|**new 步骤**|**对应 objectFactory 代码**|**说明**|
|---|---|---|
|**【参数准备】**|`let constructor = Array.prototype.shift.call(arguments)`|从传入参数中**分离出构造函数**，剩余的参数是给构造函数使用的。|
|(1) **创建对象**|`newObject = Object.create(constructor.prototype)`|创建空对象并设置原型（结合了您步骤(1)和(2)）。|
|(2) **设置原型**|`newObject = Object.create(constructor.prototype)`||
|(3) **执行构造函数**|`result = constructor.apply(newObject, arguments)`|将 `this` 绑定到 `newObject`，并传入**剩余的参数**来执行构造函数，为新对象初始化属性。|
|(4) **处理返回值**|`return flag ? result : newObject`|根据返回值类型，决定返回 `result` 还是创建的 `newObject`。|

这个 `objectFactory` 函数很好地模拟了 `new` 操作符的行为。

### 构造函数

首先，定义一个我们将用作模板的构造函数 `Animal`：

function Animal(name, species) {
  this.name = name;
  this.species = species;

Animal.prototype.makeSound = function() {

### 您的 `objectFactory` 函数

JavaScript

```
function objectFactory() {
	let newObject = null
	// 1. 取出构造函数，剩余的 arguments 是构造函数所需的参数
	let constructor = Array.prototype.shift.call(arguments)
	let result = null
	
	if (typeof constructor !== "function") {
		console.error("type error: First argument must be a function")
		return 
	}
	
	// 2. 创建一个新对象，并将新对象的原型指向构造函数的 prototype 对象
	newObject = Object.create(constructor.prototype)
	
	// 3. 将 this 指向新建对象，并执行构造函数，为新对象添加自有属性
	// 注意：这里的 arguments 已经是移除了第一个参数（构造函数）后的剩余参数
	result = constructor.apply(newObject, arguments)
	
	// 4. 判断构造函数的返回值：如果是对象（引用类型），则返回 result；否则返回 newObject
	let flag = result && (typeof result === 'object' || typeof result === 'function')
	
	return flag ? result : newObject
}
```

### 示例使用

现在，我们使用 `objectFactory` 来“手写”创建一个新的 `Animal` 实例，效果等同于 `new Animal('Max', 'Dog')`。

JavaScript

```

console.log(myDog);
// 打印结果类似: { name: 'Max', species: 'Dog' }

// 验证自有属性是否正确设置 (步骤 3)
console.log(`Name: ${myDog.name}`);      // 输出: Name: Max

// 验证原型方法是否被继承 (步骤 2)
console.log(myDog.makeSound());  // 输出: Max makes a sound.

// 验证原型链是否正确
console.log(Object.getPrototypeOf(myDog) === Animal.prototype); // 输出: true
```

    // 手写 Object.create (myObjectCreate) 内部

### 如何理解这种“循环套用”

这并不是真正的循环依赖，而是一种**概念上的解耦和分层实现**。在 JavaScript 语言层面，`new` 和 `Object.create` 是两个**不同的基本机制**，但它们都可以用彼此的底层原理来模拟实现。

#### 1. 手写 `new` 使用 `Object.create`（概念解耦）

new 操作符的核心目标：

创建一个实例对象，这个实例的创建过程是复杂的：

- ✅ **创建对象并关联原型** (这只是其中一步)
    
- ✅ 执行构造函数
    
- ✅ 处理返回值
    

当我们在 `objectFactory` 中手写 `new` 时，我们希望**专注于**完成它的 4 个步骤。其中“创建对象并设置原型”这一步骤，恰好是 `Object.create()` 的**唯一职责**。

- **为什么要用 `Object.create()`？**
    
    - `Object.create()` 完美地解决了 `new` 步骤中的关键部分：`创建一个对象，并将其原型设置为 Person.prototype`。
        
    - 通过使用 `Object.create()`，我们**简化了 `objectFactory` 的实现**，不用自己再去操心空函数和 `new F()` 的细节，而是直接调用一个专门解决这个问题的工具。
        
    - 这体现了代码的**模块化和高内聚**：让专门的工具做专门的事。
        

#### 2. 手写 `Object.create` 使用 `new`（基于底层原理实现）

Object.create() 的核心目标：

创建一个新对象，其唯一的职责是设置原型。

- **为什么要用 `new` F()？**
    
    - `Object.create()` 必须在不执行任何构造函数逻辑的情况下，创建一个对象的实例，并让这个实例的原型指向指定对象 (`proto`)。
        
    - 在 JavaScript 的底层设计中，`new` 操作符是唯一能直接触发**原型链链接**的机制（即 `实例.__proto__ === 构造函数.prototype`）。
        
    - 我们通过创建一个**空函数** `F` 并执行 `new F()`，来**借用** `new` 的底层原型链接机制，从而达到设置原型的目的，同时避免执行任何不相关的初始化逻辑。
        

### 总结关系

|**机制**|**目标（作用）**|**实现中使用的工具**|**为什么使用它？**|
|---|---|---|---|
|**`new`**|创建并初始化一个实例|使用 `Object.create()`|将“创建和链接原型”这一功能分解出去，简化实现。|
|**`Object.create`**|仅创建一个对象并设置原型|使用 `new` (空函数)|借用 `new` 操作符底层自带的“原型链接”能力，实现设置原型的目标。|

这两种手写实现，都是利用了 JavaScript 语言中**已有的、更底层的机制**来搭建上层的、更复杂的概念。在实际的面试中，如果让您手写 `new`，使用 `Object.create` 是一个简洁且正确的选择；如果让您手写 `Object.create`，那么使用空函数 `F` 和 `new F()` 是最经典的答案。

## 他具体的内部实现更复杂是吗
是的，您的理解是**完全正确**的。JavaScript 引擎的内部实现要比我们手动模拟或概念上描述的复杂得多。

当我们讨论 **`new` 操作符** 和 **`Object.create()`** 的底层实现时，它们涉及到的其实是语言核心规范中定义的、与内存和对象结构直接相关的抽象操作。

### 内部实现比模拟复杂的原因

#### 1. 抽象操作（Abstract Operations）

`new` 操作符和 `Object.create` 最终都是通过调用一系列 **ECMAScript 规范中的“抽象操作”** 来完成的，这些操作是面向引擎级别的，无法直接在 JS 代码中访问：

- **`Object.create()` 对应：** `OrdinaryCreateFromConstructor(constructor, intrinsicProto)`
    
- **`new` 操作符（函数调用）对应：** `[[Construct]]` 内部方法。
    

#### 2. 内存管理和对象结构

我们的 JS 代码模拟，如 `new F()` 或 `Object.create(constructor.prototype)`，只能在 JS 层面操作对象和函数。但引擎的内部实现必须处理：

- **分配内存 (Memory Allocation)：** 为新对象在堆上分配连续或非连续的内存空间。
    
- **设置内部槽位 (Internal Slots)：** JS 对象包含一些特殊的、不可直接访问的内部属性，例如：
    
    - `[[Prototype]]`：这是真正的原型指针。
        
    - `[[Extensible]]`：对象是否可扩展（能否添加新属性）。
        
    - `[[Constructor]]`：指向构造函数（如果适用）。
        
- **属性存储优化 (Property Storage Optimization)：** 现代 JS 引擎（如 V8）使用隐藏类（Hidden Classes）或形状（Shapes）来优化属性查找和访问速度，这远比我们简单地设置一个键值对复杂。
    

#### 3. 关于原型链的设置

我们手写 `Object.create` 时使用 `function F() {}` 和 `new F()` 是为了**绕过**无法直接操作 `[[Prototype]]` 的限制。

JavaScript

```
// JS 模拟：借用 new 的副作用
F.prototype = proto;
const newObject = new F();
```

但引擎在执行 `Object.create(proto)` 时，它会直接执行类似 C++ 或其他底层代码，**直接设置**新创建对象的 `[[Prototype]]` 内部槽位为 `proto`，无需任何中间函数或 `new` 操作。

**总结：**

我们的手写代码和概念描述是基于 **JavaScript 语言特性**和**高层逻辑**的抽象；而引擎的内部实现是基于 **计算机科学原理**和**底层内存操作**的优化。您应该专注于理解它们在 JS 层面上的**功能和作用机制**，这对于前端面试已经足够了。
