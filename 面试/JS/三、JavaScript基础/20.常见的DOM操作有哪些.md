## (1)DOM节点的获取
DOM节点的获取的API及使用

	document.getElementById
	document.getElementsByTagName
	document.getElementsByClassName
	document.querySelector
	document.querySelectorAll

```js
getElementById // 按照id查询
getElementByTagName // 按照标签名查询
getElementByClassName // 按照类名查询
querySelectorAll // 按照 css 选择器查询

// 按照id查询
var imooc = document.getElementById('imooc') // 查询到id为imooc的元素
// 按照标签名查询
var divList = document.getElementByTagName('div') // 查询到标签为 div 的集合
console.log(divList.length)
console.log(divList[0])
// 按照类名查询
var moocList = document.getElementByClassName('mooc') // 查询到类名为 mooc 的集合
// 按照 css 选择器查询
var pList = document.querySelectorAll('.mooc') // 查询到类名为 mooc 的集合
```

### 1. `document.getElementById`:

   - 语法: `document.getElementById(elementId)`
   - 参数:
     - `elementId`: 一个字符串，表示要选择的元素的 ID。
   - 返回值: 返回与指定 ID 匹配的元素，如果找不到匹配的元素，则返回 `null`。
   - 用法示例:
     ```javascript
     const element = document.getElementById('my-element'); // 通过 ID 选择元素
     ```

   易错点：

   - 如果指定的 ID 不存在于文档中，`getElementById` 方法将返回 `null`，因此在使用返回结果之前，需要确保所需的元素存在。

### 1. `document.getElementsByTagName`:

   - 语法: `document.getElementsByTagName(tagName)`
   - 参数:
     - `tagName`: 一个字符串，表示要选择的元素的标签名。
   - 返回值: 返回一个 HTMLCollection 对象，其中包含匹配指定标签名的所有元素，如果找不到匹配的元素，则返回空的 HTMLCollection。
   - 用法示例:
     ```javascript
     const elements = document.getElementsByTagName('div'); // 选择所有 <div> 元素
     ```

   易错点：

   - `getElementsByTagName` 方法返回的是一个 HTMLCollection 对象，它是一个实时集合，会随着文档的变化而更新。如果需要对结果进行迭代或操作，需要注意在循环中使用正确的索引范围。

### 1. `document.getElementsByClassName`:

   - 语法: `document.getElementsByClassName(className)`
   - 参数:
     - `className`: 一个字符串，表示要选择的元素的类名。
   - 返回值: 返回一个 HTMLCollection 对象，其中包含具有指定类名的所有元素，如果找不到匹配的元素，则返回空的 HTMLCollection。
   - 用法示例:
     ```javascript
     const elements = document.getElementsByClassName('my-class'); // 选择所有具有 'my-class' 类名的元素
     ```

   易错点：

   - `getElementsByClassName` 方法返回的是一个 HTMLCollection 对象，它是一个实时集合，会随着文档的变化而更新。如果需要对结果进行迭代或操作，需要注意在循环中使用正确的索引范围。

注意事项：

- 这些方法返回的是静态或实时的集合对象，需要根据具体的需求来选择使用哪种对象。
- 在使用返回的集合对象时，需要注意处理集合为空的情况，以避免出现错误。
- `getElementById` 方法是通过元素的 ID 进行选择，因此在文档中应保持 ID 的唯一性。
- `getElementsByTagName` 和 `getElementsByClassName` 方法返回的是类数组对象，可以使用索引或循环来访问其中的元素。
- `getElementsByTagName` 和 `getElementsByClassName` 方法返回的集合对象是动态的，会随着文档变化而更新。

`querySelector` 和 `querySelectorAll` 是 JavaScript 中用于选择 DOM 元素的方法。

### 1. `querySelector`:

   - 语法: `element.querySelector(selectors)`
   - 参数:
     - `selectors`: 一个字符串，表示要选择的元素的 CSS 选择器。
   - 返回值: 返回匹配选择器的第一个元素，如果没有匹配的元素，则返回 `null`。
   - 用法示例:
     ```javascript
     const element = document.querySelector('.my-class'); // 通过类名选择元素
     const element = document.querySelector('#my-id'); // 通过 ID 选择元素
     const element = document.querySelector('div'); // 通过元素类型选择元素
     ```

### 1. `querySelectorAll`:

   - 语法: `element.querySelectorAll(selectors)`
   - 参数:
     - `selectors`: 一个字符串，表示要选择的元素的 CSS 选择器。
   - 返回值: 返回一个 NodeList 对象，其中包含匹配选择器的所有元素，如果没有匹配的元素，则返回空的 NodeList。
   - 用法示例:
     ```javascript
     const elements = document.querySelectorAll('.my-class'); // 通过类名选择元素集合
     const elements = document.querySelectorAll('div'); // 通过元素类型选择元素集合
     ```

易错点：

- 选择器字符串的书写错误：在使用 `querySelector` 和 `querySelectorAll` 时，选择器字符串需要按照正确的 CSS 选择器语法书写，否则可能无法正确选择到元素。
- 返回值为空的处理：如果使用 `querySelector` 或 `querySelectorAll` 返回的是空结果（`null` 或空的 NodeList），需要进行合理的判断和处理，以避免后续操作出错。
- 动态元素选择：如果使用 `querySelector` 或 `querySelectorAll` 选择的元素是动态生成的，需要确保在元素生成后再进行选择，否则可能选择不到目标元素。
- 兼容性问题：`querySelector` 和 `querySelectorAll` 是在较新的 JavaScript 版本中引入的，因此在一些旧版本的浏览器中可能不被支持。在使用时需注意浏览器的兼容性。

## (2)DOM节点的创建
创建一个新节点，并把它添加到指定节点的后面，已知的HTML结构如下
```js
<html>
	<head>
		<title>DEMO</title>
	<head>
	<body>
		<div id="container">
			<h1 id="title">我是标题</h1>
		<div>
	</body>
</html>
```
要求添加一个有内容的span节点到id为title的节点后面，做法就是
```js
// 首先获取父节点
var container = document.getElementById('container')
// 创建新节点
var targetSpan = document.createElement('span')
// 设置 span 节点到内容
targetSpan.innerHtml = 'hello world'
// 把新创建的元素塞进父节点里去
container.appendChild(targetSpan)
```

## (3) DOM节点的添加
删除指定的DOM节点，已知的HTML结构如下
```js
<html>
	<head>
		<title>DEMO</title>
	</head>
	<body>
		<div id="container">
			<h1 id="title">我是标题</h1>
		</div>
	</body>
</html>
```

需要删除 id  为 title 元素，做法是：
```js
// 获取目标元素的父元素
var container = document.getElementById('container')
// 获取目标元素
var targetNote = document.getElementById('title')
// 删除目标元素
container.removeChild(targetNode)
```

或者通过自节点数组来完成删除

```js
// 获取目标元素的父元素
var container = document.getElementById('container')
// 获取目标元素
var targetNode = container.childNodes[1]
// 删除目标元素
container.removeChild(targetNode)
```

## (4).修改DOM元素
修改DOM元素这个动作可以分很多维度, 比如说移动DOM元素的位置，改变DOM元素的属性等

**将指定的两个DOM元素交换位置**
已知HTML的结构如下
```js
<html>
	<head>
		<title>DEMO</title>
	</head>
	<body>
		<div id="container">
			<h1 id="title">我是标题</h1>
			<p id='content'>我是内容</p>
		</div>
	</body>
</html>
```

现在需要调换title和content的位置，可以考虑insertBefore或者appendChild

```js
// 获取目标元素的父元素
var container = document.getElementById('container')
// 获取两个需要被交换的元素
var title = document.getElementById('title')
var content = document.getElementById('content')
// 交换两个元素，把content 置于title前面
container.insertBefore(content, title)
```
