一个拥有 **length 属性**和**若干索引属性的对象**就可以被称为**类数组对象**，类数组对象和数组类似，但是**不能调用数组**的方法。常见的类数组对象有 **arguments** 和**DOM 方法的返回结果**，还有**一个函数**也可以被看作是**类数组对象**，因为它含有**length** 属性值，代表**可接收的参数个数。**

常见的类数组转换为数组的方法有这样几种:
### (1) 通过 call 调用数组的 slice 方法来实现转换
```js
Array.prototype.slice.call(arrayLike)
```
##### 例子
```js
function toArray1() {
  console.log(Array.prototype.slice.call(arguments));
}

toArray1(1, 2, 3); // 输出 [1, 2, 3]

const arrayLike1 = { 0: 'a', 1: 'b', 2: 'c', length: 3 };
console.log(Array.prototype.slice.call(arrayLike1)); // 输出 ['a', 'b', 'c']
```

在这个例子中，我们定义了一个函数 toArray1，它通过调用 Array.prototype.slice.call(arguments) 将传入的参数转换为数组。我们还使用了一个类数组对象 arrayLike1，它模拟了一个数组，但是没有数组的一些方法，例如 slice。我们通过调用 Array.prototype.slice.call(arrayLike1) 将其转换为数组。

### (2) 通过 call 调用数组的 splice 方法来实现转换
```js
Array.prototype.splice.call(arrayLike, 0)
```

##### 例子
```js
const arrayLike2 = { 0: 'a', 1: 'b', 2: 'c', length: 3 };
console.log(Array.prototype.splice.call(arrayLike2, 0)); // 输出 ['a', 'b', 'c']
console.log(arrayLike2); // 输出 { length: 0 }
```
在这个例子中，我们使用了一个类数组对象 arrayLike2，并通过调用 Array.prototype.splice.call(arrayLike2, 0) 将其转换为数组。这个方法的原理是使用 splice 方法删除数组的所有元素，并返回被删除的元素组成的数组。由于我们没有指定删除的范围，所以它会删除数组的所有元素。


### (3) 通过 apply 调用数组的 concat 方法来实现转换
```js
Array.prototype.concat.apply([], arrayLike)
```
##### 例子
```js
const arrayLike3 = { 0: 'a', 1: 'b', 2: 'c', length: 3 };
console.log(Array.prototype.concat.apply([], arrayLike3)); // 输出 ['a', 'b', 'c']
```

在这个例子中，我们使用了一个类数组对象 arrayLike3，并通过调用 Array.prototype.concat.apply([], arrayLike3) 将其转换为数组。这个方法的原理是将一个空数组作为 concat 方法的上下文（即 this），并将类数组对象作为参数传入 concat 方法。由于 concat 方法会将参数中的所有数组合并成一个新数组，所以这个方法的返回值就是转换后的数组。
### (4) 通过 Array.from 方法来实现转换
```js
Array.from(arrayLike)
```
##### 例子
```js
const arrayLike4 = { 0: 'a', 1: 'b', 2: 'c', length: 3 };
console.log(Array.from(arrayLike4)); // 输出 ['a', 'b', 'c']
```
在这个例子中，我们使用了一个类数组对象 arrayLike4，并通过调用 Array.from(arrayLike4) 将其转换为数组。这个方法的原理是将类数组对象（或者可迭代对象）转换为数组。它会返回一个新数组，其中包含类数组对象中的所有元素。
