encodeURI 是对**整个 URI** 进行转义，将 URI 中的**非法字符转换为合法字符**，所以对于一些在 URI 中**有特殊意义的字符不会进行转义。**

encodeURIComponent 是对 **URI 的组成部分**进行转义，所以**一些特殊字符也会得到转义,**

escape 和 encodeURI 的作用相同，不过它们对于 unicode 编码为 0xff 之外字符的时候会有区别，**escape 是直接在字符的 unicode 编码前加上 %u**，而**encodeURI 首先会将字符转换为 UTF-8 的格式**，再在**每个字节前加上 %**。

下面是一些使用 encodeURI、encodeURIComponent、escape 的例子：

##### encodeURI 的例子

```js
const uri = 'http://example.com/Hello World.html';
const encodedUri = encodeURI(uri);
console.log(encodedUri); // 输出 http://example.com/Hello%20World.html
```

在这个例子中，我们使用 encodeURI 方法对整个 URI 进行转义。URI 中的空格被转换为 %20。

##### encodeURIComponent 的例子

```js
const uriComponent = 'Hello, World!';
const encodedUriComponent = encodeURIComponent(uriComponent);
console.log(encodedUriComponent); // 输出 Hello%2C%20World%21
```

在这个例子中，我们使用 encodeURIComponent 方法对 URI 的组成部分进行转义。逗号和感叹号这些特殊字符也被转义了。

##### escape 的例子

```js
const str = '你好，世界！';
const escapedStr = escape(str);
console.log(escapedStr); // 输出 %u4F60%u597D%uFF0C%u4E16%u754C%uFF01
```

在这个例子中，我们使用 escape 方法将字符串转义为 URI 组件。中文字符被转换为了形如 %uxxxx 的形式，其中 xxxx 是字符的 unicode 编码。注意到这里的编码方式和 encodeURI 不同，它直接在字符的 unicode 编码前加上了 %u，而不是先将字符转换为 UTF-8 的格式再在每个字节前加上 %。
