```js
// (1) 匹配 16 进制颜色值
var regex = /#([0-9a-fA-F]{6}|[0-9a-fA-F]{3})/g

// (2) 匹配日期，如 yyyy-mm-dd 格式
var regex = /^[0-9]{4}-(0[1-9]|1[0-2])-(0[1-9]|[12][0-9]|3[01])$/

//匹配 qq 号
var regex = /^[1-9][0-9]{4, 10}$/g

//匹配手机号码正则
var regex = /^1[34578]\d{9}$/g

// 匹配用户名正则
var regex = /^[a-zA-Z\$][a-zA-Z0-9_\$]{4, 16}$/
```

在正则表达式中，美元符号 `$` 通常表示匹配字符串末尾的位置，例如 `/hello$/` 就可以匹配以 "hello" 结尾的字符串。

但是在某些情况下，我们需要匹配字符本身而不是特殊含义。这时候就需要使用转义字符 `\` 来表示字符的字面意义。在这个正则表达式中，`\$` 表示匹配字符 `$` 本身，而不是特殊含义。

另外，正则表达式中的方括号 `[]` 表示匹配一个字符集合，其中的任意字符都可以匹配，例如 `[a-zA-Z0-9_\$]` 表示匹配一个大小写字母、数字、下划线或者美元符号。`{4,16}` 表示前面的字符集合需要重复出现 4 到 16 次，这个正则表达式的含义是匹配一个长度在 5 到 17 之间的字符串，以字母或者美元符号开头，包含英文字母、数字、下划线或者美元符号。
