## (1) Map
map本质上就是**键值对**的集合，但是普通的Object中的键值对中的键只能是**字符串**
而ES6提供的Map数据结构类似于对象，但是它的**键不限制范围，可以是任意类型**，是一种更加完善的Hash结构。
如果Map的键是一个**原始数据类型**，只要**两个键严格相同**，就视为是同一个键。


实际上**Map是一个数组**，它的**每一个数据也都是一个数组**，其形式如下:
```js
const map = [
	["name", "张三"],
	["age", 18]
]
```

Map数据结构有以下操作方法:

	- size: map.size返回Map结构的成员总数
	- set(key;value): 设置键名key对应的键值value，然后返回整个Map结构，如果key已经有值，则键值会被更新，否则就新生成该键。(因为返回的是当前Map对象，所以可以链式调用)
	- get(key): 该方法读取key对应的键值，如果找不到key，返回undefined.
	- has(key): 该方法返回一个布尔值，表示某个键是否在当前Map对象中,
	- delete(key): 该方法删除某个键，返回true，如果删除失败，返回false。
	- clear(): map.clear()清除所有成员，没有返回值。

Maps结构原生提供是三个遍历器生成函数和一个遍历方法

	- keys(): 返回键名的遍历器
	- values(): 返回键值的遍历器
	- entries(): 返回所有成员的遍历器
	- forEach(): 遍历Map的所有成员

```js
const map = new Map([
	["foo", 1],
	["bar", 2]
])
for (let key of map.keys()) {
	console.log(key) // foo bar
}
for (let value of map.values()) {
	console.log(value) // 1 2
}
for (let items of map.entries()) {
	console.log(items) // ["foo", 1] ["bar", 2]
}
map.forEach((value, key, map) => {
	console.log(key, value) // foo 1 bar 2
})
```


### 下面是一个使用 Map 的例子：

```js
const map = new Map();
const key1 = { name: 'Alice' };
const key2 = { name: 'Bob' };

map.set(key1, 1);
map.set(key2, 2);

console.log(map.get(key1)); // 输出1
console.log(map.get(key2)); // 输出2
console.log(map.size); // 输出2

map.delete(key1);
console.log(map.get(key1)); // 输出undefined
console.log(map.size); // 输出1
```

在这个例子中，我们创建了一个 Map 对象，并使用两个对象作为键，分别设置它们对应的值为 1 和 2。我们还可以通过调用 map.get() 方法获取键对应的值，通过 map.size 获取 Map 结构的成员总数，通过 map.delete() 方法删除指定键。

## (2) WeakMap
WeakMap 对象**也是一组键值对**的集合，其中的键是**弱引用**的。其**键**必须是**对象**,**原始数据类型不能作为key值**，而值可以是任意的。

该对象也有以下几种方法:

	- set(key;value): 设置键名key对应的键值value，然后返回整个Map结构，如果key已经有值，则键值会被更新，否则就新生成该键。(因为返回的是当前Map对象，所以可以链式调用)
	- get(key): 该方法读取key对应的键值，如果找不到key，返回undefined.
	- has(key): 该方法返回一个布尔值，表示某个键是否在当前Map对象中。
	- delete(key): 该方法删除某个键，返回true，如果删除失败，返回false。其clear()方法已经被弃用，所以可以通过创建一个空的WeakMap并替换原对象来实现清除

WeakMap的设计目的在于，有时**想在某个对象上面存放一些数据**，但是这会形成对于这个对象的引用。一旦不再需要这两个对象，就必须**手动删除这个引用**，**否则垃圾回收机制就不会释放对象占用的内存**。

而WeakMap的**键名所引用的对象都是弱引用**，即**垃圾回收机制不将该引用考虑在内**。因此，只要所引用的对象的其他引用都被清除，垃圾回收机制就会释放该对象所占用的内存。也就是说，一旦不再需要，**WeakMap 里面的键名对象和所对应的键值对会自动消失，不用手动删除引用**


总结:

	- Map 数据结构。它类似于对象，也是键值对的集合，但是“键”的范围不限于字符串，各种类型的值 (包括对象）都可以当作键。
	- WeakMap 结构与 Map 结构类似，也是用于生成键值对的集合。但是WeakMap 只接受对象作为键名 (null 除外)，不接受其他类型的值作为领名。而且 WeakMap 的键名所指向的对象，不计入垃圾回收机制。


### 下面是一个使用 WeakMap 的例子：

```js
const weakMap = new WeakMap();
const key1 = { name: 'Alice' };
const key2 = { name: 'Bob' };

weakMap.set(key1, { age: 18 });
weakMap.set(key2, { age: 20 });

console.log(weakMap.get(key1)); // 输出{ age: 18 }
console.log(weakMap.get(key2)); // 输出{ age: 20 }

key1 = null;
console.log(weakMap.get(key1)); // 输出undefined
```

在这个例子中，我们创建了一个 WeakMap 对象，并使用**两个对象作为键**，分别设置它们对应的值为另外一个对象。我们还可以通过调用 **weakMap.get()** 方法获取**键对应的值**，但是我们**不能像 Map 一样使用 size 和 delete 方法**。我们还可以看到，当我们将 key1 设置为 null 后，它所对应的键值对也被自动删除了。这是因为 key1 不再引用原对象，所以该对象就可以被垃圾回收机制回收，从而自动删除键值对。、



`Map` 和 `WeakMap` 是 JavaScript 中的两种不同的键值存储集合。它们之间有以下区别：

1. 键的类型和引用：
   - `Map` 的键可以是任意类型的值（包括原始类型和对象引用），并且会保留对键的引用。
   - `WeakMap` 的键只能是对象引用，并且对键的引用是弱引用。这意味着如果没有其他引用指向键对象时，`WeakMap` 中的键值对可能会被垃圾回收机制自动清除。

2. 内存管理：
   - `Map` 使用常规的垃圾回收机制进行内存管理，即使存在对键的引用，只有在 `Map` 对象本身被垃圾回收时，键值对才会被清除。
   - `WeakMap` 使用弱引用，当键对象没有其他引用时，垃圾回收机制会自动清除相应的键值对，无需手动处理。

3. 遍历和大小：
   - `Map` 提供了遍历方法（如 `forEach`、`keys`、`values` 和 `entries`），并且可以通过 `size` 属性获取键值对的数量。
   - `WeakMap` 不提供直接的遍历方法，也没有 `size` 属性，因为键的引用可能已经被垃圾回收。

4. 安全性：
   - `Map` 中的键值对是可枚举的，可以通过 `for...of` 循环或 `Map` 的遍历方法访问。
   - `WeakMap` 中的键值对是不可枚举的，无法直接访问所有键值对，因为键的引用是弱引用，可能已经被垃圾回收。

适用场景：
- `Map` 适用于需要存储键值对，并且需要保留对键的引用，以及遍历和获取大小等操作的情况。
- `WeakMap` 适用于需要存储键值对，并且键是对象引用，且随时可能被垃圾回收的情况。它常用于存储和跟踪对象的附加数据或私有数据。

需要根据具体的需求来选择使用 `Map` 还是 `WeakMap`。

### 2. 部署私有属性

利用弱映射，将内部属性设置为实例的弱引用对象，当实例删除时，私有属性也会随之消失，因此不会内存泄漏

![image-20210725172559971](https://p3-juejin.byteimg.com/tos-cn-i-k3u1fbpfcp/9843042808ba4d888d838f9a434e35ed~tplv-k3u1fbpfcp-zoom-in-crop-mark:1512:0:0:0.awebp)

使用弱映射（`WeakMap`）可以确保在实例被删除时，相关的私有属性也会被自动清除，从而避免内存泄漏。下面是一个示例，演示了如何使用弱映射来管理实例的私有属性：

```javascript
// 创建一个弱映射来存储实例的私有属性
const privateProps = new WeakMap();

// 创建一个类
class Person {
  constructor(name) {
    // 在构造函数中，将私有属性存储到弱映射中
    privateProps.set(this, { name });
  }

  // 其他公共方法可以访问和操作私有属性
  getName() {
    return privateProps.get(this).name;
  }
}

// 创建实例
let person = new Person('John');

// 获取私有属性
console.log(person.getName()); // 'John'

// 删除实例
person = null;

// 实例被删除后，与其关联的私有属性也会被自动清除
```

在上述示例中，我们使用弱映射 `privateProps` 来存储实例的私有属性。在 `Person` 类的构造函数中，我们将私有属性存储到弱映射中，其中键是实例对象，值是一个对象，包含实例的私有属性。

通过 `getName()` 方法，我们可以在类的内部访问和操作私有属性。当我们删除实例 `person`（将其设置为 `null`）时，与该实例关联的私有属性也会被自动清除。这确保了在实例被删除时不会出现内存泄漏。

这是一个简单的示例，演示了如何使用弱映射来管理实例的私有属性。弱映射的特性可以帮助我们更好地处理对象之间的关联，同时避免潜在的内存泄漏问题。
