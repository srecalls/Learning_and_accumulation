### prototype里面有什么，为什么Object.entries获取不到

```js
    function fn(name) {
        this.name = name
    }
    let a = new fn('aaa')
    console.log('a', a) 
    // fn {name:'aaa'}
    console.log('prototype', fn.prototype) 
    // prototype {constructor:f}
    console.log('proto', a.__proto__) 
    // prototype {constructor:f}
    console.log(Object.entries(a)) 
    // [Array(2)]
    console.log(Object.prototype.toString.call(fn)) 
    // [object Function]
    console.log(Object.prototype.toString.call(fn.prototype)) 
    // [object Object]
    console.log(Object.prototype.toString.call(a)) 
    // [object Object]
    console.log(Object.prototype.toString.call(a.__proto__)) 
    // [object Object]
    console.log(Object.entries(fn.prototype)) 
    // []
```


![[Pasted image 20230620234802.png]]


在这段代码中，`fn` 是一个构造函数，它的 `prototype` 属性是一个对象。在 JavaScript 中，每个函数都有一个 `prototype` 属性，它指向一个原型对象（即 `__proto__`），包含了该构造函数创建的所有实例共享的属性和方法。当使用 `new` 关键字调用构造函数创建一个实例时，该实例的 `__proto__` 属性会指向构造函数的 `prototype` 属性。

在这个例子中，`fn.prototype` 对象默认只有一个属性，即 `constructor`，它指向 `fn` 函数本身。因此，`fn.prototype` 对象的内容如下所示：

```js
{
    constructor: fn
}
```

需要注意的是，`Object.entries()` 方法只能获取到对象自身的可枚举属性，而不能获取到对象原型链上的属性。在这个例子中，`fn.prototype` 对象只有一个不可枚举属性 `constructor`，因此无法通过 `Object.entries()` 方法获取到任何键值对。如果想要获取原型对象上的属性，可以通过 `Object.getOwnPropertyNames()` 或 `Object.getOwnPropertySymbols()` 方法获取到对象自身的所有属性，然后再通过 `Object.getPrototypeOf()` 方法递归遍历原型链上的属性。
