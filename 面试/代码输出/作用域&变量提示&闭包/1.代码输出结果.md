[[黑马pink闭包]]
```js
(function() {
	var x = y = 1
})()
var z

console.log(y) // 1
console.log(z) // undefined
console.log(x) // Uncaught ReferenceError: x is not defined
```

这段代码的关键在于: var x =y = 1; 实际上这里是从右往左执行的，首先执行y = 1,因为y没有使用var声明，所以它是一个全局变量，然后第二步是将y赋值给X，将一个全局变量赋值给了一个局部变量，最终，x是一个局部变量，y是一个全局变量，所以打印x是报错。
