```Js
var obj = {
	say: function() {
		var f1 = () => {
			console.log('1111', this)
		}
		f1()
	},
	pro: {
		getPro: () => {
			console.log(this)
		}
	}
}
var o = obj.say
o()
obj.say()
obj.pro.getPro()
```

## 输出结果
```js
1111 window对象
1111 obj对象
window对象
```


解析:
1.o0)，0是在全局执行的，而f1是箭头函数，它是没有绑定this的，它的this指向其父级的this，其父级say方法的this指向的是全局作用域，所以会打印出window;
2.obj.say()，谁调用say，say 的this就指向谁，所以此时this指向的是obj对象;
3.obj,pro.getPro()，我们知道，箭头函数时不绑定this的，getPro处于pro中，而对象不构成单独的作用域，所以箭头的函数的this就指向了全局作用域window。


这段代码定义了一个名为`obj`的对象，它有两个属性：`say`和`pro`。`say`是一个函数，它内部定义了一个名为`f1`的箭头函数，并在函数内部调用了`f1()`。`f1`函数打印了字符串`'1111'`和`this`。`pro`是另一个对象，它只有一个`getPro`属性，它定义了一个箭头函数，并在函数体内打印了`this`。

接下来，代码定义了一个变量`o`，它将`obj.say`函数赋值给它。然后，代码首先调用`o()`，这会调用`obj.say()`函数，但是因为`o`是一个独立的函数，所以在调用`f1()`函数时，它的上下文并不是`obj`对象，而是全局对象。因此，它打印的`this`是全局对象。

接着，代码调用`obj.say()`函数，这会调用`f1()`函数，但是因为`f1`函数是一个箭头函数，它会继承`say`函数的上下文，即`obj`对象。因此，它打印的`this`是`obj`对象。

最后，代码调用`obj.pro.getPro()`函数，它的函数体内的箭头函数同样会继承`obj.pro`对象的上下文，即全局对象，因此它打印的`this`也是全局对象。

在这个代码中，`obj.pro`对象内部定义的是一个箭头函数。箭头函数是没有自己的`this`绑定的，它会捕获所在上下文的`this`值，并且继承它。在这个箭头函数中，它所在的上下文是`obj.pro`对象，而`obj.pro`对象是一个普通的对象，它并没有被绑定到任何特定的`this`值上。

因为箭头函数没有自己的`this`绑定，所以在这个例子中，箭头函数会继承它所在的上下文，也就是全局上下文。因此，当`obj.pro`对象内部的箭头函数被调用时，它的`this`值会指向全局对象。
