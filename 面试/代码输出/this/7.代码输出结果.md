```js
var myObject =  {
	foo: 'bar',
	func: function() {
		var self = this
		console.log(this.foo) 
		console.log(self.foo)
		(function() {
			console.log(this.foo)
			console.log(self.foo)
		}())
	}
}
myObject.func()
// bar
// bar
// undefined
// bar
```

## 输出结果
```js
bar bar undefined bar
```

解析:
- 1.首先func是由myObject调用的，this指向myObject。又因为var self = this;所以self指向myObject。
- 2.这个立即执行匿名函数表达式是由window调用的，this指向window 。立即执行匿名函数的作用域处于myObject.func的作用域中，在这个作用域找不到self变量，沿着作用域链向上查找self变量，找到了指向 myObject对象的self。

## IIFE（立即执行的函数表达式）
IIFE（Immediately Invoked Function Expression）的`this`指向取决于它的执行环境。在IIFE中，`this`的值取决于它的执行上下文，并且由于IIFE是立即执行的，所以它的执行上下文通常是全局执行上下文。

因此，在大多数情况下，IIFE中的`this`指向的是全局对象，比如在浏览器环境中，指向的是`window`对象，在Node.js环境中，指向的是`global`对象。这是因为在IIFE中没有明确指定`this`的值，所以它会继承上层的执行上下文，即全局执行上下文。

如果需要在IIFE中使用特定的`this`值，可以使用`call`、`apply`或`bind`等函数来显式地绑定`this`的值。例如：

```js
var myObject = {
  name: "Alice",
  sayHello: function() {
    (function() {
      console.log("Hello, " + this.name + "!");
    }).call(this);
  }
};

myObject.sayHello(); // 输出 "Hello, Alice!"
```

在上面的例子中，通过使用`call`函数，在IIFE中将`this`绑定到`myObject`对象上，使得在IIFE中可以访问到对象的属性`name`，输出正确的结果。
