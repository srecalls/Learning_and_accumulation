```js
function foo(something) {
	this.a = something
}
var obj1 = {}
var bar = foo.bind(obj1)
bar(2)
console.log(obj1.a) // 2
var bar2 = new bar(3)
console.log(obj1.a) // 2
console.log(bar2.a) // 3
```

## 输出结果
```js
2 2 3
```

这道题目和上面题目差不多，主要都是考察this绑定的优先级。记住以下结论即可: 
**this绑定的优先级: new绑定 > 显式绑定 > 隐式绑定 > 默认绑定**
