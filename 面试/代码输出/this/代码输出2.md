```js
let user = {
	name: 'John',
	obj: function() {
		alert(this.name);
	}
}
let admin = user;
user = null;
admin.obj();
```

## 结果
打印John


在这段代码中，首先创建了一个名为`user`的对象，它有一个名为`name`的属性和一个名为`obj`的方法。然后将`admin`变量初始化为`user`，也就是说`admin`和`user`引用了同一个对象。

接下来，将`user`赋值为`null`，这意味着`user`不再引用原来的对象，而是引用了一个空值`null`。此时，原来的对象没有任何变化，仍然被`admin`所引用。

最后调用`admin.obj()`方法，由于该方法中的`this`指向调用它的对象，因此`this.name`指向的是`admin`对象的`name`属性，即`'John'`。这是因为`admin`仍然引用原来的那个对象，而`user`已经不再引用它了，因此对`user`的赋值不会影响`admin`。
