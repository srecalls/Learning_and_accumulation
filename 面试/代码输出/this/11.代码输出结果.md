```js
var x = 3
var y = 4
var obj = {
	x: 1,
	y: 6,
	getX: function() {
		var x = 5
		return function() {
			return this.x
		}()
	},
	getY: function() {
		var y = 7
		return this.y
	}
}
console.log(obj.getX())
console.log(obj.getY())
```

## 输出结果
```js
3 6
```

解析:
1. 我们知道，匿名函数的this是指向全局对象的，所以this指向window，会打印出3
2. getY是由obj调用的，所以其this指向的是obj对象，会打印出6。
