```js
var length = 10
function fn() {
	console.log(this.length)
}
var obj = {
	length: 5,
	method: function(fn) {
		fn()
		arguments[0]()
	}
}
obj.method(fn, 1)
```

## 输出结果
```js
10 2
```

解析:
代码创建了一个名为 `obj` 的对象，其中包含一个属性 `length`，其值为 `5`，以及一个方法 `method()`。这个方法接受一个函数作为参数 `fn`，并在其内部分别调用了两次这个函数。
- 第一次调用了 `fn()`，此时 `this` 指向的是全局对象，因为函数 `fn()` 是在全局作用域下定义的，所以打印的是全局变量 `length` 的值 `10`。
- 第二次调用了 `arguments[0]()`，也就是调用了传递给 `method()` 方法的第一个参数 `fn`，此时 `this` 指向的是 `arguments` 对象本身，因为 `arguments` 对象是一个类数组对象，所以它也有一个 `length` 属性。由于传递给 `method()` 的第二个参数是 `1`，所以 `arguments` 对象的长度为 `2`，因此打印的是 `2`。
