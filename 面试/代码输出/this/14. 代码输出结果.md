```js
function foo(something) {
	this.a = something
}
var obj1 = {
	foo: foo
}
var obj2 = {}

obj1.foo(2)
console.log(obj1.a) // 2

obj1.foo.call(obj2, 3)
console.log(obj2.a) // 3

var bar = new obj1.foo(4)
console.log(obj1.a) // 2
console.log(bar.a) // 4
```

## 输出结果
```js
2 3 2 4
```

解析:
1. 首先执行obi1.foo(2): 会在obi中添加a属性，其值为2。之后执行obi1.a，a是右obi1调用的，所以this指向obj，打印出2;
2. 执行 obi1.foo.call(obi2, 3)时，会将foo的this指向obi2，后面就和上面一样了，所以会打印出3;
3. obj1.a会打印出2;
4. 最后就是考察this绑定的优先级了，new 绑定是比隐式绑定优先级高，所以会输出4.


这段代码定义了一个名为 `foo` 的函数，它接受一个参数 `something`，并将其赋值给 `this.a` 属性。接着，代码创建了两个对象 `obj1` 和 `obj2`，其中 `obj1` 包含一个名为 `foo` 的属性，其值为函数 `foo`，而 `obj2` 则是一个空对象。

接下来，代码分别调用了 `obj1.foo(2)` 和 `obj1.foo.call(obj2, 3)`。第一次调用将 `this.a` 属性设置为 `2`，因为 `foo` 函数中 `this` 指向了 `obj1` 对象。第二次调用使用 `call()` 方法将 `foo` 函数中的 `this` 指向了 `obj2`，因此 `obj2.a` 的值被设置为 `3`。

接着，代码使用 `new` 关键字创建了一个新的对象 `bar`，并将其初始化为 `obj1.foo(4)` 的返回值。由于 `foo` 函数没有显式返回任何值，因此默认返回一个空对象。但是由于使用了 `new` 关键字，这个空对象被赋值给了 `bar`。同时，由于 `foo` 函数中的 `this` 指向了 `bar`，因此 `bar.a` 的值被设置为 `4`。

最后，代码分别打印了 `obj1.a` 和 `bar.a` 的值，分别输出 `2` 和 `4`，因为 `obj1.a` 的值在第一次调用 `obj1.foo()` 时被设置为 `2`，而 `bar.a` 的值在使用 `new` 关键字创建对象时被设置为 `4`。
