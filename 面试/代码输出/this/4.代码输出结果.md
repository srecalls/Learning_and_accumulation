```js
var obj = {
	name: 'cugg2',
	fun: function() {
		console.log(this.name)
	}
}
obj.fun() // cugg2
new obj.fun() // undefined
```

在 JavaScript 中，当使用 `new` 关键字调用一个函数时，会创建一个新的对象并将其作为函数的 `this` 值。同时，如果该函数返回一个对象，则 `new` 表达式的结果为该对象；否则，结果为新创建的对象。这就是构造函数的基本实现原理。

在上述代码中，`obj.fun` 是一个函数，当直接调用 `obj.fun()` 时，函数内部的 `this` 指向的是 `obj` 对象本身，因此输出的结果是 `cugg2`。

当使用 `new` 关键字调用 `obj.fun` 时，会创建一个新的对象并将其作为函数的 `this` 值。由于 `obj.fun` 函数内部没有返回任何值，因此 `new obj.fun()` 表达式的结果是新创建的对象。由于该新对象没有 `name` 属性，因此输出的结果是 `undefined`。
