## 循环链
这段代码会导致一个 TypeError 的错误，错误信息为 `"Chaining cycle detected for promise #<Promise>"`

这是因为在这段代码中，我们创建了一个 Promise 对象 `promise`，然后在它的 `then` 方法中返回了它自己。当 Promise 对象的 `then` 方法返回一个新的 Promise 对象时，这个新的 Promise 对象会被添加到 Promise 链中，成为前一个 Promise 对象的后继，形成一个链式调用的结构。在这个例子中，我们返回的 Promise 对象是 `promise` 自身，因此这个 Promise 链就会形成一个循环链的结构，导致出现循环引用。

因为 Promise 链中不能存在循环引用，所以当出现这种情况时，JavaScript 引擎会抛出一个 TypeError 的错误，以便及时地发现问题。如果不及时地处理这个错误，可能会导致程序崩溃或出现其他意外的问题。因此，我们在编写 Promise 相关的代码时，需要避免出现循环链的情况，以确保程序的稳定性

## 为什么会造成循环，不是返回一个新的Promise对象吗，又不回一直返回
确实，`Promise.resolve().then(() => { return promise })` 语句中，返回的是一个 Promise 对象 `promise`，而不是一个新的 Promise 对象。因此，这个语句不会一直返回新的 Promise 对象，而是会返回 `promise` 对象本身。

但是，由于 Promise 对象具有异步执行的特性，当 `then` 方法返回一个 Promise 对象时，这个 Promise 对象并不会立即执行，而是会被添加到异步任务队列中，等待 JavaScript 引擎空闲时再执行。因此，在这个例子中，当 `then` 方法中返回 `promise` 对象时，它不会立即执行，而是会等待当前 Promise 对象的执行完成，并且被添加到 Promise 链的末尾。

由于 `promise` 对象被添加到 Promise 链的末尾，因此当它被执行时，它又会返回自身，继续被添加到 Promise 链的末尾，形成一个循环链的结构。这种循环链会导致 Promise 链一直执行下去，直到 JavaScript 引擎抛出一个错误，或者程序崩溃。

因此，虽然返回的是 `promise` 对象本身，但由于 Promise 对象的异步执行特性，它仍然会导致 Promise 链中出现循环引用，从而导致程序出现错误。所以，我们需要特别小心地处理 Promise 链中可能出现的循环引用，以确保程序的正确性和稳定性。
