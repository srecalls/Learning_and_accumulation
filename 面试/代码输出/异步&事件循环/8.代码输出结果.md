```js
Promise.resolve(1)
	.then(res => {
		console.log(res)
		return 2
	})
	.catch(err => {
		return 3
	})
	.then(res => {
		console.log(res)
	})
```

## 输出结果
```js
1
2
```

`Promise`是可以链式调用的，由于每次调用`.then` 或者都会返回一个新的 `promise`，从而实现了链`.catch`式调用它并不像一般任务的链式调用一样`return this`。
上面的输出结果之所以依次打印出` 1 `和` 2 `，是因为 `resolve(1)` 之后走的是第一个`then`方法，并没有进`catch`里所以第二个`then`中的`res`得到的实际上是第一个`then`的返回值。并`return 2`会被包装成 `resolve(2)`，被最后的`then`打印输出`2`。
