```js
Promise.resolve().then(() => {
	return new Error('error!!!')
}).then(res => {
	console.log("then: ", res)
}).catch(err => {
	console.log("catch: ", err)
})
```

## 输出结果
```js
 "then: " "Error: error!!!"
```

返回任意一个非 `promise` 的值都会被包裹成 `promise` 对象，因此这里的 `return new Error('error!!!')`也
被包裹成了 `return Promise.resolve(new Error('error!!!'))`，
因此它会被`then`捕获而不是`catch`。
