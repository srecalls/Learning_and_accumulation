以下是一个使用 `throw` 语句抛出异常的例子：

```javascript
function divide(a, b) {
  if (b === 0) {
    throw new Error('Cannot divide by zero!')
  }
  return a / b
}

try {
  console.log(divide(10, 0))
} catch (error) {
  console.error(error)
}
```

在这个例子中，如果 `b` 的值为 `0`，那么 `divide()` 函数会抛出一个异常，这个异常会被控制流程传递到 `try` 块之外的异常处理程序。在这个例子中，我们使用了 `try-catch` 语句来捕获这个异常，并且在控制台中输出异常信息。因此，如果我们执行这个函数并且传递 `0` 作为第二个参数，那么控制台会输出以下信息：

```
Error: Cannot divide by zero!
    at divide (/path/to/file.js:3:11)
    at Object.<anonymous> (/path/to/file.js:7:15)
    at Module._compile (internal/modules/cjs/loader.js:1072:14)
    at Object.Module._extensions..js (internal/modules/cjs/loader.js:1101:10)
    at Module.load (internal/modules/cjs/loader.js:937:32)
    at Function.Module._load (internal/modules/cjs/loader.js:778:12)
    at Function.executeUserEntryPoint [as runMain] (internal/modules/run_main.js:76:12)
    at internal/main/run_main_module.js:17:47
```

在这个例子中，我们使用了 `console.error()` 方法来输出异常信息。与 `console.log()` 方法不同的是，`console.error()` 方法通常会以红色字体显示输出内容，以便更加突出地显示错误信息。此外，使用 `console.error()` 方法输出的内容通常会包括错误的堆栈信息，以便更好地调试程序。



## 多个异常处理程序
如果在程序中有多个异常处理程序，那么在抛出异常时，控制流程会在当前函数中查找最近的异常处理程序，并在找到之后跳转到该处理程序。如果当前函数中没有异常处理程序，那么控制流程会将异常传递到调用者中，直到找到一个异常处理程序为止。

以下是一个使用多个异常处理程序的例子：

```javascript
function divide(a, b) {
  if (b === 0) {
    throw new Error('Cannot divide by zero!')
  }
  return a / b
}

try {
  console.log(divide(10, 0))
} catch (error) {
  console.error('Caught error in first try-catch block:', error)
}

try {
  console.log(divide(20, 5))
} catch (error) {
  console.error('Caught error in second try-catch block:', error)
}
```

在这个例子中，我们在调用 `divide()` 函数时使用了两个不同的参数：`0` 和 `5`。由于第一个参数为 `10`，第二个参数为 `0`，因此第一个调用会抛出一个异常，第二个调用会正常返回。我们使用了两个不同的 `try-catch` 语句来捕获这两个调用中可能出现的异常，并在控制台中输出异常信息。在这个例子中，第一个 `try-catch` 块会捕获到异常，输出错误信息，而第二个 `try-catch` 块不会捕获到异常，不会输出任何信息。

需要注意的是，多个 `try-catch` 语句之间是相互独立的，即一个 `try-catch` 块中的异常处理程序不会处理其他 `try-catch` 块中的异常。因此，如果在一个 `try-catch` 块中抛出了异常，而在该块之外没有找到异常处理程序，那么程序就会终止，并且不会执行之后的代码。




是的，当程序执行 `throw` 语句时，如果没有找到合适的异常处理程序，那么程序会在控制台中输出错误信息和堆栈跟踪信息，这与使用 `console.error` 输出错误信息的方式是类似的。实际上，抛出异常就是一种在程序中发生错误时，向控制台输出错误信息和堆栈跟踪信息的方式。

例如，在以下代码中，我们使用 `throw` 语句抛出一个异常，并且在控制台中输出错误信息和堆栈跟踪信息：

```javascript
function divide(a, b) {
  if (b === 0) {
    throw new Error('Cannot divide by zero!')
  }
  return a / b
}

console.log(divide(10, 0))
```

在这个例子中，由于第二个参数等于 `0`，`divide()` 函数会抛出一个异常，并且在控制台中输出以下错误信息和堆栈跟踪信息：

```
Error: Cannot divide by zero!
    at divide (/path/to/file.js:3:11)
    at Object.<anonymous> (/path/to/file.js:7:13)
    at Module._compile (internal/modules/cjs/loader.js:776:30)
    at Object.Module._extensions..js (internal/modules/cjs/loader.js:787:10)
    at Module.load (internal/modules/cjs/loader.js:643:32)
    at Function.Module._load (internal/modules/cjs/loader.js:556:12)
    at Function.executeUserEntryPoint [as runMain] (internal/modules/run_main.js:71:12)
    at internal/main/run_main_module.js:17:47
```

从输出的信息中可以看出，抛出异常与使用 `console.error` 的方式类似，都可以在控制台中输出错误信息和堆栈跟踪信息。但是，抛出异常还可以中断程序的执行，以便及时地发现问题并进行相应的处理。
