[[宏任务&微任务介绍]]
Promise.resolve方法的参数如果是一个**原始值**，或者是一个**不具有then方法的对象**，则Promise.resolve方法返回个新的Promise对象，状态为resolved，Promise.resolve方法的参数，会同时传给回调函数

then方法接受的参数是函数，而如果传递的并非是一个函数，它实际上会将其解释为then(null)，这就会导致前个Promise的结果会传递下面
[[⭐Promise基本概念]]

当你使用Promise.resolve(1)时，你会创建一个已经完成的promise，它的值为1。之后的`.then`函数会接收到这个值，并将其传递给下一个`.then`函数。让我们详细分析一下代码：

```
Promise.resolve(1)
.then(2)
.then(Promise.resolve(3))
.then(console.log)
```

1. 首先，`Promise.resolve(1)`会创建一个已解析的promise，值为1。
2. 然后，`.then(2)`应该接收一个函数作为参数，但在这里我们传递了一个值2。当`.then`方法接收到一个非函数类型的值时，它会忽略这个值，并将上一个promise的值（1）传递给下一个`.then`函数。
3. 接下来，`.then(Promise.resolve(3))`也应该接收一个函数作为参数。然而，我们传递了一个已解析的promise，值为3。和前面一样，该方法会忽略这个值，将上一个promise的值（仍然是1）传递给下一个`.then`函数。
4. 最后，`.then(console.log)`接收到了一个函数，所以它将前一个promise的值1作为参数传递给`console.log`，输出为1。

所以，输出结果是1。要注意的是，`.then`函数应该接收一个函数作为参数，而非直接传递值。如果你想让`.then`函数返回一个新的值，你应该将其包裹在一个函数中：

```javascript
Promise.resolve(1)
.then(() => 2)
.then(() => Promise.resolve(3))
.then(console.log)
```

这段代码将输出3，因为我们将值包裹在函数中，让`.then`函数正常运行。


当我们将 `console.log` 函数作为回调函数传递给 `then()` 方法时，它会在 Promise 对象被解决时被调用，并且接收到 Promise 对象的解决值作为参数。在这个代码片段中，`Promise.resolve(1)` 方法创建了一个 Promise 对象，并且立即解决了一个值为 `1` 的 Promise 实例，然后将这个 Promise 对象传递给下一个 `then()` 方法。在这个 `then()` 方法中，`console.log` 函数会接收到解决值 `1`，并把它打印到控制台中。

因此，这个代码片段相当于：


```js
Promise.resolve(1).then(function(value) {
  console.log(value);
});
```
