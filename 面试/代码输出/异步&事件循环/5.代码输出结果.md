
```js
const promise = Promise((resolve, reject) => {
    resolve('success1')
    reject('error')
    resolve('success2')
})

Promise.then((res) => {
    console.log('then', res)
}).catch((err) => {
    console.log('catch', err)
})
```

## 输出结果
```js
then success1
```
这个题目考察的就是`Promise`的状态在发生变化之后，就不会再发生变化。开始状态由 `pending` 变为 `resolve`说明已经变为已完成状态，下面的两个状态的就不会再执行，同时下面的`catch`也不会捕获到错误。
