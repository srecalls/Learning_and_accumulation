## 如何获取输入链接到页面显示的全部时间？
获取输入链接到页面显示的全部时间可以通过 Performance API 中的 timing 属性来实现。具体步骤如下：

1. 使用 Performance API 中的 `window.performance.timing` 属性，获取页面加载的时间相关信息。
2. 使用 `window.performance.timing.navigationStart` 属性获取导航开始时间。
3. 使用 `window.performance.timing.loadEventEnd` 属性获取页面加载结束时间。
4. 计算页面加载时间差，即 `loadEventEnd - navigationStart`。
`window.performance.timing.domContentLoadedEventEnd` 表示文档的 DOM 结构加载完成的时间，即 DOMContentLoaded 事件触发的时间。该事件发生时，文档中的所有 DOM 解析器已完成其工作，因此，此时可以对文档进行操作，而不会影响页面的可用性。

`window.performance.timing.loadEventEnd` 表示页面完全加载完成的时间，即 load 事件触发的时间。在此事件发生后，页面中的所有资源都已加载完毕，并且用户可以与页面进行交互。

`window.performance.timing.loadEventEnd` 包括了 `window.performance.timing.domContentLoadedEventEnd` 的时间，还包括了其他资源（如 JavaScript、CSS、图像、视频等）的加载时间。

示例代码如下：

```js
// 获取导航开始时间
const navigationStart = window.performance.timing.navigationStart;

// 获取页面加载结束时间
const loadEventEnd = window.performance.timing.loadEventEnd;

// 计算页面加载时间
const loadTime = loadEventEnd - navigationStart;

console.log(`页面加载时间为 ${loadTime} 毫秒`);
```

在这个例子中，使用 `window.performance.timing.navigationStart` 属性获取了页面导航开始的时间，使用 `window.performance.timing.loadEventEnd` 属性获取了页面加载结束的时间。然后计算了页面加载时间差，即 `loadEventEnd - navigationStart`，最后将计算结果输出到控制台中。

需要注意的是，由于 Performance API 中的 timing 属性可能受到浏览器和设备的不同而有所不同，因此计算得到的页面加载时间仅供参考，可能会存在一定的误差。



当浏览器开始加载页面时，它会通过网络请求获取页面中的各种资源，例如 HTML、CSS、JavaScript、图像、视频等。在此过程中，Performance API 会记录一系列时间戳，以便在加载完成后分析页面性能。

`window.performance.timing.navigationStart` 属性表示浏览器开始导航到当前页面的时间戳。它是 Performance API 中的第一个时间戳，也是所有其他时间戳的基准点。

`window.performance.timing.domContentLoadedEventEnd` 属性表示文档的 DOM 结构加载完成的时间戳。当浏览器解析完 HTML 并构建出 DOM 树后，它会触发 DOMContentLoaded 事件，并记录下此时的时间戳。

`window.performance.timing.loadEventEnd` 属性表示页面中的所有资源（包括图片、视频等）都已加载完成的时间戳。当浏览器加载完所有资源后，它会触发 load 事件，并记录下此时的时间戳。

因此，如果您想获取从输入链接URL到页面完全加载完成所需的时间，可以使用以下公式：

```
var startTime = window.performance.timing.navigationStart;
var endTime = window.performance.timing.loadEventEnd;
var loadTime = endTime - startTime;
console.log("页面加载时间为 " + loadTime + " 毫秒");
```

如果您只想获取从输入链接URL到文档的 DOM 结构加载完成所需的时间，可以使用以下公式：

```
var startTime = window.performance.timing.navigationStart;
var endTime = window.performance.timing.domContentLoadedEventEnd;
var loadTime = endTime - startTime;
console.log("DOM 加载时间为 " + loadTime + " 毫秒");
```

需要注意的是，这些时间戳的准确性可能会受到网络延迟、服务器响应时间等因素的影响。
