
	git fetch 只是将远程仓库的变化下载下来，并没有和本地分支合并。 
	git pull 会将远程仓库的变化下载下来，并和当前分支合并。

当你使用 `git fetch` 命令时，Git会将远程仓库的最新变化下载下来并存储在本地的一个名为 "FETCH_HEAD" 的引用中。这个引用指向了远程仓库的最新提交，但它并没有改变你当前所在的分支或者工作目录中的任何内容。

换句话说，`git fetch` 命令只是将远程仓库的最新变化下载到本地，但并没有直接合并到你的本地分支中。这样做的好处是你可以先查看远程仓库的最新变化，然后再决定是否要将它们合并到当前分支中。

如果你希望将 `git fetch` 命令下载下来的变化合并到本地分支中，可以使用 `git merge FETCH_HEAD` 命令来完成。这个命令会将 `FETCH_HEAD` 引用所指向的远程仓库的最新提交合并到当前分支中。
