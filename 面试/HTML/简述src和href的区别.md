

### **简述src和href的区别：**

■ src (Source) 是来源地址，用在img、script等元素上。

src作用：指向资源所在位置，加载完资源，替换掉当前元素，例如当前元素是img，src加载完图片，就用图片直接替换掉img标签。

■ href（hypertext reference）是超文本引用，用在link和a等元素上。

href 作用：也是指向资源所在位置。使当前文档和引用资源之间建立联系。
例如建立链接元素和锚点元素之间的联系。又例如：link属性引入第三方的样式，引入BootStrap.css.

`src` 和 `href` 是 HTML 中常用的两个属性，它们分别用于指定引入资源的位置和链接的目标位置，具有以下几点区别：

1.  作用对象不同：`src` 属性用于引入外部资源，例如图片、音频、视频、脚本等等，而 `href` 属性则用于指定链接的目标位置，通常用于创建文本链接或页面内跳转。
    
2.  加载方式不同：`src` 属性指定的资源会在页面加载时自动加载并显示，而 `href` 属性指定的链接则需要用户手动点击或调用 JavaScript 来触发。
    
3.  适用标签不同：`src` 属性通常用于 `<img>`、`<audio>`、`<video>`、`<script>` 等标签中，而 `href` 属性则常用于 `<a>`、`<link>`、`<base>` 等标签中。
    
4.  功能不同：`src` 属性指定的资源是必需的，如果无法加载，则会导致相应的标签无法正常显示或工作；而 `href` 属性指定的链接是可选的，如果无法加载，则不会影响页面的正常显示和工作。
    

需要注意的是，`src` 和 `href` 属性的值都可以是相对路径或绝对路径，但在引入外部资源时，应该使用绝对路径来避免路径错误或资源无法加载的问题。同时，为了提高页面的性能和用户体验，应该合理使用 `src` 和 `href` 属性，并避免过多或不必要的资源引入和链接。

总之，`src` 和 `href` 属性都是 HTML 中常用的属性，但它们的作用对象、加载方式、适用标签、功能和使用方法有所不同，需要根据具体情况选择合适的属性来引入外部资源或创建链接。
