以下是一些常用的 HTML 标签：

1. `<html>`：定义 HTML 文档。
2. `<head>`：定义 HTML 文档的头部，包含文档的元数据和链接信息。
3. `<title>`：定义文档的标题，会显示在浏览器的标题栏中。
4. `<body>`：定义 HTML 文档的主体部分，包含页面的内容。
5. `<h1>`-`<h6>`：定义标题，从大到小分别表示一级到六级标题。
6. `<p>`：定义段落。
7. `<a>`：定义超链接，用于跳转到其它页面或位置。
8. `<img>`：定义图像，用于在页面中显示图片。
9. `<ul>` 和 `<ol>`：定义无序列表和有序列表，分别用于显示项目顺序和无序关系。
10. `<li>`：定义列表项，用于包含列表中的每个项目。
11. `<table>`：定义表格。
12. `<tr>`：定义表格行。
13. `<td>`：定义表格单元格。
14. `<form>`：定义表单，用于向服务器提交数据。
15. `<input>`：定义表单中的输入控件，如文本框、单选按钮、复选框等。
16. `<select>` 和 `<option>`：定义下拉列表框，用于选择一个或多个选项。
17. `<button>`：定义按钮，用于触发一些操作或提交表单。

这仅是一些常用的 HTML 标签，还有很多其它标签和属性可以用于创建更复杂的页面结构。需要注意的是，在使用 HTML 标签时，应该遵循标准的语法规范和语义化原则，以确保页面结构清晰、易于维护和理解。
