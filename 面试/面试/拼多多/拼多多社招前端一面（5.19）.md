1. 写一个函数，参数为任意个数组数据，求它们的交集，  
```js
例：func([1, 2, 3, 5], [2, 4, 6], [2, 3, 5]) => [2]  
func([1, 2, 3, 5]) => [1, 2, 3, 5]  

```

以下是一个函数 `findIntersection`，它接受任意个数组数据作为参数，并返回它们的交集：

```javascript
function findIntersection(...arrays) {
  if (arrays.length === 0) {
    return [];
  }

  // 将第一个数组作为基准，对比其他数组的元素是否存在于基准数组中
  const baseArray = arrays[0];
  const intersection = baseArray.filter((item) => {
    return arrays.every((array) => array.includes(item));
  });

  return intersection;
}

console.log(findIntersection([1, 2, 3, 5], [2, 4, 6], [2, 3, 5])); // 输出 [2]
console.log(findIntersection([1, 2, 3, 5])); // 输出 [1, 2, 3, 5]
```

在上述示例中，`findIntersection` 函数使用了扩展运算符 `...` 来接收任意个数组数据作为参数，并将它们存储在 `arrays` 数组中。

首先，我们检查 `arrays` 的长度，如果为 0，则返回一个空数组。

然后，我们将第一个数组 `baseArray` 作为基准，使用 `filter` 方法对基准数组进行筛选。在筛选的回调函数中，我们使用 `every` 方法来检查其他数组中的每个元素是否都存在于基准数组中，如果存在则返回 `true`，否则返回 `false`。最终，我们得到的 `intersection` 数组即为交集。

最后，我们通过 `console.log` 打印两个示例的交集结果。第一个示例中的交集为 `[2]`，第二个示例中的交集为 `[1, 2, 3, 5]`。


2. 用 react / vue 写一个页面，页面上显示一个计数及一个按钮，点击按钮计数 +1，在 5 秒内没有再次点击时，计数清零。  
```js
<template>
<div>
	<div>{{count}}</div>
	<button @click="increase"></button>
</div>
</template>
<script>
export default {
	name: 'myTest',
	data() {
		count: 0
		timer: null
	},
	methods: {
		increase() {
			clearTimeout(this.timer)
			this.count++
			this.timer = setTimeout(() => {
				this.count = 0
			}, 5000)
		}
	}
}
</script>
```
