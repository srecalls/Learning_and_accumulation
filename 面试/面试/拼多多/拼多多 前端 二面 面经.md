5，img 加载图片失败，如何判断  
要判断`<img>`元素加载图片是否失败，可以使用`onerror`事件监听器。当图片加载失败时，浏览器会触发`onerror`事件，我们可以通过绑定该事件来捕捉加载失败的情况。

以下是一个示例代码，演示如何判断`<img>`元素加载图片是否失败：

```html
<img src="path/to/image.jpg" onerror="handleImageError()" />

<script>
function handleImageError() {
  console.log("Image failed to load");
  // 进行失败后的处理逻辑
}
</script>
```

在上述代码中，`<img>`元素指定了一个图片的`src`属性，当图片加载失败时，会触发`onerror`事件，并调用`handleImageError()`函数。在该函数中，我们可以进行自定义的失败处理逻辑，例如输出错误信息到控制台、显示备用图片等。

你也可以通过JavaScript代码动态为`<img>`元素添加`onerror`事件监听器，而不是直接在HTML中写入。示例代码如下：

```html
<img id="myImage" src="path/to/image.jpg" />

<script>
const imgElement = document.getElementById("myImage");
imgElement.onerror = function() {
  console.log("Image failed to load");
  // 进行失败后的处理逻辑
};
</script>
```

在这个例子中，我们使用`document.getElementById()`方法获取了`<img>`元素的引用，并为其添加了`onerror`事件监听器。

通过在`onerror`事件中执行相应的操作，例如输出错误消息、替换为备用图片或显示错误提示，你可以根据需要来判断`<img>`元素是否成功加载图片。
