1. Axios 的设计模式有哪些  
```js
Axios是一个基于Promise的现代化HTTP客户端库，它提供了多种设计模式来支持不同的用例和开发需求。以下是Axios的主要设计模式：

1. Promise-based（基于Promise）：
   Axios的核心设计模式是基于Promise的异步操作。它返回一个Promise对象，可以使用`.then()`和`.catch()`等方法来处理异步操作的结果和错误。

2. Interceptor（拦截器）：
   Axios提供了拦截器机制，允许在发送请求和接收响应之前对其进行拦截和处理。拦截器可以用于修改请求配置、添加认证信息、对请求和响应进行转换等操作。

3. 请求和响应转换器：
   Axios支持请求和响应的转换器。转换器允许在请求发送之前或响应被处理之前对它们进行自定义转换。例如，可以使用转换器将请求数据转换为JSON格式或将响应数据解析为特定的数据结构。

4. 并发请求：
   Axios提供了多种并发请求的方式。可以使用`axios.all()`方法同时发送多个请求，并使用`axios.spread()`方法对它们的结果进行处理。这样可以提高并发请求的效率。

5. 取消请求：
   Axios允许取消请求，以防止不再需要的请求继续执行。可以使用取消令牌（cancel token）来取消请求，以及使用拦截器来处理取消请求的逻辑。

6. 自定义实例：
   Axios支持创建自定义实例，通过复制现有的Axios实例并自定义其默认配置。这样可以为不同的请求场景创建不同的实例，并独立地管理它们的配置和拦截器。

这些设计模式使得Axios在处理HTTP请求时更加灵活、可扩展和可定制。开发人员可以根据具体的需求选择适当的设计模式，并结合Axios提供的API和功能来构建强大的HTTP请求交互。
```

```js
function sleep(sleepTime) {
	return new Promise((resolve, reject) => {
		setTimeout(() => {
			resolve()
		}, sleepTime)
	})
}
```
