[[typeof]]
`typeof`原理：**不同的对象在底层都表示为二进制，在Javascript中二进制前（低）三位存储其类型信息**。

- 000: 对象
- 010: 浮点数
- 100：字符串
- 110：布尔
- 1：整数

typeof null 为"object", 原因是因为 不同的对象在底层都表示为二进制，在Javascript中二进制前（低）三位都为0的话会被判断为Object类型，null的二进制表示全为0，自然前三位也是0，所以执行typeof时会返回"object"。一个不恰当的例子，假设所有的Javascript对象都是16位的，也就是有16个0或1组成的序列，猜想如下：

```js
Array: 1000100010001000 
null: 0000000000000000 
typeof [] // "object" 
typeof null // "object"
```
因为Array和null的前三位都是000。为什么Array的前三位不是100?因为二进制中的“前”一般代表低位， 比如二进制00000011对应十进制数是3，它的前三位是011。

String.prototype.trim = function() {

下面是使用正则表达式实现字符串的 `trim()` 方法，并将其添加到 `String.prototype` 上的代码示例：

```javascript
String.prototype.trim = function() {
  return this.replace(/^\s+|\s+$/g, '');
};
```

在这个代码中，我们定义了一个新的 `trim()` 方法并将其添加到 `String.prototype` 上。该方法使用正则表达式 `/^\s+|\s+$/g` 来匹配字符串中的前导空白字符和尾部空白字符，并将其替换为空字符串。

- `^\s+` 匹配字符串开头的一个或多个空白字符。
- `\s+$` 匹配字符串末尾的一个或多个空白字符。
- `|` 表示或的意思，用于同时匹配开头和结尾的空白字符。
- `g` 是全局修饰符，表示匹配字符串中所有符合条件的部分。

使用这个自定义的 `trim()` 方法，可以移除字符串开头和结尾的空白字符，得到一个修剪后的字符串。例如：

```javascript
let str = "   Hello, World!   ";
let trimmedStr = str.trim();

console.log(trimmedStr); // 输出 "Hello, World!"
```

注意，这只是一个简单的示例实现，并且不处理字符串内部的空白字符。如果需要更复杂的处理逻辑，可以根据具体需求进行修改和扩展。
