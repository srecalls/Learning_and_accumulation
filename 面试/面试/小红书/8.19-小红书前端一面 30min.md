2. `window.onhashchange` 事件：这是一个浏览器事件，当 URL 的哈希部分发生变化时触发。Vue Router 通过监听这个事件来实现路由的变化监测和响应。

1. `push` 方法：基于浏览器原生的 `history.pushState()` API 进行封装。`push` 方法用于将新的路由状态添加到浏览器的历史记录中，并更新页面的内容，同时不触发完整的页面刷新。

在 Vue Router 的哈希模式下，可以使用 `push`、`replace` 和 `go` 方法进行路由跳转，而不会触发实际的请求。

1. `push` 方法：使用 `push` 方法可以向路由堆栈中添加一个新的路由记录，并更新浏览器的 URL。这将触发 `window.onhashchange` 事件，从而使 Vue Router 感知到路由的变化并更新相应的组件。使用 `push` 方法时，不会发送请求到服务器。例如：

```js
router.push('/path'); // 添加新的路由记录并更新 URL
```

2. `replace` 方法：使用 `replace` 方法可以替换当前的路由记录，并更新浏览器的 URL。这将触发 `window.onhashchange` 事件，从而使 Vue Router 感知到路由的变化并更新相应的组件。与 `push` 方法类似，使用 `replace` 方法时也不会发送请求到服务器。例如：

```js
router.replace('/path'); // 替换当前的路由记录并更新 URL
```

3. `go` 方法：使用 `go` 方法可以在浏览器的历史记录中进行前进或后退导航。这不会更改 URL，而是直接触发 `window.onhashchange` 事件，从而使 Vue Router 感知到路由的变化并更新相应的组件。与前两种方法一样，使用 `go` 方法也不会发送请求到服务器。例如：

```js
router.go(1); // 向前导航
router.go(-1); // 向后导航
```

在哈希模式下，路由的切换是通过修改 URL 中的哈希部分（`window.location.hash`）来实现的，而不是发送实际的请求到服务器。这种方式使得前端路由可以在不刷新整个页面的情况下进行切换，从而创建流畅的单页应用体验。

除了 `push`、`replace` 和 `go` 方法之外，Vue Router 还提供了其他一些跳转方法和选项，以满足不同的路由需求。

1. `router.push` 方法：可以传递一个包含路径、查询参数和哈希的完整地址对象，以进行路由跳转。例如：

```js
router.push({ path: '/path', query: { key: 'value' }, hash: '#section' });
```

2. 命名路由：如果你在 Vue Router 的路由配置中为路由定义了名称（name），则可以使用该名称进行跳转。例如：

```js
router.push({ name: 'routeName' });
```

3. 动态路由参数：如果你的路由配置包含动态路由参数，你可以在 `push` 方法中传递对应的参数值。例如：

```js
router.push({ name: 'user', params: { userId: 123 } });
```

4. 字符串路径：除了对象参数，`push` 方法还可以接受一个字符串路径进行路由跳转。例如：

```js
router.push('/path');
```

5. 编程式导航：在 Vue 组件中，你还可以通过 `$router` 对象进行编程式的路由跳转。例如：

```js
this.$router.push('/path');
```

这些方法和选项提供了灵活的方式来进行路由跳转，适应不同的场景和需求。无论是通过对象参数传递完整路由信息、使用名称进行跳转、处理动态路由参数，还是直接传递字符串路径，Vue Router 都提供了简洁和方便的接口来实现路由的切换和导航。

在 Vue Router 的历史模式下，`go` 方法是基于浏览器的 `window.history` 对象的 `go` 方法进行封装的，与哈希模式下的 `go` 方法类似。

在历史模式下，路由的切换是通过修改 URL 中的路径部分来实现的，而不是通过修改哈希部分。而且，历史模式下的路由切换可能会涉及到向服务器发送请求，特别是在首次加载应用程序或刷新页面时。

当使用 `router.push()`、`router.replace()` 或 `router.go()` 方法进行路由跳转时，如果当前路径与目标路径不同，Vue Router 会调用 `window.history.pushState()` 或 `window.history.replaceState()` 方法来更新浏览器的历史记录，并更新页面的内容，而不会触发实际的请求到服务器。
