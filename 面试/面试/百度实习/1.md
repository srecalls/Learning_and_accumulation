11. flex布局是一种用于页面布局的CSS技术，通过将容器元素的display属性设置为flex或inline-flex，可以将其转换为弹性容器，然后使用flex属性控制其子元素的位置和尺寸。具体来说，flex布局通过以下三个属性来控制子元素的位置和尺寸：

- flex-direction：控制子元素的排列方向，可以是水平方向或垂直方向。
- justify-content：控制子元素在主轴方向上的对齐方式，可以是居中、两端对齐、等间距分布等。
- align-items：控制子元素在交叉轴方向上的对齐方式，可以是居中、顶部对齐、底部对齐等。

例如，以下代码将一个div元素转换为弹性容器，并使用flex属性控制其子元素的位置和尺寸：

```css
.container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
}

.container > div {
  flex: 1;
  height: 100px;
  margin: 10px;
}
```

2. Vite和Webpack都是现代JavaScript应用程序的构建工具，它们都可以将源代码转换为可在浏览器中运行的静态文件。它们的主要区别在于它们的构建方式和配置文件。

- Vite是一种基于ESM（ES Modules）的构建工具，它使用原生ESM来加载和运行应用程序代码，从而实现了更快的构建速度和更好的开发体验。Vite的配置文件非常简单，通常只需指定入口文件和输出目录即可，而其他配置都可以通过插件和命令行选项进行扩展。

- Webpack是一个功能更强大的构建工具，它可以处理各种模块类型，包括CommonJS、AMD、ES6等，并且可以使用各种插件和loader来扩展其功能。Webpack的配置文件比较复杂，需要指定入口文件、输出文件、loader、插件等各种配置项。

以下是Vite和Webpack的配置文件示例：

Vite的配置文件（vite.config.js）：

```javascript
import { defineConfig } from 'vite'

export default defineConfig({
  build: {
    outDir: 'dist',
    minify: true,
    sourcemap: false,
    rollupOptions: {
      input: 'src/main.js',
      output: {
        format: 'esm'
      }
    }
  }
})
```

Webpack的配置文件（webpack.config.js）：

```javascript
const path = require('path')
const HtmlWebpackPlugin = require('html-webpack-plugin')
```

3. 在Vue中，如果您想要将HTML标记从标题中移除并将其用作纯文本，请使用一个HTML解析库，例如DOMParser或vue-template-compiler，将HTML标记从文本中删除。以下是使用DOMParser的示例代码：

```vue
<template>
  <div>
    <my-custom-component :title="titleWithHtml"></my-custom-component>
    <!-- 其他内容 -->
  </div>
</template>

<script>
import MyCustomComponent from './MyCustomComponent.vue'

export default {
  components: {
    MyCustomComponent
  },
  data() {
    return {
      titleWithHtml: '<span style="color: red;">This is a <strong>bold</strong> title</span>'
    }
  }
}
</script>
```

在这个例子中，我们将带有HTML标记的字符串`'<span style="color: red;">This is a <strong>bold</strong> title</span>'`传递给了自定义组件的`title` prop。在自定义组件中，我们使用DOMParser解析这个字符串并从中提取纯文本标题。以下是示例代码：

```vue
<template>
  <div>
    <h1>{{ titleText }}</h1>
    <!-- 其他组件内容 -->
  </div>
</template>

<script>
export default {
  props: {
    title: {
      type: String,
      required: true
    }
  },
  computed: {
    titleText() {
      const parser = new DOMParser();
      const html = parser.parseFromString(this.title, 'text/html');
      return html.body.textContent;
    }
  }
}
</script>
```

在这个例子中，我们使用了Vue的计算属性来从`title` prop中提取纯文本标题。我们首先使用DOMParser将带有HTML标记的字符串解析为HTML文档对象，然后从HTML文档对象的body属性中提取纯文本内容。最终，我们将提取出来的纯文本标题作为计算属性的返回值，并在组件的模板中使用它来渲染标题。

请注意，使用DOMParser或其他HTML解析库可以帮助您从HTML标记中提取纯文本内容，但是请确保您所传递的HTML标记是可信的，并且不包含任何恶意代码。

在这个例子中，我们将带有HTML标记的字符串`'<span style="color: red;">This is a <strong>bold</strong> title</span>'`传递给了自定义组件的`title` prop。在自定义组件中，我们使用`v-html`指令将这个字符串作为HTML渲染到`<h1>`标记中。

## 格式化上下文
在CSS中，格式化上下文（Formatting Context）是一种用于控制元素布局和渲染的机制。其中，最常用的格式化上下文包括块级格式化上下文（BFC）、行内格式化上下文（IFC）、Flex格式化上下文（FFC）和网格格式化上下文（GFC）。

1. 块级格式化上下文（BFC）
块级格式化上下文是一个独立的渲染区域，其中的元素按照一定的规则进行布局和渲染。在BFC中，每个盒子（元素）的左外边缘会触碰其包含块的左边缘（除非该盒子在一个浮动元素内部），而且盒子垂直方向上的距离由它们之间的垂直外边距（margin）决定。

BFC的常见应用场景包括：

- 清除浮动（Clearfix Hack）
- 避免margin重叠
- 处理多列布局（Column Layout）

2. 行内格式化上下文（IFC）
行内格式化上下文是一个独立的渲染区域，其中的元素按照一定的规则进行布局和渲染。在IFC中，每个行盒子（line box）会在其包含块中形成一个行内的排列。

IFC的常见应用场景包括：

- 处理文本的换行和对齐
- 处理基线对齐（Baseline Alignment）

3. Flex格式化上下文（FFC）
Flex格式化上下文是一个独立的渲染区域，其中的元素按照一定的规则进行布局和渲染。在FFC中，元素会按照Flex容器的属性进行排列，可以自由的调整其宽度、高度和顺序。

FFC的常见应用场景包括：

- 实现Flex布局

4. 网格格式化上下文（GFC）
网格格式化上下文是一个独立的渲染区域，其中的元素按照一定的规则进行布局和渲染。在GFC中，元素会按照Grid容器的属性进行排列，可以自由的调整其宽度、高度和顺序。

GFC的常见应用场景包括：

- 实现Grid布局

总之，格式化上下文是一种非常重要的CSS机制，可以帮助我们更好地控制元素的布局和渲染。熟练掌握各种格式化上下文的特性和应用场景，有助于我们编写更加高效、灵活和易于维护的CSS代码。

## 我在容器里设置display为flex，那么我这个容器就会变成Flex格式化上下文吗
是的，当你设置一个元素的 `display` 属性为 `flex` 时，该元素就会成为一个 Flexbox 容器，也就是一个 Flexbox Formatting Context（Flexbox 格式化上下文）。

Flexbox 格式化上下文是一种布局模式，它可以使其子元素按照一定的规则进行排列和对齐，从而实现灵活的布局效果。Flexbox 布局可以在主轴和交叉轴上分别定义对齐方式和排列方式，以实现各种复杂布局。

当你将一个元素设置为 Flexbox 容器时，它的子元素就会成为 Flexbox 项目，从而可以受到 Flexbox 布局的控制。需要注意的是，Flexbox 布局的规则比较复杂，需要熟悉一定的语法和属性才能灵活使用。

页面示例：一个简单的登录页面

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8" />
    <title>Login Page</title>
    <style>
      /* 全局样式 */
      * {
        margin: 0;
        padding: 0;
        box-sizing: border-box;
      }
      html,
      body {
        height: 100%;
      }

      /* 登录框样式 */
      .login-box {
        width: 400px;
        height: 300px;
        margin: auto;
        border: 1px solid #ccc;
        border-radius: 5px;
        background-color: #f5f5f5;
        padding: 20px;
        display: flex;
        flex-direction: column;
        justify-content: center;
      }

      .login-box input[type="text"],
      .login-box input[type="password"] {
        width: 100%;
        height: 40px;
        margin-bottom: 10px;
        font-size: 16px;
        border: 1px solid #ccc;
        border-radius: 5px;
        padding: 10px;
      }

      .login-box input[type="submit"] {
        width: 100%;
        height: 40px;
        margin-top: 20px;
        background-color: #00bcd4;
        color: #fff;
        font-size: 16px;
        border: none;
        border-radius: 5px;
        cursor: pointer;
      }
    </style>
  </head>

  <body>
    <div class="login-box">
      <h1>Login</h1>
      <form>
        <input type="text" placeholder="Username" />
        <input type="password" placeholder="Password" />
        <input type="submit" value="Login" />
      </form>
    </div>
  </body>
</html>
```

在这个页面中，我们可以看到：

1. 登录框使用了 Flex 格式化上下文（FFC）
在 .login-box 中设置了 display: flex;，从而将其设置为 Flex 容器，形成了 Flex 格式化上下文（FFC）。这样，我们就可以使用强大的 Flex 布局来实现登录框内元素的排列和布局。

2. 使用了块级格式化上下文（BFC）
在全局样式中，使用了 * { box-sizing: border-box; }，从而让所有元素的盒模型都采用了 border-box 模型，这也就意味着所有元素都会形成块级格式化上下文（BFC），从而避免了 margin 重叠等问题。

3. 使用了行内格式化上下文（IFC）
在 .login-box input[type="submit"] 中设置了 display: inline-block;，从而将其设置为行内块级元素，形成了行内格式化上下文（IFC）。这样，我们就可以使用行内块级元素的特性来实现登录按钮的排列和布局。

基于以上分析，我们可以看到在这个简单的登录页面中，使用了不同的格式化上下文来控制元素的布局和渲染，从而实现了一个简单而有效的页面布局效果。

1. Flexbox（Flex）是CSS的一个模块，用于创建复杂的、响应式的和可调整大小的布局。在Flex布局中，子元素的大小可以根据可用空间“弹性”地增长或缩小。以下是如何使用Flex的基本示例：

```css
.container {
  display: flex;
}

.item {
  flex: 1;  /* Grow and shrink relative to other items */
}
```

当你说"flex的ffc"，我猜你可能是指"flex-flow"和"flex-container"。`flex-flow` 是一个简写属性，用于同时设置 `flex-direction` 和 `flex-wrap`。`flex-container` 是应用了 `display: flex` 或 `display: inline-flex` 的元素，其子元素自动成为flex项。

```css
.container {
  display: flex;
  flex-flow: row wrap; /* Direction is row and items will wrap if needed */
}
```
