```js
for (var i = 0; i < 10 ; i++) {
	setTimeout(() => {
		console.log(i)
	}, 1000)
}
```

这种情况被称为JavaScript中的"变量提升"和"作用域"问题。

在JavaScript中，使用`var`声明变量时，变量会被提升到函数或全局作用域的顶部，即使在声明之前使用变量也不会报错。这意味着在你的代码中，变量`i`会被提升到`for`循环的顶部，并且循环中的每个迭代都会使用同一个变量`i`。

由于`setTimeout()`函数是异步执行的，当`console.log(i)`被执行时，循环已经完成，`i`的值被更新为10。因此，无论`setTimeout()`函数的延迟时间设置为多少，最终都会输出10个值为9的结果。
