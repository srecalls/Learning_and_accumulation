## 2.\[\]的valueOf和toString的结果是什么？
- [x] A.`[]` 的 valueOf 结果为 `[]` ，toString 的结果为 ""
- [ ] B.`[]` 的 valueOf 结果为 `[]` ，toString 的结果为 "`[]`"
- [ ] C.`[]` 的 valueOf 结果为 0 ，toString 的结果为 "`[]`"
- [ ] D.`[]` 的 valueOf 结果为 "" ，toString 的结果为 ""

valueOf 方法用于返回一个对象的原始值。当 JavaScript 需要将对象转换为原始值时（例如，使用加法运算符进行运算时），会自动调用该对象的 valueOf 方法。如果对象没有定义 valueOf 方法，则默认返回对象本身。
toString 方法用于将一个对象转换为字符串。当 JavaScript 需要将一个对象转换为字符串时（例如，使用模板字符串或字符串拼接时），会自动调用该对象的 toString 方法。如果对象没有定义 toString 方法，则默认返回 "[object Object]"。  
两者的区别在于，valueOf 方法返回对象的原始值，而 toString 方法返回对象的字符串表示。如果对象同时定义了 valueOf 和 toString 方法，那么在将对象转换为原始值或字符串时，**valueOf 方优先于 toString 方法被调用**。

	console.log([].valueOf());
	// []

	console.log([].toString()); 
	// ''

	console.log([1, 2, 3].toString()); 
	// '1,2,3'

	console.log({}.valueOf());
	// {}

	console.log({}.toString());
	// [object Object]

- [ ] A.!important>类选择器>ID选择器>行内样式>元素选择器
- [ ] B.!important>行内样式>元素选择器 >伪类选择器>ID选择器

- [ ] D.!important>行内样式>ID选择器>元素选择器 >属性选择器

- !important
- 内联样式（1000）
- ID选择器（0100）
- 类选择器/属性选择器/伪类选择器（0010）
- 元素选择器/伪元素选择器（0001）
- 关系选择器/通配符选择器（0000）

带!important 标记的样式属性优先级最高； 样式表的来源相同时：!important > 行内样式>ID选择器 > 类选择器 > 标签 > 通配符 > 继承 > 浏览器默认属性

这里给出一个例子，假设有以下 CSS 规则：

```css
h1 {
  font-size: 36px;
  color: red;
}

#logo {
  width: 200px;
  height: 100px;
}

nav ul li {
  display: inline-block;
}

a:hover {
  text-decoration: underline;
}

* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
```

其中，`!important` 的优先级最高，会覆盖其他所有规则，因此不需要考虑其它选择器的优先级。假设某个元素同时匹配了上述所有规则，那么这个元素应用的样式规则如下：

1. `#logo` 的选择器的优先级为 `0100`，其中 ID 选择器的优先级最高，因此 `width` 和 `height` 属性值将应用于该元素。
2. `a:hover` 的选择器的优先级为 `0010`，其中类选择器/属性选择器/伪类选择器的优先级次于 ID 选择器，因此 `text-decoration` 属性值将应用于该元素。
3. `nav ul li` 的选择器的优先级为 `0010`，与上面的选择器优先级相同，但是它的位置更靠前，因此 `display` 属性值将应用于该元素。
4. `h1` 的选择器的优先级为 `0001`，其中元素选择器/伪元素选择器的优先级最低，因此 `font-size` 和 `color` 属性值将应用于该元素。
5. `*` 的选择器的优先级为 `0000`，其中关系选择器/通配符选择器的优先级最低，因此 `box-sizing`、`margin` 和 `padding` 属性值将应用于该元素。

根据选择器优先级的规则，选择器中每个部分的值相应地转换成了 4 位二进制数，然后组成一个四元组，表示该选择器的优先级。这四个数字中，第一个数字表示 `!important` 的出现次数，因为 `!important` 的优先级比其它选择器都高。如果两个规则的优先级相同，则后面的规则会覆盖前面的规则，因此优先级高的规则要放在优先级低的规则之后。

别管那些，被减数 和 值 只要是相同的， 就是 true。 x - y == y 就是 true， x - y == z 就是 false。
好的，让我们来具体计算一下 `b - a` 的值。

首先，我们需要知道在 JavaScript 中，浮点数采用的是 **IEEE 754** 标准的双精度浮点数表示法，即 64 位二进制数表示一个浮点数。在这种表示法中，浮点数通常被分成三部分：**符号位、指数位和尾数位**。例如，对于 0.4 这个浮点数，它的 IEEE 754 双精度表示是：

```basic
0 01111101110 1001100110011001100110011001100110011001100110011010
```

其中，**第 1 位是符号位，表示正负号，0 表示正数；接下来的 11 位是指数位，表示浮点数的指数部分；最后的 52 位是尾数位，表示浮点数的小数部分**。对于 0.3 这个浮点数，它的 IEEE 754 双精度表示是：

```basic
0 01111110110 0100110011001100110011001100110011001100110011001101
```

现在，我们可以将这两个二进制数进行减法运算。具体来说，需要将它们的符号位、指数位和尾数位分别相减。由于这里的尾数位数值较长，我只列出了一部分：

```asciidoc
  0 01111101110 1001100110011001100110011001100110011001100110011010
- 0 01111110110 0100110011001100110011001100110011001100110011001101
--------------------------------------------------------------------
  1 0000000000 1100110011001100110011001100110011001100110011001011
```

在减法运算过程中，由于两个浮点数的尾数位数值位数不同，需要使用尾数位补零的方式进行对齐。此外，在计算机中，浮点数的运算通常采用舍入模式，例如向最近的偶数舍入（即“四舍六入五留双”）或向零舍入等。这也会对运算结果产生影响。

因此，最终的结果是一个近似值，可能与预期的精度不完全一致。在实际编程中，我们需要注意这一点，尽可能避免使用浮点数进行精确计算。


**尾数计算**
要确定一个分数在二进制下的**循环节**，可以使用除法的方法。具体步骤如下：

1. 将分数转化为分数形式，即分子除以分母。
2. 将分数的小数部分乘以 2，得到一个整数和一个新的小数部分。
3. 将新的小数部分记录下来，并将其再次乘以 2，重复步骤 2 直到小数部分为 0 或者出现了重复的小数部分。
4. 如果小数部分为 0，则该分数在二进制下的表示是有限的。如果出现了重复的小数部分，则这个重复的部分就是分数在二进制下的循环节。

例如，对于分数 2/5，在二进制下的循环节是 0110，可以按照以下步骤进行计算：

```
2 / 5 = 0.4

0.4 * 2 = 0.8
0.8 * 2 = 1.6
0.6 * 2 = 1.2
0.2 * 2 = 0.4
```

在第四步时出现了重复的小数部分 0110，因此分数 2/5 在二进制下的循环节是 0110。

对于分数 1/3，在二进制下的循环节是 0101，可以按照以下步骤进行计算：

```
1 / 3 = 0.3333...

0.3333... * 2 = 0.6666...
0.6666... * 2 = 1.3333...
0.3333... * 2 = 0.6666...
```

在第四步时出现了重复的小数部分 0101，因此分数 1/3 在二进制下的循环节是 0101。

对于分数 0.1 和 0.2，它们在二进制下的循环节是无规律的，无法通过简单的公式计算出来。但是，我们可以使用类似上面的方法，通过手动计算来确定它们的循环节。

**指数计算**
好的，我们再以浮点数 0.3 为例说明如何计算指数位。

首先，将 0.3 转换为二进制数。这可以通过将 0.3 不断乘以 2 并取整数部分，直到小数部分为 0 或达到所需的精度为止。例如，将 0.3 转换为二进制小数的过程如下：

```
0.3 * 2 = 0.6，整数部分为 0，小数部分为 0.6
0.6 * 2 = 1.2，整数部分为 1，小数部分为 0.2
0.2 * 2 = 0.4，整数部分为 0，小数部分为 0.4
0.4 * 2 = 0.8，整数部分为 0，小数部分为 0.8
0.8 * 2 = 1.6，整数部分为 1，小数部分为 0.6
0.6 * 2 = 1.2，整数部分为 1，小数部分为 0.2
0.2 * 2 = 0.4，整数部分为 0，小数部分为 0.4
0.4 * 2 = 0.8，整数部分为 0，小数部分为 0.8
0.8 * 2 = 1.6，整数部分为 1，小数部分为 0.6
...
```

同样地，这个过程无限循环下去，因此我们需要在某个精度上停止。如果我们只需要 52 位的精度，那么可以停止在第 53 位，也就是 0.0100110011001100110011001100110011001100110011001101...。

接下来，我们需要将这个二进制小数转换为科学计数法的形式，也就是 $(-1)^s \times m \times 2^e$，其中：

- $s$ 表示符号位，0 表示正数，1 表示负数。
- $m$ 表示尾数位，它是一个二进制小数，范围在 1 到 2 之间。
- $e$ 表示指数位，它是一个整数，用二进制表示。

对于浮点数 0.3，它的二进制表示为 0.0100110011001100110011001100110011001100110011001101...，这里省略了无限循环的部分。按照科学计数法的形式，它可以写成：

$$
0.3 = 1.0011001100110011001100110011001100110011001100110011_2 \times 2^{-2}
$$

$$
0 01111111010 0011001100110011001100110011001100110011001100110100
$$

其中，第 1 位是符号位，表示正负号，0 表示正数；接下来的 11 位是指数位，表示浮点数的指数部分；最后的 52 位是尾数位，表示浮点数的小数部分。

当将 0.3 转换为 IEEE 754 双精度浮点数时，我们需要将其表示为科学计数法的形式，也就是 $(-1)^s \times m \times 2^e$，其中 $s$ 表示符号位，$m$ 表示尾数位（小数部分），$e$ 表示指数位。

首先，将 0.3 转换为二进制数。这可以通过将 0.3 不断乘以 2 并取整数部分，直到小数部分为 0 或达到所需的精度为止。例如，将 0.3 转换为二进制小数的过程如下：

```

0.2 * 2 = 0.4，整数部分为 0，小数部分为 0.4
0.4 * 2 = 0.8，整数部分为 0，小数部分为 0.8
0.8 * 2 = 1.6，整数部分为 1，小数部分为 0.6
0.6 * 2 = 1.2，整数部分为 1，小数部分为 0.2
0.2 * 2 = 0.4，整数部分为 0，小数部分为 0.4
0.4 * 2 = 0.8，整数部分为 0，小数部分为 0.8
0.8 * 2 = 1.6，整数部分为 1，小数部分为 0.6
...
```

这个过程无限循环下去，因此我们需要在某个精度上停止。如果我们只需要 52 位的精度，那么可以停止在第 53 位，也就是 0.0100110011001100110011001100110011001100110011001101...

接下来，我们需要将这个二进制小数转换为科学计数法的形式。为了将其表示为科学计数法的形式，我们需要找到一个指数 $e$，使得 $m$ 在范围 $[1, 2)$ 内，也就是 $1 \leq m < 2$。为了找到这个指数 $e$，我们可以不断将小数点向左或向右移动，直到小数部分的最高位是 1。这个过程可以用以下公式来表示：

$$
m = 1.d_1 d_2 d_3 \ldots d_n \times 2^e
$$

其中，$d_1$ 是小数部分的最高位，$n$ 是小数部分的位数。在这个公式中，$m$ 的范围是 $[1, 2)$，$e$ 的范围是任意整数。对于浮点数 0.3，它的二进制表示为 0.0100110011001100110011001100110011001100110011001101...，这里省略了无限循环的部分。

$$
0.3 = 1.0011001100110011001100110011001100110011001100110011_2 \times 2^{-2}
$$

$$
0\ 01111111010\ 0011001100110011001100110011001100110011001100110100
$$

其中，第 1 位是符号位，为 0 表示正数；接下来的 11 位是指数位，为 01111111010，表示指数为 3；最后的 52 位是尾数位，为 0011001100110011001100110011001100110011001100110100，这是将原始尾数位末位舍入到最接近的偶数的结果。因此，浮点数 0.3 在 IEEE 754 双精度浮点数表示法中的二进制表示为：

$$
0\ 01111111010\ 0011001100110011001100110011001100110011001100110100
$$

请注意，这个表示法是一个近似值，因为我们对原始二进制小数进行了舍入。因此，在进行浮点数计算时，可能会出现舍入误差和精度损失的情况。

parseFloat()可以解析以数字开头的部分数字字符串(⾮数字部分字符串在转换过程中会被去除)。parseFloat()可以将字符串转换成浮点数；但同时，parseFloat()只接受⼀个参数，且该方法**忽略前导0**。  
（1）字符串中的**第⼀个⼩数点是有效的，⽽第⼆个⼩数点就是⽆效的**了，因此它**后⾯的字符串将被忽略**。  
（2）如果字符串包含的是⼀个可解析为整数的数（**没有⼩数点，或者⼩数点后⾯都是零**），parseFloat()会返回**整数**。


	A. parseFloat('1234blue') === 1234
	解释：parseFloat('1234blue') 会将字符串解析为浮点数。由于 '1234blue' 开头是一个有效的浮点数，解析结果为 1234。因此，判断语句为 1234 === 1234，返回 true。

	B. parseFloat('0xA') === 0
	解释：parseFloat('0xA') 会将字符串解析为浮点数。虽然 '0xA' 是十六进制表示的字符串，但 parseFloat() 会将其解析为十进制数。因此，解析结果为 0。因此，判断语句为 0 === 0，返回 true。

	C. parseFloat('22.34.5') === 22.34
	解释：parseFloat('22.34.5') 会将字符串解析为浮点数。然而，由于 '22.34.5' 包含多个小数点，它无法正确解析为浮点数。因此，解析结果为 22.34，而不是 22.34.5。因此，判断语句为 22.34 === 22.34，返回 true。

	D. parseFloat('0908.5') === 908.5
	解释：parseFloat('0908.5') 会将字符串解析为浮点数。由于字符串以零开头，并且后面是一个有效的浮点数表示，解析结果为 908.5。因此，判断语句为 908.5 === 908.5，返回 true。
	所以，A、B、C 和 D 这四个判断语句都是正确的。

	- 如果 parseFloat 在解析过程中遇到了正号（+）、负号（- U+002D HYPHEN-MINUS）、数字（0-9）、小数点（.）、或者科学记数法中的指数（e 或 E）** 以外的字符，则它会忽略该字符以及之后的所有字符 **，返回当前已经解析到的浮点数。

	- 参数首位和末位的空白符会被忽略。
	- 如果参数字符串的第一个字符不能被解析成为数字，则 parseFloat 返回 NaN。
	- parseFloat 也可以解析并返回 Infinity。
	- parseFloat 解析 BigInt为 Numbers, 丢失精度。因为末位 n 字符被丢弃。
	所以并不会把0x当成16进制数字

## 18.如下方式创建的数组长度为5的有（多选题）
- [x] A.`const array = [,,,,,]`
- [x] B.`const array = new Array(5)`
- [ ] C.`const array = Array(,,,,,)`
- [x] D.`const array = new Array('', '', '', '', '')`
- [x] E.`const array = Array(5)`


* 使用 `Array(5)`或 `new Array(5)`构造函数，这会创建一个长度为5但没有值的数组。  
* 使用 `Array.from({length: 5})`方法，这会创建一个长度为5且每个元素都是 `undefined`的数组。  
* 使用 `Array.from({length: 5}, (v, i) => i)`方法，这会创建一个长度为5且每个元素都是索引值的数组。  
* 使用 `[,,,,,]`字面量，这会创建一个长度为5但没有值的稀疏数组。  
* 使用 `['', '', '', '', '']`或类似的字面量，这会创建一个长度为5且每个元素都是空字符串的数组。

`const array = new Array(5)` 和 `const array = Array(5)` 都可以创建一个长度为 5 的新数组，但它们的创建方式略有不同。

- `new Array(5)`：使用 `new` 操作符创建一个新的 `Array` 对象，并将其长度设置为 5。这种方式创建数组的缺点是，如果传入的参数是一个数字，则 `Array` 构造函数会将其视为数组的长度；如果传入的是一个非数字类型，则 `Array` 构造函数会将其视为数组的一个元素。这可能会导致一些意外的行为，如 `new Array(3, 5)` 会创建一个包含两个元素 `[3, 5]` 的数组，而不是长度为 3 的数组。

- `Array(5)`：直接调用 `Array` 构造函数，省略了 `new` 操作符。这种方式创建数组的优点是简单、明确，不会有上述的意外行为。实际上，在大多数情况下，推荐使用这种方式创建数组。

总的来说，这两种方式都可以创建一个长度为 5 的数组，但是在使用上有所不同，特别是在传入参数时需要注意。

在这个例子中，数组中的逗号表示省略了一个元素，而不是添加了一个元素。因此，`const array = [,,,,,]` 创建了一个包含 5 个空位的数组，而不是 6 个元素的数组。

在 JavaScript 中，可以使用逗号来创建一个包含空位的数组，每个逗号表示省略一个元素。例如，下面的代码创建了一个包含 3 个元素和 2 个空位的数组：

```
const array = [1, 2, , , 5];
console.log(array); // [1, 2, undefined, undefined, 5]
```

注意，**最后一个元素后面的逗号不会创建一个空位**，因此 `array` 数组中只有 2 个空位，而不是 3 个空位。这个特性在某些情况下很有用，但是在大多数情况下，最好避免使用稀疏数组。
