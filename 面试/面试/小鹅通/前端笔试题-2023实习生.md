### 2、使用JS编写排序函数（冒泡或快排皆可）：输入随意数字数组；输出值为数组，数组内数字按从大到小排列  

```js
function partition(arr, start, end) {
	let pivotValue = arr[end]
	let pivotIndex = start
	for (let i = start; i < end; i++) {
		if (arr[i] > pivotValue) {
			[arr[i], arr[pivotIndex]] = [arr[pivotIndex], arr[i]]
			pivotIndex++
		}
	}
	[arr[end], arr[pivotIndex]] = [arr[pivotIndex], arr[end]]
	return pivotIndex
}

function quickSort(arr, start, end) {
	if (start <= end) {
		return
	}
	let index = partition(arr, start, end)
	quickSort(arr, start, index - 1)
	quickSort(arr, index + 1, end)
}
```
### 3、vue或react等前端框架的数据绑定响应，实现原理大致是怎样的？  

vue的双向数据绑定是进行数据劫持，然后通过发布订阅者模式实现的
vue2是通过Object.defineProperty()来进行数据劫持，而vue3是通过proxy来进行数据劫持
实现原理：
首先在创建vue实例的时候通过Observer函数对数据进行递归遍历，为每个数据添加上getter和setter属性，从而能够监听到数据的变化
然后通过Compile函数对vue的指令模版进行解析，将指令模版中的变量更改成数据，同时初始化渲染页面，同时为指令所在的节点的添加一个监听函数，当视图发生变化时从而更新数据。同时创建订阅者Watcher，通过Observe中的getter函数将订阅者添加进Dependency的订阅者数组，以便数据更新时通知订阅者，当数据发生变化时，触发Observer中的setter函数，从而触发Dependency中的notify函数对订阅者进行通知，订阅者触发对应的回调函数从而实现对视图的更新。


### 4、有用户访问网站页面，出现了页面白屏无法访问的情况，现需要排查是什么导致的。用户这个问题可能是怎么导致的？可以通过什么方法排查确认？  

**1.可能是由网络情况导致的**
- 首先查看自己的网络是否出现了问题

		通过去浏览其他网站查看是否是网络出现的问题，或者在f12中去network里查看自己的网络请求时间来判断
	
- 可能是网页的URL输入出现了问题

		  通过看自己是不是访问了正确的网站，在f12点network里查看是否访问的是正确的url
- 可能是调用的API的问题

		  在f12的network里面看与后台对接的API是否拼写正确，有时候会出现api接口路径的‘/’没加的问题导致请求失败
		  在network里面看后台对接的API是否正确响应，查看他的状态码和响应体来判断

- 可能是代码编写错误的问题

		在f12的console里面看是否出现控制台的报错，根据是否出现错误代码来判断白屏导致的原因

- 可能是路由的路径错写的问题

		打开对应的路由配置文件，查看是否是引入了错误的组件导致的问题

**2.可能是js和css的不正常引入引起了渲染的阻塞**

		在网页中js和css错误引入会导致渲染阻塞，因为浏览器执行代码是从上到下执行，如果说请求的js文件或者css文件过大，且都是在html元素之前，就会导致加载js或者css文件的时间过长而导致阻塞，无法加载后续的html元素导致白屏
