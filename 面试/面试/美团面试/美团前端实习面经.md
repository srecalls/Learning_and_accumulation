13、代码题：promise+xhr实现异步网络请求（promise语法没记清，没写出来，囧）

是的，XMLHttpRequest对象（xhr）也可以通过Promise来处理异步操作。虽然XMLHttpRequest本身并不返回Promise对象，但可以将其封装在一个Promise对象中，以便更方便地处理异步操作。以下是一个使用Promise封装XMLHttpRequest的示例：

```js
function makeRequest(url) {
  return new Promise(function(resolve, reject) {
    var xhr = new XMLHttpRequest();
    xhr.open('GET', url);
    xhr.onload = function() {
      if (xhr.status === 200) {
        resolve(xhr.responseText);
      } else {
        reject(xhr.statusText);
      }
    };
    xhr.onerror = function() {
      reject(xhr.statusText);
    };
    xhr.send();
  });
}
```

在上面的示例中，makeRequest()函数使用了一个Promise对象来封装XMLHttpRequest对象，以便更方便地处理异步操作。在Promise对象的构造函数中，创建了一个XMLHttpRequest对象，并设置了请求的方法、URL和事件处理函数。当请求成功时，resolve()方法被调用，并将响应文本作为参数传递给.then()方法；当请求失败时，reject()方法被调用，并将状态文本作为参数传递给.catch()方法。

需要注意的是，尽管使用Promise可以简化XMLHttpRequest的异步操作处理，但在实际应用中，建议使用更现代的API，例如fetch或Axios，以便更方便、更灵活地处理异步操作。
