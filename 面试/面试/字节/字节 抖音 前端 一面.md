在微任务队列中，`async/await` 和 `Promise.then` 的执行顺序是不同的。`async/await` 的优先级高于 `Promise.then`。

当遇到 `async` 函数时，函数内部的 `await` 关键字会暂停函数的执行，将其后面的代码作为微任务放入微任务队列中。而 `Promise.then` 会将回调函数放入微任务队列中，但它的执行时机相对较晚。

因此，在一个 `async` 函数中，当遇到 `await` 关键字时，会先执行后续的 `async/await` 内部的代码，然后再执行 `Promise.then` 中的回调函数。

下面是一个示例代码来说明这个优先级关系：

```javascript
async function example() {
  console.log('1');
  await Promise.resolve();
  console.log('2');
}

console.log('3');
example();
console.log('4');
```

输出结果为：

```
3
1
4
2
```

在这个示例中，先输出 "3"，然后调用 `example()` 函数。在 `example()` 函数内部，先输出 "1"，然后遇到 `await Promise.resolve()`，这里会将后续的代码作为微任务放入微任务队列。然后 `example()` 函数继续执行，输出 "4"。接着，微任务队列中的代码开始执行，输出 "2"。

因此，可以看出 `async/await` 优先级高于 `Promise.then`，在微任务队列中，`async/await` 内部的代码会先执行，然后才执行 `Promise.then` 中的回调函数。

2. 数组去重的4种办法  

有多种方法可以对数组进行去重，下面介绍的是常见的四种办法：

1. 使用 Set 数据结构：Set 是 ES6 引入的一种新的数据结构，它存储唯一的值，可以利用它的去重特性来对数组进行去重。

```js
const array = [1, 2, 2, 3, 3, 4, 5];
const uniqueArray = [...new Set(array)];
console.log(uniqueArray); // Output: [1, 2, 3, 4, 5]
```
    
2. 使用 filter 方法：使用数组的 `filter` 方法结合 `indexOf` 可以遍历数组，对每个元素进行判断，只保留第一次出现的元素，从而达到去重的效果。
    
```js
const array = [1, 2, 2, 3, 3, 4, 5];
const uniqueArray = array.filter((value, index, self) => {
  return self.indexOf(value) === index;
});
console.log(uniqueArray); // Output: [1, 2, 3, 4, 5]
```
    
3. 使用 reduce 方法：使用数组的 `reduce` 方法遍历数组，将每个元素存储在一个新数组中，但只存储第一次出现的元素，从而实现去重。

```js
const array = [1, 2, 2, 3, 3, 4, 5];
const uniqueArray = array.reduce((acc, curr) => {
  if (!acc.includes(curr)) {
	acc.push(curr);
  }
  return acc;
}, []);
console.log(uniqueArray); // Output: [1, 2, 3, 4, 5]
```
    
4. 使用 Map 数据结构：使用 Map 数据结构存储数组中的元素，并使用元素的值作为键，对应的布尔值表示是否出现过。然后从 Map 中提取唯一的键集合，即得到去重后的数组。
    
```js
const array = [1, 2, 2, 3, 3, 4, 5];
const uniqueArray = Array.from(new Map(array.map((value) => [value, true])).keys());
console.log(uniqueArray); // Output: [1, 2, 3, 4, 5]
```
3. 实现百度搜索框，防抖节流  

```js
<!DOCTYPE html>
<html>
<head>
  <title>百度搜索框</title>
</head>
<body>
  <form id="search-form">
    <input type="text" id="search-input" placeholder="请输入搜索关键字">
    <button type="submit">搜索</button>
  </form>

  <div id="search-results"></div>

  <script>
    const searchForm = document.getElementById('search-form');
    const searchInput = document.getElementById('search-input');
    const searchResults = document.getElementById('search-results');

    let debounceTimer;
    let throttleTimer;

    searchInput.addEventListener('input', function(event) {
      const keyword = event.target.value;

      // 防抖：等待一段时间后执行搜索操作
      clearTimeout(debounceTimer);
      debounceTimer = setTimeout(function() {
        search(keyword);
      }, 500); // 设置等待时间，例如 500ms

      // 节流：一定时间内只执行一次搜索操作
      if (!throttleTimer) {
        throttleTimer = setTimeout(function() {
          search(keyword);
          throttleTimer = null;
        }, 1000); // 设置间隔时间，例如 1000ms
      }
    });

    function search(keyword) {
      // 清空搜索结果
      searchResults.innerHTML = '';

      // 模拟搜索请求和结果
      const results = [
        '搜索结果1',
        '搜索结果2',
        '搜索结果3',
        '搜索结果4',
        '搜索结果5'
      ];

      // 显示搜索结果
      results.forEach(function(result) {
        const resultItem = document.createElement('p');
        resultItem.textContent = result;
        searchResults.append(resultItem);
      });
    }
  </script>
</body>
</html>
```
4. 红包分配，每个人至少1分钱
要实现红包分配，保证每个人至少分到1分钱，可以使用以下算法:

1. 将红包总金额以及要分配的人数作为输入参数。
    
2. 首先，生成一个（人数-1）范围内的随机数，表示第一个人分到的金额。确保至少会有一个人分到1分钱。
    
3. 然后，将剩余金额（总金额减去第一个人分到的金额）作为新的红包总金额。
    
4. 依次随机生成每个人分到的金额，直到最后一个人。每个人分到的金额应该在剩余的红包金额和剩余人数之间随机分配。
    
5. 最后一个人分到的金额就是剩下的红包金额，确保最后一个人至少分到1分钱。
    

下面是一个示例的JavaScript代码实现：

```js
// totalAmount = 1
// totalPeople = 100
function allocateRedPacket(totalAmount, totalPeople) {
  const amounts = [];
  
  for (let i = 0; i < totalPeople - 1; i++) {
    const maxAmount = (totalAmount - (totalPeople - i - 1)) * 100;  // 把金额扩大100倍处理
    const randomAmount = Math.floor(Math.random() * maxAmount) + 1;  // 随机分配
    amounts.push(randomAmount / 100); // 把金额恢复到原来的大小
    totalAmount -= randomAmount / 100;
  }
  
  amounts.push(totalAmount); // 剩余的金额作为最后一个人的金额
  
  return amounts;
}

const totalAmount = 10;  // 总金额（单位：分）
const totalPeople = 10;  // 总人数
const result = allocateRedPacket(totalAmount, totalPeople);
console.log(result);

请注意，这种分配算法是基于随机生成金额来实现的，所以每次运行的结果都可能不同。但是，可以保证每个人至少分到1分钱，且总金额分配正确。


function distributeRedPacket(totalAmount, totalPeople) {
  const result = [];

  let remainingAmount = totalAmount * 100; // 将总金额转换为分
  let remainingPeople = totalPeople;

  for (let i = 0; i < totalPeople - 1; i++) {
    // 随机生成一个金额，范围是 1 到剩余金额（保证每个人至少获得 1 分钱）
    const amount = Math.floor(Math.random() * (remainingAmount - remainingPeople + 1)) + 1;

    result.push(amount / 100); // 将金额转换为元

    remainingAmount -= amount;
    remainingPeople--;
  }

  // 最后一个人获得剩余的金额
  result.push(remainingAmount / 100); // 将剩余的金额转换为元

  return result;
}

// 示例使用
const totalAmount = 100; // 总金额为 100 元
const totalPeople = 10; // 总人数为 10 人

const redPacket = distributeRedPacket(totalAmount, totalPeople);

console.log(redPacket);
```
