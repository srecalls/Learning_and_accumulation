前提条件：
```html
<div class="father">
    <div class="son"></div>
  </div>
```

```css
	*{
		margin:0;
		padding:0;
	}
```

1.定位+margin
```css
<style>
      .father {
        position: relative;
        height: 400px;
        width: 400px;
        border: solid 1px black;
      }

      .son {
        position: absolute;
        height: 200px;
        width: 200px;
        background-color: red;
        top: 0;
        right: 0;
        bottom: 0px;
        left: 0px;
        margin: auto;
      }
</style>
```


2.定位+transform
```css
.father {
	position: relative;
	height: 400px;
	width: 400px;
	border: solid 1px black;
      }
      
.son {
	position: absolute;
	height: 200px;
	width: 200px;
	background-color: red;
	top: 50%;
	left: 50%;
	transform: translate(-50%, -50%);
  }```

3.flex布局
```css
.father {
	display: flex;
	justify-content: center;
	align-items:center;
	height: 400px;
	width: 400px;
	border: solid 1px black;
}

.son {
	height: 200px;
	width: 200px;
	background-color: red;
}
```

4.grid布局
```css
.father{
	display:grid;
	height:400px;
	width:400px;
	background-color:orange;
	margin:0 auto;
}

.son{
	display:inline-block;
	height:200px;
	width:200px;
	background-color:red;
	justify-self:center;
	align-self:center;
}
```

5.table布局
注意：son块需要给予inline-block
```css
.father{
	display:table-cell;
	//垂直居中
	vertical-align:middle;
	//水平居中
	text-align:center;
	height:400px;
	width:400px;
	background-color:orange;
}

.son{
	display:inline-block;
	height:200px;
	width:200px;
	background-color:red;
}
```
