# 一、基本样式

一个父元素中有两个子元素，其中两个子元素分别左右浮动。

HTML代码：


```HTML
<div class="father">
    <div class="son left"></div>
    <div class="son right"></div>
</div
```

CSS代码：



```CSS
.father {
    width: 400px;
    border: 1px solid red;
}
.son {
    width: 100px;
    height: 100px;
    background-color: aqua;
}
.left {
    float: left;
}
.right {
    float: right;
}
```

可以看到，父元素的高度原先由子元素撑起，因为子元素浮动，导致父元素高度坍塌。

# 二、清除浮动的5种方法

## 1、给父元素设置height

直接给父元素的height属性设一个固定值：



```CSS
.father {
    height: 100px;
}
```

---

## 2、clear: both

向父元素中最后一个子元素后添加一个div：



```HTML
<div class="father">
    <div class="son left"></div>
    <div class="son right"></div>
    <div class="clear"></div>
</div>
```


```CSS
.clear {
    clear: both;
}
```

---

## 3、给父元素设置float

直接让父元素也浮动起来，打不过就加入：


```CSS
.father {
    float: left;
}

```
---

## 4、给父元素设置overflow

overflow属性为元素对溢出内容的处理方式，可以将其值设置为hidden或者auto来包含子元素：



```CSS
.father { 
	overflow: hidden; 
	/* 或者 */ 
	/* overflow: auto; */ 
}
```

---

## 5、给父元素设置after伪元素

可以添加一个不占用空间的after伪元素，将其clear属性设置为both：



```CSS
.father::after {
    content: '';
    display: block;
    clear: both;
}
```

---

# 三、总结

-   添加子元素设置clear和添加after伪元素设置clear都差不多，但是代码量偏多；
-   给父元素设置height会导致父元素高度固定，如果要求父元素高度随子元素高度变化而变化那这个方法就不太合适；
-   给父元素设置float可能会破坏原先的布局；
-   给父元素设置overflow建议使用。

## 为什么给父元素加入overflow：hideen和clear：both可以清除浮动

在 CSS 中，浮动元素会从普通文档流中脱离出来，而且它们的位置不会对后续元素的布局产生影响。这就可能导致父元素的高度无法自动适应其内部的浮动元素，进而影响页面布局。因此，为了解决这个问题，可以使用 `overflow: hidden` 和 `clear: both` 这两个 CSS 属性来清除浮动。

具体来说，`overflow: hidden` 可以通过创建一个新的 BFC（块级格式化上下文）来清除浮动。BFC 是一个独立的渲染区域，其中的元素布局不会影响到 BFC 外部的元素。当为父元素添加 `overflow: hidden` 属性时，它会创建一个新的 BFC，从而使浮动元素的高度被包含在父元素中，同时也能够避免父元素高度塌陷的问题。

而 `clear: both` 则可以通过在浮动元素下方添加一个空元素来清除浮动。具体来说，可以在浮动元素的下方添加一个空的 `<div>` 元素，并设置其样式为 `clear: both`，这样就可以清除浮动元素对父元素高度的影响。

需要注意的是，`overflow: hidden` 和 `clear: both` 这两个属性的使用场景不同。`overflow: hidden` 主要用于解决包含浮动元素的父元素高度无法自动适应的问题，而 `clear: both` 则主要用于解决浮动元素对后续元素布局的影响问题。在实际开发中，应根据具体情况选择合适的属性进行清除浮动。




## 父元素有float：left但是子元素没有，子元素会怎样


当父元素设置了 `float: left` 而子元素没有设置浮动时，子元素会出现在父元素的顶部，而不是按照正常的文档流布局在父元素的下方。

这是因为，当父元素设置了浮动后，它会从文档流中脱离出来，不再占据文档流中的位置，而是向左或向右浮动。而子元素没有设置浮动时，它仍然按照正常的文档流布局，会将父元素的顶部作为基准线，占据原本应该是父元素的位置。

为了解决这个问题，可以给子元素设置 `clear: left` 或 `clear: both`，这样子元素就会在父元素下方开始布局，而不是在父元素的顶部。具体来说，`clear: left` 表示子元素需要清除其左侧的浮动元素，而 `clear: both` 表示子元素需要同时清除其左右两侧的浮动元素。

示例代码如下：

```html
<div class="parent" style="float: left;">
  <div class="child" style="clear: both;">子元素</div>
</div>
```

在这个例子中，父元素设置了 `float: left`，而子元素设置了 `clear: both`，这样子元素就会在父元素的下方开始布局。

需要注意的是，当子元素设置了浮动时，它的布局会受到父元素浮动的影响，因此也需要根据具体情况来选择合适的清除浮动方式。

## 为什么clear：both对inline和inline-block不生效
`clear: both` 属性对于 `inline` 和 `inline-block` 元素不生效，是因为它们是行内元素，并且默认情况下不具有块级元素的特性，即不会创建块级格式化上下文（BFC）。

在 CSS 中，当一个元素设置了 `float` 属性后，它会脱离常规文档流，导致其所在的容器高度坍塌。为了解决这个问题，可以在容器的最后添加一个空元素，并设置为 `clear: both`，从而清除浮动元素的影响，并且撑开容器的高度。但是，如果容器中只包含 `inline` 或 `inline-block` 元素，那么添加一个空元素并设置为 `clear: both` 将不会有效果，因为它们不会创建 BFC。

在块级元素中，`clear: both` 属性可以将元素下方的浮动元素清除掉，因为块级元素会创建 BFC，从而可以包含浮动元素，并且清除浮动元素的影响。但是，`inline` 和 `inline-block` 元素不会创建 BFC，因此 `clear: both` 属性对它们无效。

如果想要在 `inline` 或 `inline-block` 元素中清除浮动元素的影响，并且撑开容器的高度，可以使用其他方法，如使用 `overflow: hidden` 属性或使用 Flexbox 或 Grid 等布局技术。例如，可以将容器设置为 Flex 容器，并使用 `align-items: stretch` 属性来使 `inline` 元素在纵向方向上占据整个容器的高度。同时，可以将浮动元素的 display 属性值设置为 `block` 或 `inline-block`，从而能够撑开容器的高度。
