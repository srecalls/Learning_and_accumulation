## 三者的区别:
- px是固定的像素，一旦设置了就无法因为适应页面大小而改变
- em和rem相对于px更具有灵活性，他们是相对长度单位，其长度不是固定的，更适用于响应式布局。
- em是相对于其父元素来设置字体大小，这样就会存在一个问题，进行任何元素设置，都有可能需要知道他父元素的大小。而rem是相对于根元素，这样就意味着，只需要在根元素确定一个参考值。

## 使用场景:
- 对于只需要适配少部分移动设备，且分辨率对页面影响不大的，使用px即可
- 对于需要适配各种移动设备，使用rem，例如需要适配iPhone和iPad等分辨率差别比较挺大的设备。


当涉及到选择使用 px、em 或 rem 作为长度单位时，以下是一些使用场景的具体示例：

1. 使用 px：
   - 固定宽度的元素：如果你希望一个元素始终保持固定的宽度，不随页面大小变化而改变，可以使用 px。例如，页面的导航栏或固定宽度的侧边栏。

2. 使用 em：
   - 字体大小：对于需要根据父元素的字体大小来进行调整的文本内容，可以使用 em。例如，段落文本、标题等。
   - 相对尺寸调整：对于需要根据父元素的尺寸进行相对调整的元素，可以使用 em。例如，一个占据父容器宽度一半的盒子。

3. 使用 rem：
   - 响应式布局：对于需要在不同屏幕尺寸下进行自适应布局的元素，可以使用 rem。通过在根元素设置一个参考值，可以方便地根据屏幕尺寸进行相对调整。
   - 全局尺寸控制：对于需要在整个页面上维护一致的尺寸比例的元素，可以使用 rem。例如，整个页面的基准字体大小和间距等。

举例：

```css
/* 使用 px */
.navbar {
  width: 960px; /* 固定宽度的导航栏 */
}

/* 使用 em */
p {
  font-size: 1.2em; /* 相对于父元素的字体大小 */
}

.box {
  width: 2em; /* 相对于父元素的宽度 */
}

/* 使用 rem */
html {
  font-size: 16px; /* 设置根元素的参考字体大小 */
}

.container {
  width: 20rem; /* 相对于根元素的宽度 */
}
```

在这个示例中，`.navbar` 使用了固定的像素单位 px 来定义宽度。`p` 元素使用了相对单位 em 来设置字体大小，`.box` 使用了相对单位 em 来设置宽度。根元素 `html` 使用了相对单位 rem 来设置字体大小，`.container` 使用了相对单位 rem 来设置宽度。

使用哪种单位取决于具体的需求和设计要求。px 提供了固定的精确控制，em 和 rem 提供了更灵活和相对的控制，适用于不同的布局和调整需求。
