外边距塌陷（Margin Collapse）是指在垂直方向上，两个相邻盒子之间的外边距（margin）发生合并的现象。当两个相邻盒子的上下外边距相遇时，它们会合并成一个外边距，而不是保持各自的外边距。这种合并现象称为“塌陷”。

外边距塌陷的情况有以下几种：

1. 父元素和第一个子元素的外边距合并

当父元素和其第一个子元素的外边距相邻时，它们的外边距会合并成一个外边距。例如：

```html
<style>
  .parent {
    margin: 20px;
    padding: 10px;
    border: 1px solid black;
  }
  .child {
    margin: 30px;
    padding: 10px;
    border: 1px solid black;
  }
</style>

<div class="parent">
  <div class="child">Child element</div>
</div>
```

在这个例子中，父元素和子元素之间的垂直外边距应该是 20px + 30px = 50px，但实际上它们只有 30px 的外边距，因为父元素和子元素的外边距发生了塌陷。

2. 相邻兄弟元素的外边距合并

当相邻的两个兄弟元素之间存在外边距时，它们的外边距也会合并成一个外边距。例如：

```html
<style>
  .box {
    margin: 20px;
    padding: 10px;
    border: 1px solid black;
  }
</style>

<div class="box">Box 1</div>
<div class="box">Box 2</div>
```

在这个例子中，两个相邻的盒子之间应该有 20px 的垂直间距，但实际上它们之间只有 20px 的上边距，因为下边距被上面的盒子的上边框所吞噬了。

3. 空元素的外边距塌陷

如果一个没有内容的元素设置了外边距，它的外边距也会合并到其父元素的外边距上。例如：

```html
<style>
  .parent {
    margin: 20px;
    padding: 10px;
    border: 1px solid black;
  }
  .empty {
    margin: 30px;
  }
</style>

<div class="parent">
  <div class="empty"></div>
</div>
```

在这个例子中，空元素的外边距会合并到父元素的外边距上，从而使父元素的外边距变成了 30px，而不是 20px。

解决外边距塌陷的方法有多种，以下是其中的一些：

1. 将父元素设置为 `<table>` 元素或者 `float` 元素，这样可以防止外边距塌陷。

2. 为父元素添加 `border`、`padding` 或者 `inline-block` 属性，也可以避免外边距塌陷。

3. 使用 `overflow: auto` 或 `overflow: hidden`，可以创建一个新的块级格式化上下文，从而避免外边距塌陷。

4. 使用 CSS3 的 `flexbox` 或者 `grid` 布局，这两种布局方式可以很好地解决外边距塌陷问题。

总之，外边距塌陷是一个常见的 CSS 布局问题，但是通过以上方法，我们可以很好地避免和解决这个问题。
