在谷歌下css设置字体大小为12px及以下时，显示都是一样大小，都是默认12px。

**解决办法：**

- 使用Webkit的内核的-webkit-text-size-adjust的私有CSS属性来解决，只要加了-webkit-text-size-adjust:none;字体大小就不受限制了。但是**chrome更新到27版本之后就不可以用**了。所以高版本chrome谷歌浏览器已经**不再支持-webkit-text-size-adjust**样式，所以要使用时候慎用。
- 
- 使用css3的transform缩放属性 -webkit-transform:scale(0.5);  **注意-webkit-transform:scale(0.75);收缩的是整个元素的大小**，这时候，如果是**内联元素，必须要将内联元素转换成块元素**，可以使用display：block/inline-block/...；

- 使用图片：如果是内容固定不变情况下，使用将小于12px文字内容切出做图片，这样不影响兼容也不影响美观。

## 使用-webkit-transform: scale()
```js
<html lang="en">
<body>
    <style type="text/css">
        .box1 {
            height:300px;
            width: 300px;
            /* background-color: blue; */
        }
        span {
            display: block;
            font-size: 10px;
            -webkit-transform: scale(0.5);
		}
    </style>
    <div class="box1">
        <span>我</span>
        <span>小</span>
        <span>于</span>
        <span>十</span>
        <span>二</span>
    </div>
</body>
</html>
```

注意点：这里的-webkit-transform:scale是根据12px来进行转换的

如果你不使用 CSS 预处理器，你可以使用 JavaScript 动态生成样式：

```js
const scaleRatio = 5 / 6; // 定义缩放比例

const element = document.querySelector('.element');
element.style.transform = `scale(${scaleRatio})`; // 应用样式
```

在这个示例中，我们使用 JavaScript 定义了变量 `scaleRatio`，然后通过 DOM 操作将缩放比例应用到元素的样式中。

确实，使用 `-webkit-text-size-adjust: none;` 可以在 WebKit 内核的浏览器（如早期版本的 Chrome 和 Safari）中禁用字体大小调整。然而，随着浏览器的更新，高版本的 Chrome 和其他现代浏览器已经不再支持该样式属性。

以下是你提到的两种解决方案的示例：

## 1. 使用 CSS3 的 `transform` 缩放属性：

```css
.element {
  -webkit-transform: scale(0.5); /* Chrome 和 Safari */
  transform: scale(0.5); /* 其他现代浏览器 */
}
```

通过应用 `transform` 的 `scale` 属性，你可以缩小元素的大小。请注意，如果要应用于内联元素，确保将其转换为块级元素或内联块级元素（通过 `display: block;` 或 `display: inline-block;`）。



在CSS中，`-webkit-` 是一种浏览器引擎前缀（vendor prefix），用于指定特定浏览器的私有CSS属性或特性。不同的浏览器厂商可能会为实验性或尚未标准化的CSS属性添加浏览器引擎前缀，以在其浏览器中实现特定的效果。

在给定的代码中，`-webkit-transform` 是一个应用于元素的CSS属性，用于指定元素的缩放效果。它是用于支持基于WebKit引擎的浏览器（如Chrome和Safari）的私有属性。而 `transform` 则是标准化的CSS属性，适用于其他现代浏览器。

为了确保在不同的浏览器中都能正确显示和应用缩放效果，需要使用浏览器引擎前缀来覆盖不同浏览器的兼容性。通过添加 `-webkit-` 前缀，可以确保该属性在WebKit引擎的浏览器中被正确识别和应用，而其他浏览器则会忽略该前缀，直接应用标准的 `transform` 属性。

需要注意的是，随着时间的推移和标准的发展，一些CSS属性已经不再需要浏览器引擎前缀，并且可以直接使用标准属性。因此，建议在编写CSS代码时，根据需要使用适当的浏览器引擎前缀，并且定期检查是否仍然需要这些前缀来支持特定的浏览器。可以使用自动化工具（如Autoprefixer）来自动生成适当的浏览器引擎前缀。
## 2. 使用图片：

如果你的内容是固定的且不需要动态更改，你可以将小于 12px 的文本内容制作成图片，并将其作为背景图像或内联图像嵌入到页面中。这样做可以确保文本在任何浏览器中都以相同的大小呈现，不受字体大小调整的影响。

```html
<div class="element" style="background-image: url('small-text-image.png');"></div>
```

在这个示例中，我们通过设置元素的背景图像来呈现小字体内容。你需要将 `small-text-image.png` 替换为你自己的小字体文本图像。

需要注意的是，这种方法仅适用于静态内容，如果你的文本内容需要动态更新，这种方法可能不适用。

## 计算Css
### 1.js
要直接计算 CSS 属性而无需使用预处理语言，可以使用 JavaScript 来操作和计算 CSS 属性的值。以下是一些常见的方法：

1. 获取计算后的样式：
   使用 JavaScript 中的 `getComputedStyle` 方法可以获取元素的计算后样式。这个方法返回一个对象，包含了元素的所有计算后的样式属性和值。你可以通过该对象来获取和计算 CSS 属性的值。
   
```javascript
var element = document.getElementById('myElement');
var computedStyle = window.getComputedStyle(element);
var width = computedStyle.getPropertyValue('width');
console.log(width);
```
   
   在上面的例子中，我们获取了 `myElement` 元素的计算后样式，并通过 `getPropertyValue` 方法获取了 `width` 属性的值。

2. 动态修改样式属性：
   使用 JavaScript 可以直接修改元素的内联样式属性。可以通过元素的 `style` 对象来访问和修改样式属性。


```javascript
var element = document.getElementById('myElement');
element.style.width = '200px';
element.style.height = '100px';
```
   
   上面的代码将 `myElement` 元素的宽度设置为 200 像素，高度设置为 100 像素。

3. 计算属性值：
   如果需要对 CSS 属性值进行计算，可以使用 JavaScript 进行数学运算或字符串操作。例如，可以将两个属性值相加或连接起来。

```javascript
var element = document.getElementById('myElement');
var computedStyle = window.getComputedStyle(element);
var width = parseInt(computedStyle.getPropertyValue('width'), 10);
var newWidth = width + 50;
element.style.width = newWidth + 'px';
```
   
   在上面的例子中，我们获取了 `myElement` 元素的计算后样式的宽度值，并将其转换为整数。然后，我们对宽度值进行计算，并将新的宽度应用于元素。

通过这些方法，你可以直接使用 JavaScript 操作和计算 CSS 属性的值，而无需使用预处理语言。请注意，这些操作是在客户端执行的，因此可能会受到浏览器兼容性和性能的影响。

### 2.calc
是的，你可以使用 CSS 的 `calc()` 函数来进行简单的数学计算，以计算 CSS 属性值。`calc()` 函数接受一个表达式作为参数，并返回计算后的结果。

`calc()` 函数可以在很多地方使用，例如设置元素的宽度、高度、边距、内边距等。它支持加法、减法、乘法和除法操作。

以下是一些使用 `calc()` 函数的示例：

```css
/* 计算宽度为父元素宽度的一半 */
div {
  width: calc(50%);

/* 计算高度为视口高度减去80像素 */
div {
  height: calc(100vh - 80px);
}

/* 计算边距为宽度的一半 */
div {
  margin: calc(50%);

/* 计算字体大小为基础大小加上10像素 */
p {
  font-size: calc(16px + 10px);
}
```

在这些示例中，`calc()` 函数用于计算各种 CSS 属性的值。你可以在表达式中使用长度单位（如像素、百分比等）进行计算，并且可以结合不同的操作符（如加号、减号、乘号、除号）。

需要注意的是，`calc()` 函数的表达式中不能包含空格，要注意正确的语法和操作符的顺序。此外，不是所有的 CSS 属性都支持 `calc()` 函数，具体的支持情况可以参考相关属性的文档或规范。

总结来说，通过使用 `calc()` 函数，你可以在 CSS 中进行简单的数学计算来设置属性的值，从而实现更灵活的布局和样式效果。
