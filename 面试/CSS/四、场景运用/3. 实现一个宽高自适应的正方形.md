- 利用元素的**margin/padding**百分比是**相对父元素width**的性质来实现：
- 注意：padding的百分比是相对父元素宽度width进行

在CSS中，padding的百分比值是相对于父元素的宽度（width）计算的。当设置一个元素的padding属性为百分比值时，它会根据父元素的宽度计算出最终的像素值。

例如，如果父元素的宽度为200像素，而你设置子元素的padding属性为50%，那么子元素的padding将会是父元素宽度的50%。即子元素的padding为100像素（50% × 200像素）。

请注意，这里的百分比值是相对于父元素的宽度而不是高度。如果需要相对于其他属性（如高度）计算padding，可以使用其他单位或百分比值，如百分比值相对于父元素的高度（height）。

```css
.square {
  width: 20%;
  height: 0;
  padding-top: 20%;
  background: orange;
}
```


- 利用子元素的margin-top的值来实现：
```css
.square {
  width: 30%;
  overflow: hidden;
  background: yellow;
}
.square::after {
  content: '';
  display: block;
  margin-top: 100%;
}
```

这段CSS代码使用了一个伪元素(::after)来创建一个占位元素，并通过设置其margin-top为100%来实现宽高自适应的效果。

当设置一个元素的margin-top为百分比值时，它会相对于父元素的宽度计算出最终的像素值。在这种情况下，设置margin-top为100%，意味着占位元素的上外边距（margin-top）的像素值将等于父元素宽度的100%。

这样设置后，占位元素将会被推离父元素的顶部，并撑开一个等高的空间。由于父元素的宽度是相对于父元素的百分比值（30%）来设置的，因此占位元素的高度将与父元素的宽度保持相同的比例。

通过设置overflow: hidden属性，父元素将隐藏超出其边界的内容，确保只显示占位元素的部分，从而实现了宽高自适应的效果。

值得注意的是，这种方法仅适用于需要创建一个等高的盒子，而不是实际包含内容的盒子。如果需要在盒子内添加内容，可以通过其他布局技术来实现。
