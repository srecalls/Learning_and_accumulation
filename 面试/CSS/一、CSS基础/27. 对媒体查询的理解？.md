媒体查询由⼀个可选的媒体类型和零个或多个使⽤媒体功能的限制了样式表范围的表达式组成，例如宽度、⾼度和颜⾊。媒体查询，添加⾃CSS3，允许内容的呈现针对⼀个特定范围的输出设备⽽进⾏裁剪，⽽不必改变内容本身，适合web⽹⻚应对不同型号的设备⽽做出对应的响应适配。

媒体查询包含⼀个可选的媒体类型和满⾜CSS3规范的条件下，包含零个或多个表达式，这些表达式描述了媒体特征，最终会被解析为true或false。如果媒体查询中指定的媒体类型匹配展示⽂档所使⽤的设备类型，并且所有的表达式的值都是true，那么该媒体查询的结果为true。那么媒体查询内的样式将会⽣效。
```html
<!-- link元素中的CSS媒体查询 --> 
<link rel="stylesheet" media="(max-width: 800px)" href="example.css" /> 


<!-- 样式表中的CSS媒体查询 --> 
<style> 
@media (max-width: 600px) { 
  .facet_sidebar { 
    display: none; 
  } 
}
</style>
```
简单来说，使用 @media 查询，可以针对不同的媒体类型定义不同的样式。@media 可以针对不同的屏幕尺寸设置不同的样式，特别是需要设置设计响应式的页面，@media 是非常有用的。当重置浏览器大小的过程中，页面也会根据浏览器的宽度和高度重新渲染页面。


媒体查询（Media Queries）是一种CSS特性，用于根据设备的特性和属性，以及视口（viewport）的大小，来应用不同的样式规则。它允许开发者根据不同的媒体类型、设备尺寸、屏幕方向等条件，针对不同的设备和环境提供不同的样式和布局。

媒体查询的基本语法如下：

```css
@media mediaType and (mediaFeature) {
  /* 样式规则 */
}
```

- `mediaType`：媒体类型指定了媒体查询应用的设备类型，如`screen`（屏幕）、`print`（打印）等。它可以省略，默认为`all`，表示适用于所有媒体类型。
- `mediaFeature`：媒体特性表示设备的属性或条件，如设备宽度、设备高度、屏幕方向等。常见的媒体特性包括`width`（设备宽度）、`height`（设备高度）、`orientation`（屏幕方向）等。
- `样式规则`：在媒体查询条件满足时应用的样式规则。

示例：

```css
/* 当设备宽度小于等于600px时应用以下样式规则 */
@media (max-width: 600px) {
  /* 样式规则 */
}

/* 当设备宽度大于等于768px且高度小于等于1024px时应用以下样式规则 */
@media (min-width: 768px) and (max-height: 1024px) {
  /* 样式规则 */
}
```

媒体查询可以用于响应式设计，使得网页能够根据设备的属性和视口的大小，提供不同的布局和样式。通过使用媒体查询，可以针对不同的设备类型（如桌面、平板、手机）、设备方向（横向或纵向）、设备尺寸等，优化用户体验、布局排版、图像大小、字体大小等方面。

媒体查询可以在CSS文件中直接使用，也可以在HTML文件中使用`<link>`标签的`media`属性来引入不同的样式文件，从而实现针对不同媒体条件的样式控制。

需要注意的是，媒体查询并不只限于CSS，它也可以在JavaScript中使用，通过`window.matchMedia()`方法来检测设备的媒体条件，从而实现动态的逻辑处理。
