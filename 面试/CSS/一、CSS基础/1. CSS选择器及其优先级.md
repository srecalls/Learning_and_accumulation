
|**选择器**|**格式**|**优先级权重**|
|---|---|---|
|id选择器|\#id|100|
|类选择器|\.classname|10|
|属性选择器|a[ref=“eee”]|10|
|伪类选择器|li:last-child|10|
|标签选择器|div|1|
|伪元素选择器|li::after|1|
|相邻兄弟选择器|h1+p|0|
|子选择器|ul>li|0|
|后代选择器|li a|0|
|通配符选择器|*|0|

对于选择器的**优先级**：

- 标签选择器、伪元素选择器：1
- 类选择器、伪类选择器、属性选择器：10
- id 选择器：100
- 内联样式：1000

**注意事项：**
- !important声明的样式的优先级最高；
- 如果优先级相同，则最后出现的样式生效；
- 继承得到的样式的优先级最低；
- 通用选择器（\*）、子选择器（>）和相邻同胞选择器（+）并不在这四个等级中，所以它们的权值都为 0 ；
- 样式表的来源不同时，优先级顺序为：内联样式 > 内部样式 > 外部样式 > 浏览器用户自定义样式 > 浏览器默认样式。

## 伪类、伪元素
伪类（pseudo-class）和伪元素（pseudo-element）是 CSS 中用于选择和样式化特定元素状态或元素的部分内容的机制。它们以冒号（:）为前缀，并附加到选择器的末尾。

**伪类（Pseudo-class）**：
伪类用于选择具有特定状态或特征的元素。它们可以根据用户的交互、文档结构、状态等进行选择。以下是一些常见的伪类：

- `:hover`：选择鼠标悬停在元素上的状态。
- `:active`：选择被激活或按下的元素。
- `:focus`：选择当前拥有焦点的元素。
- `:first-child`：选择作为其父元素的第一个子元素的元素。
- `:last-child`：选择作为其父元素的最后一个子元素的元素。
- `:nth-child(n)`：选择作为其父元素的第 n 个子元素的元素。

示例：
```css
a:hover {
  color: red;
}

li:first-child {
  font-weight: bold;
}
```

上述示例中，`:hover` 伪类选择鼠标悬停在锚元素上时的样式，`li:first-child` 伪类选择作为其父元素的第一个子元素的列表项并应用样式。

**伪元素（Pseudo-element）**：
伪元素用于向文档中的元素的特定部分添加样式。它们允许你在元素的内容之前或之后插入生成的内容。以下是一些常见的伪元素：

- `::before`：在元素内容之前插入生成的内容。
- `::after`：在元素内容之后插入生成的内容。
- `::first-line`：选择元素的第一行。
- `::first-letter`：选择元素内容的第一个字母。

示例：
```css
p::before {
  content: "前缀：";
  font-weight: bold;
}

p::first-letter {
  color: blue;
  font-size: 24px;
}
```

上述示例中，`::before` 伪元素在段落内容之前插入一个前缀，`::first-letter` 伪元素选择段落内容的第一个字母并应用样式。

值得注意的是，伪类和伪元素在语法上有所不同。伪类使用单冒号（:），而伪元素使用双冒号（::）。然而，为了保持向后兼容性，单冒号仍然可以用于表示伪元素。

总结：
- 伪类用于选择具有特定状态或特征的元素。
- 伪元素用于向元素的特定部分添加样式或生成内容。
- 伪类和伪元素可与选择器一起使用，以精确选择元素或元素的部分内容，并为其应用样式。

**相邻兄弟选择器**
相邻兄弟选择器（Adjacent Sibling Selector）是 CSS 中一种选择器，用于选择紧接在另一个元素后面的直接兄弟元素。它使用加号（+）作为选择器符号。


相邻兄弟选择器的语法如下：
```
element1 + element2
```

其中，`element1` 是一个元素选择器，表示要匹配的元素的类型或类名，`element2` 也是一个元素选择器，表示紧接在 `element1` 后面的元素。

以下是一个示例来说明相邻兄弟选择器的使用：

```html
<p>Paragraph 1</p>
<p>Paragraph 2</p>
<p>Paragraph 3</p>
<p>Paragraph 4</p>
```

```css
p + p {
  color: red;
}
```

![[1. CSS选择器及其优先级.png]]

在上述示例中，`p + p` 选择器选择紧跟在 `<p>` 元素后面的另一个 `<p>` 元素，并将其文本颜色设置为红色。因此，第二个、第三个和第四个 `<p>` 元素都会应用红色文本颜色样式。

需要注意的是，相邻兄弟选择器仅选择直接相邻的兄弟元素。如果有其他元素位于两个相邻元素之间，该选择器将不会匹配。

相邻兄弟选择器在某些情况下非常有用，特别是在需要选择特定位置的元素时。通过结合不同类型的选择器，可以更精确地选择和样式化文档中的元素。
