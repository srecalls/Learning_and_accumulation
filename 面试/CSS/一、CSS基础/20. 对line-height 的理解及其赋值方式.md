**（1）line-height的概念：**

- line-height 指**一行文本的高度**，包含了**字间距**，实际上是**下一行基线到上一行基线距离**；**baseline到baseline的距离**
- 如果一个标签**没有定义 height 属性**，那么其最终表现的**高度由 line-height** 决定；
- 一个容器没有设置高度，那么撑开**容器高度的是 line-height**，而**不是容器内的文本内容**；
- 把 line-height 值设置为 height 一样大小的值可以实现**单行文字**的垂直居中；
- line-height 和 height 都能撑开一个高度；
[[vertical-align 属性应用]]


**（2）line-height 的赋值方式：**

- 带单位：px 是固定值，而 em 会参考父元素 font-size 值计算自身的行高
- 纯数字：会把比例传递给后代。例如，父级行高为 1.5，子元素字体为 18px，则子元素行高为 1.5 * 18 = 27px
- 百分比：将计算后的值传递给后代


line-height（行高）的默认值是通常由浏览器或用户代理（User Agent）决定的，它可以根据不同浏览器和用户设置而有所差异。然而，大多数浏览器的默认行高约为1.2倍到1.4倍的字体大小。

具体来说，如果没有显式地设置line-height属性，那么浏览器会使用默认值。例如，如果字体大小为16像素，那么默认的line-height可能在19.2到22.4像素之间（16乘以1.2到1.4）。

需要注意的是，line-height的计算方式还可以受到其他因素的影响，如文本的排列方式、元素的继承样式等。因此，实际的行高可能会略有不同。

如果你希望在自己的样式表中明确设置line-height的值，可以使用具体的像素、百分比或无单位的数值来定义行高。例如：

```css
p {
  line-height: 1.5; /* 行高为字体大小的1.5倍 */
}

h1 {
  line-height: 24px; /* 行高为24像素 */
}

div {
  line-height: 120%; /* 行高为字体大小的120% */
}
```

通过显式设置line-height，你可以确保文本在不同浏览器和设备上具有一致的行高效果。

##### 字的上下间距如何调整
要调整字的上下间距，你可以使用CSS中的line-height属性或margin属性，具体取决于你想要实现的效果。

1. 使用line-height属性：
   line-height属性可以控制行高，从而影响字的上下间距。通过增加或减少line-height的值，可以调整字的垂直间距。

   例如，你可以使用以下CSS样式来增加字的上下间距：
   ```css
   p {
     line-height: 1.5; /* 行高为字体大小的1.5倍，增加上下间距 */
   }
   ```

   如果你想减小上下间距，可以选择一个比字体大小小的line-height值。

2. 使用margin属性：
   另一种调整字的上下间距的方法是使用margin属性。通过为字元素设置上下边距（margin-top和margin-bottom），可以改变上下间距。

   例如，你可以使用以下CSS样式来增加字的上下间距：
   ```css
   p {
     margin-top: 10px;
     margin-bottom: 10px;
   }
   ```

   你可以根据需要调整上下边距的数值来增加或减少上下间距。

无论是使用line-height还是margin属性，都可以根据具体的需求来调整字的上下间距。请记住，在进行调整时要注意遵循良好的设计原则，以确保文本的可读性和视觉美感。
