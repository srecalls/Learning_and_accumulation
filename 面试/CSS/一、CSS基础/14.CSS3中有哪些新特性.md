## 1. `:not(.input)` 选择器：选择所有 class 不是“input”的节点。

```css
/* 选择所有不带有 class 为 input 的 <p> 元素 */
p:not(.input) {
  color: red;
}

属性选择器
input[type="text"] {
  /* 样式规则 */
}

- 相邻兄弟选择器：
h2 + p {
  /* 样式规则 */
}
```

## 2. `border-radius` 属性：将元素的边角设置为圆角。

```css
/* 设置圆角为 8px */
div {
  border-radius: 8px;
}
```

## 3. 多列布局 (`multi-column layout`)：将内容分成多列显示。

```css
/* 将文章内容分成 2 列显示 */
article {
  column-count: 2;
  column-gap: 20px;
}
```

## 4. 阴影和反射 (`Shadoweflect`)：为元素添加阴影和反射效果。

```css
/* 添加阴影和反射效果 */
img {
  box-shadow: 2px 2px 5px rgba(0, 0, 0, 0.5);
  transform: scaleY(-1);
}
```

## 5. 文字特效 (`text-shadow`)：为文字添加阴影效果。

```css
/* 添加文字阴影效果 */
h1 {
  text-shadow: 2px 2px 5px rgba(0, 0, 0, 0.5);
}
```

## 6. 文字渲染 (`text-decoration`)：为文字添加下划线、删除线等效果。

```css
/* 为链接添加下划线效果 */
a {
  text-decoration: underline;
}
```

## 7. 线性渐变 (`gradient`)：为元素的背景添加线性渐变效果。

```css
/* 添加水平方向的线性渐变背景 */
div {
  background: linear-gradient(to right, #000000, #ffffff);
}
```

## 8. 旋转 (`transform`)：将元素旋转一定角度。

```css
/* 将图片顺时针旋转 45 度 */
img {
  transform: rotate(45deg);
}
```

## 9. 缩放 (`transform`)：将元素缩放一定比例。

```css
/* 将图片放大 1.2 倍 */
img {
  transform: scale(1.2);
}
```

## 10. 定位 (`position`)：将元素相对于父元素或文档定位。

```css
/* 将 <div> 元素相对于父元素定位 */
div {
  position: relative;
  top: 20px;
  left: 50px;
}
```

## 11. 倾斜 (`transform`)：将元素倾斜一定角度。

```css
/* 将 <h1> 元素向右倾斜 10 度 */
h1 {
  transform: skewX(-10deg);
}
```

## 12. 动画 (`animation`)：为元素添加动画效果。

```css
/* 为 <div> 元素添加旋转动画效果 */
div {
  animation: spin 2s linear infinite;
}

@keyframes spin {
  0% {
    transform: rotate(0deg);
  }
  100% {
    transform: rotate(360deg);
  }
}
```

## 13. 多背景 (`background`)：为元素添加多个背景。

```css
/* 为 <div> 元素添加两个背景 */
div {
  background-image: url(bg1.jpg), url(bg2.jpg);
  background-position: top left, bottom right;
  background-repeat: no-repeat, no-repeat;
}
```

以上是一些 CSS 新增的选择器和属性，这些功能可以让开发者更方便地实现各种样式效果。
