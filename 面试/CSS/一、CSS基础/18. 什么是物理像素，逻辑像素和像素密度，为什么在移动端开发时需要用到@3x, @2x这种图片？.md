以 iPhone XS 为例，当写 CSS 代码时，针对于单位 px，其宽度为 414px & 896px，也就是说当赋予一个 DIV元素宽度为 414px，这个 DIV 就会填满手机的宽度；

而如果有一把尺子来实际测量这部手机的物理像素，实际为 1242\*2688 物理像素；经过计算可知，1242/414=3，也就是说，在单边上，一个逻辑像素=3个物理像素，就说这个屏幕的像素密度为 3，也就是常说的 3 倍屏。

对于图片来说，为了保证其不失真，**1 个图片像素**至少要对应**一个物理像素**，假如原始图片是 500\*300 像素，那么在 3 倍屏上就要放一个 1500*\900 像素的图片才能保证 1 个物理像素至少对应一个图片像素，才能不失真。

物理像素（Physical Pixels）：物理像素是显示设备的最小显示单元，它是屏幕上最小的可见点。在液晶显示屏中，物理像素通常由三个亮度子像素（红、绿、蓝）组成。物理像素的数量决定了屏幕的分辨率，例如 1920x1080 表示屏幕有 1920 个物理像素宽度和 1080 个物理像素高度。

逻辑像素（Logical Pixels）：逻辑像素也称为设备独立像素（dp或dip），是在移动设备上使用的一个抽象单位。它与物理像素的关系取决于设备的像素密度。逻辑像素用于屏幕上的布局和绘制，而不考虑实际物理像素的数量。例如，在 Android 开发中，1 个逻辑像素可能等于 1 个物理像素（像素密度为 160 dpi 的设备），也可能等于 2 个物理像素（像素密度为 320 dpi 的设备）。

像素密度（Pixel Density）：像素密度表示屏幕上**每英寸**包含的**物理像素数量**。常用的度量单位是像素每英寸（PPI）或点每英寸（DPI）。高像素密度意味着屏幕上每英寸的物理像素数量较高，图像和文本会显示得更加细腻和清晰。

在移动端开发中，使用@3x、@2x等命名规则的图片是为了适应不同像素密度的设备。不同设备的像素密度可能不同，因此同样大小的图像在不同设备上可能会显示得过小或模糊。为了解决这个问题，开发人员需要提供多个版本的图像资源。

通过命名规则和后缀，例如@3x、@2x，开发人员可以提供不同分辨率的图像资源。这些后缀表示图像资源相对于基准像素密度的缩放比例。例如，@3x表示图像资源相对于基准像素密度需要放大3倍，@2x表示放大2倍。这样，设备可以根据自身的像素密度选择合适的图像资源进行显示，确保图像在不同设备上显示的大小和比例一致。

计算逻辑像素（dp）和物理像素之间的关系可以通过以下公式进行：

逻辑像素 = 物理像素 / 设备像素比

其中，设备像素比表示逻辑像素和物理像素之间的比例关系。

例如，假设有一个设备的物理像素为 1080x1920，设备像素比为 2:1（@2x），我们可以计算逻辑像素如下：

逻辑像素 = 1080 / 2 = 540（宽度）
逻辑像素 = 1920 / 2 = 960（高度）

这意味着在该设备上，逻辑像素的宽度为 540dp，高度为 960dp。

需要注意的是，设备像素比可以根据设备的像素密度和缩放级别进行调整。不同的设备可能具有不同的设备像素比，因此在进行移动端开发时，应该考虑到不同设备的像素密度和适当地调整逻辑像素和物理像素之间的关系。

PPI（Pixels Per Inch）和DPI（Dots Per Inch）是用于描述图像或显示设备分辨率的单位，它们分别表示每英寸的像素数和每英寸的点数。

PPI的计算方法：
PPI = √(水平像素数² + 垂直像素数²) / 屏幕对角线长度

例如，如果一个显示设备的水平像素数是1080，垂直像素数是1920，屏幕对角线长度是5英寸，则PPI计算如下：
PPI = √(1080² + 1920²) / 5 ≈ 440.58 PPI

DPI的计算方法：
DPI = PPI / 缩放比例

缩放比例是指在打印时将图像缩小或放大的比例。例如，如果一个图像的PPI是300，而打印时将其缩小为原尺寸的50%，则DPI计算如下：
DPI = 300 / 0.5 = 600 DPI

需要注意的是，PPI和DPI的计算方法是基于给定的像素数和尺寸，它们并不表示图像的实际质量或清晰度。在实际应用中，PPI和DPI的值可以作为参考，但实际图像质量还受到其他因素的影响，如图像的分辨率、色彩深度、显示设备的技术等。


缩放比是用于描述图像在打印或显示过程中的缩小或放大比例。它可以表示为百分数或小数。

如果要将图像缩小为原尺寸的一部分，缩放比可以计算如下：

缩放比 = 目标尺寸 / 原始尺寸

例如，假设原始图像的尺寸是800像素 x 600像素，而你想将其缩小为原尺寸的一半，则缩放比可以计算如下：

缩放比 = 0.5

同样，如果你想将图像放大到原尺寸的两倍，则缩放比可以计算如下：

缩放比 = 2.0

在打印应用中，缩放比还可以表示为百分比。例如，如果要将图像缩小为原尺寸的30%，则缩放比可以计算如下：

缩放比 = 30% / 100% = 0.3

需要注意的是，缩放比是相对于原尺寸而言的，因此小于1的缩放比表示缩小，大于1的缩放比表示放大。缩放比的计算方法可以根据具体需求和应用场景进行调整，以满足所需的尺寸要求。
