- transition是过渡属性，强调过度，它的实现需要**触发一个事件** (比如鼠标移动上去，焦点，点击等》才执行动画。它类似于flash的补间动画，设置一个开始关键帧，一个结束关键顿。
- animation是动画属性，它的实现**不需要触发事件**，设定好时间之后可以自己执行，且可以循环一个动画。它也类似于flash的补间动画，但是它可以设置多个关键帧 (用@keyframe定义)完成动画


当谈到网页设计和开发时，"transition"（过渡）和 "animation"（动画）是两个常用的术语。它们都是用于改变元素外观和行为的CSS特性。下面详细介绍它们的含义、用法和区别。


**在animation关键帧里可以用transition吗**

**在 CSS 的 `animation` 关键帧中不能直接使用 `transition`，因为它们是两种不同的动画技术。**

`animation` 是通过在关键帧之间设置样式变化来创建复杂的动画效果。您可以在 `@keyframes` 规则中定义关键帧，并在每个关键帧中指定样式的变化。
## Transition（过渡）
[[5. transition]]
[[position的属性有哪些,区别是什么]]
Transition是一种CSS特性，用于在元素状态变化时创建平滑的过渡效果。它可以应用于任何可被渐变的属性，例如颜色、大小、位置、透明度等。通过过渡，元素可以**以渐进的方式从一个状态过渡到另一个状态，而不是突然改变**。
[[transform属性]]
### 用法

通过设置`transition`属性，可以定义元素的过渡效果。下面是`transition`属性的语法：

```css
transition: [property] [duration] [timing-function] [delay];
```

- `property`：要过渡的属性名称，可以是单个属性或多个属性的组合。多个属性之间用逗号分隔。例如：`color`、`background-color`、`width, height`。
- `duration`：过渡的持续时间，以秒或毫秒为单位。例如：`0.5s`、`1000ms`。
- `timing-function`：过渡的时间函数，用于定义过渡的速度变化。常用的值有：`ease`（默认值，缓慢开始，缓慢结束）、`linear`（线性变化）、`ease-in`（缓慢开始）、`ease-out`（缓慢结束）、`ease-in-out`（缓慢开始和结束）等。
- `delay`：过渡开始之前的延迟时间，以秒或毫秒为单位。

### 示例

以下是一个示例，展示了如何通过过渡效果改变元素的背景颜色：

```css
.box {
  background-color: blue;
  transition: background-color 0.5s ease;
}

.box:hover {
  background-color: red;
}
```

在上面的示例中，当鼠标悬停在`.box`元素上时，它的背景颜色将以0.5秒的过渡时间平滑地从蓝色变为红色。

## Animation（动画）

Animation是一种CSS特性，用于创建更复杂、更丰富的动态效果。与过渡不同，动画可以定义多个关键帧（keyframes），每个关键帧指定元素在不同时间点的状态，从而实现更多样化的动画效果。
[[1、animation有什么组成？]]
### 用法

通过设置`animation`属性，可以定义元素的动画效果。下面是`animation`属性的语法：

```css
animation: [animation-name] [duration] [timing-function] [delay] [iteration-count] [direction] [fill-mode];
```

- `animation-name`：动画的名称，可以通过`@keyframes`规则定义。例如：`myAnimation`。
- `duration`：动画的持续时间，以秒或毫秒为单位。例如：`2s`、`2000ms`。
- `timing-function`：动画的时间函数，用于定义动画的速度变化。与过渡的时间函数相同。
- `delay`：动画开始之前的延迟时间，以秒或毫秒为单位。
- `iteration-count`：动画的重复次数。可以是具体次数（例如：`2`），也可以是`infinite`表示无限次循环。
- `direction`：动画的播放方向，可以是`normal`（默认值，正常播放）、`reverse`（反向播放）、`alternate`（交替正向和反向播放）等。
- `fill-mode`：动画结束后的样式状态，可以是`none`（默认值，回到初始状态）、`forwards`（保持动画结束时的状态）、`backwards`（使用动画的第一个关键帧的样式）等。


2. `animation`属性：`animation`属性用于将动画应用于元素。它指定动画的名称、持续时间、延迟、重复次数等属性。下面是一个示例：

```css
.element {
  animation-name: slide-in;
  animation-duration: 2s;
  animation-delay: 1s;
  animation-iteration-count: 3;
  animation-timing-function: ease-in-out;
}
```

在上面的示例中，`.element`是要应用动画的元素。`animation-name`属性指定了动画的名称（在`@keyframes`规则中定义）。`animation-duration`属性指定了动画的持续时间（以秒为单位）。`animation-delay`属性指定了动画的延迟时间（以秒为单位）。`animation-iteration-count`属性指定了动画的重复次数。`animation-timing-function`属性指定了动画的时间函数，用于控制动画的加速度和减速度。

### 示例以下是一个示例，展示了如何使用关键帧（`@keyframes`）和动画（`animation`）创建一个元素的淡入淡出效果：

```css
@keyframes fadeInOut {
  0% {
    opacity: 0;
  }
  50% {
    opacity: 1;
  }
  100% {
    opacity: 0;
  }
}

.box {
  animation: fadeInOut 3s ease-in-out infinite;
}
```

在上面的示例中，`.box`元素将以3秒的持续时间循环播放名为`fadeInOut`的动画。该动画在0%时的透明度为0，50%时的透明度为1，100%时的透明度再次为0，从而实现一个淡入淡出的效果。

### 关键帧的指定方法
在CSS动画中，除了可以使用简便方式的`from`和`to`关键帧来指定动画的起始和结束状态，还可以使用具体的百分比值来定义更多的关键帧。通过在`@keyframes`规则中指定不同百分比的关键帧，可以创建更复杂的动画效果。

以下是一些常用的关键帧指定方式：

#### 使用百分比值

可以通过在`@keyframes`规则中使用百分比值来指定关键帧。这些百分比值表示动画的进程，从0%表示动画的起始状态，到100%表示动画的结束状态。你可以根据需要添加任意数量的关键帧，以控制动画在不同时间点上的样式变化。

```css
@keyframes slide-in {
  0% {
    transform: translateX(-100%);
  }
  50% {
    transform: translateX(0);
  }
  100% {
    transform: translateX(100%);
  }
}
```

在上面的示例中，`slide-in`动画使用了三个关键帧，分别在0%、50%和100%处定义了元素的位置变化。动画将会在起始状态时元素向左移动，然后在中间阶段停止移动，最后在结束状态时元素向右移动。

#### 使用关键帧名称

除了使用百分比值，也可以给关键帧指定名称，并在`@keyframes`规则中引用这些名称。这样可以在动画中重复使用相同的关键帧样式。以下是一个示例：

```css
@keyframes fade {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}

@keyframes slide {
  from {
    transform: translateX(-100%);
  }
  to {
    transform: translateX(0);
  }
}

.element {
  animation-name: fade, slide;
  animation-duration: 1s;
}
```

在上面的示例中，定义了两个关键帧动画：`fade`和`slide`。可以通过在`animation-name`属性中列出这两个关键帧名称，将两个动画应用于同一个元素。元素将会先淡入（opacity从0到1），然后从左侧滑入（translateX从-100%到0）。

通过合理地定义关键帧，你可以创造出各种复杂的动画效果，如旋转、缩放、颜色变化等。

总结一下，CSS动画中的关键帧可以通过百分比值或关键帧名称来指定。通过定义不同时间点上的样式变化，可以创建出丰富多样的动画效果。可以根据需求添加任意数量的关键帧，并使用`animation-name`属性将关键帧应用于元素。

### `animation-timing-function`
`animation-timing-function`是CSS动画属性之一，用于指定动画的时间函数（timing function）。时间函数控制动画在不同时间点上的速度变化，从而影响动画的加速度和减速度。

#### 用法

`animation-timing-function`属性可以接受多个预定义的时间函数值，也可以使用自定义的贝塞尔曲线来定义时间函数。

1. 预定义时间函数：CSS提供了一些预定义的时间函数，可以直接使用。常用的预定义时间函数包括：

- `ease`：默认值，动画在开始和结束时缓慢，中间阶段加速。
- `ease-in`：动画在开始时缓慢加速。
- `ease-out`：动画在结束时缓慢减速。
- `ease-in-out`：动画在开始和结束时缓慢，中间阶段加速减速。

2. 自定义贝塞尔曲线：除了预定义的时间函数，还可以使用自定义的贝塞尔曲线来定义时间函数。贝塞尔曲线是一种数学曲线，通过控制点来定义动画的速度变化。贝塞尔曲线可以通过`cubic-bezier()`函数来定义，该函数接受四个参数，分别表示两个控制点的坐标。

```css
.element {
  animation-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1);
}
```

在上面的示例中，`cubic-bezier(0.25, 0.1, 0.25, 1)`定义了一个自定义的贝塞尔曲线时间函数。通过调整参数值，可以实现不同的速度变化效果。

#### 示例

以下是一个示例，展示了不同时间函数对动画速度的影响：

```css
@keyframes slide-in {
  0% {
    transform: translateX(-100%);
  }
  100% {
    transform: translateX(0);
  }
}

.element {
  animation-name: slide-in;
  animation-duration: 2s;
  animation-timing-function: ease-in-out;
}
```

在上面的示例中，动画使用`slide-in`作为动画名称，并应用于`.element`元素。通过`animation-timing-function`属性将时间函数设置为`ease-in-out`，使得动画在开始和结束时缓慢，中间阶段加速减速。

可以尝试将`animation-timing-function`属性的值改为其他时间函数或自定义贝塞尔曲线，观察动画速度的变化效果。

## 总结

`animation-timing-function`属性用于控制CSS动画的时间函数，影响动画在不同时间点上的速度变化。可以使用预定义时间函数或自定义贝塞尔曲线来定义时间函数。通过调整时间函数，可以改变动画的加速度和减速度，从而实现不同的动画效果。合理选择和使用时间函数可以提升动画的流畅度和视觉效果，增强用户体验。
## 区别

Transition和Animation的主要区别在于以下几点：

1. Transition用于在两个状态之间创建平滑的过渡效果，而Animation可以创建更复杂的动画效果。
1. Transition只需要指定起始状态和结束状态，而Animation可以定义多个关键帧，控制元素在不同时间点的状态。
1. Transition通常用于响应用户交互，例如鼠标悬停、焦点变化等，而Animation更适用于创建自动播放的动画效果。
1. Transition可以应用于任何可被渐变的CSS属性，而Animation可以同时改变多个属性的值。

综上所述，Transition适用于简单的过渡效果，而Animation则适用于更复杂的动画需求。在实际应用中，可以根据具体需求选择使用哪种特性。
