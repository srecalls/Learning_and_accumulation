- white-space：空白符的处理
在 CSS 中，`white-space` 属性用于控制元素中空白字符的处理方式。它可以影响文本内容中的空格、换行符和制表符的显示和处理方式。

`white-space` 属性有多个取值选项，常用的包括：

```ts
`normal`：默认值。连续的空白字符会被合并，并且文本会根据容器的大小自动换行。
"空白字符合并"
"换行符不换行
"根据容器大小换行"

`nowrap`：连续的空白字符会被合并，但文本不会换行，会在一行内显示。
"空白字符合并"
"换行符不换行
"不根据容器大小换行, 在同一行"

`pre`：连续的空白字符会被保留，文本将按照源代码中的空白符进行显示，不会自动换行。
"空白字符保留"
"换行符换行"
"不根据容器大小换行, 在同一行"


`pre-wrap`：连续的空白字符会被保留，文本会根据容器的大小自动换行。
"空白字符保留"
"换行符换行"
"根据容器大小换行"


`pre-line`：连续的空白字符会被合并，文本会根据容器的大小自动换行，但保留换行符。
"空白字符合并"
"换行符换行"
"根据容器大小换行"
```

这些取值选项可以用于不同的情况，以控制文本的换行和空白字符的处理方式。例如，在代码展示或保留原始格式的情况下，可以使用 `pre` 或 `pre-wrap`。而在正常的文本显示和自动换行的情况下，可以使用 `normal` 或 `pre-line`。

以下是一个示例，展示了 `white-space` 属性的使用：

```html
<style>
  .container {
    width: 200px;
    border: 1px solid #ccc;
    white-space: pre-wrap;
  }
</style>

<div class="container">
  This is a long text that will wrap within the container.
</div>
```

在上述示例中，`.container` 类选择器的元素应用了 `white-space: pre-wrap;` 属性。这意味着文本内容会根据容器的宽度自动换行，同时保留源代码中的空白符。


- unicode-bidi：设置文本的方向
**`nicode-bidi`** 属性，和 [`direction`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/direction) 属性，决定如何处理文档中的双书写方向文本（bidirectional text）。比如，如果一块内容同时包含有从左到右书写和从右到左书写的文本，那么用户代理（the user-agent）会使用复杂的 Unicode 算法来决定如何显示文本。`unicode-bidi` 属性会覆盖此算法，允许开发人员控制文本嵌入（text embedding）。

5. **定位属性**：float、clear、position、top、right、bottom、left、min-width、min-height、max-width、max-height、overflow、clip、z-index

下面是关于定位属性的一些解释：

1. `float`：设置元素的浮动方式，让元素脱离文档流并在其容器中浮动。常用值为 `left`（左浮动）和 `right`（右浮动）。
[[什么是浮动]]
2. `clear`：指定元素是否允许浮动元素出现在其旁边。常用值为 `left`、`right`、`both` 和 `none`。

3. `position`：设置元素的定位方式。常用值包括 `static`（默认，按照正常文档流布局）、`relative`（相对定位）、`absolute`（绝对定位）和 `fixed`（固定定位）。

4. `top`、`right`、`bottom`、`left`：与绝对定位（`position: absolute`）和固定定位（`position: fixed`）一起使用，指定元素相对于其包含块的上、右、下、左边缘的距离。

5. `min-width`、`min-height`：指定元素的最小宽度和最小高度。

6. `max-width`、`max-height`：指定元素的最大宽度和最大高度。

`min-width` 和 `max-width` 是用于指定元素的最小宽度和最大宽度的 CSS 属性。

- `min-width` 属性设置元素的最小宽度，即元素的宽度不会小于指定的值。如果内容的宽度大于 `min-width`，则元素会自动扩展以适应内容。如果内容的宽度小于 `min-width`，则元素的宽度将等于 `min-width`。

- `max-width` 属性设置元素的最大宽度，即元素的宽度不会超过指定的值。如果内容的宽度小于或等于 `max-width`，则元素的宽度将等于内容的宽度。如果内容的宽度大于 `max-width`，则元素的宽度将等于 `max-width`，并且内容会被裁剪或换行。

以下是 `min-width` 和 `max-width` 属性的语法示例：

```css
selector {
  min-width: value;
  max-width: value;
}
```

其中 `value` 可以是具体的长度单位（如像素、百分比）或者是关键字（如 `auto`）。

以下是一些示例，展示了 `min-width` 和 `max-width` 属性的使用：

```css
div {
  min-width: 200px;
  max-width: 500px;
}
```

在上述示例中，`div` 元素的最小宽度被设置为 200 像素，最大宽度被设置为 500 像素。这意味着元素的宽度不会小于 200 像素，也不会超过 500 像素。

```css
img {
  min-width: 100%;
  max-width: 400px;
}
```

在上述示例中，`img` 元素的最小宽度被设置为父容器的宽度的百分之百，最大宽度被限制为 400 像素。这样可以确保图像始终至少占满其父容器的宽度，但不会超过 400 像素的宽度。

7. `overflow`：控制元素内容溢出时的处理方式。常用值包括 `visible`（溢出内容可见，默认）、`hidden`（溢出内容隐藏）、`scroll`（显示滚动条）和 `auto`（根据内容自动决定是否显示滚动条）。
[[overflow 溢出显示隐藏]]

6. **生成内容属性**：**content、counter-reset、counter-increment**

CSS 计数器（CSS counters）是一种可以自动生成序号或标记的机制，用于在网页中创建有序列表、章节编号、注脚等。计数器允许您为元素分配一个自动递增的值，并将其用于生成内容或样式。

使用 CSS 计数器，您可以定义一个或多个计数器，每个计数器都具有一个名称和一个初始值。然后，您可以在样式规则中使用计数器相关的属性来增加或重置计数器的值，并将计数器的值应用于元素的内容或样式。

以下是 CSS 计数器的基本步骤：

1. 定义计数器：使用 `counter-reset` 属性定义一个计数器并设置其初始值。例如：`counter-reset: my-counter 1;` 定义了名为 `my-counter` 的计数器，初始值为 1。

2. 递增计数器：使用 `counter-increment` 属性递增计数器的值。例如：`counter-increment: my-counter;` 将 `my-counter` 计数器的值递增 1。

3. 应用计数器：使用 `content` 属性在伪元素（如 `::before` 或 `::after`）中应用计数器的值。例如：`content: counter(my-counter);` 将 `my-counter` 计数器的值作为内容插入到元素中。

通过这些步骤，您可以实现自动生成序号、标记和注脚等效果。您可以使用计数器来创建有序列表、章节标题的编号、图表标签等，而无需手动编写每个项目的编号或标记。

请注意，计数器只在其作用域内有效，并且通常与伪元素一起使用。它们提供了一种强大的方法来生成自动化的内容，并为网页带来更多的灵活性和可维护性。
以下是关于 CSS 中的 `content`、`counter-reset` 和 `counter-increment` 属性的解释：

1. `content`：`content` 属性用于在 CSS 伪元素（如 `::before` 和 `::after`）中插入内容。它可以接受不同类型的值，包括文本字符串、特殊字符和引用其他属性值。例如，您可以使用 `content` 将一些文本或图标添加到元素的前面或后面。

示例：
```css
p::before {
  content: "前缀：";
}

p::after {
  content: url(icon.png);
}
```
在上述示例中，`::before` 伪元素在每个 `p` 元素前添加了文本 "前缀："，而 `::after` 伪元素在每个 `p` 元素后添加了一个图标。

2. `counter-reset`：`counter-reset` 属性用于重置 CSS 计数器的值。计数器是一种自动生成的数字或字符串，您可以在文档中的特定元素上使用它。通过 `counter-reset`，您可以将计数器重置为指定的值或初始值。

示例：
```css
ol {
  counter-reset: my-counter;
}

li::before {
  content: counter(my-counter) ". ";
  counter-increment: my-counter;
}
```
在上述示例中，`counter-reset` 将 `my-counter` 计数器重置为初始值（默认为 0）。然后，通过 `counter-increment`，每个 `li` 元素的 `my-counter` 计数器值递增，并将其作为 `::before` 伪元素的内容显示。

3. `counter-increment`：`counter-increment` 属性用于递增 CSS 计数器的值。通过 `counter-increment`，您可以将计数器递增一个特定的步长。

示例：
```css
p {
  counter-increment: my-counter 2;
}

p::before {
  content: counter(my-counter) ". ";
}
```
在上述示例中，`counter-increment` 将 `my-counter` 计数器的值递增 2。然后，`::before` 伪元素在每个 `p` 元素前显示递增后的计数器值。

这些属性可用于添加内容、创建自动生成的标记或序号，并实现更丰富的样式和布局效果。

8. **页面样式属性**：size、page-break-before、page-break-after
`page-break-before` 和 `page-break-after` 是 CSS 属性，用于控制在打印或分页时元素的分页行为。

- `page-break-before` 属性用于指定在元素之前是否插入分页符。
- `page-break-after` 属性用于指定在元素之后是否插入分页符。

这些属性可以应用于各种元素，如 `<div>`、`<p>`、`<table>` 等，以控制它们在分页时的表现。

这两个属性可以接受以下值：

- `auto`：表示根据浏览器的默认设置自动插入分页符。
- `always`：表示始终在元素之前（或之后）插入分页符。
- `avoid`：表示尽量避免在元素之前（或之后）插入分页符。
- `left`：表示在元素之前（或之后）插入分页符，并将内容放置在新页面的左侧。
- `right`：表示在元素之前（或之后）插入分页符，并将内容放置在新页面的右侧。

示例：
```css
.page-break-before {
  page-break-before: always;
}

.page-break-after {
  page-break-after: avoid;
}
```

上述示例中，`.page-break-before` 类将在元素之前始终插入分页符，而 `.page-break-after` 类将尽量避免在元素之后插入分页符。

这些属性主要用于打印样式表或将内容分页显示的情况，以确保在打印时或在分页浏览器中正确控制元素的分页行为。

4. **列表布局属性**
- list-style：列表风格，包括list-style-type、list-style-image等


在 CSS 中，`list-style` 属性用于设置列表（`<ul>` 和 `<ol>`）的样式，包括列表项符号、编号和位置。

`list-style` 属性是一个简写属性，可以同时设置以下三个子属性：

1. `list-style-type`：用于设置列表项的符号类型或编号样式。
2. `list-style-position`：用于设置列表项符号或编号的位置。
3. `list-style-image`：用于设置自定义图片作为列表项符号。

以下是 `list-style` 属性的语法和常用值：

```css
list-style: list-style-type list-style-position list-style-image;
```

- `list-style-type` 可接受的常用值包括：
  - `none`：无符号或编号。
  - `disc`：实心圆点（默认值）。
  - `circle`：空心圆圈。
  - `square`：实心方块。
  - `decimal`：十进制数字编号。
  - `decimal-leading-zero`：前导零的十进制数字编号。
  - `lower-roman`：小写罗马数字编号。
  - `upper-roman`：大写罗马数字编号。
  - `lower-alpha`：小写字母编号。
  - `upper-alpha`：大写字母编号。

- `list-style-position` 可接受的常用值包括：
  - `inside`：列表项符号或编号位于列表项内容内部。
  - `outside`：列表项符号或编号位于列表项内容外部（默认值）。

- `list-style-image` 可接受的值包括：
  - `url('image.png')`：指定图片的路径作为列表项符号。
以下是一个示例，展示了 `list-style` 属性的使用：

```html
<style>
  ul {
    list-style: square inside;
  }
</style>

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```

在上述示例中，`<ul>` 元素的 `list-style` 属性设置为 `square inside`，表示列表项使用实心方块作为符号，并位于列表项内容内部。

通过使用 `list-style` 属性，您可以自定义列表的样式，包括符号类型、位置和自定义图片。这样可以根据设计需求和风格来调整列表的外观，以使其更符合您的布局和品牌要求。
