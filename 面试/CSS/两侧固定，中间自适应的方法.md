需要注意的是，如果左右两侧的 div 元素高度不同，可能会出现布局错乱的情况。为了避免这种情况，可以在左右两侧的 div 元素中添加一个包含元素，用来清除浮动，或者使用 flexbox 或 grid 布局等其他布局方式。
左右浮动两块div元素，脱离标准流，中间那块元素就会上去，跟他们一行，利用margin留出左右宽度.

### 圣杯布局
圣杯布局的实现方式是将左右两列设置为浮动，并使用负边距将它们拉到中间列的两侧，中间列使用 margin-left 和 margin-right 为左右列留出空间。同时，为了避免左侧列和右侧列覆盖中间列的内容，还需要使用相对定位和 z-index 属性对它们进行层叠处理。圣杯布局的名称来源于其布局结构类似于一个圣杯。

### 双飞翼布局
双飞翼布局的实现方式与圣杯布局类似，也是将左右两列设置为浮动，并使用负边距将它们拉到中间列的两侧，中间列使用 margin-left 和 margin-right 为左右列留出空间。不同之处在于，双飞翼布局使用一个嵌套 div 来包含中间列的内容，并将其设置为负边距，以避免左右列覆盖中间列的内容。双飞翼布局的名称来源于其布局结构类似于两个飞翼。

无论是圣杯布局还是双飞翼布局，都是比较经典的三栏布局方式，它们的主要优点是可以实现左右两栏固定宽度，中间栏自适应宽度的效果，同时也比较容易实现。不过需要注意的是，由于使用了负边距和浮动等技术，这些布局方式可能会对文档的结构和样式产生一定的影响，使用时需要仔细调试和测试。

## 为什么圣杯布局和双飞翼布局要加float

圣杯布局和双飞翼布局都是基于浮动和负边距的三栏布局方式，主要是为了实现左右两栏固定宽度，中间栏自适应宽度的效果，其中使用 float 属性是为了将左右两列设置为浮动，使它们可以脱离文档流并向左或右浮动。

使用浮动的好处是可以在不影响文档流的情况下实现元素的定位和布局，从而实现左右两列固定宽度，中间列自适应宽度的效果。同时，浮动元素可以自动调整位置，以适应浏览器窗口大小的变化，从而提高页面的可适应性和可用性。

另外，使用 float 属性还可以避免元素之间产生不必要的空隙，从而实现更紧凑的布局。不过需要注意的是，在使用 float 属性时，需要注意清除浮动，以避免浮动元素对后面的内容产生影响。

因此，圣杯布局和双飞翼布局要加 float 主要是为了实现布局效果和提高页面的可适应性和可用性。



### 1、相同之处

（1）布局类似，都是实现特定需求的三列布局。

（2）都使用了`float`浮动向左脱离文档流,让左中右三列浮动，通过父外边距形成三列布局。

### 2、不同之处

**（1）实现方法的不同：**

**圣杯布局**是通过`float`搭建布局+`margin`使三列布局到一行上+`relative`相对定位调整位置。

**双飞翼布局**是通过`float`+`margin`，**没有使用相对定位**。

**（2）怎么处理两列的位置：**

**圣杯布局**是给外部容器加`padding`，通过相对定位把两边定位出来。

**双飞翼布局**是靠在中间这层外面套一层`div`加`padding`将内容挤出来中间。
