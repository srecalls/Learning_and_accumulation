浏览器渲染主要有以下步骤
- 首先解析收到的文档，根据文档定义构建一棵 DOM 树，DOM 树是由 DOM 元素及属性节点组成的
- 然后对 CSS 进行解析，生成 CSSOM 规则树,
- 根据 DOM 树和 CSSOM 规则树构建渲染树。渲染树的节点被称为渲染对象，渲染对象是一个包含有颜色和大小等属性的矩形，渲染对象和 DOM 元素相对应，但这种对应关系不是一对一的，不可见的 DOM 元素不会被插入渲染树。还有一些 DOM元素对应几个可见对象，它们一般是一些具有复杂结构的元素，无法用一个矩形来描述。
- 当渲染对象被创建并添加到树中，它们并没有位置和大小，所以当浏览器生成渲染树以后，就会根据渲染树来进行布局 (也可以叫做回流)。这一阶段浏览器要做的事情是要弄清楚各个节点在页面中的确切位置和大小。通常这一行为也被称为“自动重排”
- 布局阶段结束后是绘制阶段，遍历渲染树并调用渲染对象的 paint 方法将它们的内容显示在屏幕上，绘制使用 UI 基础组件。

假设我们有这样一个简单的 HTML 和 CSS 文件：

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    body {
      background-color: #f0f0f0;
    }
    h1 {
      color: #333;
    }
  </style>
</head>
<body>
  <h1>Hello, World!</h1>
</body>
</html>
```

1. **构建 DOM 树**：浏览器解析 HTML 文件，创建 DOM 树。对于上述例子，DOM 树可能看起来像这样：

    ```
    html
    ├── head
    │   └── style
    └── body
        └── h1
    ```

2. **解析 CSS，生成 CSSOM 规则树**：浏览器解析 CSS 规则，并将它们与相对应的 DOM 节点匹配。例如，`body` 节点有一个 CSS 规则，它设定了背景颜色为 `#f0f0f0`；`h1` 节点有一个 CSS 规则，它设定了颜色为 `#333`。

3. **构建渲染树**：浏览器结合 DOM 树和 CSSOM 规则树，创建渲染树。渲染树只包含需要显示的节点。例如，上面的 `head` 节点和 `style` 节点不会出现在渲染树中，因为它们不会显示在页面上。在这个例子中，渲染树可能看起来像这样：

    ```
    html
    └── body (background-color: #f0f0f0)
        └── h1 (color: #333)
    ```

4. **布局（回流）**：浏览器计算渲染树中每个节点的位置和大小。这通常涉及到计算每个元素的宽度、高度、上下左右边距等属性。

5. **绘制**：浏览器遍历渲染树，使用每个节点的 `paint` 方法将节点绘制到屏幕上。例如，它会绘制一个具有特定背景颜色和大小的 `body` 元素，然后在其上绘制一个具有特定颜色和文本内容的 `h1` 元素。

以上就是浏览器渲染页面的基本步骤。值得注意的是，这是一个简化的描述，实际的浏览器渲染过程可能会更复杂。例如，浏览器可能会利用层（layer）和合成（compositing）技术来优化渲染性能。
