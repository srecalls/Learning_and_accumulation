## 浏览器缓存的全过程:
- 浏览器第一次加载资源，服务器返回 200，浏览器从服务器下载资源文件，并缓存资源文件与 responseheader，以供下次加载时对比使用:
- 下一次加载资源时，由于强制缓存优先级较高，先比较当前时间与上一次返回 200 时的时间差，如果没有超过` cache-control `设置的` max-age`，则没有过期，并命中强缓存，直接从本地读取资源。如果浏览器不支持`HTTP1.1`，则使用` expires `头判断是否过期;
- 如果资源已过期，则表明强制缓存没有被命中，则开始协商缓存，向服务器发送带有` If-None-Match `和` If-Modified-Since `的请求:
- 服务器收到请求后，优先根据` Etag `的值判断被请求的文件有没有做修改，`Etag `值一致则没有修改，命中协商缓存，返回 304;如果不一致则有改动，直接返回新的资源文件带上新的` Etag `值并返回 200
- 如果服务器收到的请求没有` Etag `值，则将` If-Modified-Since `和被请求文件的最后修改时间做比对，一致则命中协商缓存，返回 304;不一致则返回新的 last-modified 和文件并返回 200:

很多网站的资源后面都加了版本号，这样做的目的是: 每次升级了JS 或 CSS 文件后，为了防止浏览器进行缓存，强制改变版本号，客户端浏览器就会重新下载新的JS 或 CSS 文件，以保证用户能够及时获得网站的最新更新。

## 强缓存与协商缓存例子

当客户端请求一个资源时，服务器可以通过设置响应头来指定该资源的缓存策略，包括协商缓存和强缓存。下面是协商缓存和强缓存的请求头和响应头的内容：

### 强缓存

强缓存是指在客户端本地缓存中保存一个资源的副本，并在一定时间内不向服务器发送请求，直接从本地缓存中读取资源。强缓存可以通过设置响应头中的 `Cache-Control` 和 `Expires` 字段来实现。

下面是强缓存的请求头和响应头的内容：

**请求头**

```http
GET /index.html HTTP/1.1
Host: www.example.com
```

**响应头**

```http
HTTP/1.1 200 OK
Date: Sun, 13 Jun 2023 06:00:00 GMT
Cache-Control: max-age=3600
Expires: Sun, 13 Jun 2023 07:00:00 GMT
Content-Type: text/html; charset=UTF-8
Content-Length: 12345
```

在上面的响应头中，`Cache-Control` 字段指定了缓存策略的参数，`max-age=3600` 表示该资源可以被缓存的最长时间为 3600 秒（1小时）。`Expires` 字段也指定了缓存的时间，表示该资源在 2023 年 6 月 13 日 7 点之前都可以被缓存。客户端在下一次请求该资源时，会先检查缓存是否过期，如果没有过期，就直接从本地缓存中读取资源，否则就向服务器发送请求。

### 协商缓存

协商缓存是指在客户端本地缓存中保存一个资源的副本，并在一定时间内向服务器发送请求进行验证，如果资源没有发生变化，则直接从本地缓存中读取资源。协商缓存可以通过设置响应头中的 `Last-Modified` 和 `ETag` 字段来实现。

下面是协商缓存的请求头和响应头的内容：

**第一次请求**

**请求头**

```http
GET /index.html HTTP/1.1
Host: www.example.com
```

**响应头**

```http
HTTP/1.1 200 OK
Date: Sun, 13 Jun 2023 06:00:00 GMT
Last-Modified: Sun, 13 Jun 2023 05:00:00 GMT
ETag: "12345"
Content-Type: text/html; charset=UTF-8
Content-Length: 12345
```

在上面的响应头中，`Last-Modified` 字段指定了该资源的最后修改时间，`ETag` 字段指定了该资源的标识符。客户端在下一次请求该资源时，会向服务器发送一个带有 `If-Modified-Since` 和 `If-None-Match` 字段的请求头，服务器会根据这些字段判断资源是否发生了变化。

**第二次请求**

**请求头**

```http
GET /index.html HTTP/1.1
Host: www.example.com
If-Modified-Since: Sun, 13 Jun 2023 05:00:00 GMT
If-None-Match: "12345"
```

**响应头**

```http
HTTP/1.1 304 Not Modified
Date: Sun, 13 Jun 2023 06:30:00 GMT
```

在上面的响应头中，服务器返回了一个 `304 Not Modified` 的响应状态码，表示资源没有发生变化。客户端会直接从本地缓存中读取资源，而不是从服务器重新下载资源。如果资源发生了变化，服务器会返回一个新的资源，客户端会将新的资源保存到本地缓存中。
