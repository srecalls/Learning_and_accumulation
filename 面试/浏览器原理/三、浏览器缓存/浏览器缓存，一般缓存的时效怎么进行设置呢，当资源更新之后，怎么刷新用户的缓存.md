## 时效怎么设置
浏览器缓存的时效性可以通过设置 HTTP 响应头中的缓存控制头字段来进行配置。以下是两个常用的缓存控制头字段：

1. Cache-Control: 通过设置 `max-age` 指令来定义资源在缓存中的最长存储时间（以秒为单位）。例如，`Cache-Control: max-age=3600` 表示资源在缓存中最长存储 1 小时。还可以使用其他指令，如 **`no-cache`**（**每次都从服务器请求资源并验证缓存**）和 **`no-store`**（**不缓存资源**）等。
    
2. Expires: 通过设置一个具体的过期日期/时间来定义资源的过期时间。例如，`Expires: Fri, 31 Dec 2023 23:59:59 GMT` 表示资源将在指定时间后过期。

## 刷新缓存
当资源发生更新并且你想刷新用户的缓存时，可以使用以下方法：

### 1. 文件名更改：

   假设你有一个名为 `styles.css` 的 CSS 文件。当你对该文件进行更新时，可以通过更改文件名来强制浏览器重新下载和缓存更新后的文件。

   原始 HTML：
   ```html
   <link rel="stylesheet" href="styles.css">
   ```

   更新后的 HTML：
   ```html
   <link rel="stylesheet" href="styles-v2.css">
   ```

   通过将文件名从 `styles.css` 更改为 `styles-v2.css`，浏览器将认为这是一个新的文件，并重新下载和缓存它。

1. 文件名更改：
    
    - 在更新资源的同时，确保将 HTML 或其他文件中引用该资源的地方进行相应的更改，以匹配新的文件名。这样浏览器就能够找到并获取到更新后的资源。
    - 确保服务器上存在新的文件名对应的资源文件。如果服务器上没有新的文件名对应的资源文件，浏览器将无法获取到该资源。

### 2. 版本号参数：

   另一种方法是在资源的 URL 中添加一个版本号参数，通过更改版本号的值来刷新缓存。

   原始 HTML：
   ```html
   <link rel="stylesheet" href="styles.css?v=1">
   ```

   更新后的 HTML：
   ```html
   <link rel="stylesheet" href="styles.css?v=2">
   ```

   通过将版本号参数 `v` 的值从 `1` 更改为 `2`，浏览器会将其视为新的 URL，并重新下载和缓存资源。

2. 版本号参数：
    
    - 在更新资源时，修改版本号参数的值。确保 HTML 或其他文件中引用该资源的地方的版本号参数与新的值匹配。
    - 确保服务器能够处理带有版本号参数的请求，并正确地返回对应的资源文件。服务器应该忽略版本号参数，只返回与请求的资源文件名相匹配的文件。

### 3. 更新缓存控制头字段：

   在服务器端，可以通过设置适当的缓存控制头字段来通知浏览器刷新缓存。以下是一个示例，将 `Cache-Control` 头字段设置为 0，表示资源立即过期，浏览器需要重新下载和缓存。

   ```javascript
   // 通过 Express 框架设置缓存控制头字段
   app.get('/styles.css', function(req, res) {
     res.setHeader('Cache-Control', 'max-age=0');
     // 其他响应设置和发送文件的代码
   });
   ```

   通过在服务器端设置适当的响应头字段，可以控制浏览器对资源的缓存行为。

需要注意的是，无论使用哪种方法，都需要确保前端和后端开发人员之间的协作和沟通，以便正确更新资源的标识（文件名或版本号参数）或设置缓存控制头字段。
