需要在路由配置中添加一个字段，它是用于判断路由是否需要拦截的
```js
{
	name: ' index' ,
	path: ' /index' ,
	component: Index,
	meta:{
		requirtAuth: true
	}
}

router.beforeEach((to，from, next) => {
	if(to.meta.requirtAuth){
		if( store.status.token ){

		}
	}
})
```

# 页面登录后就会有token吗？
一般来说，在用户注册后并不会立即获得token。通常情况下，用户需要在注册后再次进行登录操作，系统才会生成并返回一个token给用户。

在用户登录成功后，系统会验证用户的身份并生成一个token，这个token会被保存在客户端（例如浏览器、移动应用）中，并在后续的请求中携带该token。服务端会在每个请求中验证token的合法性，并根据token中包含的用户信息来判断该请求是否合法。

需要注意的是，为了保证用户的安全性，token通常具有一定的有效期限制，过期后需要用户重新登录获取新的token。同时，为了防止token被恶意获取或截获，系统通常会对token进行加密或签名等处理，以确保token的安全性。
