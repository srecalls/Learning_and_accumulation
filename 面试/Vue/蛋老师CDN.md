# 分发流程
## 静态内容
![[Pasted image 20230524111946.png]]
首先CDN是肯定没有网站的源内容，因此源服务器就会把静态内容提前备份给CDN，也叫push，这样在世界各地用户需要访问网页的时，
就近的CDN服务器就会把静态内容提供给用户

![[Pasted image 20230524112121.png]]

如果源服务器没有把静态内容提前备份给CDN，那当用户访问网页的时候，CDN就得去问源服务器索取相应的静态内容，也叫pull，源服务器还可以让CDN进行备份，CDN得到内容以后再提供给用户，因为有了备份，其它同时做出请求的用户也可以马上拿到内容了

## 安全性和可靠性
如果被攻击。
