虚拟DOM的解析过程:
- 首先对**将要插入到文档中的 DOM 树结构进行分析，使用` js `对象将其表示出来**，比如一个元素对象，包合` lagName `、` prop ` 和 `Children` 这些属性。然后**将这个js 对象树给保存下来**，**最后再将 DOM 片段插入到文档**
- 当页面的状态发生改变，需要对页面的 `DOM` 的结构进行调整的时候，首先根据变更的状态，重新构建起棵` 对象树 `，然后**将这棵新的对象树和旧的对象树进行比较**，记录下两棵树的的差异。
- 最后将记录的**有差异**的地方应用到真正的 `DOM 树`中去，这样视图就更新了。


**真实DOM**
```js
<div class="container">?
	<p class="item">思学堂</p>
	<strong class="item">课程很精彩</strong>
</div>
```


**虚拟DOM（JS对象）**
```js
let Vnode = {
	tagName = 'div',
	props: {
		'class': 'container',
	}
	children: [
		{
			tagName: 'p',
			props: {
				'class': 'item',
			},
			text: '惠学堂'
		},
		{
			tagName: 'strong',
			props: {
				'class': 'item',
			},
			text: '课程很精彩'
		}
	]
}
```
