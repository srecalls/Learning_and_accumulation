	$route 是“路由信息对象”，包括 path，params，hash，query，fullPath，matched，name 等路由信息参数

	$router 是“路由实例”对象包括了路由的跳转方法，钩子函数等

在Vue.js中，`$route`和`$router`是两个与路由相关的对象，用于处理路由导航和获取当前路由信息。它们之间的区别如下：

## 1. `$route`对象：
   - `$route`对象代表当前活动路由的状态，包含当前路由的信息，例如路径、参数、查询参数、哈希等。
   - 它是一个只读对象，用于获取当前路由的信息。

示例：

假设有以下路由配置：

```javascript
const routes = [
  { path: '/', component: Home },
  { path: '/about', component: About },
  { path: '/contact', component: Contact }
];
```

在组件中，可以通过访问`$route`对象来获取当前路由的信息：

```javascript
export default {
  mounted() {
    console.log(this.$route.path); // 输出当前路由的路径，例如 '/about'
    console.log(this.$route.params); // 输出当前路由的参数对象
    console.log(this.$route.query); // 输出当前路由的查询参数对象
    console.log(this.$route.hash); // 输出当前路由的哈希值
  }
}
```

## 2. `$router`对象：
   - `$router`对象是路由器实例，用于进行路由导航操作，例如跳转到其他路由、前进、后退等。
   - 它提供了一组方法用于操作路由，例如`push`、`replace`、`go`等。

示例：

在组件中，可以通过访问`$router`对象来进行路由导航操作：

```javascript
export default {
  methods: {
    goToAboutPage() {
      this.$router.push('/about'); // 导航到 '/about' 路由
    },
    goBack() {
      this.$router.go(-1); // 后退一步
    }
  }
}
```

在上面的示例中，`goToAboutPage`方法使用`$router.push()`方法将用户导航到`/about`路由，而`goBack`方法使用`$router.go()`方法后退一步。

总结：
- `$route`用于获取当前路由的信息，是一个只读对象。
- `$router`用于进行路由导航操作，提供了一组方法来操作路由。
