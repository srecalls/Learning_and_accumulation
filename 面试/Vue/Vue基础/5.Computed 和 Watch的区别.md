#### 为什么
在Vue.js中，计算属性是一个基于它们所依赖的响应式数据进行缓存的属性。当响应式数据发生变化时，计算属性会重新计算，并返回新的值。这个过程是同步的，也就是说，计算属性会立即返回计算结果。

然而，异步操作可能需要一定的时间来完成，如果在计算属性中包含异步操作，那么计算属性就无法立即返回计算结果。这也就意味着，当响应式数据发生变化时，计算属性可能并没有完成计算，从而无法触发监听器。

```js

    return fetchData(this.data);

}
```

当`data`发生变化时，计算属性会重新计算，但是由于`fetchData`是异步操作，计算属性并不能立即返回计算结果。这就导致了计算属性的值无法及时更新，从而无法触发监听器。

## 总结:
	- computed 计算属性:依赖其它属性值，并且 computed 的值有缓存，只有它依赖的属性值发生改变，下一次获取 computed 的值时才会重新计算 computed 的值。
	- watch 侦听器: 更多的是观察的作用，无缓存性，类似于某些数据的监听回调，每当监听的数据变化时都会执行回调进行后续操作。

## 运用场景:
	- 当需要进行数值计算,并且依赖于其它数据时，应该使用 computed，因可以利用 computed 的缓存特性，避免每次获取值时都要重新计算。
	- 当需要在数据变化时执行异步或开销较大的操作时，应该使用 watch，用 watch 选项允许执行异步操作(访问一个 API)，限制执行该操作的频率，并在得到最终结果前，设置中间状态。这些都是计算属性无法做到的
