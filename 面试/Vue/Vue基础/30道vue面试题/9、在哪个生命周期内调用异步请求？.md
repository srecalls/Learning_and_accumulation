可以在钩子函数 created、beforeMount、mounted 中进行调用，因为在这三个钩子函数中，data 已经创建，可以将服务端端返回的数据进行赋值。但是本人推荐在 created 钩子函数中调用异步请求，因为在 created 钩子函数中调用异步请求有以下优点：

- 能更快获取到服务端数据，减少页面 loading 时间；
- ssr 不支持 beforeMount 、mounted 钩子函数，所以放在 created 中有助于一致性；

## 什么是SSR
同时在 SSR（服务器端渲染）场景下，`beforeMount` 和 `mounted` 钩子函数是不会执行的，因此在 `created` 钩子函数中进行异步请求有助于保持一致性。

另外，SSR 是指服务器端渲染（Server-Side Rendering），是指将 Vue 组件在服务端渲染成 HTML 字符串，并将其直接返回给浏览器，这样可提升页面的首屏加载速度和 SEO（搜索引擎优化）效果。通俗地说，如果我们使用 SSR，用户在访问我们的网站时，首先会看到服务器返回的已经渲染好的 HTML 文档，而不是空白的文档或者需要等待 JavaScript 加载和执行的文档。

在 Vue.js 中，我们可以使用 SSR 技术来进行服务器端渲染，这需要使用一些 SSR 框架或插件，例如 Nuxt.js、Vue-SSR 等。使用 SSR 技术需要注意的是，因为 Vue 组件需要在服务端和客户端都能够运行，所以需要遵循一些 SSR 的规范和限制，例如不能在组件中直接操作 DOM，不能在组件中使用一些客户端特有的 API 等。
