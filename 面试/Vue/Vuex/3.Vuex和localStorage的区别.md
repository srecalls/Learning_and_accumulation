## (1) 最重要的区别
- vuex存储在内存中
- localstorage 则以文件的方式存储在本地，只能存储字符串类型的数据，存储对象需要JSON的stringify和parse方法进行处理。
- 读取内存比读取硬盘速度要快

## (2) 应用场景
- Vuex 是一个专为 Vue.js 应用程序开发的状态管理模式。它采用集中式存储管理应用的所有组件的状态，并以相应的规则保证状态以一种可预测的方式发生变化。vuex用于组件之间的传值。
- localstorage是本地存储，是将数据存储到浏览器的方法，一般是在跨页面传递数据时
- 使用Vuex能做到数据的响应式，localstorage不能

## (3) 永久性
刷新页面时vuex存储的值会丢失，localstorage不会。

**注意:**
对于不变的数据确实可以用localstorage可以代替vuex，但是当两个组件共用一个数据源(对象或数组)时，如果其中一个组件改变了该数据源，希望另一个组件响应该变化时，localstorage无法做到，原因就是区别'1'



#### JSON字符串和普通字符串的区别
		JSON 字符串与普通字符串最大的区别在于 JSON 字符串需要使用双引号来表示字符串类型的值，而普通字符串不需要。
	

#### 内存和硬盘
刷新页面会导致内存中的数据丢失，因为内存中的数据是临时存储的，它只在当前的会话中有效，一旦会话结束或者刷新页面，内存中的数据就会被清空。而硬盘中的数据则可以长期保存，即使关闭程序或者关机，硬盘中的数据仍然可以被保留下来。

在 Web 应用程序中，浏览器通常会将页面中的数据存储在内存中，以便快速访问和更新。当用户刷新页面时，浏览器会重新加载页面，并清空之前存储在内存中的数据。这就是为什么刷新页面会导致内存中的数据丢失的原因。

#### 数据的读取
数据读取通常会先从缓存开始，然后是内存，最后才是硬盘。这是因为缓存的读写速度非常快，而且可以直接访问，因此如果数据已经存在于缓存中，程序就可以直接从缓存中读取数据，而无需访问内存和硬盘。这样可以大大提高数据访问速度和系统的性能。

当数据不在缓存中时，程序就会访问内存。内存的读写速度相对较慢，但是仍然比硬盘快得多。如果数据也不在内存中，程序就会从硬盘中读取数据，并将数据加载到内存中，然后再进行操作。这个过程需要花费相对较长的时间，因此尽可能地减少对硬盘的访问次数，可以有效地提高系统的性能和效率。

需要注意的是，缓存和内存通常都是有限的，因此在实际应用中需要注意数据的大小和访问频率，以避免缓存和内存的溢出和频繁访问硬盘，从而影响系统的性能和效率。
