无感刷新token，本质是优化用户体验
token过期后用户不用跳转到登录页面重新登录，而是token失效时对token进行一个拦截，同时发生刷新token的请求，获取到最新的token进行一个覆盖。



好的，下面是一个简单的实现：

假设我们有一个Web应用，需要使用JWT进行认证，并且需要实现无感刷新token的功能。具体流程如下：

1. 用户访问Web应用，并进行身份认证。如果认证成功，则应用服务器生成一个JWT，并将其发送回客户端。

2. 客户端将JWT保存在本地，通常是在浏览器的本地存储或者cookie中。

3. 当客户端发送HTTP请求时，检查本地存储中的JWT是否过期。如果JWT未过期，则将其添加到HTTP请求头的Authorization字段的值中，并发送请求给服务器。

4. 如果JWT已过期，则客户端将发送刷新token的请求。这个请求包含过期的JWT和一个刷新token。刷新token是一个长期有效的凭证，用于获取新的JWT。

5. 应用服务器接收到刷新token的请求后，验证刷新token的有效性。如果刷新token有效，则生成一个新的JWT，并将其发送回客户端。

6. 客户端接收到新的JWT后，将其覆盖掉本地存储中的旧JWT，并将新的JWT添加到HTTP请求头的Authorization字段的值中，并重新发送原始请求。

7. 应用服务器接收到带有新JWT的请求后，进行JWT验证，并执行相应的操作。

// 检查JWT是否过期的函数
function isTokenExpired(token) {
  const decoded = jwt_decode(token);
  const now = Date.now() / 1000;
  return decoded.exp < now;
}

// 发送HTTP请求的函数，自动添加Authorization头部
async function request(url, options) {
  const token = localStorage.getItem('jwt');
  if (token && !isTokenExpired(token)) {
    options.headers = Object.assign({}, options.headers, {
      Authorization: `Bearer ${token}`
    });
  }
  const response = await fetch(url, options);
  if (response.status === 401 && token && !isTokenExpired(token)) {
    // 如果JWT已过期，则发送刷新token的请求
    const refreshToken = localStorage.getItem('refreshToken');
    const newToken = await refreshJwt(token, refreshToken);
    if (newToken) {
      localStorage.setItem('jwt', newToken);
      options.headers.Authorization = `Bearer ${newToken}`;
      return request(url, options);
    }
  } else {
    return response;
  }
}

// 发送刷新token的请求，并获取新的JWT的函数
async function refreshJwt(token, refreshToken) {
  const response = await fetch('/refresh', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      token,
      refreshToken
    })
  });
  if (response.ok) {
    const data = await response.json();
    return data.jwt;
  } else {
    return null;
  }
}
