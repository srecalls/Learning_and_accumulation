```js
var a = {}
b = { key: 'b' };
c = { key: 'c' };
a[b] = 123
a[c] = 456
console.log(a[b])
```

求输出的是什么

做这道题前先看看
```js
var a = {}
var b = 'abc'
a[b] = 123 // 相当于a.abc
console.log(a.abc) // 输出123
```

在看看原题，
对象可以作为对象的属性名吗？

在js里，对象的属性名类型只能有两种
![[属性名的类型.png]]

如果对象的属性名类型不为这两种，就自动转换为字符串

这里有问题：数组不是对象吗，数组的下标不是数字吗，也不是字符串也不是symbol
不是因为数组特殊，是数组的下标也会被转换成字符串

比如
```js
var arr = []
arr[1] = 1
arr['1'] = 3
console.log(arr[1]) // 3
```

那
```js
b = { key: 'b' };
c = { key: 'c' };
```
如何被转换成字符串呢
调用对象的toString()方法
![[属性名的类型-1.png]]
![[属性名的类型-2.png]]


所以
```js
var a = {}
b = { key: 'b' };
c = { key: 'c' };
a[b] = 123
a[c] = 456
console.log(a[b])
```
相当于

```js
var a = {}
b = { key: 'b' };
c = { key: 'c' };
a['[object Object]'] = 123
a['[object Object]'] = 456
console.log(a['[object Object]'])
```

最后输出456
