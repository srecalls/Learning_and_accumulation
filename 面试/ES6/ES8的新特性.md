ES8（也称为 ECMAScript 2017）是 JavaScript 语言的一个版本，于 2017 年发布。ES8 引入了一些新的语言特性和 API，下面是其中的一些：

1. `async/await`：这是一种用于处理异步操作的语法糖，可以使异步操作的代码看起来更像同步代码，使得程序的可读性和可维护性更好。
    
2. `Object.values()` 和 `Object.entries()`：这两个方法可以用于获取对象的属性值和键值对，方便对对象进行遍历和操作。
    
3. 字符串填充方法：ES8 引入了 `padStart()` 和 `padEnd()` 方法，可以用于在字符串的开头或结尾填充一定数量的字符，使字符串达到指定长度。
    
4. `Object.getOwnPropertyDescriptors()`：这个方法可以返回指定对象所有自有属性的描述符，包括属性的值、可写性、可枚举性、可配置性等等。
    
5. `SharedArrayBuffer` 和 `Atomics`：这两个 API 可以用于在多个线程之间共享内存和原子操作，方便进行高性能的并发编程。
    
6. `Promise.prototype.finally()`：这个方法可以在 Promise 执行完毕后，无论成功或失败，都执行指定的回调函数，方便进行处理和清理操作。
    

这些是 ES8 中的一些新特性和 API，它们可以让 JavaScript 语言更加强大和灵活，提高开发效率和代码质量。
