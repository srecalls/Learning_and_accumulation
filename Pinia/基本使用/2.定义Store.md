# 2.定义Store
`store `是使用`defineStore()` **定义的，**第一个参数是整个应用中store的唯一名称(id)

**建议：**

**可以为**`defineStore()`**的返回值任意命名，**但是最好使用**`use`**加上**`store`**的名称和**`Store`**，例如：**`useUserStore`**、**`useCartStore`**、**`useProductStore`
```JAVASCRIPT
import { defineStore } from 'pinia'

export const useStore = defineStore('main', {
  // 具体代码...
})
```
