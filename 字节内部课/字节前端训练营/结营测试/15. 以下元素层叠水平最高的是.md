以下元素层叠水平最高的是：

-    D元素: 根元素上一个block元素，D元素position: absolute、z-index: 10

解析：

在 CSS 中，元素的层叠水平是由以下因素决定的，从高到低排列：

1.  position 属性值为 fixed 的元素，它们的层叠顺序比其他所有元素都要高。
    
2.  position 属性值为 absolute 的元素，如果它们的祖先元素中存在 position 属性值为 relative 或者 fixed 的元素，那么它们的层叠顺序比没有定位的元素要高。
    
3.  position 属性值为 relative 或者 static 的元素，以及没有定位的元素，它们的层叠顺序由它们在 HTML 中的位置和 z-index 值共同决定。位置越靠后的元素层叠顺序越高，z-index 值越大的元素层叠顺序越高。
    

在题目中，A元素和B元素都没有定位，因此它们的层叠顺序由它们在 HTML 中的位置决定，A元素比B元素位置靠前，因此A元素层叠顺序比B元素高。

C元素有相对定位，但是它的 z-index 值为 auto，因此它的层叠顺序和它的兄弟元素一样，由它在 HTML 中的位置决定。

D元素有绝对定位，并且它的 z-index 值为 10，因此它的层叠顺序比其他元素都要高。

因此，D元素层叠水平最高。
