【多选题】 如何在shell脚本中使用参数？
- [x] $#
- [x] $*
- [ ] argument
- [x] $1



以下是在 shell 脚本中使用参数的正确方法：

- [x] $#
- [x] $*
- [x] $1

解析：

- $# 表示传递给脚本的参数个数。

- $* 或者 $@ 表示所有的参数列表，可以用于循环遍历所有参数。

- $1、$2、$3、... 表示对应位置的参数，例如 $1 表示第一个参数，$2 表示第二个参数，以此类推。

- argument 不是 shell 脚本中用于使用参数的名称，因此选项 C 不正确。

因此，正确选项为 A、B 和 D。
