关于跨端方案，以下说法正确的有：

- [x] 小程序的渲染层基于 webview 实现。

- [x] React Native 框架将 JSCore 作为 JavaScript 的运行环境。

- [x] Flutter 是依赖 skia 图形库进行绘制，所以在各平台都有相同的 UI 表现。

解析：

跨端方案是指一种技术方案，可以将一份代码运行在多个端上，比如 Web、iOS、Android 等端。以下是关于跨端方案的几个正确的说法：

- App 中可以使用系统浏览器自带的 webview 控件，但是也可以使用第三方 webview 控件，比如 Crosswalk、WebView+ 等。

- 小程序的渲染层基于 webview 实现，通过 JavaScript 控制 DOM 和 CSS 样式，实现页面渲染和交互。

- React Native 框架将 JSCore 作为 JavaScript 的运行环境，将 React 组件映射到原生组件上，通过 JavaScript 控制原生组件的渲染和交互。

- Flutter 是依赖 skia 图形库进行绘制，通过 Dart 语言控制 UI 组件的渲染和交互，因此在各平台都有相同的 UI 表现。

因此，选项 B“小程序的渲染层基于 webview 实现”、选项 C“React Native 框架将 JSCore 作为 JavaScript 的运行环境”和选项 D“Flutter 是依赖 skia 图形库进行绘制，所以在各平台都有相同的 UI 表现”都是正确的。选项 A“App 中只能使用系统浏览器自带的 webview 控件”是错误的。
