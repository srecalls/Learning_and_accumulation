以下说法正确的是：

- [x] 当我们不希望把变量转换为值的时候使用单引号
- [x] 双引号会计算所有变量的值并用值替代

解析：

在 shell 脚本中，双引号和单引号都用于引用字符串，但是它们之间存在一些区别：

- 双引号会对其中的变量进行展开，将变量替换为其对应的值。例如：

  ```
  name="Alice"
  echo "My name is $name"
  ```

  输出结果为：

  ```
  My name is Alice
  ```

- 单引号不会对其中的变量进行展开，会将变量名作为普通字符串处理。例如：

  ```
  name="Alice"
  echo 'My name is $name'
  ```

  输出结果为：

```
  My name is $name
 ```

- 双引号中可以使用转义字符，例如：`\n` 表示换行，`\t` 表示制表符等。

- 单引号中不能使用转义字符，但是可以使用 `\'` 来表示单引号本身。

- 单引号内部不能执行 shell 命令，而双引号内部可以执行。

因此，选项 B 和 C 正确，选项 A 和 D 不正确。
