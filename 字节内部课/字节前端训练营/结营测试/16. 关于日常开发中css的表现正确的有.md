关于日常开发中 CSS 的表现正确的有：

-    将一个元素设置为 display: inline-block，可以阻止它和它的子元素之间的外边距重叠。
    
-    一个内联元素的 vertical-align: middle，表示将它的中线和父元素的基线上移半个 x 的高度对齐。
    
-    一个元素的 padding 设置为 20%，是基于其父元素的宽度计算。
    
-    .title + .content {...} 和 .wrapper > .content {...} 如果作用于同一个元素，需要根据 CSS 代码的位置判定哪个生效。
    

解析：

以上几个描述都是正确的：

-   当一个元素设置为 display: inline-block 时，可以阻止它和它的子元素之间的外边距重叠，这是因为 display: inline-block 让元素既具有块级元素的特性又具有行内元素的特性。
    
-   一个内联元素的 vertical-align: middle，表示将它的中线和父元素的基线上移半个 x 的高度对齐，其中 x 表示元素的字号大小。
    
-   当一个元素的 padding 设置为百分比值时，这个百分比值是基于其父元素的宽度计算的。
    
-   .title + .content {...} 和 .wrapper > .content {...} 这两个 CSS 选择器都可以选择 class 为 content 的元素，但是它们的作用范围不同，前者表示紧接在 class 为 title 的元素后面的 class 为 content 的元素，后者表示 class 为 wrapper 的元素下直接子元素中的 class 为 content 的元素。如果这两个选择器都作用于同一个元素，那么需要根据 CSS 代码的位置判断哪个生效。
    
-   设备像素比是指在未放缩状态下，设备像素和参考像素的比值。这个描述是错误的，因为设备像素比是指设备像素和 CSS 像素的比值，不是参考像素。
