下面关于 CSS 变量的说法正确的是：

-    声明 CSS 变量需以 "--" 开始。
    
-    读取 CSS 变量值时可以直接通过 var() 函数。
    
-    大小写不敏感，--custom-color 和 --Custom-Color 是同一个 CSS 变量。
    
-    浏览器遇到无效的 var() 时，会使用继承值或初始值代替。
    

解析：

CSS 变量是 CSS3 中引入的一种新特性，用于在 CSS 中声明和使用变量。以下是关于 CSS 变量的几个正确的说法：

-   声明 CSS 变量时需要以 "--" 开始，比如：--primary-color: #007bff。
    
-   读取 CSS 变量的值时需要使用 var() 函数，并将变量名作为参数，比如：color: var(--primary-color)。
    
-   CSS 变量的变量名大小写不敏感，--custom-color 和 --Custom-Color 是同一个 CSS 变量。
    
-   如果浏览器在计算 var() 函数时遇到无效的变量名或变量值，会使用继承值或初始值代替。
    

因此，以上四个说法都是正确的。
