【单选题】以下关于HTTP协议的说法正确的有
- [ ] HTTP 2一定比 HTTP 1或 HTTP/1.1 更快
- [ ] HTTP 3 在任何情况下都可以实现 O RTT 连接
- [ ] HTTP 2 中已经不存在任何形式的队头阻塞了
- [x] HTTPS 是由夹在 HTTP 和 TCP 之间的 TLS/SSL 层实现通讯加密的

以下关于 HTTP 协议的说法正确的是：

-    HTTPS 是由夹在 HTTP 和 TCP 之间的 TLS/SSL 层实现通讯加密的

解析：

-   HTTP 2 相比于 HTTP/1.x，采用了多路复用技术，可以在一个 TCP 连接上同时传输多个请求和响应，从而提高了性能，但并不是在任何情况下都比 HTTP/1.x 更快，因此选项 A 不正确。
    
-   HTTP 3 采用了 QUIC 协议作为传输层协议，可以在任何情况下实现 O RTT 连接，因此选项 B 正确。
    
-   HTTP 2 中引入了二进制分帧（Binary Framing）和流（Stream）的概念，可以避免队头阻塞问题，但并不是不存在任何形式的队头阻塞了，因此选项 C 不正确。
    
-   HTTPS 是由夹在 HTTP 和 TCP 之间的 TLS/SSL 层实现通讯加密的，它可以保证 HTTP 通信过程中的数据传输的安全性，因此选项 D 正确。
    

因此，正确选项为 D。
