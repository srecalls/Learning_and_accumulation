【单选题】 关于变量提升，以下说法正确的是
- [x] var有变量提升
- [ ] let有变量提升
- [ ] const有变量提升
- [ ] JS没有变量提升

关于变量提升，以下说法正确的是：

- [x] var 有变量提升。

解析：

在 JavaScript 中，变量提升是指在代码执行前，变量和函数的声明会被提升到作用域的顶部。这意味着可以在声明之前使用这些变量或函数，但是它们的值为 undefined。

在 ES6 之前，只有 var 声明的变量存在变量提升，而 let 和 const 声明的变量不存在变量提升。因此，选项 A“var 有变量提升”是正确的。

举个例子：

```javascript
console.log(a); // 输出 undefined
var a = 1;
```

上面的代码中，变量 a 的声明会被提升到作用域的顶部，因此可以在声明之前使用变量 a，但是它的值为 undefined。

对于 let 和 const 声明的变量，它们存在暂时性死区（TDZ），在变量声明之前使用这些变量会抛出 ReferenceError 错误，因此它们不会发生变量提升。

因此，选项 B“let 有变量提升”、选项 C“const 有变量提升”和选项 D“JavaScript 没有变量提升”都是错误的。
