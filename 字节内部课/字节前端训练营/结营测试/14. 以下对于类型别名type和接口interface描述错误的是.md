- [ ] 类型别名可以为任何类型引入名称。例如基本类型，联合类型等
- [x] 类型别名无法被实现(implements)，而接口可以被派生类实现
- [ ] 类型别名重名时编译器会抛出错误，接口重名时会产生合并


以下对于类型别名 type 和接口 interface 描述错误的是：

-    类型别名无法被实现(implements)，而接口可以被派生类实现。

解析：

在 TypeScript 中，类型别名 type 和接口 interface 都用于定义类型，但是有一些不同点：

-   类型别名可以为任何类型引入名称，包括基本类型、联合类型、交叉类型、函数类型、对象类型等，而接口 interface 只能定义对象类型。
    
-   类型别名支持继承，可以继承其他类型别名或者接口，而接口也可以继承其他接口。
    
-   类型别名无法被实现(implements)，而接口可以被类或者对象实现。
    
-   类型别名重名时编译器会抛出错误，而接口重名时会产生合并，合并后的接口包含重名接口的所有成员。
    

因此，选项 C 中的描述“类型别名无法被实现(implements)，而接口可以被派生类实现”是错误的，应该是“类型别名无法被实现(implements)，而接口可以被类或者对象实现”。
