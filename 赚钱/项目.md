### 1. 使用动态路由，配置路由守卫，对路由跳转设置拦截，进行权限认证

使用路由守卫router.beforeEach，先获取下token是否存在，如果不存在则判断是否在白名单里面，白名单是不用登陆就可以访问的页面，在白名单里就放行，没在白名单里就跳转到登陆页面，如果token存在，则已经登陆，再判断store里面是否有菜单列表，如果有菜单列表了则直接放行，没有菜单列表则使用dispatch动态生成路由，获取菜单，动态生成路由的过程是使用遍历服务器返回回来的路由表，递归它的children，使用router.addRoute()方法去动态添加路由。

```js
const whiteList = ['/login']; //白名单
router.beforeEach(async(to,from,next) =>{
    //获取token
    let token = getToken();
    if(token){
        if(to.path === '/login' || to.path ==='/'){
            next({path:'/'})
        }else{
            //判断是否已经获取菜单列表
            let hasMenuList = store.state.menu.menuList.length > 0
            if(hasMenuList){
                next()
            }else{
                try{
                    //获取菜单、动态生成路由
                    await store.dispatch('menu/getMenuList',router)
                    //确保动态添加的路由已经被完全加载上去
                    next({...to,replace:true})
                }catch(error){
                    //重置token
                    cleanSession();
                    //跳到登录
                    next({path:'/login'})
                }
            }
        }
    }else{
        //判断是否在白名单中
        if(whiteList.indexOf(to.path) !== -1){ //存在白名单，放行
            next(); 
        }else{ //不存在，登录
            next({path:'/login'})
        }
    }
})
```

    const res: Array<RouteRecordRaw> = [];
    routes.forEach((route: any) => {
        const tmp = { ...route }
        const component = tmp.component;
        if (route.component) {
            if (component == 'Layout') {
                tmp.component = Layout;
            } else {

### 2.封装axios，实现调用接口函数模块化，使用响应拦截器实现token无感知刷新

生成两个token，第一个是token（两小时），第二个是refresh_token（15天）：用于生成新的token，每15天需要重新登陆一次。

请求拦截器：如果有token且不在刷新状态就给请求头加上token，如果是post请求就让content-type变成"application/x-www-form-urlencoded，并用qs.stringify序列化；

响应拦截器：判断状态码，如果是401就使用refresh_token去请求，获取新的token，在获取新的token，此时发出的请求利用promise和函数压入队列中，使promise处于pedding状态，直到拿到新token，再遍历队列执行回调函数，使pedding变为reject的状态，重新去发请求。如果拿新token的请求返回错误，则清空数据跳转到登陆页面。

```js
import axios from "axios";
import qs from "qs";

// 是否正在更新token的标记
let isRefreshing = false
let requests = [];

// 创建 axios 请求实例
const serviceAxios = axios.create({
  baseURL: "xxx", // 基础请求地址
  timeout: 10000, // 请求超时设置
  withCredentials: false, // 跨域请求是否需要携带 cookie
});

// 创建请求拦截
serviceAxios.interceptors.request.use(
  (config) => {
    // 如果token存在
    let token = localStorage.getItem("token");
    if(token && !isRefreshing){
        config.headers["token"] = localStorage.getItem("token");
    }
    // 设置请求头
    if(!config.headers["content-type"]) { // 如果没有设置请求头
      if(config.method === 'post') {
        config.headers["content-type"] = "application/x-www-form-urlencoded"; // post 请求
        config.data = qs.stringify(config.data); // 序列化,比如表单数据
      } else {
        config.headers["content-type"] = "application/json"; // 默认类型
      }
    }
    return config;
  },
  (error) => {
    Promise.reject(error);
  }
);

function refreshToken () {
    let refresh_token = localStorage.getItem("refresh_token");
    // instance是当前request.js中已创建的axios实例
    return serviceAxios({
		method: 'get',
		url: '/refreshToken',
		headers: {
			Authorization: refresh_token
		}
	})
}

serviceAxios.interceptors.response.use(response => {
  const { code } = response.data
  if (code === 401) {
    const config = response.config
    if (!isRefreshing) {
      	isRefreshing = true
      	return refreshToken().then(res => {
        	const { token } = res.data
        	localStorage.setItem("token",token);
            isRefreshing = false;
        	// 已经刷新了token，将所有队列中的请求进行重试
        	requests.forEach(cb => cb(token))
        	requests = []
        	return serviceAxios(config)
      }).catch(res => {
            localStorage.setItem("token","");
            localStorage.setItem("refresh_token","");
            requests = [];
            isRefreshing = false;
        	router.push({ path: `/login?path=${router.currentRoute.fullPath}` })
      })
  } else {
      // 正在刷新token，将返回一个未执行resolve的promise
      return new Promise((resolve) => {
        	// 将resolve放进队列，用一个函数形式来保存，等token刷新后直接执行
      		requests.push((token) => {
          		resolve(serviceAxios(config))
     	 	})
      })
  	}
  }
  return response
}, error => {
  return Promise.reject(error)
})


export default serviceAxios;
```

### 4. 使用websocket，加入心跳检测及自动重连机制，实现用户新增消息的实时提醒

原理：使用websocket时设备网络断开，不会触发任何函数，前端无法得知当前连接已经断开，如果此时调用websocket.send方法，浏览器会发现消息发不出去，浏览器便会触发onclose函数；而后端的websocket服务也可能出现异常，断开后前端也并没有收到通知，因此需要前端定时发送心跳消息Ping，后端收到Ping后回复前端Pong消息，告知前端连接正常，如果一段时间没收到Pong消息，就说明连接不正常，前端执行重连。

定义初始化函数initWebsocket，该函数先判断浏览器是否支持webSocket，不支持就return，支持就给四个事件绑定函数，分别是onopen、onerror、onmessage、onclose，onopen是连接成功会调用的函数，该函数里调用start方法让定时器开始工作，定时器会定时使用send方法发送心跳检测，如果后端能收到则会回复消息，此时onmessage触发，onmessage里会调用start让定时器重时开始计时，如果后端收到消息，则会等另一个定时器触发onclose函数，onclose函数会调用reconnect函数进行重连，reconnect函数里会重新调用initWebSocket重新连接。

```js
let timeout = 60 * 1000,
    timer: any = null,
    serverTimer: any = null,
    wsuri = 'ws://123.207.167.163:9010/ajaxchattest', // ws wss
    lockReconnect = false, // 连接失败不进行重连
    maxReconnect = 5, // 最大重连次数，若连接失败
    socket: any = null;

function reset() {
    timer && clearTimeout(timer)
    serverTimer && clearTimeout(serverTimer)
}
function start(ws: any) {
    reset()
    timer = setTimeout(() => {
        // console.log('发送心跳,后端收到后，返回一个心跳消息')
        // onmessage拿到返回的心跳就说明连接正常
        ws.send(JSON.stringify({ heart: 1 }))
        serverTimer = setTimeout(() => {
            // 如果超过一定时间还没响应(响应后触发重置)，说明后端断开了
            ws.close()
        }, timeout)
    }, timeout)
}

function reconnect() {
    console.log('尝试重连')
    if (lockReconnect || maxReconnect <= 0) {
        return
    }
    setTimeout(() => {
        // maxReconnect-- // 不做限制 连不上一直重连
        initWebSocket()
    }, 60 * 1000)
}

export function initWebSocket() {
    try {
        if ('WebSocket' in window) {
            socket = new WebSocket(wsuri)
        } else {
            console.log('您的浏览器不支持websocket')
            return;
        }
        socket.onopen = websocketonopen
        socket.onerror = websocketonerror
        socket.onmessage = websocketonmessage
        socket.onclose = websocketclose
    } catch (e) {
        reconnect()
    }
}

function websocketonopen(data?:any) {
    start(socket);
    websocketsend(data);
}
function websocketonerror(e: any) {
    console.log('WebSocket连接发生错误', e)
    reconnect()
}
export function websocketonmessage(e: any) {
    // console.log(e)
    let data = JSON.parse(e.data);
    // 消息获取成功，重置心跳
    start(socket);
    return data;
}
function websocketclose(e: any) {
    console.log('connection closed (' + e.code + ')')
    reconnect()
}

export function websocketsend(data:any) {
    socket.send(JSON.stringify(data))
}

```

export function throttle(callback, gap) {
    let oldTime = 0;
    return function () {
        let nowTime = Date.now();
        if (nowTime - oldTime > gap) {
            callback.apply(this, arguments)
            oldTime = nowTime;
        }
    }
}

export function deepClone(obj,newObj){
        for(key in obj){
            if(obj.hasOwnProperty(key) && obj[key] instanceof Array){
                newObj[key] = [];
                deepClone(obj[key],newObj[key]);
            }else if(obj.hasOwnProperty(key) && obj[key] instanceof Object){
                newObj[key] = {};
                deepClone(obj[key],newObj[key]);
            }else if(obj.hasOwnProperty(key)){
                newObj[key] = obj[key];
            }
        }
        return newObj;
}

/**
 * @param {string} format

 * @return {string} 
 */
function formatDate(format='Y-M-D h:m', timestamp=Date.now()){
  let date = new Date(timestamp)
  let dateInfo = {
    Y: date.getFullYear(),
    M: date.getMonth()+1,
    D: date.getDate(),
    h: date.getHours(),
    m: date.getMinutes(),
    s: date.getSeconds()
  }
  let formatNumber = (n) => n > 10 ? n : '0' + n
  let res = format
    .replace('Y', dateInfo.Y)
    .replace('M', dateInfo.M)
    .replace('D', dateInfo.D)
    .replace('h', formatNumber(dateInfo.h))
    .replace('m', formatNumber(dateInfo.m))
    .replace('s', formatNumber(dateInfo.s))
  return res
}

   ```js
   const container = document.querySelector('#container');
   const renderList = async () => {
       const list = await getList();
       const total = list.length;
       const page = 0;
       const limit = 20;
       const totalPage = Math.ceil(total / limit);
       const render = (page) => {
           if(page >= totalPage) return;
           requestAnimationFrame(() => {
               const fragment = document.createDocumentFragment();
               for(let i = page * limit; i < page * limit + limit; i++){
                   const div = document.createElement('div');
                   div.innerHTML = list[i];
                   fragment.appendChild(div);
               }
               container.appendChild(fragment);
               render(page + 1);
           })
       }
       render(page);
   }
   ```

### 18. 切片大文件实现断点续传

我做这个大文件的初衷是一次我在实验室里用我写的项目上传文件，那天实验室的网络不太好，在上传的时候失败了，失败了又要全部重传，所以我就想着做这个功能，这是我做这个东西的初衷，后面的话还了解到实现并发的话可以提高文件传输速度，所以我也做了这个并发。接下来我先简单说下整个流程，首先就是低于200M的文件我就直接上传了，不做切片上传处理，生成hash值使用一个库叫md5的，生成完后用slice方法对文件切片，每个切片的名字是hash值加上切片的序号，上传发个请求带上hash值问一下服务器，之前有没有上传过，如果有就把上传过的序号返回，我这边进行对比，把已经上传过的切片过滤掉，如果全部都上传过了，那就直接完成了，也就是秒传，如果还有切片没上传过，那就开始上传还没上传过的切片，有个暂停按钮，利用的是axios中的cancelToken，去中断当前请求，点继续之后就会从这个记录这里继续开始传，传完之后再发个请求通知下服务器进行合并，这是整个流程。下面再说下一些细节，第一个是我自己有一次传了个几G的文件，发现页面卡顿了，我一想应该是在计算生成hash值的时候卡住了，所以就想解决办法，第一个办法就是，那计算量大，肯定就是用万能的web worker，计算量大的都可以丢给它，但缺点就是你还是需要等待它计算完毕，文件一大，还是要等一会的，第二个办法就是去抽样hash，我的方案是第一片和最后一片都保留，其它的切片我只取开头中间和结尾，各取2kb，合并后进行hash，这样提升效率，缺点就有小概率误判，如果两个不完全相同的文件，你抽样到的文件刚好相同，那就会误判为同一个文件，但在这里我也做了弥补，我在hash值后面拼接了文件的size，减小误差的概率，两种我都实现过了，具体的话还是看实际情况去选择吧，就是需不需要对文件判断更加精准；第二个是需要实现一个并发，浏览器的并发请求数量一般是6个，考虑到上传文件的时候可能会有别的请求，所以我把并发数控制在4个，主要是使用promise去实现并发的，切片上传成功就传下一片，上传失败就进行重传，但是这里我遇到了一个问题，就是当我点击完暂停按钮的时候，有时后端发现有些切片传了两次，我就打开开发者工具，就是F12里的network去看，一次一次试那个暂停按钮，最后发现了原因，原因就是我是这么实现暂停的，我先假设我的并发量是2，正常情况下第一个就请求第一片，第二个就请求第二片，我用一个全局变量指向下一片应该传的切片，也就是第三片，如果第一个请求先传完，那他就会开始传第三个切片，全局变量就会指向第四个切片，这个时候我按暂停，第二片和第三片中断请求，那我这个全局变量应该指向第二片，下次重传的时候从第二片开始，到这里都是正常的，但是有一种情况，第一个请求比较慢，卡在第六片了，第二个请求已经到第八片了，因为已经到第八片了，第七片是肯定已经传过了，这个时候我按下暂停，全局指示变量指向第六片，下次重新传就从第六片开始，所以会导致第七片传过两次，这个情况也可以让后端帮我解决，就是用set去过滤一下，两片就取一片就好了，但是多传一片没用的总觉得不行，所以我就想了一会要怎么解决，最后我想到就是，不用全局变量了，上传的文件我是放在一个数组里，正在上传的文件我就把它从数组里弹出来，用一个临时变量保存，如果我点暂停再把正在上传的文件给加回到数组里去。
