# 一、系统介绍

飞书招聘系统是承载小米招聘运转的工具，是社招、校招、实习生招聘、内推等渠道的系统载体，小米的同事们可使用该系统完成**内推**、**简历评估、面试/评价**等招聘动作。

3. ## 面试与评价
    

飞书招聘的面试邀约支持**视频面试**、**现场面试**、**电话面试****，**下面将以常用的视频面试邀约为例，介绍如何使用飞书招聘进行视频面试。

> 注意：候选人可选择使用PC端或移动端进入面试，PC端支持使用链接直接进入，建议使用Chrome浏览器或360浏览器；移动端仅支持使用飞书进行视频面试，需要候选人提前安装客户端。

1. ### **进入****视频****面试**
    

当HR给您分配了面试任务后，您可通过下列两个入口查看面试任务：

**入口一：****PC****端或移动端小米办公->日历**

在日历中找到面试日程，点开日程后将显示详细信息，如候选人、面试轮次、视频面试链接等。

您点击‘发起视频会议’即可进入面试，或点击面试信息内的链接进入面试。

![[各位亲爱的小米面试官：-15.png]]



![[各位亲爱的小米面试官：-16.png]]




![[各位亲爱的小米面试官：-17.png]]

**入口二：****飞书招聘****（首页）->我的面试**

进入飞书招聘后，首页左侧 **我的面试** 模块展示了您需要参与的面试信息，可从此处进入面试。

- **PC****端：**可通过以下两种方式进入面试。
    

方式一：通过首页进入面试
![[各位亲爱的小米面试官：-18.png]]



方式二：通过面试模块进入面试
![[各位亲爱的小米面试官：-19.png]]

- **移动端：**在“我的面试”模块，选择候选人，点击开始视频。
    

![[各位亲爱的小米面试官：-21.png]]




![[各位亲爱的小米面试官：-22.png]]


![[各位亲爱的小米面试官：-23.png]]

2. ### 开启面试界面
    

面试界面中**“****面试空间****”**功能可以帮助您更高效的开展面试，支持在小米办公的视频面试窗口中展开候选人简历详情页，您无需反复切换窗口，可直接在“面试空间”中查看简历、填写面评**（候选人端无法看到“面试空间”）****。**

仅PC端小米办公支持使用“面试空间”，移动端仅支持基础视频功能。

- “面试空间”总览：
    

![[各位亲爱的小米面试官：-24.png]]

- “面试空间”主模块包含视频窗口、候选人信息、面试官操作区域。
    
![[各位亲爱的小米面试官：-25.png]]

- 视频窗口下方为功能区域，可以进行麦克风/视频管理、会议录制等操作。
    

**注意：****如在****面试时****选择进行****录屏需要经过候选人同意，切勿在未与候选人沟通的情况下自行点击录制****（****候选人会收到****弹窗****提醒****）****，以免造成误会。**

3. ### 开启代码考核
    

代码考核功能可更高效的帮助您在视频面试时考察候选人的代码能力，在使用代码考核功能前，可参考3.3完成相应配置，提前预置考察题目。

面试官**仅支持**使用**PC****端小米办公** 打开“面试空间”并进行代码考核，移动端仅支持基础视频功能；候选人如果需要参加代码考核，必须使用**PC浏览器网页**打开面试链接，移动端不支持。

- 进入“面试空间”，点击下方图示位置，进入代码考核功能（前提：需在进行面试安排时，选择含代码考核的面试）。
    

![[各位亲爱的小米面试官：-26.png]]

- 左侧可进行题目创建，或使用面试题库（需提前录入题目，题库设置请查看：[4.1.3面试题库设置](https://xiaomi.f.mioffice.cn/docx/doxk4aRtCpxA6W2BbdgLJPROTm8#doxk4csKwYAES4kGiMLHGiRPzqh)），右侧点击邀请候选人并复制链接，通过下方聊天功能发送给候选人。
    

![[各位亲爱的小米面试官：-27.png]]

- 当界面为代码考核时：
    
    - 界面左侧为题目、评价区，题目为候选人可见，评价区为面试官记录使用，对候选人不可见。
        
    - 界面右侧为代码区，候选人可在代码区实时同步编写代码，完成代码后，可点击“运行代码”，进行测试。
        
    - 界面右下方为输入记录区，可测试候选人代码的输入输出是否正常。
        
        - 候选人运行记录可记录运行次数、状态。
            
        - 页面切换记录可记录候选人切出页面次数。
            

![[各位亲爱的小米面试官：-28.png]]

- 代码考核结束后，可点击返回按钮，返回“面试空间”。
    

![[各位亲爱的小米面试官：-29.png]]

- 代码考核的部分将记录在面试评价表中的“记录”模块，便于后续查看。
    

![[各位亲爱的小米面试官：-30.png]]

# 三、Q&A

**Q：我在Moka中仍有****流程****中的候选人，我需要怎么处理？**

A：如您在Moka中仍然有筛选中/面试中/待评价的候选人，您需继续在Moka系统中处理完这部分候选人。当Moka系统里所有候选人的流程处理完毕后，我们将关闭Moka系统。

  

**Q：我曾经面试或筛选过的候选人简历，在新系统中能找到****吗****？**

A：Moka系统中已经归档/淘汰的简历、面试评价等信息，均已转移到飞书招聘的人才库，招聘HR可进行查找和操作；您在新系统中无法查看过去的筛选记录、面试记录等。

  

**Q：新的系统我需要申请面试官权限吗？**

A：飞书招聘系统不需要面试官主动申请权限，当招聘HR向您安排了评估/面试任务后，您将自动获得面试官权限，但您仍需通过面试官考核与认证来获取面试官资格[面试官培训及认证线上运营规则](https://xiaomi.f.mioffice.cn/docs/dock4C59Nks2nOhuYkLewgQr77e#) ，如您未能及时完成面试官认证，我们将取消您的面试官资格。

  

**Q：如果我对系统有其他问题，需要怎么反馈？**

A：如您有任何系统相关问题，或者意见及建议，欢迎通过以下两种途径反馈：

1. 联系客服：飞书招聘提供5*8的客服支持，您可在小米办公中，点击头像-帮助与客服，在小米办公中找到飞书客服进行咨询，**该客服非小米员工，请注意切勿沟通敏感信息**。
    
2. 内部沟通群：您可通过下方群名片加入反馈群，我们将为您及时解答。
