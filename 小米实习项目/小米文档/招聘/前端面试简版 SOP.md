# 招聘目标

招聘目标：**对于校招生，我们要招聘【未来】能在小米创造【高绩效】 的人**

# 怎么理解招聘目标

- 两个关键词：未来、高绩效
    
- 未来意味着要有潜力
    
- 能创造高绩效、他自己需要有动力、组织才能培养出能力，所以招聘的逻辑也就很清晰了
    

# 招聘原则

**动机第一**：动机极其重要，自驱力，目标驱动，结果导向，过程强执行

**能力第二**：学习的能力和底层能力优先；专业纵深能力

**绩效第三**：过去的绩效和经验。尤其是成功的经验。

  

# 面试是什么、不是什么

- 面试是为了充分挖掘对方长处、不是为了刁难对方，让对方难堪
    
- 面试是有目的信息获取，不是唠嗑式的闲聊
    
- 面试是双向的吸引、不是单向考察，我们在探查对方的实力，也是在展现团队的素养与风貌
    

  

# 面试准备

- 基本要求关于仪容仪表，基本礼仪这些，这里就不再赘述了，可以阅读[商店-研发招聘流程](https://xiaomi.f.mioffice.cn/docx/doxk4vjXjvemTbRqMgqVkr2mTSh)
    
- 展开一下几个关键点
    
    - 面试前认真阅读简历、这个是基本要求，仅仅考八股文式的面试最简单，但效果相对也最差，原因有二
        
        - 八股文面试很容易背题，问出的信息量有限，从过往面试经验看，优秀的同学往往较反感
            
        - 挖掘对方能力的效率低，如果不能针对性的对【思考能力】【分析能力】进行考察，很难区分普通与优秀
            
        - 因此，基础问题该八股一定要八股，但一定要根据候选人的实际情况准备1~2道【有挑战】的【综合题】；可以根据简历中面试者的亮点多设定1~2道开放的【思考题】
            
    - 提前创建好飞书文档，准备好面试大纲和相应考察题目
        
    - 面试模板可见
        
    
      
    

# 面试过程

- 一个规范化的面试开场不仅能让面试者放松心态充分发挥，也能体现咱们团队、体现小米的专业形象
    
- 面试过程
    
    - 面试问题遵循 STAR 法则
        
        - 场景是什么？
            
        - 要解决什么问题？
            
        - 怎么解决的？
            
        - 结果怎么样？
            
    - 对应聘者的回答做好详细记录
        
        - 可以提前告知他会记录，避免记录时面试者觉得你在干其他事情，觉得不尊重
            
        - 面试后立马进行总结梳理（避免时间太久，靠记忆的信息失真）
