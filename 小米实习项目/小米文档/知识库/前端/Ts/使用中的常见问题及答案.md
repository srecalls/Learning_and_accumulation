

1. 在window上显示的设置属性

```
window.MyNamespace = window.nameSpace || {} 
// Property 'MyNamespace' does not exist on type 'Window & typeof globalThis'
```

正解：

```
(window as any).MyNamespace = {};
```

或者：

```
declare interface Window {
  MyNamespace: any;
}

window.MyNamespace = window.MyNamespace || {};
```

2. 为对象动态的分配属性

```
let obj = {};
obj.name = 'ellie';
// Property 'name' does not exist on type '{}'
```

正解：

```
interface LooseObject {
  [key: string]: any
}

let obj: LooseObject = {};
obj.name = 'ellie';
```

或者：

```
interface Person extends Record<string, any> {
    name: string;
}
let obj: Person = {
    name: 'ellie'
}
```
