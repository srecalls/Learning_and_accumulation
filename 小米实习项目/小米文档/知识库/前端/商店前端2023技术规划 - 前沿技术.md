# 前沿技术

## 框架

框架：React、Vue、AngularJS、**Svelte**



服务端渲染框架：nuxt、next、elderjs、Fresh

> **Islands 架构发展迅猛。** Islands 架构最早由 preact 作者于 2020.8.11 提出，解页面性能问题，包括 SSR 全栈框架下「重复数据、JS 尺寸大、注水消耗大」的问题。其特点是「More HTML，Less JavaScript」，默认全部 HTML，然后在轮播、搜索补全、购买按钮等需要交互的地方加上少量 JavaScript。低碳、节电，哈哈。社区已有很多实践，前有 astro、qwik、基于 svelte 的 elderjs 等，后有基于 deno 的 Fresh，都是对于 Islands 架构的实践。看到 Fresh 之后，个人感觉方案已逐渐成熟，可尝试用于生产。

跨端框架：React Native、Flutter

小程序以及小程序转译框架：Taro、Chameleon

桌面软件：Electron、Tauri

> 「Electron is easy, but slow and bloated.」Electron 虽然易上手，但问题是大和慢。Tauri 可以解这个问题，满足大家「既要用 JavaScript 开发，又要产品性能」的需求，基于 Rust。

## 工程化能力

打包技术：webpack、babel、esbuild、vite（Bundleless 与 ESM）

> **原生语言已成为** **JS** **工具链重要组成部分。** 犹记得好久以前有人发过一个投票，你会选 JavaScript Tool 还是 Native Code Tool？这其实是在速度和上手门槛之间做选择。这么久过去，开发者已经用脚投票。现在社区有大量基于 Native Code 实现的 JavaScript 工具和框架，比如 Deno（Rust）、Bun（Zig）、Rome Formatter（Rust）、esbuild（go）、swc（Rust）、Parcel CSS（Rust），比如 kdy 之前画的 tsc 的大饼（go），以及像 Next、Vite、Nuxt、Umi 等上层框架和工具也都有大量原生语言工具的应用。

测试：基于图像算法的智能走查方案

Severless、微前端、及函数式编程

### 数据流及数据持久化

很多应用实际上还有持久化数据和同步数据的需求，所以在这个单向数据流之外，还会有个和服务端交互的数据流。Remix 把这个数据流扩展到了全栈，通过获取数据的 loader 和修改数据的 action，形成「Loader > Component > Action」的全栈数据流。同时 React Query、SWR、RTK Query 和 useRequest 也可以理解为广义上的全栈数据流，处理服务端和客户端之间的数据同步。
