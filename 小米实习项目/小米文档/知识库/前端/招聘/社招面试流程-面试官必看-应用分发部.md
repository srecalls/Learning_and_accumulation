# 二、面试流程

1. **概述**

- 15-16级社招：非研发岗位，汤进是业务侧终面。研发岗位，朱宾是业务侧终面（16级及以上岗位HRBP-张赫展，参与面试）；
- 17级-18级社招岗位，秋实是业务侧终面；
- 19级及以上社招岗位，马总/技术委/组织部是业务侧终面；
- 三级部门各职能负责人为其部门的业务侧招聘责任人，为招聘节奏+结果共同负责；
- 除一面可电话/视频外，理论上所有面试建议现场进行

# 四、面试反馈规则

1、招什么样的人

- 价值观正，积极主动，有责任感，有自驱力和韧性
- 专业扎实，学习能力强，自我高要求
    - 用户/增长产品：需要考察业务逻辑和交互基础题
    - 策略/数据产品：需要考察策略逻辑和数据分析基础题
    - 运营：需要考察逻辑和数据分析基础题
    - 研发：需要考察基础功底（包含代码功底），项目经历，架构设计能力
- 有增长意识，工作以数据驱动
- 学历，本科及以上

2、面试评分标准：（5分制、3分为及格线。）

- 注：评分直接关系到人选在该级别框架下的定薪高低，三轮Strong Hire定义为卓越，会在该级别范围内全力争取。

|   |   |   |
|---|---|---|
|5分|- 各方面超出预期<br>- 需要全力争取|卓越|
|4分|- 基础扎实，常规问题可以快速正确作答<br>- 困难问题可以给出思路，在简单提示下想到关键点，并持续展开|优秀-Strong Hire|
|3.5分|- 有一些亮点，但不算突出|良好-Hire|
|3分|- 满足基本要求|及格-Hire|
|2分|- 基本功不达标，或人品/态度有明显硬伤|不通过-No Hire|

2、面试反馈模版

|   |   |
|---|---|
|综合评分+结论|如：良好-Hire|
|优势|总结性描述|
|劣势|总结性描述|
|面试问题记录|详细记录面试中的关键问题及人选回答|
