1. ## 创建爬虫收录任务
    

- 接口描述: 上传Excel文件，创建爬虫收录任务
    
- 请求方式: `POST`
    
- 请求路径: `/autoCrawler/createTarget`
    
- Content-Type: `multipart/form-data`
    
- 请求参数: 如下表格
    
    |   |   |   |   |   |
    |---|---|---|---|---|
    |**参数名**|**参数类型**|**是否必填**|**说明**|**备注**|
    |`target_name`|`string`|是|创建的任务的名字||
    |`file`|`xlsx/xls`|是|excel文件，内容见[【prd】应用自动化爬虫收录上架](https://xiaomi.f.mioffice.cn/wiki/wikk4nAUFA2sKG8vWrwX8TSUuOd)||
    
- 返回参数: 如下表格
    
    |   |   |   |   |
    |---|---|---|---|
    |参数名|类型|是否必填|说明|
    |`code`|`int`|是|SUCCESS_CODE = 0 FAIL_CODE = 999|
    |`msg`|`string`|是|返回消息|
    |`data`|`Object`|否|```JSON<br>{<br>  "totalCount": 100,<br>  "successCount": 50,<br>  "failCount": 50,<br>  "failDetails": [<br>    {<br>      "packageName": "com.xingin.xhs",<br>      "appName": "小红书",<br>      "uploadFailReason": "应用已存在在架apk"<br>    },<br>    {<br>      "packageName": "com.xingin.xhs",<br>      "appName": "小红书",<br>      "uploadFailReason": "应用已经在架"<br>    }<br>  ]<br>}<br>```|
    
- 请求样例: `Nodejs Axios`
    
    ```JavaScript
    const axios = require('axios');
    const FormData = require('form-data');
    const fs = require('fs');
    let data = new FormData();
    data.append('target_name', '收录测试1');
    data.append('file', fs.createReadStream('/home/mi/Downloads/应用爬虫收录模板 .xlsx'));
    
    let config = {
      method: 'post',
      maxBodyLength: Infinity,
      url: 'ks-miui-apm-vm014.bj:8087/autoCrawler/createTarget',
      headers: { 
        ...data.getHeaders()
      },
      data : data
    };
    
    axios.request(config)
    .then((response) => {
      console.log(JSON.stringify(response.data));
    })
    .catch((error) => {
      console.log(error);
    });
    ```
    

2. ## 爬虫任务列表查询
    

- 接口描述 筛选查询爬虫任务
    
- 请求方式 `POST`
    
- 请求路径 `/autoCrawler/filterTarget`
    
- Content-Type: `application/x-www-form-urlencoded`
    
- 请求参数: 如下表格
    
    |   |   |   |   |   |
    |---|---|---|---|---|
    |**参数名**|**类型**|**是否必填**|**说明**|**备注**|
    |`target_name`|`string`|否|创建的任务的名字|模糊匹配 不填或空字符串查询全部|
    |`operator`|`string`|否|创建人|精确查询 不填或空字符串查询全部|
    |`target_status`|`int`|否|任务状态|不填或填0 查询全部 `/autoCrawler/statusCode` 获取`generalProcessStatusEnum`|
    |`create_time_start`|`Long`|否|时间戳 单位ms|不填或填0 没有限制|
    |`create_time_stop`|`Long`|否|时间戳 单位ms|不填或填0 没有限制|
    |`offset`|`int`|是|偏移量||
    |`length`|`int`|是|需要查询的数据数量|0取全部数据|
    
- 返回参数: 如下表格
    
    |   |   |   |   |
    |---|---|---|---|
    |参数名|类型|是否必填|说明|
    |`code`|`int`|是|SUCCESS_CODE = 0 FAIL_CODE = 999|
    |`msg`|`string`|是|返回消息|
    |`data`|`List<Object>`|否|```JSON<br>{<br>    "totalCount": 2,<br>    "detail": [<br>        {<br>            "targetId": 1,<br>            "targetName": "xxxx",<br>            "targetStatus": 1,<br>            "totalTargetDetailCount": 10,<br>            "targetDetailProcessCount": 5,<br>            "targetDetailFailCount": 1,<br>            "targetDetailSuccessCount": 4,<br>            "createTime": "2020-01-20 20:20:20",<br>            "updateTime": "2020-01-20 20:20:20",<br>            "operator": "wanghaohui1"<br>        },<br>        {<br>            "targetId": 1,<br>            "targetName": "xxxx",<br>            "targetStatus": 1,<br>            "totalTargetDetailCount": 10,<br>            "targetDetailProcessCount": 5,<br>            "targetDetailFailCount": 1,<br>            "targetDetailSuccessCount": 4,<br>            "createTime": "2020-01-20 20:20:20",<br>            "updateTime": "2020-01-20 20:20:20",<br>            "operator": "wanghaohui1"<br>        }<br>    ]<br>}<br>```|
    
- 请求样例: `Nodejs Axios`
    
    ```JavaScript
    const axios = require('axios');
    const qs = require('qs');
    let data = qs.stringify({
      'target_name': '测试',
      'operator': '',
      'target_status': '0',
      'create_time_start': '',
      'create_time_stop': '',
      'offset': '1',
      'length': '1' 
    });
    
    let config = {
      method: 'post',
      maxBodyLength: Infinity,
      url: 'ks-miui-apm-vm014.bj:8087/autoCrawler/filterTarget',
      headers: { 
        'Content-Type': 'application/x-www-form-urlencoded'
      },
      data : data
    };
    
    axios.request(config)
    .then((response) => {
      console.log(JSON.stringify(response.data));
    })
    .catch((error) => {
      console.log(error);
    });
    ```
    

3. ## 任务详情列表查询
    

- 请求方式 `POST`
    
- 请求路径 `/autoCrawler/filterTargetDetail`
    
- Content-Type: `application/x-www-form-urlencoded`
    
- 请求参数
    
    |   |   |   |   |   |
    |---|---|---|---|---|
    |**参数名**|**类型**|**是否必填**|**说明**|**备注**|
    |`target_name`|`string`|no|创建的任务的名字|模糊匹配 不填或空字符串查询全部|
    |`package_name`|`String`|no|包名|精确查询 不填或空字符串查询全部|
    |`app_name`|`String`|no||模糊匹配 不填或空字符串查询全部|
    |`collection_status`|`Integer`|no|收录状态|不填或填0 没有限制<br><br>`/autoCrawler/statusCode` 获取 `collectionStatusEnum`|
    |`compatibility_detection_status`|`Integer`|no|兼容检测结果|`/autoCrawler/statusCode` 获取~~`generalProcessStatusEnum`~~<br><br>`autoTestStatusEnum`|
    |`safety_detection_status`|`Integer`|no|安全检测结果(同上)|不填或填0 没有限制<br><br>`/autoCrawler/statusCode` 获取~~`generalProcessStatusEnum`~~<br><br>`autoTestStatusEnum`|
    |`privacy_detection_status`|`Integer`|no|隐私检测结果(同上)|不填或填0 没有限制<br><br>`/autoCrawler/statusCode` 获取~~`generalProcessStatusEnum`~~<br><br>`autoTestStatusEnum`|
    |`collection_failure_reason`|`Integer`|no|失败原因|不填或填0 没有限制<br><br>`/autoCrawler/statusCode` 获取 `collectionFailureReasonEnum`|
    |`create_time_start`|`Long`|no|时间戳 单位ms|不填或填0 没有限制|
    |`create_time_stop`|`Long`|no|时间戳 单位ms|不填或填0 没有限制|
    |`offset`|`int`|YES|偏移量||
    |`length`|`int`|YES|需要查询的数据数量||
    
- 返回参数
    
    |   |   |   |   |
    |---|---|---|---|
    |参数名|类型|是否必填|说明|
    |`code`|int|是|SUCCESS_CODE = 0 FAIL_CODE = 999|
    |`msg`|string|是|返回消息|
    |`data`|List<Object>|否|```JSON<br>{<br>  "detail": [<br>    {<br>      "targetDetailId": 3,<br>      "targetId": 1,<br>      "createTime": "1970-01-01 08:00:00",<br>      "updateTime": "2023-08-31 15:26:30",<br>      "targetName": "测试3",<br>      "packageName": "com.tianyancha.skyeye",<br>      "packageNameHash": "149763307d11da756e92deeac2a9ebab",<br>      "appName": "天眼查",<br>      "operator": "wsl20280831",<br>      "collectionStatus": 999,<br>      "collectionFailureReason": 6,<br>      "compatibilityDetectionStatus": 1,<br>      "safetyDetectionStatus": 1,<br>      "privacyDetectionStatus": 1,<br>    }<br>  ],<br>  "totalCount": 1<br>}<br>```|
    
- 请求样例`Nodejs Axios`
