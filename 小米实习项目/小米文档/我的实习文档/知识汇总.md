## ECMAScript

ECMAScript（简称 ES）是一种标准化的脚本语言规范，定义了一系列语法、数据类型、函数和其他编程功能，用于处理和控制网络浏览器中的对象。它是由 Ecma 国际组织制定的，该组织负责制定和维护 ECMAScript 标准。

ECMAScript 的目标是提供一种通用的脚本语言，以便在不同的平台和环境中使用。它为开发者提供了一套统一的规范，使得不同浏览器和应用程序能够在执行 JavaScript 代码时具有一致的行为和功能。ECMAScript 定义了语法、数据类型、操作符、控制流语句、函数、对象和错误处理等方面的规则和规范。

JavaScript 是基于 ECMAScript 标准的一种实现。JavaScript 实现了 ECMAScript 定义的语法、数据类型和函数，并添加了与网页相关的功能，例如 DOM 操作（文档对象模型）和浏览器 API（应用程序编程接口）的访问。因此，JavaScript 可以看作是 ECMAScript 的一种特定实现，用于在网页上实现交互和动态功能。

ECMAScript 标准不仅仅局限于浏览器环境，它也可用于其他环境，如服务器端开发（如 Node.js）和移动应用开发。通过遵循 ECMAScript 标准，开发者可以编写可移植且具有一致行为的脚本代码，无论在哪个支持 ECMAScript 的平台上运行。

### JavaScript和ECMAScript的关系

JavaScript是脚本语言，ECMAScript是规范。**JavaScript是基于ECMAScript规范的脚本语言**。

JavaScript只是ECMAScript的其中一种实现，除此之外还有其他的实现。

JavaScript是一门遵循了ECMAScript语言规范而设计的编程语言。

JavaScript是一种脚本语言，最初由网景公司（Netscape）开发，用于在网页中实现交互和动态效果。它是一种基于ECMAScript标准的编程语言。

ECMAScript是一种由Ecma国际组织制定的脚本语言标准。JavaScript是ECMAScript标准的一种实现，它是根据ECMAScript规范来开发的。因此，JavaScript可以看作是ECMAScript的一种具体实现。

ECMAScript（简称ES）是一种脚本语言标准，它定义了一种通用的编程语言规范。更具体地说，ECMAScript规范规定了语法、类型、语义、内置对象等方面的规则，用于定义一种脚本语言的特性和行为。

虽然ECMAScript本身是一种规范，但它也可以被视为一种编程语言，因为它定义了一套编程语言的规则和功能。开发人员可以根据ECMAScript规范来实现具体的编程语言，例如JavaScript就是一种基于ECMAScript标准的具体实现。

JavaScript 可以看作是 ECMAScript 的一种特定实现，它添加了与网页交互相关的功能，使得开发者能够创建丰富的网页应用程序。

一，JScript和[JavaScript](https://so.csdn.net/so/search?q=JavaScript&spm=1001.2101.3001.7020)的联系

1、ECMAScript是JavaScript的规格，JavaScript是ECMAScript的一种实现，在日常场合，这两个词是可以互换的。

JavaScript的创造者Netscape公司，将JavaScript提交给国际标准化组织ECMA，希望这种语言能够成为国际标准，后来ECMA发布标准文件的第一版（ECMA-262），规定了浏览器脚本语言的标准，并将这种语言称为ECMAScript。该标准从一开始就是针对JavaScript语言制定的，之所以不叫JavaScript，有两个原因：一是商标，Java是Sun公司的商标，根据授权协议，只有Netscape公司可以合法地使用JavaScript这个名字，且JavaScript本身也已经被Netscape公司注册为商标；二是想体现这门语言的制定者是ECMA，不是Netscape，有利于保证这门语言的开放性和中立性。

ECMAScript，正式名称为 ECMA 262 和 ISO/IEC 16262，是宿主环境中脚本语言的国际 Web 标准。 ECMAScript 规范定义了一种脚本语言实现应该包含的内容；但是，因为它是可扩充的，所以其实现所提供的功能与这个最小集相比可能变化很大。

ECMAScript 是一种开放的、国际上广为接受的脚本语言规范。 它本身并不是一种脚本语言。正如在 Web 应用程序中执行有用操作的 bean 集合（例如，Netscape 的 AWT）是 Sun 的 JavaBean 规范的一种实现一样，JavaScript 是 ECMAScript 规范的一种实现。

ECMAscript定义的只是JavaScript的基础，而在此基础之上可以构建更完善的脚本语言。web浏览器只是ECMAscript实现可能的宿主环境之一。宿主环境不仅提供基本的ECMAScript实现，同时也会提供JavaScript的扩展，以便语言与环境之间对接交互。

2、但事实上，JavaScript比ECMA-262的含义多得多，一个完整的JavaScript实现应该由以下三个部分组成：

1) ECMAScript：核心

2) DOM：文档对象模型

3) BOM：浏览器对象模型

二，JScript和JavaScript的区别

JavaScript语言的前身叫作LiveScript。自从Sun公司推出著名的Java语言之后， Netscape公司引进了Sun公司有关Java的程序设计概念，将自己原有的LiveScript重新进行设计,并更名为JavaScript。这所 以取名为JavaScript，原因就在于JavaScript作为一种嵌入HTML文档的、基于对象的脚本设计语言。其中很大一部分的语法同Java语 言很相似，而且JavaScript的设计可以使它很容易地同Java语言一同工作，它可以充分支持Java的applet小应用程序，Java的 applet小应用程序也可以很方便地访问已有的JavaScript代码。所以，也可以JavaScript看成是Java语言的某种简化版本。 JScript 是 Microsoft 公司对 ECMA 262 语言规范（ECMAScript 编辑器 3）的一种实现。除了少数例外（为了保持向后兼容），JScript 完全实现了 ECMA 标准。JScript 是一种解释型的、基于对象的脚本语言。

## 包

在计算机编程中，「包」（英文：Package）是指将一组相关的函数、类、变量等组织在一起，以便于模块化、复用和管理的一种机制。包可以包含多个模块（Module），一个模块是指一个独立的代码文件，其中定义了函数、类、变量等。

通常情况下，包会被组织成一个文件夹，文件夹中包含了多个相关的模块文件，以便于代码的组织和管理。在一些编程语言中，比如Python、Java、Go等，包的概念都得到了广泛的应用。

使用包可以帮助我们将复杂的程序分解成多个独立的部分，每个部分都可以独立开发、测试和维护。同时，包还可以提供一些额外的功能，例如命名空间的管理、导入的控制等，以便于更好地组织代码。

## NVM

nvm主要原理

nvm（Node Version Manager）的主要原理是通过管理不同版本的Node.js实例来帮助开发者在不同项目间进行切换。它会通过在系统上安装多个Node.js版本，并将其存储在特定的路径中，然后可以使用nvm命令进行切换。

nvm通过设置不同的环境变量来控制当前系统使用的Node.js版本，并且可以通过简单的命令行操作来切换到不同的版本。这样，开发者就可以在不影响其他项目的情况下，在特定项目中使用特定版本的Node.js。
