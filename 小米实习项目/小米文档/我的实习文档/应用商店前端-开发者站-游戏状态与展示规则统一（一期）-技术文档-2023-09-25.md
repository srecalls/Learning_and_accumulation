2. ## 内部设计
    

### DatePicker组件展示函数修改

要求：因产品需求设计，本次放宽至'**当前的时间'**为用户'**本地当前的时间'，**时间颗粒度精确到秒

设计：

- 此前：原先DatePicker组件中通过**disabledDate**与**showTime**进行**可选日期**与**禁选日期**的展示，**disabledDate**只针对**日期**进行禁选，颗粒度仅为**天，**且自定义的disabledDate函数**只针对当前天数之后的天数可选。需要重新设计。**
    

```JavaScript
// DatePicker组件
<DatePicker
  showTime
  placeholder="请选择新游预计首发时间"
  disabledDate={(current) => disabledDate(current, moment().endOf('day'))}
  ...
```

```JavaScript
// 自定义disabledDate函数
function disabledDate(current, dateBefore = moment().endOf('day'), dateAfter) {
  if (!dateAfter) return current && current < dateBefore;
  return current && (current < dateBefore || current > dateAfter);
}
```

- 目前：
    
    - 放宽天数修改：针对需求文档基于原本自定义**disabledDate**函数进行修改，使其放宽天数至当天。
        
    
      
    

3. ## 数据设计
    

### 3.1 数据处理

#### 放宽天数修改：

```JavaScript
<DatePicker
  showTime
  placeholder="请选择新游预计首发时间"
  disabledDate={(current) => disabledDate(current, moment().StartOf('day'))}
```

细节：针对传入`disabledDate`字段进行修改，`current`会与传入字段进行比较，原本`moment.endOf('day')`会导致原函数返回`true`从而导致当前日期无法选择。因此修改为`moment.startOf('day')`。
