1. # 配置git
    

安装git并配置本地config，将email改为小米账号，username改为本人姓名

```Python
git config --global user.name "huangrun"
git config --global user.name

git config --global user.email "huangrun1@xiaomi.com"
git config --global user.email
```

2. # **配置 ssh-key 连接到远程仓库**
    

注意：此处以Macos为例。

1. 在终端中输入下列代码
    

```Shell
$cd ~/.ssh
```

如果没有该文件夹，将会提示：

```undefined
-bash: cd: /Users/xxx/.ssh: No such file or directory
```

如果有该文件夹则会进入到该文件夹如果ssh文件夹里面没有内容，需要创建ssh秘钥。 打开终端： 输入ssh-keygen -t rsa -C [xxx@xxx.com](https://link.jianshu.com?t=mailto:xxx@xxx.com)后回车(邮箱是你代码管理工具的邮箱名字) 然后会提示Enter file in which to save the key，让你输入存放ssh秘钥的路径，默认是~/.ssh，所以直接回车即可。

  
![[【总结】项目开发阶段流程.png]]

有了上面的ssh文件后，打开id_rsa.pub文件(用文本编辑器)，把里面的内容复制到对应的代码管理工具中需要填写ssh秘钥的地方即可。

4. # 进行需求开发
    

1. 切换node源，目前公司内部使用小米源：https://pkgs.d.xiaomi.net/artifactory/api/npm/mi-npm/，开发前，如项目中未设置 [.npmrc](https://docs.npmjs.com/cli/v8/configuring-npm/npmrc)，切换到该源后再开发
    

```SQL
npm config get registry
npm config set registry https://pkgs.d.xiaomi.net/artifactory/api/npm/mi-npm/
```

2. 输入下列代码进行项目依赖下载
