### 3.2 根据接口返回提示

- 错误状态码提示
    

```JavaScript
getVerificationCode({ phoneNumber: formState.contactPhone })
  .then(({ code, msg }) => {
    if (code === 0) {
      setHasSend(true);
    }
    else {
      setHasSend(false);
      dispatch({
        type: 'update/errors',
        payload: {
          contactPhone: [{
            field: 'contactPhone',
            message: msg,
          }],
        },
      });
    }
  })
  .catch((msg) => {
    setHasSend(false);
    dispatch({
      type: 'update/errors',
      payload: {
        contactPhone: [{
          field: 'contactPhone',
          message: msg,
        }],
      },
    });
  });
```

根据状态码进行对应提示的展示。
