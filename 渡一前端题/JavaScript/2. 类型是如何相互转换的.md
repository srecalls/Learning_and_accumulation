## 1. 类型转换规则

### 原始类型转数字类型
![[2. 类型是如何相互转换的-1.png]]

```js
'对象'转'数字'类型要先转成'原始'类型，再转成'数字'类型

Number(true) // 1
Number(false) // 0
Number(null) // 0
Number(undefined) // NaN
Number('') // 0
Number('    ') // 0
Number('  \n\r\t  ') // 0
Number('123') // 123
Number('123a') // NaN
Number('    123   ') // 123
Number('   12   3  ') // NaN
```

### 原始类型转字符串类型
```js
'对象'转成'字符串'类型要先转成'原始'类型，再转成'字符串'类型
String(null) // null
String(undefiend) // 'undefined'
String(1) // '1'
String(true) // 'true'
String(false) // 'fasle'
```

### 对象类型转原始类型
![[2. 类型是如何相互转换的-4.png]]

```js
var obj = {}
console.log(+obj)
console.log(obj.valueOf()) // {} 还是对象，调用toString
console.log(obj.toString()) // '[Object object]'

var obj = {
	valueOf() {
		return 1
	}
}
console.log(+obj)
console.log(obj.valueOf()) // 1

var obj = {
	valueOf() {
		return {}
	}
	toString() {
		return {}
	}
}
console.log(+obj) // TypeError: Cannot convert object to primitive value
at Object


```

### 逻辑运算
![[2. 类型是如何相互转换的-13.png]]
```js
先转换成boolean
1 && 2 // 2
// true && true - > true -> 2

1 || 2 // 1
// true || true  -> true -> 1

与运算符&&
true 返回后面
false 返回前面


或运算符 ||
true 返回前面
false 返回后面
```
