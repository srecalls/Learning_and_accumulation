## 鼠标事件对象
```js
dom.addEventListener('click', e => {})
// click 
// mouseup
// mousedown
// mousemove
```


这些事件都是与鼠标操作相关的事件，它们在用户与页面上的元素进行交互时触发。下面是它们之间的区别：

1. **click**（点击事件）：click 事件在用户点击（**按下并释放**）鼠标按钮时触发。它表示用户执行了一个完整的点击操作。click 事件通常在 **mousedown（按下鼠标按钮）和 mouseup（释放鼠标按钮）之后**触发。click 事件适合处理用户单击元素的操作，例如链接跳转、按钮点击等。
    
2. **mouseup**（鼠标释放事件）：mouseup 事件在用户释放鼠标按钮时触发。当用户按下鼠标按钮后，移动鼠标并释放按钮时，mouseup 事件会被触发。mouseup 事件通常与 mousedown 事件配对使用，用于捕获用户的点击动作。
    
3. **mousedown**（鼠标按下事件）：mousedown 事件在用户按下鼠标按钮时触发。当用户点击并按住鼠标按钮时，mousedown 事件会被触发。mousedown 事件通常与 mouseup 事件配对使用，用于捕获用户的点击动作。
    
4. **mousemove**（鼠标移动事件）：mousemove 事件在用户移动鼠标时触发。当用户在页面上移动鼠标时，mousemove 事件会连续触发，可以捕获鼠标的位置和移动信息。mousemove 事件通常用于实现与鼠标位置相关的交互效果，例如跟随鼠标移动的元素、拖拽等。


		mousedown -> mouseup -> click

```js
<div class="container">
	<div class="box"></div>
	<div class="box1"></div>
</div>
const box = document.getElementsByClassName('box')[0]
box.addEventListener('mousedown', e => {
  console.log('1')
})
box.addEventListener('mouseup', e => {
  console.log('2')
})
box.addEventListener('click', e => {
  console.log('3')
})
// 1
// 2
// 3
```

## 常见的位置属性
### clientX、clientY、pageX、pageY
`clientX`、`clientY`、`pageX` 和 `pageY` 是 JavaScript 中与鼠标事件相关的属性，用于获取鼠标事件发生时的坐标信息。

**clientX** 和 **clientY**：
- `clientX` 属性表示鼠标事件发生时，鼠标指针相对于**浏览器窗口（视口）左上角**的**水平坐标值**。
- `clientY` 属性表示鼠标事件发生时，鼠标指针相对于**浏览器窗口（视口）左上角**的**垂直坐标值**。
- 这两个属性提供的坐标值是相对于浏览器窗口的坐标，坐标原点位于浏览器窗口的左上角，水平向右增加，垂直向下增加。

**pageX** 和 **pageY**：
- `pageX` 属性表示鼠标事件发生时，鼠标指针相对于**整个页面文档左上角**的**水平坐标值**。
- `pageY` 属性表示鼠标事件发生时，鼠标指针相对于**整个页面文档左上角**的**垂直坐标值**。
- 这两个属性提供的坐标值是相对于整个页面文档的坐标，坐标原点位于整个页面文档的左上角，水平向右增加，垂直向下增加。

下面是一个示例，演示如何使用 `clientX`、`clientY`、`pageX` 和 `pageY` 属性获取鼠标事件的坐标值：

```javascript
document.addEventListener('mousemove', function(event) {
  console.log('clientX:', event.clientX);
  console.log('clientY:', event.clientY);
  console.log('pageX:', event.pageX);
  console.log('pageY:', event.pageY);
});
```

在上述示例中，当鼠标移动时，`mousemove` 事件会被触发，并打印出鼠标事件的 `clientX`、`clientY`、`pageX` 和 `pageY` 值。

需要注意的是，这些属性的表现可能会因浏览器和设备而异。在某些情况下，例如当页面发生滚动时，`clientX` 和 `clientY` 的值可能会发生变化，而 `pageX` 和 `pageY` 的值则相对稳定。

综上所述，`clientX`、`clientY`、`pageX` 和 `pageY` 属性提供了鼠标事件的坐标信息，用于处理与鼠标位置相关的交互行为。

### movementX、movementY
`movementX` 和 `movementY` 是 JavaScript 中与鼠标事件相关的属性，用于获取鼠标移动的相对位移量。

**movementX** 和 **movementY**：
- `movementX` 属性表示鼠标事件发生时，鼠标指针在水平方向上的相对位移量。
- `movementY` 属性表示鼠标事件发生时，鼠标指针在垂直方向上的相对位移量。
- 这两个属性提供的值表示鼠标指针在两次事件之间的相对移动距离。

下面是一个示例，演示如何使用 `movementX` 和 `movementY` 属性获取鼠标事件的相对位移量：

```javascript
let previousX = 0;
let previousY = 0;

document.addEventListener('mousemove', function(event) {
  let deltaX = event.movementX - previousX;
  let deltaY = event.movementY - previousY;
  
  console.log('movementX:', deltaX);
  console.log('movementY:', deltaY);
  
  previousX = event.movementX;
  previousY = event.movementY;
});
```

在上述示例中，当鼠标移动时，`mousemove` 事件会被触发，并计算鼠标事件的相对位移量 `deltaX` 和 `deltaY`。通过记录上一次的 `movementX` 和 `movementY` 值，可以计算出两次事件之间的相对位移量。

需要注意的是，`movementX` 和 `movementY` 属性在不同浏览器和设备上的行为可能会有所差异。有些浏览器可能只在活动窗口内提供相对移动值，而在非活动窗口或隐藏标签页中返回零。

这些属性通常用于实现与鼠标移动相关的交互行为，例如拖拽、平移等。通过获取相对位移量，可以根据鼠标的移动来更新元素的位置或执行其他相应的操作。

综上所述，`movementX` 和 `movementY` 属性提供了鼠标事件的相对位移量信息，用于处理与鼠标移动相关的交互行为。
