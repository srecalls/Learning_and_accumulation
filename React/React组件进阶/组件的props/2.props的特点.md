- 1.可以给组件传递任意类型的数据
- 2. props 是只读的对象，只能读取属性的值，无法修改对象
- 3.注意:使用类组件时，如果写了构造函数，应该将 props 传递给 super()，否则，无法在构造函数中获取到props !

```js
class Hello extends React.Component {
	constructor(props) {
	//.  推荐将props传递给父类构造函数
		super(props)
	}
	render() {
		return (
			<div>接收到的数据: {this.props.age}</div>
		)
	}
}
```
