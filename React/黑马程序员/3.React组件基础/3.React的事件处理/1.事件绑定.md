类创建组件绑定
![[1.事件绑定-1.png]]
```js
class App extends React.Component {
	handleClick() {
		console.log('1111')
	}
	render() {
		return (
			// 这里要加this，因为是类里面的方法
			<button onClick={this.handleClick}>点我，点我</button>
		)
	}
}
```

函数创建组件绑定
![[1.事件绑定-2.png]]

```js
function App() {
	// 事件处理程序
	function handleClick() {
		console.log('111')
	}
	return (
		// 这里就不用this，因为是函数里套一个函数
		<button onClick={handleClick}>点我</button>
	)
}
```
