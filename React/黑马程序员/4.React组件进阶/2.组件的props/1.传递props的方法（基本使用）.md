## 函数组件
```js
function Hello(props) {
	console.log(props)
	return (
		<div>接收到数据:{props.name}</div>
	)
}

//或
conse Hello = props => {
	console.log(props)
	return (
		<div>接收到数据:{props.name}</div>
	)
}

<Hello name="jack" age={19}/>
```

## 类组件
```js
class Hello extends React.Component {
	render() {
		return (
			<div>接收到的数据: {this.props.age}</div>
		)
	}
}
<Hello name="jack" age={19}/>
```
