```js
class App extends React.Component {
	state = {
		this.count = 0
	}
	handleClick() {
		/*this.setState({
			count: this.state.count + 1
		})*/
		// 注意:这种语法也是异步更新state的!
		this.setState((state, prop) => {
			console.log(state.count) // 0
			return {
				count: state.count + 1
			}
		})
		// 这种写法，可以获得最新的state的值
		this.setState((state, prop) => {
			console.log(state.count) // 1
			return {
				count: state.count + 1
			}
		})
		console.log(this.state.count) // 0
	}
	render() {
		return (
			<button onClick={this.handleClick}>
			+1
			</button>
		)
	}
}
ReactDOM.render(<App/>, document.getElementById('root'))
```

#### 函数式
函数形式的 `setState()` 方法可以解决连续调用多次 `setState()` 方法时，每次都使用最新的状态值的问题，原因是函数形式的 `setState()` 方法是基于当前状态值进行更新的，而不是基于当前状态对象进行更新的。

具体来说，函数形式的 `setState()` 方法接收一个函数作为参数，这个函数会接收当前的状态值作为参数，并返回一个新的状态对象。React 会在调用这个函数时立即更新状态，并将最新的状态值传递给下一个 `setState()` 方法。这样就可以确保在连续调用多次 `setState()` 方法时，每次都使用最新的状态值。

#### 非函数式
在 React 中，调用 `setState()` 方法并不会立即更新组件的状态，而是将更新请求添加到一个队列中，等到下一次渲染时才会执行更新。因此，连续调用多次 `setState()` 方法时，每次更新可能都会基于之前的状态值进行计算，而不是基于最新的状态值进行计算。
