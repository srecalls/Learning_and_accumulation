## 纯函数
纯函数是指在相同的输入下，始终产生相同的输出，并且没有任何副作用的函数。

特点和要求：

1. 相同的输入始终产生相同的输出：纯函数对于给定的输入，返回的结果是确定的，不受外部状态的影响。这种可预测性是纯函数的重要特点。

2. 没有副作用：纯函数不会修改传入的参数，也不会对函数外部的状态产生影响，包括修改全局变量、发送网络请求、改变 DOM 状态等。纯函数只依赖于输入参数，计算结果只通过返回值来传递。

纯函数的优势：

1. 可测试性：由于纯函数的输出只依赖于输入，不受外部环境的影响，因此可以更容易地编写和执行单元测试。

2. 可维护性：纯函数具有自包含性，不依赖于外部状态，因此更容易理解和维护。由于没有副作用，纯函数在代码调试和排查问题时也更可靠。

3. 并行和缓存优化：由于纯函数没有副作用，相同的输入始终产生相同的输出，可以更方便地进行并行计算和结果缓存。

注意事项：

1. 纯函数不适合执行具有副作用的操作，如 I/O 操作、网络请求、DOM 操作等。这些操作应该放在纯函数之外进行。

2. 纯函数可能会对性能产生一定影响，特别是在处理大规模数据时。因为纯函数要求每次都重新计算结果，可能会导致重复计算。在性能敏感的场景中，可以考虑使用记忆化等技术来优化纯函数。

总结来说，纯函数是一种具有确定性和无副作用的函数，它们在函数式编程中起到重要的作用，带来可测试性、可维护性和并行性等优势。

下面是一个不是纯函数的例子：

```javascript
let counter = 0;

function impureFunction(value) {
  counter++;
  return value + counter;
}
```

在这个例子中，`impureFunction` 函数具有副作用，它修改了外部状态 `counter` 的值。每次调用 `impureFunction` 时，都会增加 `counter` 的值，并将其与传入的 `value` 相加返回。由于函数的返回值依赖于外部状态的变化，它在相同的输入下不会始终产生相同的输出。

因此，`impureFunction` 不是纯函数，因为它具有副作用，即修改了外部状态。纯函数要求函数的结果只依赖于输入参数，并且没有副作用，而 `impureFunction` 违反了这些要求。
