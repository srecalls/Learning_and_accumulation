`本节任务:` 能够学会useEffect的基础用法并且掌握默认的执行执行时机

**作用**

为react函数组件提供副作用处理

**使用步骤**

1. 导入 `useEffect` 函数
2. 调用 `useEffect` 函数，并传入回调函数
3. 在回调函数中编写副作用处理（dom操作）
4. 修改数据状态
5. 检测副作用是否生效

**代码实现**
```jsx
import { useEffect, useState } from 'react'

function App() {
  const [count, setCount] = useState(0)
 
  useEffect(()=>{
    // dom操作
    document.title = `当前已点击了${count}次`
  })
  return (
    <button onClick={() => { setCount(count + 1) }}>{count}</button>
  )
}

export default App
```


## 例子

当涉及到副作用时，我们可以使用 React 的 `useEffect` 钩子来处理。`useEffect` 允许我们在**组件渲染**之后执行副作用操作，或者在组件卸载之前执行清理操作。下面是一些使用 `useEffect` 处理常见副作用的示例：

### 1. 数据请求（Ajax 发送）:

```jsx
import React, { useState, useEffect } from 'react';

function App() {
  const [data, setData] = useState(null);

  useEffect(() => {
    // 在组件渲染后执行副作用操作（数据请求）
    fetchData();
  }, []);

  const fetchData = () => {
    // 发送数据请求
    fetch('https://api.example.com/data')
      .then(response => response.json())
      .then(data => setData(data))
      .catch(error => console.log(error));
  };

  return (
    <div>
      {data ? (
        <ul>
          {data.map(item => (
            <li key={item.id}>{item.name}</li>
          ))}
        </ul>
      ) : (
        <p>Loading...</p>
      )}
    </div>
  );
}

export default App;
```

在上述示例中，我们使用 `useEffect` 来在组件渲染后执行数据请求的副作用操作。通过传递一个空数组作为第二个参数，我们确保副作用只会在组件初始渲染时执行一次。

### 2. 手动修改 DOM:

```jsx
import React, { useEffect } from 'react';

function App() {
  useEffect(() => {
    // 在组件渲染后执行副作用操作（手动修改 DOM）
    const element = document.getElementById('myElement');
    element.style.color = 'red';
  }, []);

  return <div id="myElement">Hello React!</div>;
}

export default App;
```

在上述示例中，我们使用 `useEffect` 来在组件渲染后执行手动修改 DOM 的副作用操作。通过传递一个空数组作为第二个参数，我们确保副作用只会在组件初始渲染时执行一次。

### 3. LocalStorage 操作:

```jsx
import React, { useState, useEffect } from 'react';

function App() {
  const [name, setName] = useState('');

  useEffect(() => {
    // 在组件渲染后执行副作用操作（LocalStorage 操作）
    const storedName = localStorage.getItem('name');
    if (storedName) {
      setName(storedName);
    }
  }, []);

  const handleInputChange = event => {
    setName(event.target.value);
  };

  useEffect(() => {
    // 在 name 变化时执行副作用操作（更新 LocalStorage）
    localStorage.setItem('name', name);
  }, [name]);

  return (
    <div>
      <input type="text" value={name} onChange={handleInputChange} />
      <p>Hello, {name}!</p>
    </div>
  );
}

export default App;
```

在上述示例中，我们使用 `useEffect` 来在组件渲染后执行 LocalStorage 操作的副作用操作（读取和更新）。通过传递一个空数组作为第二个参数，我们确保读取操作只会在组件初始渲染时执行一次，并且通过传递一个依赖数组 `[name]`，我们确保更新操作只会在 `name` 发生变化时执行。

这些示例展示了如何使用 `useEffect` 处理不同类型的副作用。`useEffect` 的灵活性使得我们能够在 React 组件中管理和处理副作用，从而保持代码的可靠性和可维护性。
