## **需求描述**：自定义一个hook函数，实现获取滚动距离Y

`const [y] = useWindowScroll()`

```js
import { useState, useEffect } from "react"

export function useWindowScroll () {
  const [y, setY] = useState(0)
  useEffect(()=>{
     const scrollHandler = () => {
        const h = document.documentElement.scrollTop
        setY(h)
     })
     window.addEventListener('scroll', scrollHandler)
     return () => window.removeEventListener('scroll', scrollHandler)
  })
 
  return [y]
}
```


你可以按照以下步骤使用自定义的 `useWindowScroll` 钩子函数：

1. 将自定义的 `useWindowScroll` 函数导入到你的组件中。

```jsx
import { useWindowScroll } from './useWindowScroll';
```

2. 在组件中使用 `useWindowScroll` 函数来获取滚动距离 `y`。

```jsx
function MyComponent() {
  const [y] = useWindowScroll();

  // 在这里可以使用滚动距离 `y` 进行进一步处理

  return (
    <div>
      <p>滚动距离：{y}px</p>
    </div>
  );
}
```

在上述示例中，我们使用 `useWindowScroll` 钩子函数来获取滚动距离 `y`。通过解构赋值 `[y]`，我们可以将滚动距离赋值给变量 `y`。你可以根据需要在组件中使用 `y` 进行进一步的处理和渲染。

请确保将自定义的 `useWindowScroll` 钩子函数与你的组件文件放在同一个目录下，并正确导入它。这样，你就可以在组件中使用 `useWindowScroll` 钩子函数来获取滚动距离 `y` 了。



## **需求描述：** 自定义hook函数，可以自动同步到本地LocalStorage

`const [message, setMessage] = useLocalStorage(key，defaultValue)`

1. message可以通过自定义传入默认初始值
2. 每次修改message数据的时候 都会自动往本地同步一份

```js
import { useEffect, useState } from 'react'

export function useLocalStorage (key, defaultValue) {
  const [message, setMessage] = useState(defaultValue)
  // 每次只要message变化 就会自动同步到本地ls
  useEffect(() => {
    window.localStorage.setItem(key, message)
  }, [message, key])
  return [message, setMessage]
}
```

你可以按照以下步骤使用自定义的 `useLocalStorage` 钩子函数：

1. 将自定义的 `useLocalStorage` 函数导入到你的组件中。

```jsx
import { useLocalStorage } from './useLocalStorage';
```

2. 在组件中使用 `useLocalStorage` 函数来获取本地存储的数据。

```jsx
function MyComponent() {
  const key = 'myMessage';
  const defaultValue = 'Hello, World!';
  const [message, setMessage] = useLocalStorage(key, defaultValue);

  // 在这里可以使用 message 进行进一步处理

  const handleMessageChange = (event) => {
    setMessage(event.target.value);
  };

  return (
    <div>
      <input type="text" value={message} onChange={handleMessageChange} />
      <p>本地存储的消息：{message}</p>
    </div>
  );
}
```

在上述示例中，我们使用 `useLocalStorage` 钩子函数来获取本地存储的数据，并将其存储在 `message` 变量中。通过解构赋值 `[message, setMessage]`，我们可以使用 `message` 来访问和展示本地存储的消息，并使用 `setMessage` 来更新消息的值。

每当 `message` 发生变化时，`useEffect` 钩子函数会自动将新的消息值同步到本地存储中。这确保了每次修改消息数据时都会自动更新本地存储。

请确保将自定义的 `useLocalStorage` 钩子函数与你的组件文件放在同一个目录下，并正确导入它。这样，你就可以在组件中使用 `useLocalStorage` 钩子函数来获取本地存储的数据并自动同步到本地存储中了。
