`本节任务:` 能够学会useState的基础用法

**作用**

useState为函数组件提供状态（state）

**使用步骤**

1. 导入 `useState` 函数
2. 调用 `useState` 函数，并传入状态的初始值
3. 从`useState`函数的返回值中，拿到状态和修改状态的方法
4. 在JSX中展示状态
5. 调用修改状态的方法更新状态


```js
import { useState } from 'react'

function App() {
  // 参数：状态初始值比如,传入 0 表示该状态的初始值为 0
  // 返回值：数组,包含两个值：1 状态值（state） 2 修改该状态的函数（setState）
  const [count, setCount] = useState(0)
  return (
    <button onClick={() => { setCount(count + 1) }}>{count}</button>
  )
}
export default App
```


在上述示例中，我们使用了 `useState` 钩子函数来在函数组件中定义和使用状态。下面是如何使用的详细步骤：

1. 将 `useState` 从 React 中导入到你的组件中。

```jsx
import React, { useState } from 'react';
```

2. 在组件中使用 `useState` 定义状态变量和对应的更新函数。

```jsx
function App() {
  // 使用 useState 定义状态变量 count 和对应的更新函数 setCount
  const [count, setCount] = useState(0);

  // 在点击按钮时调用 setCount 更新 count 的值
  const handleClick = () => {
    setCount(count + 1);
  };

  return (
    <button onClick={handleClick}>{count}</button>
  );
}
```

在上述示例中，我们使用 `useState` 定义了一个名为 `count` 的状态变量和对应的更新函数 `setCount`。初始值为 `0`，因此 `count` 的初始状态为 `0`。

在点击按钮时，我们调用 `setCount` 函数来更新 `count` 的值。这会触发组件重新渲染，并在按钮上显示新的 `count` 值。

通过这种方式，我们可以在函数组件中使用 `useState` 钩子函数来管理和更新状态。这使得我们能够在函数组件中使用类似于类组件中的状态管理功能。
