> Hooks的本质：**一套能够使函数组件更强大，更灵活的“钩子”**

React体系里组件分为 **类组件** 和 **函数组件**

经过多年的实战，**函数组件**是一个更加匹配React的设计理念 `UI = f(data)`，也更有利于逻辑拆分与重用的组件表达形式，而先前的函数组件是不可以有自己的状态的，**为了能让函数组件可以拥有自己的状态，所以从react v16.8开始，Hooks应运而生**

  

**注意点：**

1. 有了hooks之后，为了兼容老版本，**class类组件并没有被移除，俩者都可以使用**
2. 有了hooks之后，**不能在把函数称为无状态组件了，因为hooks为函数组件提供了状态**
3. hooks**只能在函数组件**中使用
