**React有什么特点**

### 1- 声明式UI（JSX）

写UI就和写普通的HTML一样，抛弃命令式的繁琐实现

![[React介绍.png]]
### 2- 组件化  

组件是react中最重要的内容，组件可以通过搭积木的方式拼成一个完整的页面，通过组件的抽象可以增加复用能力和提高可维护性
![[React介绍-1.png]]

### 3- 跨平台  

react既可以开发web应用也可以使用同样的语法开发原生应用（react-native），比如安卓和ios应用，甚至可以使用react开发VR应用，想象力空间十足，react更像是一个 `元框架`  为各种领域赋能
