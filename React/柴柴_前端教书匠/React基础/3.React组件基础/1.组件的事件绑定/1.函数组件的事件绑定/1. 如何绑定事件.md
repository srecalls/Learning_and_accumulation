- 语法  
    on + 事件名称 = { 事件处理程序 } ，比如：`<div onClick={ onClick }></div>`

- 注意点  
    react事件采用驼峰命名法，比如：onMouseEnter、onFocus

- 样例
```jsx
// 函数组件
function HelloFn () {
  // 定义事件回调函数
  const clickHandler = () => {
    console.log('事件被触发了')
  }
  return (
    // 绑定事件
    <button onClick={clickHandler}>click me!</button>
  )
}
```
