`目标任务:`   能够在JSX中使用表达式

**语法**

`{ JS 表达式 }`

```jsx
const name = '柴柴'

<h1>你好，我叫{name}</h1>   //    <h1>你好,我叫柴柴</h1>
```


**可以使用的表达式**


	1. 字符串、数值、布尔值、null、undefined、object（ [] / {} ）
	2. 1 + 2、'abc'.split('')、['a', 'b'].join('-')
	3. fn()

  

**特别注意**

if 语句/ switch-case 语句/ 变量声明语句，这些叫做语句，不是表达式，不能出现在 `{}` 中！！
