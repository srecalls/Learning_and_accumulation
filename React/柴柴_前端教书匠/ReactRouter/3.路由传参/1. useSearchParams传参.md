**路由传参**
![[1.searchParams传参.png]]

```jsx
navigate('/about?id=1001')
```

**路由取参**
![[1.searchParams传参-1.png]]

```jsx
let [params] = useSearchParams()
let id = params.get('id')
```


在你的例子中，使用 `searchParams` 进行路由传参和取参。以下是一个示例：

```jsx
import { useSearchParams } from 'react-router-dom';

// 路由传参
const handleNavigate = () => {
  navigate('about?id=1001');
};

// 路由取参
const MyComponent = () => {
  let [params] = useSearchParams();
  let id = params.get('id');

  return (
    <div>
      <p>ID: {id}</p>
    </div>
  );
};
```

在上述示例中，首先我们使用 `navigate` 函数进行路由导航，并传递了参数 `'about?id=1001'`。这将导航到带有查询参数的 `'about'` 路由。

然后，在另一个组件中，我们使用 `useSearchParams` 钩子函数来获取路由查询参数。通过解构赋值 `[params]`，我们可以获取到包含查询参数信息的对象。接着，我们使用 `params.get('id')` 来获取具体的查询参数值。

在组件中，我们将获取到的 `id` 值展示在页面上。
