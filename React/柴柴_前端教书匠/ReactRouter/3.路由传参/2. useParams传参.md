
**路由取参**
![[2. params传参-1.png]]

```jsx
let params = useParams()
let id = params.id
```


在你的例子中，使用路由参数 (`params`) 进行传参和取参。以下是一个示例：

```jsx
import { useParams } from 'react-router-dom';

// 路由传参
const handleNavigate = () => {
  navigate('/about/1001');
};

// 路由取参
const MyComponent = () => {
  let params = useParams();
  let id = params.id;

  return (
    <div>
      <p>ID: {id}</p>
    </div>
  );
};
```

在上述示例中，我们使用 `navigate` 函数进行路由导航，并传递了参数 `'/about/1001'`。这将导航到带有路由参数的 `'/about'` 路由，其中参数的值为 `1001`。

然后，在另一个组件中，我们使用 `useParams` 钩子函数来获取路由参数。通过调用 `useParams`，我们可以获取一个包含路由参数的对象 `params`。然后，我们可以通过 `params.id` 来获取具体的路由参数值。

在组件中，我们展示了获取到的 `id` 值。
