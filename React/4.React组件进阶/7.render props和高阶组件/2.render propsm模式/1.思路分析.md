- 思路: 将要复用的state和操作state的方法封装到一个组件中
- 问题1: 如何拿到该组件中复用的state ?
- 在使用组件时，添加一个值为**函数的prop**，通过函数**参数** 来获取( 需要组件内部实现 )
- 问题2: 如何渲染任意的UI ?
- 使用**该函数的返回值**作为要渲染的UI内容 (需要组件内部实现 )

```Js
<Mouse render={(mouse) => ()}/>
```

```js
<Mouse render={(mouse) => {
	<p>鼠标当前位置 {mouse.x}, {mouse.y}</p>
}}/>
```
