- 类组件: 使用 ES6 的 class 创建的组件
- 约定1: 类名称也必须以**大写字母开头**
- 约定2: 类组件应该继承 **React.Component** 父类，从而可以使用父类中提供的方法或属性
- 约定3: 类组件必须提供**render()** 方法
- 约定4: **render()** 方法必须有返回值，表示该组件的结构

```js
class Hello extends React.Component {
	render() {
		return null
	}
}
```
