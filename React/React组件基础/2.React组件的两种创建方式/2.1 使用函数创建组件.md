- 函数组件: 使用JS 的函数(或箭头函数)创建的组件
- 约定1: 函数名称必须以**大写字母开头**
- 约定2: 函数组件**必须有返回值**，表示该组件的结构
- 如果返回值为 null，表示不渲染任何内容
