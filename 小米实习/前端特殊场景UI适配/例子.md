要在本地开发环境下通过链接添加查询参数来模拟深色模式，可以使用 JavaScript 来实现。以下是一个示例：

HTML：

```html
<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="styles.css">
  <script src="script.js"></script>
</head>
<body>
  <h1>Hello, World!</h1>
</body>
</html>
```

CSS（styles.css）：

```css
body {
  background-color: #fff;
  color: #000;
}

.dark-mode body {
  background-color: #000;
  color: #fff;
}
```

JavaScript（script.js）：

```javascript
// 检查是否有名为 "a_darkMode" 的查询参数，并且其值为 "true"
const urlParams = new URLSearchParams(window.location.search);
const darkModeEnabled = urlParams.get('a_darkMode') === 'true';

// 根据查询参数的值添加或移除 "dark-mode" 类
if (darkModeEnabled) {
  document.body.classList.add('dark-mode');
} else {
  document.body.classList.remove('dark-mode');
}
```

在以上示例中，如果链接中添加了查询参数 `a_darkMode=true`，则会将 `dark-mode` 类添加到 `<body>` 元素上，从而应用深色模式的样式。如果查询参数不存在或值不为 "true"，则会移除 `dark-mode` 类，恢复到默认的浅色模式。

通过在开发环境中使用这个例子，你可以在链接中添加 `?a_darkMode=true` 查询参数来模拟深色模式，或者省略查询参数以使用默认的浅色模式。
