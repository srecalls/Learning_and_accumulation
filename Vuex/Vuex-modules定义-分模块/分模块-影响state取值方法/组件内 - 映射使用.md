方式2: 组件内 - **映射**使用

原语法:

```js
...mapState(['state里变量名'])
...mapState({'变量名': "state里变量名"}) // 给映射过来的state起别的名字
```

分模块后语法:

```js
...mapState({
    '变量名': state => state.模块名.变量名
})
```
