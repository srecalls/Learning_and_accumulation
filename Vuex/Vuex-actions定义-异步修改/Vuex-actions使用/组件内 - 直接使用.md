方式1: 组件内 - **直接**使用

语法:

// 直接使用
// 语法:this.$store.state.变量名 (作用: 取值)
```js
this.$store.dispatch('actions函数名', 具体值)
```

###   
AddItem直接用

-   点击事件
-   dispatch触发action

```js
<button @click="asyncAddFn">延迟1秒, 库存+5</button>
<script>
export default {
  methods: {
    asyncAddFn(){
    // this.$store.commit('addCount',1) // commit -> mutations
      this.$store.dispatch('asyncAddCount', 5) // dispatch -> actions
    }
  }
}
</script>
```
