方式2: 组件内 - **映射**使用

语法:

```js
// 1. 拿到mapGetters辅助函数
import { mapGetters } from 'vuex'
export default {
	computed: {
        // 2. 把getters里属性映射到原地
      ...mapGetters(['getters里的计算属性名'])
    }   
}
```

###   MyFooter.vue里使用

-   使用2种方式给计算属性值

```js
<script>
import { mapGetters } from 'vuex'
export default {
  computed: {
    // 直接
    allCount(){
     return this.$store.getters.allCount;
    },
    //映射
    ...mapGetters(['allPrice'])
  }
}
</script>
```
