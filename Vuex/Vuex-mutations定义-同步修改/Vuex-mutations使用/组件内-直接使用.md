方式1: 组件内 - **直接**使用

语法:

```js
this.$store.commit("mutations里的函数名", 具体值)
```

###   AddItem直接用

-   点击事件绑定
-   提交mutations传入值

```js
<button @click="addFn">库存+1</button>
<script>
export default {
  methods: {
    addFn(){
      this.$store.commit('addCount', 1)
    }
  }
}
</script>
```

### App.vue直接用 v-model

-   触发计算属性的set方法
-   提交mutations传入值


这里输入input框返回的是string,记得改成num
```js
<span>库存总数: </span>
<input type="text" v-model.number="count">

<script>
export default {
  computed: {
    count: {
      set(val){
        this.$store.commit('setCount', val) // 把表单值提交给store下的mutations
      },
      get(){
        return this.$store.state.count
      }
    }
  }
}
</script>
```
