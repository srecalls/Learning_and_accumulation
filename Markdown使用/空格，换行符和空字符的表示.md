在 Markdown 中，可以使用以下方式表示空格、换行符和空字符：

1. **空格**：可以使用 HTML 中的 `&nbsp;` 实体或者使用 Markdown 语法中的多个空格来表示。例如，输入 `hello&nbsp;world` 或者 `hello     world` 都可以在输出时显示一个空格。

2. **换行符**：可以使用 Markdown 语法中的两个空格加回车来表示。例如，输入 `第一行（空格）（空格）（回车）第二行`，输出时会将两行文本分别显示在两行。

3. **空字符**：在 Markdown 中，不能直接输入空字符。如果要在文本中插入空字符，可以使用 HTML 中的 `&#8203;` 实体来表示。例如，输入 `hello&#8203;world`，输出时会在 `hello` 和 `world` 之间插入一个空字符。

需要注意的是，不同的 Markdown 解析器可能对空格、换行符和空字符的解析方式略有不同，因此在实际使用时需要根据具体的情况进行调整。
